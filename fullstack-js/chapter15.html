Chương 15 — GraphQL Server với Apollo

Xây dựng GraphQL API bằng Node.js — Apollo Server là thư viện phổ biến nhất cho việc này.

terminal 
npm install @apollo/server graphql

Định nghĩa Schema — "hợp đồng" mô tả dữ liệu API

schema.js 
const typeDefs = `#graphql
  type SanPham {
    id: ID!
    ten: String!
    gia: Float!
  }

  type Query {                                    # tất cả truy vấn ĐỌC được phép
    tatCaSanPham: [SanPham!]!
    sanPham(id: ID!): SanPham
  }

  type Mutation {                                   # tất cả thao tác GHI được phép
    taoSanPham(ten: String!, gia: Float!): SanPham!
  }
`;

Resolver — hàm THỰC SỰ lấy/thay đổi dữ liệu

resolvers.js 
const resolvers = {
    Query: {
        tatCaSanPham: async () => {
            return await SanPham.findAll();          // dùng lại Sequelize/Prisma đã học ở chương 16-17
        },
        sanPham: async (_, { id }) => {
            return await SanPham.findByPk(id);
        },
    },
    Mutation: {
        taoSanPham: async (_, { ten, gia }) => {
            return await SanPham.create({ ten, gia });
        },
    },
};
server.js 
const { ApolloServer } = require('@apollo/server');
const { startStandaloneServer } = require('@apollo/server/standalone');

const server = new ApolloServer({ typeDefs, resolvers });
const { url } = await startStandaloneServer(server, { listen: { port: 4000 } });
console.log(`GraphQL server sẵn sàng tại ${url}`);
Mẹo
Resolver GraphQL hoạt động rất giống route handler Express đã học — chỉ khác cách tổ chức: một schema mô tả TOÀN BỘ khả năng của API, resolver là nơi hiện thực logic thực tế cho từng field.

📌 Tổng kết chương 19

Apollo Server cần typeDefs (schema mô tả kiểu dữ liệu/query/mutation) và resolvers (hàm thực thi logic) — có thể tái sử dụng ORM đã học để resolver lấy dữ liệu từ database.
