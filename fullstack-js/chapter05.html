05 Bootstrap — Grid System

Framework CSS phổ biến nhất thế giới — xây giao diện responsive nhanh chóng nhờ hệ lưới 12 cột có sẵn.

index.html 
<!-- Nhúng Bootstrap qua CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

Hệ lưới 12 cột (Grid System)

grid_system.html 
<div class="container">
    <div class="row">
        <div class="col-4">Chiếm 4/12 cột</div>
        <div class="col-8">Chiếm 8/12 cột</div>
    </div>

    <!-- Responsive: khác nhau theo kích thước màn hình -->
    <div class="row">
        <div class="col-12 col-md-6 col-lg-4">
            Mobile: full width | Tablet: 1/2 | Desktop: 1/3
        </div>
    </div>
</div>
BreakpointTiền tố classKích thước màn hình
Extra smallcol- (không tiền tố)< 576px
Smallcol-sm-≥ 576px
Mediumcol-md-≥ 768px
Largecol-lg-≥ 992px
Extra largecol-xl-≥ 1200px
Ghi chú
Bootstrap Grid dựa trên Flexbox (đã học ở giáo trình HTML/CSS chương 12) — .container giới hạn chiều rộng tối đa, .row là flex container, .col-* là các flex item chia theo 12 phần.

📌 Tổng kết chương 5

Bootstrap Grid dùng hệ 12 cột với các class col-*, kết hợp tiền tố breakpoint (sm/md/lg/xl) để tạo layout responsive nhanh chóng mà không cần tự viết CSS Grid/Flexbox từ đầu.
