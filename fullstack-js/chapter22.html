Chương 22 — Dự án cuối khóa Full-Stack

Tổng hợp toàn bộ lộ trình thành một dự án thực tế hoàn chỉnh — từ giao diện tới triển khai production.

Kiến trúc dự án: Nền tảng Quản lý Công việc (Task Manager)

┌─────────────────────────────────────────────────────────┐
│  FRONTEND (React + TypeScript + React Router + Redux)       │
│  - Đăng nhập/đăng ký, Danh sách công việc, Chi tiết          │
└───────────────────────┬───────────────────────────────────┘
                         │ REST API / GraphQL
┌───────────────────────▼───────────────────────────────────┐
│  BACKEND (NestJS)                                              │
│  - AuthModule, TaskModule, UserModule                            │
│  - Socket.IO: thông báo real-time khi có công việc mới              │
└───────────────────────┬───────────────────────────────────┘
                         │ Prisma ORM
┌───────────────────────▼───────────────────────────────────┐
│  DATABASE (MySQL)                                                 │
└─────────────────────────────────────────────────────────────┘
                         │
              Đóng gói bằng Docker Compose
                         │
              Triển khai lên VPS DigitalOcean + Nginx

Checklist tính năng tổng hợp toàn bộ kiến thức

  • ✅ Git/GitHub (ch.1-2): Quản lý code qua nhánh feature, Pull Request
  • ✅ TypeScript (ch.3-4): Toàn bộ frontend/backend dùng type an toàn
  • ✅ Bootstrap/SASS (ch.5-8): Giao diện responsive, style có tổ chức
  • ✅ React (JSX, Hooks, Router, Context, Redux) — theo track React.js Từ Zero Đến Hero: Điều hướng, quản lý state đăng nhập và danh sách công việc
  • ✅ MySQL/Prisma (ch.9-13): Lưu trữ user, công việc với quan hệ 1-nhiều
  • ✅ Socket.IO (ch.16): Thông báo real-time khi đồng nghiệp giao việc mới
  • ✅ NestJS (ch.17-18): Backend có cấu trúc, DTO xác thực dữ liệu
  • ✅ Docker/VPS (ch.19-21): Đóng gói và triển khai lên server thật
Quan trọng — Lời khuyên khi làm dự án cuối khóa
Đừng cố nhồi TẤT CẢ công nghệ đã học vào một dự án nhỏ chỉ để "khoe" — hãy chọn công nghệ PHÙ HỢP với bài toán. Một dự án Task Manager không nhất thiết cần GraphQL nếu REST đã đủ đơn giản và hiệu quả; điều nhà tuyển dụng đánh giá cao là biết KHI NÀO dùng công cụ nào, không phải dùng được bao nhiêu công cụ.

📝 Quiz tổng kết cuối khóa Full-Stack JavaScript

1. Theo lời khuyên của chương này, tiêu chí quan trọng nhất khi chọn công nghệ cho dự án là gì?

Dùng càng nhiều công nghệ mới càng tốt để gây ấn tượng Chọn công nghệ phù hợp với bài toán thực tế, biết khi nào nên và không nên dùng Luôn chọn công nghệ nhanh nhất bất kể độ phức tạp
