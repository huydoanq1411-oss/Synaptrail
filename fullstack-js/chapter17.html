17 NestJS — Kiến trúc Module/Controller/Service

Framework Node.js theo kiến trúc có cấu trúc rõ ràng, lấy cảm hứng từ Angular — phổ biến cho backend quy mô doanh nghiệp.

terminal 
npm install -g @nestjs/cli
nest new ten-du-an
nest generate module san-pham        # tự tạo module + controller + service theo cấu trúc chuẩn
nest generate controller san-pham
nest generate service san-pham

3 khối xây dựng chính của NestJS

san-pham.controller.ts 
import { Controller, Get, Post, Body, Param } from '@nestjs/common';
import { SanPhamService } from './san-pham.service';

@Controller('san-pham')                     // tiền tố route, tương đương app.use('/san-pham', router) ở Express
export class SanPhamController {
    constructor(private readonly sanPhamService: SanPhamService) {}   // Dependency Injection - chương 22

    @Get()
    layTatCa() {
        return this.sanPhamService.layTatCa();
    }

    @Post()
    taoMoi(@Body() du_lieu: { ten: string; gia: number }) {
        return this.sanPhamService.taoMoi(du_lieu);
    }
}
san-pham.service.ts 
import { Injectable } from '@nestjs/common';

@Injectable()                                  // đánh dấu class này có thể được "tiêm" (inject) vào nơi khác
export class SanPhamService {
    private danhSach = [];                         // trong thực tế sẽ gọi Prisma/Sequelize (chương 16-17)

    layTatCa() {
        return this.danhSach;
    }

    taoMoi(du_lieu) {
        const spMoi = { id: Date.now(), ...du_lieu };
        this.danhSach.push(spMoi);
        return spMoi;
    }
}
Thành phầnVai tròTương đương ở Express
ControllerNhận request, trả responseRoute handler
ServiceChứa logic nghiệp vụ thực tếKhông có sẵn, tự tổ chức thủ công
ModuleGom nhóm Controller + Service liên quanKhông có khái niệm tương đương
Quan trọng
NestJS bắt buộc cấu trúc rõ ràng (Module/Controller/Service) ngay từ đầu — khác với Express linh hoạt nhưng dễ trở nên hỗn loạn khi dự án lớn dần. Đánh đổi: NestJS có độ dốc học tập cao hơn nhưng dễ bảo trì hơn nhiều ở quy mô lớn, nhiều người cùng phát triển.

📌 Tổng kết chương 21

NestJS tổ chức code thành Module (nhóm chức năng), Controller (nhận request), Service (logic nghiệp vụ) — cấu trúc chặt chẽ hơn Express, phù hợp dự án lớn nhiều người phát triển.
