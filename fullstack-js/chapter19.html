Chương 19 — Docker — Đóng gói ứng dụng

Giải quyết vĩnh viễn câu nói kinh điển "chạy được trên máy tôi mà" — đóng gói ứng dụng cùng toàn bộ môi trường cần thiết.

Container khác Máy ảo (Virtual Machine) thế nào?

Máy ảo mô phỏng TOÀN BỘ hệ điều hành (nặng, khởi động chậm). Container chia sẻ kernel của hệ điều hành host, chỉ đóng gói ứng dụng + thư viện cần thiết — nhẹ hơn nhiều, khởi động gần như tức thì.

Dockerfile 
FROM node:20-alpine              # image nền - Node.js bản nhẹ (alpine)

WORKDIR /app                       # thư mục làm việc BÊN TRONG container

COPY package*.json ./                # copy trước để tận dụng cache - nếu package.json không đổi, không cần cài lại
RUN npm install

COPY . .                                # copy toàn bộ code còn lại

EXPOSE 3000                              # khai báo cổng ứng dụng lắng nghe
CMD ["node", "server.js"]                  # lệnh chạy khi container khởi động
terminal 
docker build -t ten-du-an .              # build image từ Dockerfile
docker run -p 3000:3000 ten-du-an           # chạy container, ánh xạ cổng máy thật:cổng container
docker ps                                     # xem các container đang chạy
docker stop <container_id>                     # dừng container
Quan trọng
Thứ tự các lệnh trong Dockerfile ảnh hưởng tới tốc độ build — Docker cache từng bước; copy package.json và npm install TRƯỚC khi copy toàn bộ code giúp lần build sau không phải cài lại dependency nếu chỉ code thay đổi (không phải package.json).

📌 Tổng kết chương 23

Docker đóng gói ứng dụng + môi trường vào "image", chạy thành "container" nhẹ và nhất quán trên mọi máy. Dockerfile mô tả từng bước xây dựng image, cần sắp xếp đúng thứ tự để tận dụng cache hiệu quả.
