Chương 20 — Docker Compose — Multi-container

Ứng dụng thực tế cần nhiều container phối hợp (app + database + cache) — Docker Compose quản lý tất cả bằng một file cấu hình.

docker-compose.yml 
version: '3.8'

services:
  app:
    build: .                          # build từ Dockerfile trong thư mục hiện tại
    ports:
      - "3000:3000"
    environment:
      - DB_HOST=db                       # "db" - tên service khác, Docker tự phân giải thành địa chỉ nội bộ
    depends_on:
      - db                                 # đảm bảo "db" khởi động TRƯỚC "app"

  db:
    image: mysql:8.0                  # dùng image có sẵn từ Docker Hub, không cần tự build
    environment:
      - MYSQL_ROOT_PASSWORD=matkhau
      - MYSQL_DATABASE=cua_hang
    volumes:
      - db_data:/var/lib/mysql            # LƯU dữ liệu database ra ngoài container, không mất khi container bị xóa
    ports:
      - "3306:3306"

volumes:
  db_data:
terminal 
docker compose up -d           # khởi động TẤT CẢ service, chạy ngầm (-d = detached)
docker compose down              # dừng và xóa tất cả container (dữ liệu volume vẫn giữ nguyên)
docker compose logs -f app          # xem log của riêng service "app", theo dõi real-time
Quan trọng — Volumes
Dữ liệu bên trong container sẽ MẤT HOÀN TOÀN khi container bị xóa — luôn dùng volumes cho database để dữ liệu được lưu ra ngoài, tồn tại độc lập với vòng đời của container.

Docker Compose định nghĩa nhiều service (app, database...) trong một file YAML, quản lý bằng vài lệnh đơn giản. Luôn dùng volumes cho dữ liệu cần giữ lại lâu dài như database.
