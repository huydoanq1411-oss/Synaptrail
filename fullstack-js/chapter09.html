Chương 9 — MySQL — Truy vấn cơ bản

Hệ quản trị cơ sở dữ liệu quan hệ phổ biến nhất — nền tảng lưu trữ dữ liệu có cấu trúc cho hầu hết ứng dụng web.

tao_bang.sql 
CREATE DATABASE cua_hang;
USE cua_hang;

CREATE TABLE san_pham (
    id INT AUTO_INCREMENT PRIMARY KEY,       -- tự động tăng, khóa chính
    ten VARCHAR(200) NOT NULL,
    gia DECIMAL(10, 2) NOT NULL,
    so_luong INT DEFAULT 0,
    ngay_tao TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

4 lệnh CRUD cơ bản

crud.sql 
-- CREATE - thêm dữ liệu
INSERT INTO san_pham (ten, gia, so_luong) VALUES ('Áo thun', 150000, 50);

-- READ - đọc dữ liệu
SELECT * FROM san_pham;
SELECT ten, gia FROM san_pham WHERE gia > 100000 ORDER BY gia DESC LIMIT 10;

-- UPDATE - cập nhật dữ liệu
UPDATE san_pham SET gia = 180000 WHERE id = 1;

-- DELETE - xóa dữ liệu
DELETE FROM san_pham WHERE id = 1;
Mệnh đềCông dụng
WHERELọc dòng theo điều kiện
ORDER BYSắp xếp kết quả (ASC tăng dần, DESC giảm dần)
LIMITGiới hạn số dòng trả về
GROUP BYNhóm dòng để tính tổng hợp (COUNT, SUM, AVG...)
Quan trọng
UPDATE/DELETE KHÔNG có mệnh đề WHERE sẽ áp dụng cho TOÀN BỘ bảng — đây là lỗi thao tác database nguy hiểm nhất, luôn kiểm tra kỹ WHERE trước khi chạy, đặc biệt trên database thật.

📌 Tổng kết chương 13

MySQL dùng SQL với 4 lệnh CRUD cơ bản (INSERT/SELECT/UPDATE/DELETE). Luôn cẩn trọng với UPDATE/DELETE thiếu WHERE — có thể ảnh hưởng toàn bộ dữ liệu.
