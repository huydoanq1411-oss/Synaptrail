Chương 2 — GitHub & Quy trình làm việc nhóm

GitHub lưu trữ repository trên đám mây và là nền tảng cộng tác phổ biến nhất — Pull Request là trái tim của làm việc nhóm chuyên nghiệp.

terminal 
git clone https://github.com/user/repo.git      # tải toàn bộ repository về máy
git remote add origin https://github.com/user/repo.git   # gắn địa chỉ GitHub cho repo local
git push -u origin main                                     # đẩy code lên GitHub lần đầu
git push                                                       # đẩy code những lần sau
git pull                                                         # kéo code mới nhất từ GitHub về

Quy trình Feature Branch Workflow (chuẩn làm việc nhóm)

  1. Tạo nhánh riêng cho mỗi tính năng: git checkout -b tinh-nang-x
  2. Code và commit thường xuyên với message rõ ràng
  3. Đẩy nhánh lên GitHub: git push origin tinh-nang-x
  4. Tạo Pull Request (PR) trên GitHub để đồng đội review code
  5. Sau khi được duyệt (approve), merge PR vào nhánh main

Quan trọng
File .gitignore liệt kê những gì KHÔNG nên đưa lên Git — luôn thêm node_modules/ (quá lớn, tự cài lại được qua npm install) và .env (chứa secret/API key, tuyệt đối không public).
