Chương 1 — Git — Kiểm soát phiên bản

Công cụ bắt buộc với mọi lập trình viên — theo dõi lịch sử thay đổi code và cho phép làm việc nhóm an toàn.

3 khu vực làm việc của Git

Khu vựcÝ nghĩa
Working DirectoryThư mục code thực tế bạn đang chỉnh sửa
Staging AreaNơi "chuẩn bị" các thay đổi trước khi commit chính thức
Repository (.git)Lịch sử toàn bộ các commit đã lưu vĩnh viễn
terminal 
git init                              # khởi tạo repository trong thư mục hiện tại
git status                              # xem trạng thái: file nào đã sửa, chưa staged...
git add file.js                           # đưa 1 file vào staging area
git add .                                   # đưa TẤT CẢ thay đổi vào staging area
git commit -m "Thêm chức năng đăng nhập"      # lưu lại 1 "điểm mốc" với mô tả rõ ràng
git log --oneline                                # xem lịch sử commit dạng rút gọn

Làm việc với nhánh (Branch)

terminal 
git branch                            # xem danh sách nhánh hiện có
git branch tinh-nang-moi                 # tạo nhánh mới
git checkout tinh-nang-moi                  # chuyển sang nhánh đó
git checkout -b tinh-nang-moi                 # tạo VÀ chuyển nhánh cùng lúc (rút gọn)
git switch tinh-nang-moi                        # cách hiện đại hơn để chuyển nhánh (Git 2.23+)

git merge tinh-nang-moi                            # gộp nhánh "tinh-nang-moi" vào nhánh hiện tại
git branch -d tinh-nang-moi                           # xóa nhánh sau khi đã gộp xong
Quan trọng — Xung đột (Merge Conflict)
Khi hai nhánh cùng sửa MỘT dòng code khác nhau, Git không thể tự động gộp — nó đánh dấu vùng xung đột bằng <<<<<<</=======/>>>>>>> ngay trong file, bạn phải tự chỉnh sửa và chọn giữ phần nào trước khi commit tiếp.
Mẹo
Luôn viết commit message mô tả "tại sao" thay đổi, không chỉ "cái gì" — giúp cả nhóm (và chính bạn 6 tháng sau) hiểu lịch sử phát triển dự án dễ dàng hơn.

📌 Tổng kết chương 1

Git quản lý phiên bản qua 3 khu vực (working/staging/repository), commit lưu lại điểm mốc, branch cho phép phát triển song song mà không ảnh hưởng code chính.
