Chương 1 — TypeScript — Kiểu dữ liệu cơ bản

JavaScript được bổ sung hệ thống kiểu tĩnh — phát hiện lỗi ngay lúc viết code thay vì đợi tới khi chạy.

TypeScript là gì?

TypeScript là "siêu tập" (superset) của JavaScript — mọi code JS hợp lệ đều là code TS hợp lệ, cộng thêm hệ thống kiểu dữ liệu tĩnh. TypeScript được biên dịch (compile) ngược lại thành JavaScript thuần để chạy được trên trình duyệt/Node.js.

vi_du.ts 
let ten: string = "Huy";              // khai báo kiểu tường minh
let tuoi: number = 20;
let dangHoc: boolean = true;
let diem: number[] = [8.5, 9.0, 7.5];      // mảng số

function cong(a: number, b: number): number {   // kiểu tham số VÀ kiểu trả về
    return a + b;
}

cong(3, 5);        // OK
// cong("3", 5);   // LỖI BIÊN DỊCH - phát hiện NGAY, không cần chạy thử mới biết
LệnhCông dụng
npm install -g typescriptCài đặt trình biên dịch TypeScript toàn cục
tsc file.tsBiên dịch file .ts thành file .js
tsc --initTạo file cấu hình tsconfig.json cho dự án

Kiểu Union — biến có thể là MỘT TRONG NHIỀU kiểu

union_type.ts 
let id: string | number;    // id có thể là string HOẶC number
id = "abc123";                // OK
id = 12345;                     // cũng OK
// id = true;                  // LỖI - boolean không nằm trong union này

type TrangThai = "dang_xu_ly" | "hoan_thanh" | "loi";   // literal type - chỉ nhận đúng 3 giá trị này
let trangThaiDonHang: TrangThai = "dang_xu_ly";
Quan trọng
TypeScript chỉ kiểm tra kiểu lúc biên dịch — sau khi biên dịch ra JavaScript, mọi thông tin kiểu dữ liệu bị loại bỏ hoàn toàn (gọi là "type erasure"). TypeScript không làm code chạy nhanh hơn, nó chỉ giúp bắt lỗi SỚM HƠN trong quá trình phát triển.

📌 Tổng kết chương 1

TypeScript thêm kiểu tĩnh vào JavaScript, biên dịch ra JS thuần để chạy. Kiểu Union (|) cho phép biến nhận nhiều kiểu dữ liệu khác nhau một cách có kiểm soát.
