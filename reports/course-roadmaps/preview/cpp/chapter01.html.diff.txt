      <p class="lead">C++ là gì, tại sao nên học, và nó khác gì so với C và các ngôn ngữ hiện đại khác.</p>

      <h3>C++ là gì?</h3>
      <p>C++ là ngôn ngữ lập trình biên dịch (compiled), đa mục đích, do Bjarne Stroustrup phát triển từ ngôn ngữ C vào năm 1985 với triết lý "zero-overhead abstraction" — cho phép viết code trừu tượng hóa cao mà không phải trả giá về hiệu năng.</p>

      <div class="box note">
        <div class="box-title">Ghi chú</div>
        Ngôn ngữ "biên dịch" (compiled) nghĩa là code nguồn được dịch trực tiếp thành mã máy (machine code) trước khi chạy, khác với Python (thông dịch) — vì vậy chương trình C++ chạy nhanh hơn đáng kể nhưng phải biên dịch lại mỗi khi sửa code.
      </div>
