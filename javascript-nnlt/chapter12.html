DOM (Document Object Model) là "cầu nối" giữa JavaScript và trang HTML — nền tảng để tạo web tương tác.

dom_basic.js 
// Giả sử HTML có: <button id="nutBam">Nhấn tôi</button>
//                <p id="ketQua"></p>

const nut = document.getElementById("nutBam");         // tìm phần tử theo id
const ketQua = document.querySelector("#ketQua");        // querySelector - cách hiện đại, dùng CSS selector

nut.addEventListener("click", () => {                       // lắng nghe sự kiện click
    ketQua.textContent = "Bạn vừa nhấn nút!";                  // thay đổi nội dung
    ketQua.style.color = "green";                                // thay đổi CSS trực tiếp
});

// Tạo phần tử mới và thêm vào trang
const divMoi = document.createElement("div");
divMoi.textContent = "Phần tử được tạo bằng JS";
document.body.appendChild(divMoi);
Phương thứcCông dụng
getElementById()Tìm phần tử theo thuộc tính id
querySelector()Tìm phần tử ĐẦU TIÊN khớp CSS selector (linh hoạt hơn)
querySelectorAll()Tìm TẤT CẢ phần tử khớp CSS selector
addEventListener()Gắn hàm xử lý cho một sự kiện (click, input, submit...)
Mẹo
Nên ưu tiên querySelector()/querySelectorAll() thay vì các phương thức cũ (getElementById, getElementsByClassName) — vì cú pháp CSS selector linh hoạt và nhất quán hơn nhiều.

📌 Tổng kết chương 12

DOM cho phép JS đọc/sửa nội dung, style, và cấu trúc HTML. querySelector() + addEventListener() là bộ đôi quan trọng nhất để xây trang web tương tác.
