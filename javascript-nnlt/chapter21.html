NPM & package.json

npm (Node Package Manager) là kho thư viện lớn nhất thế giới lập trình — quản lý dependency cho dự án Node.js.

npm (Node Package Manager) là kho thư viện lớn nhất thế giới lập trình — quản lý dependency cho dự án Node.js.

terminal 
npm init -y                  # tạo file package.json với giá trị mặc định
npm install express            # cài một thư viện, tự thêm vào package.json
npm install --save-dev nodemon   # cài thư viện chỉ dùng khi PHÁT TRIỂN (không cần khi deploy)
npm uninstall express            # gỡ thư viện
npm run start                       # chạy script định nghĩa trong package.json
package.json 
{
  "name": "du-an-cua-toi",
  "version": "1.0.0",
  "scripts": {
    "start": "node app.js",
    "dev": "nodemon app.js"
  },
  "dependencies": {
    "express": "^5.1.0"
  }
}
Ghi chú — Express 5
Từ giữa 2025, Express 5 đã trở thành phiên bản mặc định khi chạy npm install express (thay cho Express 4 tồn tại suốt hơn một thập kỷ trước đó). Điểm khác biệt đáng chú ý nhất: middleware/route bất đồng bộ (async) giờ tự động chuyển lỗi (Promise bị reject) sang error-handling middleware mà không cần tự viết try/catch thủ công như trước.
Quan trọng
Thư mục node_modules (chứa toàn bộ thư viện đã cài) không bao giờ nên đưa lên Git — luôn thêm vào .gitignore. Người khác chỉ cần file package.json và chạy npm install để tự cài lại toàn bộ dependency.

📌 Tổng kết chương 21

npm quản lý thư viện bên thứ ba qua package.json. Dependency thường (dependencies) cần khi chạy, devDependency chỉ cần khi phát triển.
