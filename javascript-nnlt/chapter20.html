Giới thiệu Node.js

Môi trường chạy JavaScript ngoài trình duyệt — biến JS thành ngôn ngữ full-stack thực thụ.

Node.js là gì?

Node.js là môi trường thực thi JavaScript được xây dựng trên V8 engine (chính là engine chạy JS trong Chrome), cho phép chạy JS trên server, không cần trình duyệt. Nhờ đó, một lập trình viên có thể viết cả frontend lẫn backend chỉ bằng một ngôn ngữ duy nhất.

app.js 
// Chạy bằng: node app.js
console.log("Xin chào từ Node.js!");
console.log(process.version);       // phiên bản Node.js đang chạy
console.log(process.argv);            // tham số dòng lệnh truyền vào

Module built-in phổ biến

module_builtin.js 
const os = require('os');           // require() - cách import kiểu CommonJS (mặc định của Node)
console.log(os.platform());           // hệ điều hành đang chạy
console.log(os.cpus().length);          // số lõi CPU

const path = require('path');
console.log(path.join('data', 'file.txt'));   // nối đường dẫn đúng chuẩn hệ điều hành
Ghi chú — CommonJS vs ES Module
Node.js truyền thống dùng require()/module.exports (CommonJS). Node hiện đại cũng hỗ trợ import/export (ES Module, đã học ở chương 19) nếu cấu hình "type": "module" trong package.json.

📌 Tổng kết chương 20

Node.js chạy JS ngoài trình duyệt dựa trên V8 engine, cung cấp nhiều module built-in (os, path, fs...) và hỗ trợ cả CommonJS lẫn ES Module.
