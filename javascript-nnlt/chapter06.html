Chương 6 — Toán tử

Toán tử số học, so sánh, logic — và một vài toán tử đặc trưng chỉ có ở JavaScript.

toan_tu.js 
console.log(5 + 3);        // 8
console.log(5 === "5");      // false - so sánh nghiêm ngặt, khác kiểu là false
console.log(5 == "5");         // true - so sánh lỏng, tự ép kiểu

// Toán tử ?? (nullish coalescing) - ES2020
let ten = null;
console.log(ten ?? "Khách");   // "Khách" - chỉ dùng giá trị mặc định khi null/undefined

// Toán tử ?. (optional chaining) - ES2020
const user = {profile: null};
console.log(user.profile?.ten);   // undefined - KHÔNG gây lỗi dù profile là null
Mẹo
?? khác ||: 0 || "mặc định" trả về "mặc định" (vì 0 là falsy), nhưng 0 ?? "mặc định" trả về 0 (vì 0 không phải null/undefined) — dùng ?? khi chỉ muốn thay thế null/undefined, không phải mọi giá trị "falsy".

📌 Tổng kết chương 6

Luôn ưu tiên ===/!==. ?? và ?. (ES2020) giúp xử lý giá trị null/undefined an toàn, ngắn gọn hơn nhiều so với kiểm tra if truyền thống.
