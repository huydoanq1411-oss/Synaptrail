JavaScript là gì?

JavaScript (JS) là ngôn ngữ lập trình thông dịch, được Brendan Eich tạo ra chỉ trong 10 ngày vào năm 1995 để làm cho trang web "sống động" hơn. Ban đầu chỉ chạy trong trình duyệt, ngày nay JS còn chạy được ở phía server (Node.js), trên mobile (React Native) và cả desktop (Electron).

Ghi chú — JavaScript KHÔNG phải Java
Dù tên gần giống nhau (vì lý do marketing thời điểm ra mắt), JavaScript và Java là hai ngôn ngữ hoàn toàn khác nhau, không liên quan về cú pháp hay thiết kế — một trong những hiểu lầm phổ biến nhất với người mới học lập trình.

Tại sao nên học JavaScript?

  • Ngôn ngữ duy nhất chạy được trực tiếp trên mọi trình duyệt — không thể xây web tương tác mà không có JS.
  • Full-stack với một ngôn ngữ duy nhất — Node.js cho phép viết cả backend bằng JS.
  • Hệ sinh thái khổng lồ — npm là kho thư viện lớn nhất trong giới lập trình.
  • Linh hoạt, dễ bắt đầu — không cần cài đặt gì, chỉ cần trình duyệt là chạy được code ngay.
