Cấu trúc dữ liệu linh hoạt, tự động thay đổi kích thước, với rất nhiều phương thức xử lý mạnh mẽ.

array.js 
const ds = [3, 1, 4, 1, 5];

ds.push(9);            // thêm vào cuối
ds.pop();                 // xóa và trả về phần tử cuối
ds.unshift(0);              // thêm vào đầu
console.log(ds.length);       // độ dài mảng

// Các phương thức lập trình hàm - CỰC KỲ quan trọng trong JS hiện đại
const so = [1, 2, 3, 4, 5];

const gapDoi = so.map(x => x * 2);          // map - biến đổi từng phần tử -> mảng mới
console.log(gapDoi);   // [2, 4, 6, 8, 10]

const soChan = so.filter(x => x % 2 === 0);   // filter - lọc phần tử thỏa điều kiện
console.log(soChan);   // [2, 4]

const tong = so.reduce((acc, x) => acc + x, 0);   // reduce - gộp thành 1 giá trị
console.log(tong);   // 15

const timThay = so.find(x => x > 3);       // find - phần tử ĐẦU TIÊN thỏa điều kiện
console.log(timThay);   // 4

console.log(so.includes(3));   // true - kiểm tra tồn tại
Mẹo
map/filter/reduce là bộ ba quan trọng nhất của JS hiện đại — hầu hết code xử lý mảng chuyên nghiệp đều ưu tiên dùng chúng thay vì vòng lặp for thủ công.
