32 WebSocket API (client thuần)

API WebSocket gốc của trình duyệt — nền tảng mà các thư viện như Socket.IO (đã học ở Full-Stack JS) xây dựng bên trên.

websocket_client.js 
const socket = new WebSocket('wss://echo.websocket.org');   // wss:// = WebSocket qua HTTPS

socket.onopen = () => {
    console.log('Đã kết nối!');
    socket.send('Xin chào server!');            // gửi tin nhắn TỚI server
};

socket.onmessage = (event) => {
    console.log('Nhận được:', event.data);        // nhận tin nhắn TỪ server
};

socket.onerror = (error) => {
    console.log('Lỗi kết nối:', error);
};

socket.onclose = () => {
    console.log('Đã ngắt kết nối');
};

// Đóng kết nối chủ động khi không cần nữa
// socket.close();
Tiêu chíWebSocket thuầnSocket.IO
Có sẵn trong trình duyệtCó, không cần cài thêmCần thư viện socket.io-client
Tự động reconnect khi mất mạngKhông — phải tự viết logicCó sẵn
Fallback khi trình duyệt cũ không hỗ trợKhôngCó (tự chuyển sang long-polling)
Đặt tên sự kiện tùy chỉnhKhông — chỉ có 1 kênh onmessageCó (socket.on('ten_su_kien', ...))
Mẹo
Hiểu WebSocket API thuần giúp hiểu ĐÚNG bản chất cách Socket.IO hoạt động bên dưới — Socket.IO thực chất là WebSocket API được "bọc" thêm nhiều tiện ích (reconnect, fallback, event namespace) để dùng dễ dàng và ổn định hơn trong thực tế.
