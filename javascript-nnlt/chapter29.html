Web Storage (localStorage/sessionStorage)

Lưu dữ liệu trực tiếp trên trình duyệt người dùng — không cần gọi server, tồn tại giữa các lần tải trang.

Lưu dữ liệu trực tiếp trên trình duyệt người dùng — không cần gọi server, tồn tại giữa các lần tải trang.

web_storage.js 
// localStorage - LƯU VĨNH VIỄN cho tới khi bị xóa thủ công
localStorage.setItem('ten_nguoi_dung', 'Huy');
localStorage.getItem('ten_nguoi_dung');        // "Huy"
localStorage.removeItem('ten_nguoi_dung');
localStorage.clear();                             // xóa TOÀN BỘ dữ liệu localStorage

// Lưu object phải chuyển qua chuỗi JSON trước
const nguoiDung = { ten: "Huy", tuoi: 20 };
localStorage.setItem('nguoiDung', JSON.stringify(nguoiDung));
const daLuu = JSON.parse(localStorage.getItem('nguoiDung'));

// sessionStorage - CÙNG cú pháp, nhưng chỉ tồn tại trong PHIÊN TAB hiện tại
sessionStorage.setItem('gio_hang_tam', JSON.stringify([1, 2, 3]));
// Đóng tab lại là mất - khác localStorage vẫn còn sau khi đóng trình duyệt

Quan trọng
Web Storage chỉ lưu được chuỗi (string) — object/array phải JSON.stringify() trước khi lưu, và JSON.parse() khi đọc ra. Không bao giờ lưu dữ liệu nhạy cảm (mật khẩu, token quan trọng) trong localStorage vì bất kỳ script nào chạy trên trang (kể cả từ lỗ hổng XSS đã học) đều đọc được.

📌 Tổng kết chương 32

localStorage lưu vĩnh viễn, sessionStorage chỉ trong phiên tab — cả hai chỉ lưu chuỗi, cần JSON.stringify/parse cho dữ liệu phức tạp. Không dùng cho dữ liệu nhạy cảm vì dễ bị đọc qua XSS.
