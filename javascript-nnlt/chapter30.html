IndexedDB — Lưu trữ dữ liệu lớn

Khi localStorage (vài MB, chỉ string) không đủ — cơ sở dữ liệu NoSQL đầy đủ chạy ngay trong trình duyệt.

Khi localStorage (vài MB, chỉ string) không đủ — cơ sở dữ liệu NoSQL đầy đủ chạy ngay trong trình duyệt.

indexeddb_basic.js 
const yeuCauMo = indexedDB.open('CuaHangDB', 1);      // tên database, phiên bản

yeuCauMo.onupgradeneeded = (event) => {                  // chạy khi tạo mới/nâng cấp version
    const db = event.target.result;
    const store = db.createObjectStore('sanPham', { keyPath: 'id' });   // tạo "bảng"
    store.createIndex('theoTen', 'ten', { unique: false });               // tạo chỉ mục để tìm nhanh theo tên
};

yeuCauMo.onsuccess = (event) => {
    const db = event.target.result;

    // Thêm dữ liệu
    const giaoDich = db.transaction('sanPham', 'readwrite');
    giaoDich.objectStore('sanPham').add({ id: 1, ten: 'Áo thun', gia: 150000 });

    // Đọc dữ liệu
    const giaoDichDoc = db.transaction('sanPham', 'readonly');
    const yeuCau = giaoDichDoc.objectStore('sanPham').get(1);
    yeuCau.onsuccess = () => console.log(yeuCau.result);
};
Ghi chú
IndexedDB là API bất đồng bộ dựa trên event (cũ hơn Promise), cú pháp khá dài dòng — trong thực tế, hầu hết dự án dùng thư viện wrapper như idb (của Jake Archibald) để có cú pháp Promise gọn gàng hơn nhiều.
Mẹo
IndexedDB là nền tảng lưu trữ offline cho Progressive Web App (PWA) — cho phép ứng dụng web hoạt động cả khi mất mạng, lưu trữ hàng nghìn bản ghi mà localStorage không kham nổi.
