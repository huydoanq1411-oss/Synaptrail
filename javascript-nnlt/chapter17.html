Destructuring & Spread nâng cao

Các kỹ thuật ES6+ giúp code JavaScript ngắn gọn và biểu cảm hơn.

Các kỹ thuật ES6+ giúp code JavaScript ngắn gọn và biểu cảm hơn.

destructuring_advanced.js 
// Destructuring mảng
const [dau, thu2, ...con_lai] = [1, 2, 3, 4, 5];
console.log(dau, thu2, con_lai);   // 1 2 [3, 4, 5]

// Destructuring object với đổi tên và giá trị mặc định
const sv = {ten: "Huy", diem: 8.5};
const {ten: hoTen, tuoi = 18} = sv;      // đổi tên "ten"->"hoTen", "tuoi" dùng mặc định vì không có
console.log(hoTen, tuoi);   // Huy 18

// Destructuring trong tham số hàm - RẤT phổ biến trong React
function gioiThieu({ten, tuoi}) {
    console.log(`${ten}, ${tuoi} tuổi`);
}
gioiThieu({ten: "Lan", tuoi: 22});

// Destructuring lồng nhau
const {profile: {email}} = {profile: {email: "huy@example.com"}};
console.log(email);   // huy@example.com
Mẹo
Destructuring tham số hàm (như ví dụ gioiThieu({ten, tuoi})) là pattern cực kỳ phổ biến trong React — giúp code component nhận props rõ ràng, tự tài liệu hóa các trường dữ liệu cần dùng.

📌 Tổng kết chương 17

Destructuring "giải nén" mảng/object ra biến riêng, hỗ trợ đổi tên, giá trị mặc định, và lồng nhau — kỹ thuật nền tảng của code JS/React hiện đại.
