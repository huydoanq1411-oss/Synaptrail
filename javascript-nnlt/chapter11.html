Object

Cấu trúc dữ liệu key-value nền tảng của JavaScript — gần như mọi thứ trong JS đều liên quan tới object.

Cấu trúc dữ liệu key-value nền tảng của JavaScript — gần như mọi thứ trong JS đều liên quan tới object.

object.js 
const sinhVien = {
    ten: "Huy",
    tuoi: 20,
    diem: [8.5, 9.0],
    gioiThieu() {                 // method ngay bên trong object
        console.log(`Tôi là ${this.ten}`);   // "this" trỏ tới chính object này
    }
};

console.log(sinhVien.ten);        // truy cập bằng dấu chấm
console.log(sinhVien["tuoi"]);      // truy cập bằng ngoặc vuông (hữu ích khi key là biến)
sinhVien.diaChi = "TP.HCM";           // thêm thuộc tính mới
sinhVien.gioiThieu();                   // Tôi là Huy

// Destructuring - "giải nén" object ra biến (ES6+)
const {ten, tuoi} = sinhVien;
console.log(ten, tuoi);   // Huy 20

// Spread operator - sao chép/gộp object (ES6+)
const svMoi = {...sinhVien, tuoi: 21};   // sao chép sinhVien, ghi đè tuoi thành 21
console.log(svMoi.tuoi);   // 21
Kỹ thuậtCông dụng
Destructuring {a, b} = objTrích xuất nhanh nhiều thuộc tính ra biến riêng
Spread {...obj}Sao chép nông (shallow copy) hoặc gộp nhiều object
Object.keys()/values()/entries()Lấy danh sách key/value/cặp key-value dạng mảng

📌 Tổng kết chương 11

Object lưu dữ liệu key-value, hỗ trợ method nội bộ. Destructuring và spread operator (ES6+) giúp thao tác object ngắn gọn, là phong cách chuẩn của JS hiện đại.
