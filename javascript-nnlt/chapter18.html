Class trong JavaScript

Cú pháp OOP hiện đại (ES6+) — thực chất là "lớp vỏ cú pháp" cho prototype-based inheritance nguyên bản của JS.

Cú pháp OOP hiện đại (ES6+) — thực chất là "lớp vỏ cú pháp" cho prototype-based inheritance nguyên bản của JS.

class_basic.js 
class DongVat {
    constructor(ten) {           // constructor - tự chạy khi tạo object
        this.ten = ten;
    }
    an() {
        console.log(`${this.ten} đang ăn`);
    }
}

class Cho extends DongVat {       // kế thừa bằng "extends"
    constructor(ten) {
        super(ten);                  // gọi constructor của lớp cha
    }
    sua() {
        console.log(`${this.ten} sủa: Gâu gâu!`);
    }
}

const cho = new Cho("Milu");
cho.an();     // Milu đang ăn - kế thừa từ DongVat
cho.sua();      // Milu sủa: Gâu gâu!

// Private field (ES2022+)
class TaiKhoan {
    #soDu = 0;                  // dấu # = thuộc tính private thực sự, không truy cập được từ ngoài
    napTien(soTien) {
        this.#soDu += soTien;
    }
    xemSoDu() {
        return this.#soDu;
    }
}
Ghi chú
Class trong JS không phải khái niệm hoàn toàn mới — nó là cú pháp dễ đọc hơn cho prototype-based inheritance, cơ chế OOP gốc của JavaScript vốn khác biệt hoàn toàn so với class-based OOP của Java/C++.

📌 Tổng kết chương 18

class/extends/super mang cú pháp OOP quen thuộc vào JS. Dấu # (ES2022+) tạo thuộc tính private thực sự, khác với quy ước đặt tên _bien chỉ mang tính ước lệ trước đây.
