Express — Server cơ bản

Framework phổ biến nhất để xây dựng web server và API bằng Node.js.

Framework phổ biến nhất để xây dựng web server và API bằng Node.js.

server.js 
// npm install express
const express = require('express');
const app = express();
const PORT = 3000;

app.use(express.json());     // middleware - tự động parse JSON trong request body

app.get('/', (req, res) => {
    res.send('Chào mừng đến với Express!');
});

app.get('/sinh-vien/:id', (req, res) => {    // :id - route parameter
    const id = req.params.id;
    res.json({id: id, ten: "Huy"});
});

app.listen(PORT, () => {
    console.log(`Server đang chạy tại http://localhost:${PORT}`);
});
Thành phầnÝ nghĩa
app.get/post/put/deleteĐịnh nghĩa route ứng với từng phương thức HTTP
reqObject chứa thông tin request (params, query, body...)
resObject dùng để gửi phản hồi (send, json, status...)
req.paramsTham số trên đường dẫn (VD: /sinh-vien/:id)
req.queryTham số trên query string (VD: ?trang=2)

Express định nghĩa route bằng app.get/post/..., xử lý request qua req và phản hồi qua res — nền tảng xây dựng REST API bằng Node.js.
