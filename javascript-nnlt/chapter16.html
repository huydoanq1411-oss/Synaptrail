Fetch API & JSON

Gọi API từ trình duyệt bằng fetch() — thay thế XMLHttpRequest kiểu cũ.

Gọi API từ trình duyệt bằng fetch() — thay thế XMLHttpRequest kiểu cũ.

fetch_basic.js 
// GET request
async function layDanhSachSanPham() {
    const response = await fetch("https://api.example.com/san-pham");
    if (!response.ok) {                          // fetch KHÔNG tự reject khi lỗi HTTP (404, 500...)
        throw new Error(`Lỗi HTTP: ${response.status}`);
    }
    const data = await response.json();            // parse JSON từ response
    return data;
}

// POST request
async function taoSanPham(sanPham) {
    const response = await fetch("https://api.example.com/san-pham", {
        method: "POST",
        headers: {"Content-Type": "application/json"},
        body: JSON.stringify(sanPham)               // object -> chuỗi JSON
    });
    return await response.json();
}
Quan trọng
fetch() chỉ reject khi có lỗi mạng (mất kết nối...) — với lỗi HTTP như 404/500, fetch() vẫn resolve bình thường, phải tự kiểm tra response.ok hoặc response.status để phát hiện lỗi.

JSON.stringify & JSON.parse

json_convert.js 
const obj = {ten: "Huy", tuoi: 20};
const chuoiJson = JSON.stringify(obj);      // object -> chuỗi JSON: '{"ten":"Huy","tuoi":20}'
const objMoi = JSON.parse(chuoiJson);         // chuỗi JSON -> object

📌 Tổng kết chương 16

fetch() gọi API bất đồng bộ, luôn kiểm tra response.ok để bắt lỗi HTTP. JSON.stringify()/JSON.parse() chuyển đổi qua lại giữa object và chuỗi JSON.
