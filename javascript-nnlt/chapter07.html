if/else, switch, và khái niệm "truthy/falsy" đặc trưng của JavaScript.

if_else.js 
const diem = 8;
if (diem >= 8) {
    console.log("Giỏi");
} else if (diem >= 6) {
    console.log("Khá");
} else {
    console.log("Cần cố gắng");
}

// Toán tử ternary
const trangThai = diem >= 8 ? "Giỏi" : "Chưa giỏi";

Truthy & Falsy — khái niệm quan trọng của JS

Trong điều kiện, JS tự động chuyển giá trị bất kỳ sang boolean. Các giá trị sau đều là falsy (coi như false): 0, "" (chuỗi rỗng), null, undefined, NaN, false. Mọi giá trị khác đều là truthy.

truthy_falsy.js 
if ("") console.log("Sẽ không chạy");        // chuỗi rỗng là falsy
if ("0") console.log("SẼ chạy!");               // chuỗi "0" (khác số 0) là TRUTHY vì không rỗng
if ([]) console.log("SẼ chạy!");                   // mảng rỗng vẫn là truthy (khác Python!)
Quan trọng — khác biệt với Python
Trong JavaScript, mảng rỗng [] và object rỗng {} đều là truthy (khác với Python, nơi list/dict rỗng là falsy) — đây là lỗi tư duy phổ biến với người chuyển từ Python sang JS.

📌 Tổng kết chương 7

if/else/switch tương tự các ngôn ngữ khác. Khái niệm truthy/falsy của JS có một số khác biệt quan trọng so với Python — đặc biệt mảng/object rỗng luôn là truthy.
