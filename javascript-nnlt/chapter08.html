Chương 8 — Vòng lặp

for, while, và các vòng lặp hiện đại for...of / for...in.

vong_lap.js 
for (let i = 0; i < 5; i++) {
    console.log(i);
}

let dem = 0;
while (dem < 5) {
    console.log(dem);
    dem++;
}

const trai_cay = ["táo", "cam", "chuối"];
for (const tc of trai_cay) {      // for...of - duyệt GIÁ TRỊ của mảng/iterable
    console.log(tc);
}

const sv = {ten: "Huy", tuoi: 20};
for (const key in sv) {              // for...in - duyệt KEY của object
    console.log(key, sv[key]);
}

trai_cay.forEach((tc, idx) => {        // forEach - phương thức của mảng, style hàm
    console.log(idx, tc);
});
Mẹo ghi nhớ
Nhớ quy tắc: for...OF cho giá trị (Of values) — dùng với mảng; for...IN cho key (In object) — dùng với object. Nhầm lẫn hai loại này là lỗi rất phổ biến.

📝 Quiz nhanh — Chương 7-8

1. Vòng lặp nào phù hợp để duyệt các GIÁ TRỊ của một mảng?

for...of for...in for...key

📌 Tổng kết chương 8

for...of duyệt giá trị (mảng/iterable), for...in duyệt key (object). forEach() là cách hiện đại, theo phong cách hàm để duyệt mảng.
