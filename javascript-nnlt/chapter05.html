Kiểu dữ liệu

JavaScript là ngôn ngữ động về kiểu (dynamic typing) và có một số hành vi ép kiểu đặc trưng cần lưu ý.

JavaScript là ngôn ngữ động về kiểu (dynamic typing) và có một số hành vi ép kiểu đặc trưng cần lưu ý.

KiểuVí dụ
number10, 3.14 — CHỈ MỘT kiểu số duy nhất, không phân biệt int/float
string"Xin chào", 'Xin chào', `Xin chào`
booleantrue, false
undefinedBiến đã khai báo nhưng chưa gán giá trị
nullGiá trị rỗng được gán CÓ CHỦ ĐÍCH
object{ten: "Huy"}, mảng cũng là object
kieu_du_lieu.js 
console.log(typeof 10);          // "number"
console.log(typeof "hello");       // "string"
console.log(typeof true);            // "boolean"
console.log(typeof undefined);         // "undefined"
console.log(typeof null);                // "object" - đây là LỖI LỊCH SỬ nổi tiếng của JS!

let x;
console.log(x);   // undefined - đã khai báo nhưng chưa gán

Template Literals — chuỗi hiện đại

template_literal.js 
const ten = "Huy";
const tuoi = 20;
console.log(`Tên: ${ten}, Tuổi: ${tuoi}`);   // dùng dấu backtick ` và ${} để nhúng biến
Lỗi thường gặp — so sánh == vs ===
== so sánh giá trị và TỰ ĐỘNG ép kiểu (VD: "5" == 5 là true) — dễ gây lỗi khó lường. Luôn dùng === (so sánh nghiêm ngặt, không ép kiểu) trong code thực tế.

📌 Tổng kết chương 5

JS chỉ có một kiểu number duy nhất cho mọi số. Luôn dùng === thay vì == để tránh ép kiểu ngoài ý muốn. Template literal (dấu backtick) là cách hiện đại để nối chuỗi.
