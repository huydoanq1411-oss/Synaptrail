Promise

Đối tượng đại diện cho một giá trị sẽ có trong tương lai — giải pháp thay thế callback hell.

Đối tượng đại diện cho một giá trị sẽ có trong tương lai — giải pháp thay thế callback hell.

promise_basic.js 
function taiDuLieu() {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const thanhCong = true;
            if (thanhCong) {
                resolve("Dữ liệu đã tải xong");    // gọi khi THÀNH CÔNG
            } else {
                reject("Lỗi khi tải dữ liệu");        // gọi khi THẤT BẠI
            }
        }, 1000);
    });
}

taiDuLieu()
    .then(ketQua => console.log(ketQua))      // xử lý khi resolve
    .catch(loi => console.log(loi))              // xử lý khi reject
    .finally(() => console.log("Hoàn tất"));       // LUÔN chạy, dù thành công hay thất bại

Chuỗi Promise — giải quyết callback hell

promise_chain.js 
taiSinhVien()
    .then(sv => taiDiem(sv))          // mỗi .then() nhận kết quả từ Promise trước
    .then(diem => taiXepLoai(diem))
    .then(xepLoai => console.log(xepLoai))
    .catch(loi => console.log("Lỗi ở bất kỳ bước nào:", loi));   // MỘT catch xử lý lỗi cho CẢ chuỗi
Trạng thái PromiseÝ nghĩa
pendingĐang chờ xử lý
fulfilledĐã hoàn thành thành công (resolve)
rejectedĐã thất bại (reject)
Mẹo
Promise.all([p1, p2, p3]) chạy nhiều Promise song song và chờ tất cả hoàn thành — nhanh hơn nhiều so với chờ tuần tự từng cái bằng chuỗi .then().

📌 Tổng kết chương 14

Promise có 3 trạng thái (pending/fulfilled/rejected), dùng .then()/.catch()/.finally() để xử lý kết quả, và có thể nối chuỗi để thay thế callback hell.
