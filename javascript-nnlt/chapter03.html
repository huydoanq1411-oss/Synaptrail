In "Hello, World!" và làm quen với console.log — công cụ debug quan trọng nhất của JS.

hello.js 
console.log("Hello, World!");
console.log("Xin chào,", "JavaScript!");   // console.log nhận nhiều tham số, tự thêm khoảng trắng

// alert() chỉ dùng được trong trình duyệt, hiện popup
// alert("Xin chào!");
Ghi chú
JavaScript không yêu cầu có hàm main() như C++/Java — code chạy tuần tự từ trên xuống ngay khi file được nạp, giống Python.

Dấu chấm phẩy (Semicolon) — có hay không?

semicolon.js 
console.log("Có dấu chấm phẩy");    // OK
console.log("Không có dấu chấm phẩy")   // vẫn chạy được nhờ ASI (Automatic Semicolon Insertion)
Mẹo
JS có cơ chế tự động thêm dấu chấm phẩy (ASI) nên code vẫn chạy được dù thiếu ;, nhưng nên viết đầy đủ dấu chấm phẩy để tránh các trường hợp hiếm gặp ASI hiểu sai ý định của code.

📌 Tổng kết chương 3

console.log() là công cụ in/debug cơ bản nhất trong JS. Code chạy tuần tự không cần hàm main, và dấu chấm phẩy tuy không bắt buộc nhưng nên viết đầy đủ.
