Module (import/export)

Chia code thành nhiều file có thể tái sử dụng — chuẩn ES Module hiện đại.

Làm quiz ở trang riêng

Chia code thành nhiều file có thể tái sử dụng — chuẩn ES Module hiện đại.

toanHoc.js 
export function cong(a, b) {          // export MỘT hàm/biến cụ thể (named export)
    return a + b;
}

export const PI = 3.14159;

export default function nhan(a, b) {   // export MẶC ĐỊNH - mỗi file chỉ có 1 default export
    return a * b;
}
main.js 
import nhan, { cong, PI } from './toanHoc.js';   // default export không cần dấu {}, named export cần

console.log(cong(3, 5));   // 8
console.log(nhan(3, 5));     // 15
console.log(PI);              // 3.14159

import * as ToanHoc from './toanHoc.js';    // import TẤT CẢ dưới dạng một object
console.log(ToanHoc.cong(1, 1));
Quan trọng
Để dùng ES Module trong trình duyệt, thẻ script cần thêm type="module": <script type="module" src="main.js"></script>. Trong Node.js, cần cấu hình "type": "module" trong package.json hoặc dùng đuôi file .mjs.

📌 Tổng kết chương 19

ES Module dùng export/import để chia sẻ code giữa các file. Named export cho nhiều giá trị, default export cho giá trị chính duy nhất của mỗi module.
