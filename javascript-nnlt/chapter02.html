Cách chạy JS (Browser & Node.js)

Hai môi trường chính để chạy JavaScript, không cần cài đặt phức tạp như C++/Java.

Hai môi trường chính để chạy JavaScript, không cần cài đặt phức tạp như C++/Java.

Cách 1: Chạy trong trình duyệt (Console)

Mở bất kỳ trình duyệt nào, nhấn F12 (hoặc chuột phải → Inspect) → tab "Console" → gõ code JS và nhấn Enter để chạy ngay lập tức.

Cách 2: Nhúng vào file HTML

index.html 
<!DOCTYPE html>
<html>
<body>
    <script>
        console.log("Xin chào từ JavaScript!");
    </script>
</body>
</html>

Cách 3: Node.js (chạy JS ngoài trình duyệt)

terminal 
node --version    # kiểm tra đã cài Node.js chưa (tải tại nodejs.org)
node app.js         # chạy file JS trực tiếp, không cần trình duyệt
Mẹo
Khi mới học, dùng Console của trình duyệt (F12) là nhanh nhất để thử nghiệm code — không cần cài đặt gì cả. Node.js chỉ thực sự cần khi muốn viết backend hoặc chạy script ngoài trình duyệt.

📌 Tổng kết chương 2

JS chạy được trong Console trình duyệt, nhúng qua thẻ <script> trong HTML, hoặc chạy độc lập bằng Node.js — không cần bước biên dịch như C++/Java.
