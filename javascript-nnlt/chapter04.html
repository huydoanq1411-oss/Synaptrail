JavaScript có 3 từ khóa khai báo biến — hiểu đúng sự khác biệt là nền tảng quan trọng nhất.

bien.js 
let ten = "Huy";        // let - có thể thay đổi giá trị, khuyến nghị dùng mặc định
const PI = 3.14159;       // const - KHÔNG THỂ gán lại sau khi khởi tạo
var tuoi = 20;               // var - cách khai báo CŨ, nên tránh dùng trong code mới

ten = "Lan";        // OK - let cho phép thay đổi
// PI = 3.14;        // LỖI - const không cho phép gán lại
Từ khóaPhạm vi (Scope)Gán lại được?Khuyến nghị
varFunction scope (cũ, dễ gây lỗi)CóTránh dùng trong code mới
letBlock scope (trong {})CóDùng khi cần thay đổi giá trị
constBlock scopeKhôngMặc định nên dùng nếu không cần đổi giá trị
Quan trọng
const với object/array vẫn cho phép thay đổi nội dung bên trong (thêm phần tử, sửa thuộc tính) — chỉ không cho phép gán lại toàn bộ biến sang giá trị khác. Ví dụ: const ds = [1,2]; ds.push(3); vẫn hợp lệ.
Mẹo
Quy tắc thực hành tốt: mặc định dùng const, chỉ chuyển sang let khi thực sự cần gán lại giá trị, và tránh var hoàn toàn trong code hiện đại.

📌 Tổng kết chương 4

const mặc định nên dùng, let khi cần thay đổi giá trị, var nên tránh vì phạm vi hoạt động (scope) dễ gây lỗi khó phát hiện.
