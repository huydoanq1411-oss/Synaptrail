Chương 27 — Stack & Queue tự cài đặt

Cài đặt hai cấu trúc dữ liệu nền tảng bằng vector — hiểu bên trong std::stack/std::queue hoạt động ra sao.

stack_queue.cpp 
#include <stack>
#include <queue>

// Dùng std::stack có sẵn - LIFO
stack<int> ngan_xep;
ngan_xep.push(1); ngan_xep.push(2); ngan_xep.push(3);
cout << ngan_xep.top() << endl;   // 3 - xem phần tử trên cùng
ngan_xep.pop();                       // xóa phần tử trên cùng (KHÔNG trả về giá trị)

// Dùng std::queue có sẵn - FIFO
queue<int> hang_doi;
hang_doi.push(1); hang_doi.push(2); hang_doi.push(3);
cout << hang_doi.front() << endl;   // 1 - xem phần tử đầu tiên
hang_doi.pop();                          // xóa phần tử đầu tiên

// Ứng dụng thực tế: kiểm tra ngoặc hợp lệ dùng stack
bool ngoacHopLe(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(') st.push(c);
        else if (c == ')') {
            if (st.empty()) return false;
            st.pop();
        }
    }
    return st.empty();
}
Mẹo
std::stack và std::queue thực chất là "container adapter" — mặc định được xây dựng bên trên deque, giới hạn chỉ cho phép các thao tác đặc trưng (push/pop/top hoặc push/pop/front) để đảm bảo tính đúng đắn của cấu trúc dữ liệu.

📌 Tổng kết chương 27

std::stack (LIFO) và std::queue (FIFO) là container adapter có sẵn trong STL, cung cấp interface an toàn, giới hạn đúng các thao tác đặc trưng của từng cấu trúc.
