Chương 23 — Lambda Expression

Hàm ẩn danh (C++11+) — cực kỳ hữu ích khi dùng với các thuật toán của STL.

lambda_basic.cpp 
#include <algorithm>
#include <vector>

auto binhPhuong = [](int x) { return x * x; };   // [] = capture list, () = tham số
cout << binhPhuong(5) << endl;                       // 25

vector<int> ds = {5, 2, 8, 1, 9};

sort(ds.begin(), ds.end(), [](int a, int b) {     // lambda làm tiêu chí so sánh cho sort
    return a > b;                                          // sắp xếp GIẢM dần
});

int nguong = 5;
int demLon = count_if(ds.begin(), ds.end(), [nguong](int x) {   // "capture" biến nguong từ bên ngoài
    return x > nguong;
});
cout << demLon << endl;
CaptureÝ nghĩa
[]Không lấy biến nào từ phạm vi ngoài
[x]Lấy biến x theo giá trị (copy)
[&x]Lấy biến x theo tham chiếu (có thể sửa biến gốc)
[=]Lấy TẤT CẢ biến ngoài theo giá trị
[&]Lấy TẤT CẢ biến ngoài theo tham chiếu
Mẹo
Lambda kết hợp với các thuật toán STL (sort, find_if, count_if, for_each) là phong cách viết C++ hiện đại — ngắn gọn hơn nhiều so với việc tự viết hàm so sánh riêng.

📌 Tổng kết chương 23

Lambda tạo hàm ẩn danh ngay tại chỗ sử dụng, với capture list linh hoạt để lấy biến từ phạm vi ngoài — rất mạnh khi kết hợp với các thuật toán STL.
