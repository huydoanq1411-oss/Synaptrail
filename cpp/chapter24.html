Namespace & File nhiều module

Tổ chức code lớn thành nhiều file, tránh xung đột tên giữa các thư viện khác nhau.

Tổ chức code lớn thành nhiều file, tránh xung đột tên giữa các thư viện khác nhau.

Namespace — tránh xung đột tên

namespace.cpp 
namespace ToanHoc {
    double PI = 3.14159;
    double tinhChuVi(double banKinh) {
        return 2 * PI * banKinh;
    }
}

namespace VatLy {
    double PI = 3.14;   // KHÔNG xung đột với ToanHoc::PI vì khác namespace
}

int main() {
    cout << ToanHoc::PI << endl;              // truy cập qua toán tử ::
    cout << ToanHoc::tinhChuVi(5) << endl;
}

Chia code thành file .h (khai báo) và .cpp (triển khai)

ToanHoc.h 
#ifndef TOANHOC_H     // header guard - tránh khai báo trùng lặp khi include nhiều lần
#define TOANHOC_H

int cong(int a, int b);   // chỉ KHAI BÁO, không có thân hàm

#endif
ToanHoc.cpp 
#include "ToanHoc.h"

int cong(int a, int b) {     // TRIỂN KHAI thực sự nằm ở file .cpp
    return a + b;
}
main.cpp 
#include "ToanHoc.h"     // chỉ cần include file header

int main() {
    cout << cong(3, 5) << endl;
}
// Biên dịch: g++ main.cpp ToanHoc.cpp -o chuong_trinh
Quan trọng
#ifndef/#define/#endif (header guard) ngăn lỗi "khai báo trùng lặp" khi một file header vô tình được #include nhiều lần trong cùng một quá trình biên dịch — luôn cần có trong mọi file .h.

📌 Tổng kết chương 24

namespace tránh xung đột tên giữa các thư viện. Dự án thực tế tách file .h (khai báo) và .cpp (triển khai), luôn có header guard để tránh include trùng lặp.
