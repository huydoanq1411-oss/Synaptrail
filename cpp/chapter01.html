Chương 1 — Giới thiệu C++

C++ là gì, tại sao nên học, và nó khác gì so với C và các ngôn ngữ hiện đại khác.

C++ là gì?

C++ là ngôn ngữ lập trình biên dịch (compiled), đa mục đích, do Bjarne Stroustrup phát triển từ ngôn ngữ C vào năm 1985 với triết lý "zero-overhead abstraction" — cho phép viết code trừu tượng hóa cao mà không phải trả giá về hiệu năng.

Ghi chú
Ngôn ngữ "biên dịch" (compiled) nghĩa là code nguồn được dịch trực tiếp thành mã máy (machine code) trước khi chạy, khác với Python (thông dịch) — vì vậy chương trình C++ chạy nhanh hơn đáng kể nhưng phải biên dịch lại mỗi khi sửa code.

Tại sao nên học C++?

  • Hiệu năng cực cao — kiểm soát trực tiếp bộ nhớ, gần với phần cứng hơn hầu hết ngôn ngữ khác.
  • Nền tảng của nhiều hệ thống lớn — game engine (Unreal Engine), hệ điều hành, trình duyệt, phần mềm nhúng.
  • Kiểm soát bộ nhớ thủ công — hiểu sâu cách máy tính hoạt động, nền tảng tốt để học các ngôn ngữ khác.
  • Đa mô hình (multi-paradigm) — hỗ trợ lập trình thủ tục, hướng đối tượng và generic programming.

C++ dùng để làm gì?

Lĩnh vựcVí dụ
Phát triển gameUnreal Engine, nhiều game engine AAA
Hệ điều hành & driverWindows, phần lớn nhân Linux driver
Phần mềm nhúng (embedded)Firmware, IoT, robot
Phần mềm hiệu năng caoTrình duyệt (Chrome), hệ thống giao dịch tài chính tốc độ cao
Mẹo ghi nhớ
C++ = "C với các lớp" (C with Classes) — tên gọi ban đầu của ngôn ngữ này, phản ánh đúng bản chất: nó là C được bổ sung thêm lập trình hướng đối tượng và nhiều tính năng hiện đại khác.

Nhớ khái niệm

1. Theo chương này, C++ thuộc loại ngôn ngữ nào?

A. Đánh dấu B. Biên dịch C. Chỉ truy vấn cơ sở dữ liệu D. Chỉ cấu hình giao diện
Giải thích đáp án
  • A. Sai: C++ không dùng vai trò của HTML.
  • B. Đúng: mã được biên dịch trước khi chạy theo bài.
  • C. Sai: Bài mô tả ngôn ngữ đa mục đích.
  • D. Sai: Bài liệt kê nhiều ứng dụng ngoài giao diện.
Nhớ khái niệm

2. “Đa mô hình” của C++ trong bài có nghĩa gì?

A. Chỉ dùng hướng đối tượng B. Chỉ dùng lập trình thủ tục C. Hỗ trợ thủ tục, hướng đối tượng và generic D. Không cho tổ chức mã
Giải thích đáp án
  • A. Sai: Bài còn nêu thủ tục và generic.
  • B. Sai: Đây chỉ là một mô hình được hỗ trợ.
  • C. Đúng: ba mô hình được liệt kê.
  • D. Sai: Đa mô hình không có nghĩa thiếu cấu trúc.
Áp dụng / đọc code

3. Trong các tình huống sau, đâu là ứng dụng C++ được bài nêu?

A. Viết thành phần cho game engine B. Viết thẻ HTML làm chương trình C++ C. Đổi mọi file .cpp thành bảng tính để chạy D. Chỉ dùng CSS để biên dịch mã C++
Giải thích đáp án
  • A. Đúng: bài nêu phát triển game và engine.
  • B. Sai: HTML không phải ví dụ chương trình C++.
  • C. Sai: Bài không có quy trình này.
  • D. Sai: CSS không phải công cụ biên dịch C++.
Áp dụng / đọc code

4. Nhóm cần làm firmware cho robot. Vì sao C++ là lựa chọn liên quan nội dung bài?

A. Vì C++ là định dạng ảnh B. Vì không cần quan tâm công cụ chạy C. Vì robot chỉ đọc HTML D. Bài liệt kê C++ cho hệ thống nhúng và robot
Giải thích đáp án
  • A. Sai: Bài mô tả ngôn ngữ lập trình.
  • B. Sai: Quy trình biên dịch vẫn cần công cụ.
  • C. Sai: Không phải nội dung được bài nêu.
  • D. Đúng: tình huống khớp nhóm ứng dụng đó.
Tìm lỗi

5. Bạn sửa mã nguồn nhưng chạy lại bản thực thi cũ. Bước còn thiếu theo bài là gì?

A. Chỉ đổi màu trình soạn thảo B. Biên dịch lại mã nguồn C. Đổi tên ngôn ngữ sang Python D. Xóa mọi đoạn nguồn
Giải thích đáp án
  • A. Sai: Không tạo bản thực thi mới.
  • B. Đúng: sửa nguồn cần cập nhật chương trình biên dịch.
  • C. Sai: Không cần đổi ngôn ngữ để cập nhật mã.
  • D. Sai: Xóa nguồn không tạo phiên bản chương trình mới.
