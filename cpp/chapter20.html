Function Template

Viết một hàm duy nhất hoạt động với nhiều kiểu dữ liệu khác nhau — tránh lặp code cho từng kiểu.

Viết một hàm duy nhất hoạt động với nhiều kiểu dữ liệu khác nhau — tránh lặp code cho từng kiểu.

function_template.cpp 
template <typename T>         // T là kiểu tổng quát, "typename" có thể thay bằng "class"
T timMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << timMax(3, 7) << endl;           // T tự suy luận là int -> 7
    cout << timMax(3.5, 2.1) << endl;         // T tự suy luận là double -> 3.5
    cout << timMax<string>("abc", "abd") << endl;   // chỉ định T tường minh -> "abd"
}
Ghi chú
Trình biên dịch tự động sinh ra một phiên bản hàm riêng cho MỖI kiểu dữ liệu được dùng (gọi là "template instantiation") — nghĩa là timMax(3, 7) và timMax(3.5, 2.1) thực chất biên dịch thành hai hàm máy hoàn toàn khác nhau.

📌 Tổng kết chương 20

Function template dùng template <typename T> để viết một hàm hoạt động với nhiều kiểu dữ liệu, trình biên dịch tự sinh phiên bản cụ thể cho từng kiểu được dùng.
