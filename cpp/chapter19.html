Chương 19 — Smart Pointers

Con trỏ thông minh (C++11+) tự động giải phóng bộ nhớ — giải pháp hiện đại thay thế new/delete thủ công.

smart_pointers.cpp 
#include <memory>

void vi_du_unique_ptr() {
    unique_ptr<int> p = make_unique<int>(10);   // TỰ ĐỘNG delete khi ra khỏi phạm vi hàm
    cout << *p << endl;
    // KHÔNG cần gọi delete - unique_ptr tự lo việc đó!
}   // p tự động được giải phóng tại đây

void vi_du_shared_ptr() {
    shared_ptr<int> p1 = make_shared<int>(20);
    shared_ptr<int> p2 = p1;                       // CÙNG chia sẻ quyền sở hữu, đếm tham chiếu tăng lên 2
    cout << p1.use_count() << endl;                  // 2 - số lượng shared_ptr đang trỏ tới cùng dữ liệu
}   // bộ nhớ chỉ được giải phóng khi CẢ p1 và p2 đều ra khỏi phạm vi
LoạiĐặc điểm
unique_ptrCHỈ MỘT con trỏ sở hữu tài nguyên, không thể sao chép, chỉ có thể "move"
shared_ptrNHIỀU con trỏ có thể cùng sở hữu, tự đếm tham chiếu, giải phóng khi về 0
weak_ptrTham chiếu tới shared_ptr mà KHÔNG tăng đếm tham chiếu, tránh circular reference
Mẹo — C++ hiện đại
Nguyên tắc vàng của C++ hiện đại (C++11 trở lên): hầu như không bao giờ dùng new/delete trực tiếp nữa — luôn ưu tiên unique_ptr (mặc định) hoặc shared_ptr (khi thực sự cần chia sẻ sở hữu) để tránh hoàn toàn memory leak.

📌 Tổng kết chương 19

Smart pointer (unique_ptr, shared_ptr) tự động quản lý vòng đời bộ nhớ, gần như loại bỏ hoàn toàn memory leak — là chuẩn mực bắt buộc trong C++ hiện đại.
