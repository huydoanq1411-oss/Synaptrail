Chương 2 — Cài đặt trình biên dịch

Chuẩn bị môi trường biên dịch và soạn thảo trước khi viết dòng code đầu tiên.

Bước 1: Cài đặt trình biên dịch (compiler)

Hệ điều hànhTrình biên dịch khuyến nghị
WindowsMinGW-w64 (GCC cho Windows) hoặc Visual Studio
macOSClang (cài qua Xcode Command Line Tools)
LinuxGCC (thường có sẵn, hoặc sudo apt install g++)

Bước 2: Kiểm tra cài đặt

terminal 
g++ --version
# Kết quả mong đợi: g++ (GCC) 14.x hoặc 15.x trở lên
Ghi chú — Chuẩn C++ hiện hành
Giáo trình này dùng C++11 trở lên làm nền tảng (đủ cho hầu hết công việc thực tế). Chuẩn mới nhất đã CHÍNH THỨC ban hành là C++23 (2024) — được GCC 11+ hỗ trợ khá đầy đủ; C++26 hiện đang trong giai đoạn hoàn thiện, dự kiến ban hành chính thức năm 2026. Muốn biên dịch theo một chuẩn cụ thể, thêm cờ: g++ -std=c++23 chuong_trinh.cpp.

Bước 3: Chọn công cụ soạn thảo

VS Code với extension "C/C++" (Microsoft) là lựa chọn phổ biến nhất — nhẹ, miễn phí, hỗ trợ debug và IntelliSense tốt.

Cảnh báo
Trên Windows, nếu gõ g++ báo "not recognized", cần thêm đường dẫn thư mục bin của MinGW vào biến môi trường PATH của hệ thống.

📌 Tổng kết chương 2

Cần cài trình biên dịch (GCC/Clang/MSVC) và một IDE như VS Code. Luôn kiểm tra bằng lệnh g++ --version trước khi bắt đầu.

Quiz — Chương 2 · 5 câu

Nhớ khái niệm

1. Để biên dịch mã C++, cần thành phần nào?

A. Trình biên dịch như GCC, Clang hoặc MSVC B. Chỉ theme của VS Code C. Chỉ trình duyệt D. Chỉ file ảnh
Giải thích đáp án
  • A. Đúng: các compiler này được bài liệt kê.
  • B. Sai: Theme không biên dịch mã.
  • C. Sai: Trình duyệt không thay compiler trong bài.
  • D. Sai: File ảnh không phải công cụ phát triển.
Nhớ khái niệm

2. Lệnh nào kiểm tra bản cài g++?

A. g++ hello.exe B. java -version C. g++ --version D. g++ --theme
Giải thích đáp án
  • A. Sai: Đây không phải lệnh kiểm tra phiên bản trong bài.
  • B. Sai: Lệnh này kiểm tra Java, không phải g++.
  • C. Đúng: bài dùng lệnh này để kiểm tra.
  • D. Sai: Không phải tùy chọn kiểm tra phiên bản.
Áp dụng / đọc code

3. Theo bảng trong bài, môi trường nào đi với Clang qua Xcode Command Line Tools?

A. Chỉ Windows với MinGW B. macOS C. Mọi trang web không cần cài gì D. Chỉ Java runtime
Giải thích đáp án
  • A. Sai: Bảng gắn Windows với MinGW/MSVC.
  • B. Đúng: bảng gắn macOS với Clang/Xcode tools.
  • C. Sai: Bảng đang nói về công cụ trên máy.
  • D. Sai: Java runtime không phải môi trường này.
Áp dụng / đọc code

4. Muốn chọn chuẩn C++23 theo cú pháp đã nêu, chọn lệnh nào?

A. g++ --version=c++23 chuong_trinh.cpp B. g++ chuong_trinh.cpp -theme=c++23 C. java -std=c++23 chuong_trinh.cpp D. g++ -std=c++23 chuong_trinh.cpp
Giải thích đáp án
  • A. Sai: --version không phải cách chọn chuẩn ở bài.
  • B. Sai: Theme không chọn chuẩn biên dịch.
  • C. Sai: Bài dùng compiler C++, không dùng java.
  • D. Đúng: cờ chọn chuẩn được bài minh họa.
Tìm lỗi

5. Trên Windows, g++ báo “not recognized” dù MinGW đã có. Cần kiểm tra gì?

A. Thư mục bin của MinGW trong PATH B. Mọi dấu chấm phẩy trong chương trình C. Màu biểu tượng IDE D. Tên biến trong Java
Giải thích đáp án
  • A. Đúng: bài nêu bổ sung/kiểm tra đường dẫn này.
  • B. Sai: Lệnh chưa được tìm thấy, chưa đến bước biên dịch nguồn.
  • C. Sai: Màu không ảnh hưởng việc tìm lệnh.
  • D. Sai: Không liên quan công cụ C++.
