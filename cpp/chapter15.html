Chương 15 — Toán tử Overloading

Định nghĩa lại ý nghĩa của toán tử (+, -, ==...) khi áp dụng lên object tự định nghĩa.

operator_overload.cpp 
class DiemSo {
public:
    int x, y;
    DiemSo(int x, int y) : x(x), y(y) {}

    DiemSo operator+(const DiemSo& khac) {    // định nghĩa lại ý nghĩa của dấu +
        return DiemSo(x + khac.x, y + khac.y);
    }

    bool operator==(const DiemSo& khac) {       // định nghĩa lại ý nghĩa của ==
        return x == khac.x && y == khac.y;
    }

    friend ostream& operator<<(ostream& os, const DiemSo& d) {   // cho phép cout << object
        os << "(" << d.x << ", " << d.y << ")";
        return os;
    }
};

int main() {
    DiemSo a(1, 2), b(3, 4);
    DiemSo c = a + b;         // gọi operator+ đã định nghĩa
    cout << c << endl;          // (4, 6) - nhờ operator<< đã định nghĩa
    cout << (a == b) << endl;    // 0 (false)
}
Mẹo
Chỉ nên overload toán tử khi ý nghĩa mới thực sự trực quan (VD: cộng hai vector, hai phân số) — lạm dụng overload cho các thao tác không liên quan tới ý nghĩa gốc của toán tử sẽ làm code khó hiểu.

📌 Tổng kết chương 15

Operator overloading cho phép object tự định nghĩa hoạt động tự nhiên với các toán tử chuẩn (+, ==, <<...), giúp code trực quan hơn khi làm việc với kiểu dữ liệu tự tạo.
