Exception Handling (try/catch)

Cơ chế xử lý lỗi runtime bằng try-catch-throw, giúp chương trình không crash đột ngột.

Cơ chế xử lý lỗi runtime bằng try-catch-throw, giúp chương trình không crash đột ngột.

exception_basic.cpp 
#include <stdexcept>

double chia(double a, double b) {
    if (b == 0) {
        throw invalid_argument("Không thể chia cho 0!");   // ném ra exception có sẵn của thư viện chuẩn
    }
    return a / b;
}

int main() {
    try {
        cout << chia(10, 0) << endl;
    } catch (const invalid_argument& e) {         // bắt CHÍNH XÁC loại exception đó
        cout << "Lỗi: " << e.what() << endl;         // .what() lấy thông báo lỗi
    } catch (const exception& e) {                    // bắt các exception khác (nếu có)
        cout << "Lỗi khác: " << e.what() << endl;
    }
    cout << "Chương trình tiếp tục chạy bình thường" << endl;
}

Custom Exception

custom_exception.cpp 
class SoDuKhongDuException : public exception {    // kế thừa từ exception chuẩn
private:
    string thongBao;
public:
    SoDuKhongDuException(string msg) : thongBao(msg) {}
    const char* what() const noexcept override {      // override phương thức what()
        return thongBao.c_str();
    }
};

void rutTien(double soDu, double soTien) {
    if (soTien > soDu) {
        throw SoDuKhongDuException("Số dư không đủ!");
    }
}
Quan trọng
Không giống Java, C++ không bắt buộc phải khai báo hoặc bắt exception (không có "checked exception"). Nếu một exception được throw mà không có catch nào bắt được, chương trình sẽ gọi terminate() và crash ngay lập tức.

📌 Tổng kết chương 22

try/catch/throw xử lý lỗi runtime. Custom exception kế thừa từ std::exception và override what(). C++ không bắt buộc xử lý exception như Java.
