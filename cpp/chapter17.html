Cấu trúc dữ liệu key-value và tập hợp không trùng lặp, tự động sắp xếp theo key.

map_basic.cpp 
#include <map>
#include <unordered_map>

map<string, int> diem;         // map - TỰ ĐỘNG sắp xếp theo key
diem["Huy"] = 85;
diem["Lan"] = 92;

for (auto& cap : diem) {           // "auto" tự suy luận kiểu dữ liệu
    cout << cap.first << ": " << cap.second << endl;
}

if (diem.find("Huy") != diem.end()) {    // kiểm tra key có tồn tại
    cout << "Tìm thấy Huy: " << diem["Huy"] << endl;
}

unordered_map<string, int> diemNhanh;    // KHÔNG sắp xếp nhưng NHANH HƠN map (hash table)
diemNhanh["Nam"] = 78;
set_basic.cpp 
#include <set>

set<int> ds = {5, 2, 8, 2, 1};   // tự động loại trùng lặp VÀ sắp xếp
for (int x : ds) cout << x << " ";    // 1 2 5 8

ds.insert(3);
ds.erase(2);
cout << (ds.count(5) > 0) << endl;   // kiểm tra tồn tại
Cấu trúcĐặc điểmĐộ phức tạp truy cập
mapKey-value, tự sắp xếp theo keyO(log n)
unordered_mapKey-value, KHÔNG sắp xếp (hash table)O(1) trung bình
setTập hợp duy nhất, tự sắp xếpO(log n)
Mẹo
Nếu không cần dữ liệu được sắp xếp, ưu tiên unordered_map/unordered_set vì nhanh hơn map/set thông thường — chỉ dùng bản có thứ tự khi thực sự cần duyệt theo key đã sắp xếp.

📌 Tổng kết chương 17

map/set tự sắp xếp theo key với O(log n), unordered_map/unordered_set nhanh hơn (O(1) trung bình) nhưng không có thứ tự — chọn tùy theo nhu cầu bài toán.
