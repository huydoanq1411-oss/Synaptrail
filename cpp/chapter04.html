Chương 4 — Biến & Kiểu dữ liệu

C++ yêu cầu khai báo kiểu dữ liệu tường minh (static typing) — khác biệt lớn so với Python.

bien.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    int tuoi = 20;                 // số nguyên
    double diem_tb = 8.5;            // số thực (độ chính xác cao)
    float chieu_cao = 1.75f;           // số thực (độ chính xác thấp hơn double)
    char ky_tu = 'A';                    // một ký tự duy nhất
    bool dang_hoc = true;                 // đúng/sai
    string ten = "Huy";                     // chuỗi (cần #include <string>)

    cout << ten << " " << tuoi << " " << diem_tb << endl;
    return 0;
}

Quan trọng — Static Typing
Khác với Python, C++ yêu cầu khai báo kiểu tường minh và không thể đổi kiểu của biến sau khi khai báo — int x = 5; thì x mãi mãi là số nguyên. Đây gọi là "static typing", giúp trình biên dịch phát hiện lỗi sớm hơn Python.

Hằng số (const)

const.cpp 
const double PI = 3.14159;   // const = giá trị không thể thay đổi sau khi gán
// PI = 3.14;                  // LỖI biên dịch nếu bỏ comment dòng này

Quiz — Chương 4 · 5 câu

Nhớ khái niệm

1. Static typing được chương mô tả như thế nào?

A. Kiểu của biến được xác định khi khai báo B. Biến luôn tự đổi kiểu theo mọi giá trị mới C. Không được khai báo biến D. Mọi biến đều là string
Giải thích đáp án
  • A. Đúng: ví dụ int x giữ kiểu int.
  • B. Sai: Đây không phải cách bài giải thích.
  • C. Sai: Bài có nhiều khai báo biến.
  • D. Sai: Bài liệt kê int, double, bool và các kiểu khác.
Nhớ khái niệm

2. const trong ví dụ có ý nghĩa gì?

A. Biến luôn tăng một B. Chỉ cho phép chuỗi C. Không được thay đổi giá trị sau khởi tạo D. Luôn làm giá trị bằng 0
Giải thích đáp án
  • A. Sai: Đây là hành vi của ++, không phải const.
  • B. Sai: PI trong bài là double.
  • C. Đúng: phép gán lại PI được đánh dấu lỗi.
  • D. Sai: Ví dụ PI khởi tạo 3.14159.
Áp dụng / đọc code

3. Dòng xuất tương ứng ví dụ bien.cpp cho nội dung nào?

string ten = "Huy";
int tuoi = 20;
double diem_tb = 8.5;
cout << ten << " " << tuoi << " " << diem_tb;
A. 20 Huy 8.5 B. Huy 20 8.5 C. Huy208.5 D. ten tuoi diem_tb
Giải thích đáp án
  • A. Sai: Thứ tự trong biểu thức bắt đầu bằng ten.
  • B. Đúng: các giá trị được xuất theo thứ tự với khoảng trắng.
  • C. Sai: Có khoảng trắng được xuất giữa các giá trị.
  • D. Sai: cout dùng giá trị biến, không in tên biến.
Áp dụng / đọc code

4. Cần lưu đúng/sai như dang_hoc trong ví dụ. Chọn khai báo nào?

A. char dang_hoc = 'A'; B. string dang_hoc = "true"; C. double dang_hoc = 8.5; D. bool dang_hoc = true;
Giải thích đáp án
  • A. Sai: char ở đây lưu ký tự.
  • B. Sai: Đây là chuỗi chữ, không phải bool.
  • C. Sai: Đây là số thực.
  • D. Đúng: bool biểu diễn giá trị logic trong mẫu.
Tìm lỗi

5. Nếu bỏ comment ở dòng thứ hai, lỗi nào xảy ra?

const double PI = 3.14159;
PI = 3.14;
A. Gán lại một hằng const B. PI chưa được khai báo C. double không nhận số thực D. Hai giá trị giống nhau nên lỗi
Giải thích đáp án
  • A. Đúng: PI không được thay đổi sau khởi tạo.
  • B. Sai: PI đã khai báo ở dòng đầu.
  • C. Sai: double được dùng chính cho số thực.
  • D. Sai: Lỗi do const, không do việc so sánh hai giá trị.

📌 Tổng kết chương 4

C++ là ngôn ngữ static typing — mọi biến phải khai báo kiểu tường minh và không thể đổi kiểu sau đó. const tạo hằng số không thể thay đổi.
