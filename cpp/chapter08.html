08 Vòng lặp

for, while và do-while — ba dạng vòng lặp trong C++.

vong_lap.cpp 
// for - biết trước số lần lặp
for (int i = 0; i < 5; i++) {
    cout << i << " ";
}   // 0 1 2 3 4

// while - lặp khi điều kiện còn đúng
int dem = 0;
while (dem < 5) {
    cout << dem << " ";
    dem++;
}

// do-while - LUÔN chạy ít nhất 1 lần trước khi kiểm tra điều kiện
int x = 10;
do {
    cout << "Chạy ít nhất 1 lần" << endl;
} while (x < 5);   // điều kiện sai ngay từ đầu nhưng vẫn chạy 1 lần

Vòng lặp for kiểu range-based (C++11+)

range_for.cpp 
int mang[] = {10, 20, 30, 40};
for (int gia_tri : mang) {     // duyệt trực tiếp qua từng phần tử, giống Python "for x in list"
    cout << gia_tri << " ";
}
Mẹo
do-while hữu ích khi bạn cần chạy khối lệnh ít nhất một lần trước khi kiểm tra điều kiện — ví dụ hiện menu và chờ người dùng chọn.

📌 Tổng kết chương 8

for phù hợp khi biết trước số lần lặp, while khi lặp theo điều kiện, do-while đảm bảo chạy ít nhất 1 lần. Range-based for (C++11+) giúp duyệt mảng ngắn gọn hơn.
