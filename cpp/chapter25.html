STL Algorithms (sort, find, count...)

Thư viện <algorithm> cung cấp sẵn các thuật toán đã tối ưu — nên dùng thay vì tự viết lại.

Thư viện <algorithm> cung cấp sẵn các thuật toán đã tối ưu — nên dùng thay vì tự viết lại.

algorithm_basic.cpp 
#include <algorithm>
#include <vector>

vector<int> ds = {5, 2, 8, 1, 9, 2};

sort(ds.begin(), ds.end());                          // sắp xếp tăng dần - O(n log n)
reverse(ds.begin(), ds.end());                          // đảo ngược thứ tự

auto it = find(ds.begin(), ds.end(), 8);                 // tìm phần tử -> trả về iterator
if (it != ds.end()) cout << "Tìm thấy tại vị trí: " << (it - ds.begin()) << endl;

int demSo2 = count(ds.begin(), ds.end(), 2);               // đếm số lần xuất hiện của 2
int tong = accumulate(ds.begin(), ds.end(), 0);              // tính tổng (cần #include <numeric>)
int lonNhat = *max_element(ds.begin(), ds.end());              // phần tử lớn nhất

bool coTrung = binary_search(ds.begin(), ds.end(), 5);         // tìm kiếm nhị phân (CẦN đã sort trước)
HàmCông dụngĐộ phức tạp
sortSắp xếpO(n log n)
findTìm tuyến tínhO(n)
binary_searchTìm nhị phân (cần dữ liệu đã sort)O(log n)
accumulateTính tổng/gộp giá trịO(n)
Mẹo
Luôn ưu tiên dùng thuật toán STL có sẵn thay vì tự viết vòng lặp thủ công — chúng đã được tối ưu kỹ lưỡng, code ngắn gọn hơn, và giảm khả năng có lỗi tự tạo ra.
