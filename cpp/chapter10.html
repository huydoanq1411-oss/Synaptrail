Chương 10 — Hàm (Function)

Khối lệnh có tên, tái sử dụng được — yêu cầu khai báo kiểu trả về và kiểu tham số tường minh.

function.cpp 
#include <iostream>
using namespace std;

int cong(int a, int b) {      // kiểu trả về (int) PHẢI khai báo tường minh
    return a + b;
}

void chao_hoi(string ten) {     // void = hàm không trả về giá trị gì
    cout << "Xin chào " << ten << endl;
}

int giai_thua(int n) {           // đệ quy vẫn hoạt động như các ngôn ngữ khác
    if (n <= 1) return 1;
    return n * giai_thua(n - 1);
}

int main() {
    cout << cong(3, 5) << endl;     // 8
    chao_hoi("Huy");
    cout << giai_thua(5) << endl;      // 120
    return 0;
}

Tham số mặc định và truyền tham chiếu

function_advanced.cpp 
void gioi_thieu(string ten, int tuoi = 18) {   // tuoi có giá trị mặc định
    cout << ten << ", " << tuoi << " tuổi" << endl;
}

void tang_gap_doi(int &n) {      // & = truyền theo tham chiếu, SỬA được biến gốc
    n = n * 2;
}

int main() {
    gioi_thieu("Lan");    // Lan, 18 tuổi (dùng mặc định)

    int x = 5;
    tang_gap_doi(x);
    cout << x << endl;   // 10 - x đã bị thay đổi vì truyền tham chiếu
}
Quan trọng
Mặc định, C++ truyền tham số theo giá trị (pass by value) — hàm nhận bản sao, sửa bên trong hàm KHÔNG ảnh hưởng biến gốc. Muốn sửa được biến gốc, phải truyền theo tham chiếu bằng dấu & (sẽ học kỹ ở chương 11).

📌 Tổng kết chương 10

Hàm C++ yêu cầu khai báo kiểu trả về tường minh (void nếu không trả về gì). Mặc định truyền theo giá trị; dùng & để truyền theo tham chiếu khi cần sửa biến gốc.
