Điều kiện (if/switch)

Câu lệnh rẽ nhánh chương trình dựa trên điều kiện.

Câu lệnh rẽ nhánh chương trình dựa trên điều kiện.

if_else.cpp 
int diem = 8;

if (diem >= 8) {
    cout << "Giỏi" << endl;
} else if (diem >= 6.5) {
    cout << "Khá" << endl;
} else {
    cout << "Cần cố gắng" << endl;
}

switch — rẽ nhánh nhiều trường hợp

switch.cpp 
int thu = 3;
switch (thu) {
    case 1:
        cout << "Thứ Hai"; break;      // BẮT BUỘC có break, nếu không sẽ "rơi" xuống case dưới
    case 2:
        cout << "Thứ Ba"; break;
    case 3:
        cout << "Thứ Tư"; break;
    default:
        cout << "Ngày khác";
}
Lỗi thường gặp — quên break
Nếu quên break trong mỗi case, chương trình sẽ tiếp tục thực thi các case tiếp theo (gọi là "fall-through") thay vì dừng lại — đây là lỗi rất phổ biến với người mới học C++.

if/else if/else dùng cho điều kiện tổng quát, switch phù hợp khi so sánh một biến với nhiều giá trị cụ thể — luôn nhớ break trong mỗi case.
