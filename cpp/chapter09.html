Mảng (Array)

Tập hợp các phần tử cùng kiểu dữ liệu, kích thước cố định, lưu liên tục trong bộ nhớ.

Tập hợp các phần tử cùng kiểu dữ liệu, kích thước cố định, lưu liên tục trong bộ nhớ.

array.cpp 
int diem[5] = {90, 85, 78, 92, 88};   // mảng 5 phần tử, kích thước CỐ ĐỊNH

cout << diem[0] << endl;        // 90 - truy cập theo chỉ số, bắt đầu từ 0
diem[1] = 100;                       // gán lại giá trị

int tong = 0;
for (int i = 0; i < 5; i++) {
    tong += diem[i];
}
cout << "Tổng: " << tong << endl;

// Mảng 2 chiều (ma trận)
int ma_tran[2][3] = {{1,2,3}, {4,5,6}};
cout << ma_tran[1][2] << endl;   // 6
Quan trọng
Mảng trong C++ (kiểu C-style array) có kích thước cố định tại thời điểm biên dịch và không tự kiểm tra tràn chỉ số — truy cập diem[10] trên mảng 5 phần tử sẽ gây lỗi khó lường (undefined behavior) thay vì báo lỗi rõ ràng như Python.
Mẹo
Trong thực tế hiện đại, nên ưu tiên dùng std::vector (mảng động, tự động thay đổi kích thước, thuộc STL) thay vì mảng C-style — sẽ học chi tiết ở phần STL sắp tới.

📌 Tổng kết chương 9

Mảng C++ có kích thước cố định, truy cập nhanh theo chỉ số nhưng không tự kiểm tra tràn biên — cần cẩn thận khi thao tác, hoặc dùng std::vector an toàn hơn.
