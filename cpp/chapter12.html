Nền tảng lập trình hướng đối tượng trong C++ — class là khuôn mẫu, object là thực thể.

class_basic.cpp 
#include <iostream>
using namespace std;

class SinhVien {
private:                       // chỉ truy cập được từ bên trong class (encapsulation)
    string ten;
    int tuoi;

public:                        // truy cập được từ bên ngoài
    SinhVien(string t, int tu) {   // constructor - tự chạy khi tạo object
        ten = t;
        tuoi = tu;
    }

    void gioi_thieu() {           // phương thức (method)
        cout << "Tôi tên " << ten << ", " << tuoi << " tuổi" << endl;
    }

    int lay_tuoi() {              // getter - đọc thuộc tính private
        return tuoi;
    }
};

int main() {
    SinhVien sv1("Huy", 20);    // tạo object, tự động gọi constructor
    sv1.gioi_thieu();             // Tôi tên Huy, 20 tuổi
    cout << sv1.lay_tuoi() << endl;   // 20
    return 0;
}
Từ khóaÝ nghĩa
privateThuộc tính/phương thức chỉ dùng được bên trong class
publicTruy cập được từ bên ngoài class
protectedTruy cập được từ class con (kế thừa) nhưng không từ bên ngoài
Mẹo
Nguyên tắc chuẩn: luôn để thuộc tính là private và cung cấp phương thức public (getter/setter) để truy cập có kiểm soát — đây là nguyên tắc Encapsulation, sẽ được học sâu hơn ở phần OOP nâng cao.

📌 Tổng kết chương 12

Class định nghĩa thuộc tính (private) và phương thức (public), constructor tự chạy khi tạo object. Đây là nền tảng để học OOP nâng cao (kế thừa, đa hình) ở phần tiếp theo.
