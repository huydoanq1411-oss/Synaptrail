Chương 13 — Kế thừa (Inheritance)

Class con kế thừa thuộc tính và phương thức từ class cha, tái sử dụng code.

inheritance.cpp 
class DongVat {
protected:                          // protected = truy cập được từ class con, KHÔNG từ bên ngoài
    string ten;
public:
    DongVat(string t) : ten(t) {}     // initializer list - cách khởi tạo thuộc tính hiệu quả hơn gán trong thân hàm
    void an() {
        cout << ten << " đang ăn" << endl;
    }
};

class Cho : public DongVat {          // Cho KẾ THỪA public từ DongVat
public:
    Cho(string t) : DongVat(t) {}       // gọi constructor của lớp cha
    void sua() {
        cout << ten << " sủa: Gâu gâu!" << endl;   // dùng được "ten" vì nó protected
    }
};

int main() {
    Cho cho("Milu");
    cho.an();     // kế thừa từ DongVat
    cho.sua();      // riêng của Cho
}
Kiểu kế thừaÝ nghĩa
publicThành viên public/protected của cha giữ nguyên mức truy cập ở con (phổ biến nhất)
protectedThành viên public của cha trở thành protected ở con
privateMọi thành viên kế thừa đều trở thành private ở con (hiếm dùng)

📌 Tổng kết chương 13

Kế thừa public là phổ biến nhất. protected cho phép class con truy cập thuộc tính cha mà vẫn ẩn với bên ngoài. Initializer list là cách khởi tạo thuộc tính chuẩn và hiệu quả trong C++.
