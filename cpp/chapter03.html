Chương 3 — Chương trình đầu tiên

Viết, biên dịch và chạy "Hello, World!" — hiểu cấu trúc cơ bản của một file .cpp.

hello.cpp 
#include <iostream>      // thư viện nhập/xuất chuẩn

int main() {                  // hàm main - điểm bắt đầu BẮT BUỘC của mọi chương trình C++
    std::cout << "Hello, World!" << std::endl;
    return 0;                   // trả về 0 nghĩa là chương trình chạy thành công
}

Biên dịch và chạy

terminal 
g++ hello.cpp -o hello     # biên dịch file .cpp thành file thực thi "hello"
./hello                       # chạy file thực thi (Linux/macOS)
hello.exe                       # chạy trên Windows

Giải thích từng phần

Thành phầnÝ nghĩa
#include <iostream>Nhúng thư viện xử lý nhập/xuất chuẩn (cin, cout)
int main()Hàm chính, nơi chương trình bắt đầu thực thi
std::coutĐối tượng xuất dữ liệu ra màn hình (thuộc namespace std)
return 0;Kết thúc hàm main, báo hiệu chạy thành công
Quan trọng
Mọi chương trình C++ đều bắt buộc phải có hàm main() — đây là điểm khởi đầu duy nhất mà hệ điều hành gọi tới khi chạy chương trình.

📌 Tổng kết chương 3

Chương trình C++ cần #include để nhúng thư viện, hàm main() bắt buộc, và phải biên dịch (g++) trước khi chạy được, khác với Python chạy trực tiếp.

Nhớ khái niệm

1. Trong ví dụ hello.cpp, main đóng vai trò gì?

A. Lưu chuỗi đầu ra B. Chọn màu terminal C. Điểm bắt đầu của chương trình D. Thay thế file mã nguồn
Giải thích đáp án
  • A. Sai: Chuỗi nằm trong lệnh cout.
  • B. Sai: Ví dụ không có chức năng này.
  • C. Đúng: bài giải thích main như điểm vào.
  • D. Sai: main là hàm trong nguồn, không thay file.
Nhớ khái niệm

2. Trong ví dụ, return 0 biểu thị điều gì?

A. Chắc chắn in số 0 B. Kết thúc main với mã thành công C. Lặp main vô hạn D. Bắt đầu biên dịch
Giải thích đáp án
  • A. Sai: return không phải lệnh cout.
  • B. Đúng: đây là ý nghĩa trong bài.
  • C. Sai: Lệnh kết thúc hàm, không tạo vòng lặp.
  • D. Sai: Biên dịch diễn ra trước khi chạy.
Áp dụng / đọc code

3. Đoạn xuất dưới đây in gì?

std::cout << "Hello, World!" << std::endl;
A. Hello, World! rồi xuống dòng B. std::cout C. Hello, World!0 D. Không có nội dung nào
Giải thích đáp án
  • A. Đúng: cout in chuỗi và endl xuống dòng.
  • B. Sai: Tên đối tượng không phải chuỗi được in.
  • C. Sai: return 0 không thêm vào đầu ra.
  • D. Sai: Lệnh cout thực hiện xuất.
Áp dụng / đọc code

4. Lệnh g++ hello.cpp -o hello tạo đầu ra nào theo bài?

A. Chỉ file HTML B. Mã Java trong hello.java C. Chỉ thay tên nguồn thành hello D. File thực thi mang tên hello theo môi trường
Giải thích đáp án
  • A. Sai: Đó không phải đầu ra của quy trình này.
  • B. Sai: Bài không chuyển C++ sang Java.
  • C. Sai: Compiler không đơn thuần đổi tên nguồn.
  • D. Đúng: -o đặt tên đầu ra biên dịch.
Tìm lỗi

5. Đã dùng cout/endl trong mẫu nhưng quên include thư viện được bài yêu cầu. Cần thêm gì?

A. #include <string> thay mọi thư viện B. #include <iostream> C. Xóa hàm main D. Đổi return 0 thành cout
Giải thích đáp án
  • A. Sai: string không phải header được mẫu này chỉ định.
  • B. Đúng: header nhập/xuất chuẩn trong hello.cpp.
  • C. Sai: Xóa điểm vào không bổ sung thư viện.
  • D. Sai: Không sửa việc thiếu include.
