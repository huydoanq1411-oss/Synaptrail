Class Template

Tương tự function template nhưng áp dụng cho toàn bộ class — chính là cách STL (vector, map...) được xây dựng.

Tương tự function template nhưng áp dụng cho toàn bộ class — chính là cách STL (vector, map...) được xây dựng.

class_template.cpp 
template <typename T>
class Hop {
private:
    T noiDung;
public:
    Hop(T noiDung) : noiDung(noiDung) {}

    T layNoiDung() {
        return noiDung;
    }

    void datNoiDung(T giaTri) {
        noiDung = giaTri;
    }
};

int main() {
    Hop<int> hopSo(42);              // T = int
    Hop<string> hopChuoi("Xin chào");   // T = string

    cout << hopSo.layNoiDung() << endl;       // 42
    cout << hopChuoi.layNoiDung() << endl;      // Xin chào
}

Template với nhiều kiểu tham số

multi_type_template.cpp 
template <typename K, typename V>
class CapKeyValue {
public:
    K key;
    V value;
    CapKeyValue(K k, V v) : key(k), value(v) {}
};

CapKeyValue<string, int> diem("Huy", 85);   // K=string, V=int
Mẹo
vector<T>, map<K,V> mà bạn đã học ở STL (chương 16-17) chính là class template — hiểu class template giúp bạn hiểu rõ hơn cách các cấu trúc dữ liệu chuẩn của C++ hoạt động bên dưới.

📌 Tổng kết chương 21

Class template cho phép định nghĩa class hoạt động với nhiều kiểu dữ liệu, có thể có nhiều tham số kiểu (K, V...) — nền tảng xây dựng nên các container của STL.
