Chương 5 — Toán tử

Các phép toán số học, so sánh, logic quen thuộc — tương tự C++ vì Java kế thừa cú pháp từ C.

toan_tu.java 
int a = 10, b = 3;
System.out.println(a / b);         // 3 - chia số nguyên làm tròn xuống
System.out.println(a % b);           // 1 - chia lấy dư
System.out.println((double) a / b);    // 3.333... - ép kiểu để có kết quả thực

boolean ketQua = (a > 5) && (b < 5);   // && và || cho logic
System.out.println(ketQua);              // true

int dem = 0;
dem++;         // hậu tố tăng
++dem;          // tiền tố tăng
System.out.println(dem);   // 2

So sánh String — lỗi kinh điển với người mới

so_sanh_string.java 
String s1 = new String("hello");
String s2 = new String("hello");

System.out.println(s1 == s2);          // false! == so sánh ĐỊA CHỈ, không phải nội dung
System.out.println(s1.equals(s2));       // true - .equals() so sánh NỘI DUNG
Quan trọng — Lỗi kinh điển
Với kiểu tham chiếu như String, toán tử == so sánh địa chỉ bộ nhớ, không phải nội dung. Luôn dùng .equals() để so sánh nội dung chuỗi — đây là một trong những lỗi phổ biến nhất của người mới học Java.

📌 Tổng kết chương 5

Toán tử số học/logic của Java tương tự C++. Lưu ý đặc biệt: dùng .equals() chứ không dùng == để so sánh nội dung String.

Nhớ khái niệm

1. Toán tử % trong ví dụ dùng để làm gì?

A. Lấy phần dư B. Lấy thương thực C. Nối mọi chuỗi D. So sánh nội dung String
Giải thích đáp án
  • A. Đúng: 10 % 3 cho 1.
  • B. Sai: Phép chia thực cần / với toán hạng phù hợp.
  • C. Sai: Ví dụ nối chuỗi dùng +.
  • D. Sai: Bài dùng equals để so nội dung.
Nhớ khái niệm

2. Muốn so sánh nội dung hai String theo bài, chọn cách nào?

A. Chỉ dùng == B. Dùng % C. Dùng equals D. Dùng ++
Giải thích đáp án
  • A. Sai: Ví dụ == so tham chiếu, không so nội dung.
  • B. Sai: % phục vụ số học, không so chuỗi.
  • C. Đúng: equals so nội dung String trong ví dụ.
  • D. Sai: ++ là tăng giá trị số.
Áp dụng / đọc code

3. Hai dòng in dưới đây cho kết quả nào?

int a = 10, b = 3;
System.out.println(a / b);
System.out.println(a % b);
A. 3.333… rồi 1 B. 3 rồi 1 C. 1 rồi 3 D. 3 rồi 0
Giải thích đáp án
  • A. Sai: a/b với hai int cho thương nguyên.
  • B. Đúng: 10/3 là 3 và dư 1.
  • C. Sai: Đã đảo thương và phần dư.
  • D. Sai: 10 không chia hết cho 3.
Áp dụng / đọc code

4. Biến ketQua có giá trị gì?

int a = 10, b = 3;
boolean ketQua = (a > 5) && (b < 5);
A. false vì a lớn hơn b B. 10 C. 3 D. true
Giải thích đáp án
  • A. Sai: Biểu thức không kiểm tra a lớn hơn b.
  • B. Sai: Kết quả khai báo boolean, không phải a.
  • C. Sai: Không trả trực tiếp giá trị b.
  • D. Đúng: cả a>5 và b<5 đều đúng.
Tìm lỗi

5. Hai new String("hello") có cùng nội dung. Vì sao kiểm tra s1 == s2 không đạt mục tiêu?

A. == so tham chiếu; cần s1.equals(s2) để so nội dung B. Chuỗi phải viết hoa mới so được C. Cần đổi String thành int D. == luôn đúng cho mọi String
Giải thích đáp án
  • A. Đúng: hai đối tượng mới không có cùng tham chiếu.
  • B. Sai: Chữ hoa không sửa cách so tham chiếu.
  • C. Sai: Đổi kiểu không giải quyết so nội dung chuỗi.
  • D. Sai: Ví dụ trong bài cho kết quả false.
