12 Exception cơ bản

Cơ chế xử lý lỗi bằng try-catch-finally — tương tự Python nhưng có thêm "checked exception" đặc trưng của Java.

Exception.java 
public class XuLyLoi {
    public static void main(String[] args) {
        try {
            int[] mang = {1, 2, 3};
            System.out.println(mang[5]);          // sẽ gây lỗi
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Lỗi: truy cập chỉ số ngoài phạm vi - " + e.getMessage());
        } finally {
            System.out.println("Khối này LUÔN chạy, dù có lỗi hay không");
        }
    }
}

Checked vs Unchecked Exception

LoạiĐặc điểmVí dụ
CheckedBắt buộc phải xử lý hoặc khai báo throws, kiểm tra lúc biên dịchIOException
UncheckedKhông bắt buộc xử lý, chỉ xảy ra lúc runtimeNullPointerException, ArithmeticException
custom_exception.java 
class SoDuKhongDuException extends Exception {    // custom exception kế thừa từ Exception
    public SoDuKhongDuException(String thongBao) {
        super(thongBao);
    }
}

static void rutTien(double soDu, double soTien) throws SoDuKhongDuException {
    if (soTien > soDu) {
        throw new SoDuKhongDuException("Số dư không đủ!");
    }
}
Quan trọng
NullPointerException (NPE) là lỗi phổ biến nhất trong Java — xảy ra khi gọi method trên một biến tham chiếu đang là null. Luôn kiểm tra if (obj != null) trước khi thao tác, hoặc dùng Optional (Java 8+) để xử lý an toàn hơn.

📌 Tổng kết chương 12

Java phân biệt checked exception (bắt buộc xử lý) và unchecked exception (runtime). NullPointerException là lỗi phổ biến nhất — luôn kiểm tra null trước khi dùng biến tham chiếu.
