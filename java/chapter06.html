Input/Output (Scanner)

Nhận dữ liệu từ bàn phím bằng class Scanner của Java.

Nhận dữ liệu từ bàn phím bằng class Scanner của Java.

NhapLieu.java 
import java.util.Scanner;

public class NhapLieu {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Nhập tên: ");
        String ten = scanner.nextLine();       // đọc cả dòng, kể cả khoảng trắng

        System.out.print("Nhập tuổi: ");
        int tuoi = scanner.nextInt();             // đọc một số nguyên

        System.out.println("Xin chào " + ten + ", " + tuoi + " tuổi");
        scanner.close();                              // nên đóng Scanner sau khi dùng xong
    }
}
Phương thứcĐọc kiểu gì
nextLine()Cả dòng (String, kể cả khoảng trắng)
nextInt()Số nguyên
nextDouble()Số thực
Lỗi thường gặp
Gọi nextInt() rồi gọi nextLine() ngay sau đó thường trả về chuỗi rỗng — vì nextInt() không "ăn" luôn ký tự xuống dòng. Cách khắc phục: thêm một scanner.nextLine() thừa để "dọn" bộ đệm trước khi đọc dòng tiếp theo.

📌 Tổng kết chương 6

Scanner (từ java.util) đọc dữ liệu nhập từ bàn phím với các phương thức nextLine()/nextInt()/nextDouble() tương ứng từng kiểu.
