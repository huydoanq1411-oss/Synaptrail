int diem = 8;

if (diem >= 8) {
    System.out.println("Giỏi");
} else if (diem >= 6) {
    System.out.println("Khá");
} else {
    System.out.println("Cần cố gắng");

Switch expression hiện đại (Java 14+)

switch_moi.java 
int thu = 3;
String tenThu = switch (thu) {       // switch KIỂU MỚI trả về giá trị trực tiếp
    case 1 -> "Thứ Hai";
    case 2 -> "Thứ Ba";
    case 3 -> "Thứ Tư";
    default -> "Ngày khác";
};
System.out.println(tenThu);   // Thứ Tư - KHÔNG cần break, không bị fall-through
Mẹo
Switch kiểu mới (mũi tên ->, từ Java 14+) an toàn hơn switch cổ điển vì không có fall-through và có thể trả về giá trị trực tiếp — nên ưu tiên dùng nếu dự án dùng Java 14 trở lên.
