Chương 4 — Biến & Kiểu dữ liệu

Java phân biệt rõ ràng kiểu nguyên thủy (primitive) và kiểu tham chiếu (reference).

bien.java 
int tuoi = 20;                  // số nguyên
double diemTb = 8.5;               // số thực độ chính xác cao
float chieuCao = 1.75f;              // số thực, cần hậu tố "f"
char kyTu = 'A';                       // MỘT ký tự (dấu nháy đơn)
boolean dangHoc = true;                  // true/false
String ten = "Huy";                        // KIỂU THAM CHIẾU (viết hoa chữ S), không phải primitive

System.out.println(ten + " " + tuoi);   // nối chuỗi bằng dấu +
Kiểu nguyên thủy (primitive)Kích thướcMô tả
int4 byteSố nguyên
long8 byteSố nguyên lớn, cần hậu tố "L" (VD: 100L)
double8 byteSố thực độ chính xác cao (mặc định nên dùng)
boolean1 bittrue/false
char2 byteMột ký tự Unicode
Quan trọng — Quy ước đặt tên
Java dùng camelCase cho biến và method (diemTb, tinhTong()), và PascalCase cho tên class (HelloWorld, SinhVien) — vi phạm quy ước này không gây lỗi nhưng bị coi là code không chuyên nghiệp.

Kiểu nguyên thủy vs Kiểu tham chiếu

int, double, boolean, char là kiểu nguyên thủy — lưu trực tiếp giá trị. String, mảng, và object của class tự định nghĩa là kiểu tham chiếu — biến lưu địa chỉ trỏ tới object trong bộ nhớ heap.

Quiz — Chương 4 · 5 câu

Nhớ khái niệm

1. String trong Java thuộc nhóm nào theo bài?

A. Nguyên thủy B. Tham chiếu C. Kiểu số nguyên D. Toán tử logic
Giải thích đáp án
  • A. Sai: Bài phân biệt String với int, char và boolean.
  • B. Đúng: String là kiểu tham chiếu.
  • C. Sai: String biểu diễn chuỗi, không phải int.
  • D. Sai: String là kiểu dữ liệu, không phải toán tử.
Nhớ khái niệm

2. Quy ước nào dùng cho tên biến trong bài?

A. PascalCase như DiemTb B. Chỉ dùng chữ hoa như DIEMTB C. Bắt đầu bằng số như 1diem D. camelCase như diemTb
Giải thích đáp án
  • A. Sai: Bài dùng PascalCase cho lớp.
  • B. Sai: Không phải quy ước biến nêu trong bài.
  • C. Sai: Đây không phải ví dụ camelCase hợp lệ.
  • D. Đúng: bài dùng diemTb cho tên biến.
Áp dụng / đọc code

3. Khai báo nào biểu diễn đúng một ký tự theo mẫu?

A. char kyTu = 'A'; B. String kyTu = "A"; C. boolean kyTu = true; D. int kyTu = 20;
Giải thích đáp án
  • A. Đúng: ký tự dùng nháy đơn trong ví dụ.
  • B. Sai: Đây là chuỗi, không phải biến char.
  • C. Sai: Đây là giá trị logic, không phải ký tự.
  • D. Sai: Đây là số nguyên trong mẫu khai báo.
Áp dụng / đọc code

4. Đoạn mã in nội dung nào?

String ten = "Huy";
int tuoi = 20;
System.out.println(ten + " " + tuoi);
A. 20 Huy B. Huy20 C. Huy 20 D. ten tuoi
Giải thích đáp án
  • A. Sai: Thứ tự nối bắt đầu bằng ten.
  • B. Sai: Có chuỗi khoảng trắng ở giữa.
  • C. Đúng: nối ten, khoảng trắng rồi tuoi.
  • D. Sai: Tên biến được thay bằng giá trị của chúng.
Tìm lỗi

5. Theo mẫu của bài, cần sửa dòng nào?

A. int tuoi = 20; B. float chieuCao = 1.75; C. char kyTu = 'A'; D. boolean dangHoc = true;
Giải thích đáp án
  • A. Sai: Số nguyên này đúng mẫu int.
  • B. Đúng: dùng 1.75f để có literal float như bài.
  • C. Sai: Một ký tự trong nháy đơn là đúng mẫu.
  • D. Sai: Giá trị true phù hợp boolean.

📌 Tổng kết chương 4

Java có 8 kiểu nguyên thủy (int, double, boolean...) lưu giá trị trực tiếp, và kiểu tham chiếu (String, mảng, object) lưu địa chỉ trong heap. Quy ước đặt tên: camelCase cho biến, PascalCase cho class.
