21 Synchronized & Race Condition

Vấn đề tranh chấp dữ liệu khi nhiều luồng cùng truy cập, và cách Java giải quyết bằng synchronized.

RaceCondition.java 
class BoDem {
    private int giaTri = 0;

    public synchronized void tang() {    // "synchronized" - chỉ MỘT luồng được vào tại một thời điểm
        giaTri++;
    }

    public int layGiaTri() {
        return giaTri;
    }
}

public class Main {
    public static void main(String[] args) throws InterruptedException {
        BoDem boDem = new BoDem();
        Runnable tangNhieuLan = () -> {
            for (int i = 0; i < 1000; i++) boDem.tang();
        };

        Thread t1 = new Thread(tangNhieuLan);
        Thread t2 = new Thread(tangNhieuLan);
        t1.start(); t2.start();
        t1.join(); t2.join();

        System.out.println(boDem.layGiaTri());   // 2000 CHÍNH XÁC nhờ synchronized
    }                                                  // nếu bỏ synchronized, kết quả thường < 2000!
}
Quan trọng — Race Condition
Nếu bỏ synchronized, hai luồng có thể cùng đọc giá trị giaTri cũ, cùng cộng 1, rồi cùng ghi lại — làm mất đi một lần tăng. Đây gọi là race condition — lỗi rất khó tái hiện và debug vì kết quả sai khác nhau mỗi lần chạy.

synchronized đảm bảo chỉ một luồng truy cập đoạn code/tài nguyên tại một thời điểm, ngăn race condition — nhưng cần cẩn thận vì dùng quá nhiều sẽ làm giảm hiệu năng đa luồng.
