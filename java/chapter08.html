Chương 8 — Vòng lặp

for, while, do-while và enhanced for (for-each).

vong_lap.java 
for (int i = 0; i < 5; i++) {
    System.out.print(i + " ");
}   // 0 1 2 3 4

int dem = 0;
while (dem < 5) {
    System.out.print(dem + " ");
    dem++;
}

int[] mang = {10, 20, 30};
for (int giaTri : mang) {     // enhanced for (for-each) - giống range-based for của C++
    System.out.print(giaTri + " ");
}
