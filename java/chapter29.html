Chương 29 — Dự án: REST API Quản lý công việc

Dự án tổng hợp Spring Boot hoàn chỉnh: Entity, Repository, Service, Controller.

CongViec.java 
@Entity
public class CongViec {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String tieuDe;
    private boolean hoanThanh = false;
    // constructor, getter, setter...
}
CongViecController.java 
@RestController
@RequestMapping("/api/cong-viec")
public class CongViecController {
    private final CongViecService service;

    public CongViecController(CongViecService service) {
        this.service = service;
    }

    @GetMapping
    public List<CongViec> layTatCa() {
        return service.layTatCa();
    }

    @PostMapping
    public CongViec taoMoi(@RequestBody CongViec cv) {
        return service.taoCongViec(cv);
    }

    @PutMapping("/{id}/hoan-thanh")
    public CongViec danhDauHoanThanh(@PathVariable Long id) {
        return service.danhDauHoanThanh(id);
    }

    @DeleteMapping("/{id}")
    public void xoa(@PathVariable Long id) {
        service.xoa(id);
    }
}
Mẹo
Đây chính là bộ khung (skeleton) chuẩn cho mọi REST API thực tế bằng Spring Boot — chỉ cần thay đổi Entity, logic nghiệp vụ trong Service, và endpoint trong Controller để áp dụng cho bất kỳ bài toán CRUD nào khác.
