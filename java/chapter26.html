Chương 26 — REST Controller

Xây dựng REST API bằng Spring Boot — chỉ cần vài annotation để định nghĩa endpoint.

SinhVienController.java 
import org.springframework.web.bind.annotation.*;
import java.util.*;

@RestController                          // đánh dấu class này xử lý REST API, tự trả về JSON
@RequestMapping("/api/sinh-vien")          // tiền tố chung cho mọi endpoint trong class này
public class SinhVienController {

    private List<SinhVien> danhSach = new ArrayList<>();

    @GetMapping                               // GET /api/sinh-vien
    public List<SinhVien> layTatCa() {
        return danhSach;                          // Spring TỰ ĐỘNG chuyển List thành JSON
    }

    @GetMapping("/{id}")                        // GET /api/sinh-vien/5
    public SinhVien layTheoId(@PathVariable int id) {
        return danhSach.stream()
            .filter(sv -> sv.getId() == id)
            .findFirst()
            .orElseThrow(() -> new RuntimeException("Không tìm thấy"));
    }

    @PostMapping                              // POST /api/sinh-vien
    public SinhVien taoMoi(@RequestBody SinhVien sv) {   // @RequestBody tự parse JSON -> object
        danhSach.add(sv);
        return sv;
    }
}
AnnotationÝ nghĩa
@RestControllerClass xử lý REST API, tự động serialize kết quả sang JSON
@GetMapping/@PostMappingÁnh xạ method với phương thức HTTP tương ứng
@PathVariableLấy giá trị từ đường dẫn URL (VD: /sinh-vien/{id})
@RequestBodyParse JSON body của request thành object Java

Spring Boot dùng annotation (@RestController, @GetMapping...) để định nghĩa REST API cực kỳ ngắn gọn, tự động xử lý serialize/deserialize JSON.
