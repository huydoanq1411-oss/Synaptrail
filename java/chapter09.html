Mảng (Array)

Tập hợp phần tử cùng kiểu, kích thước cố định — trong Java, mảng LUÔN là kiểu tham chiếu (object).

Tập hợp phần tử cùng kiểu, kích thước cố định — trong Java, mảng LUÔN là kiểu tham chiếu (object).

array.java 
int[] diem = {90, 85, 78, 92, 88};    // khai báo và khởi tạo mảng
System.out.println(diem[0]);              // 90 - truy cập theo chỉ số, bắt đầu từ 0
System.out.println(diem.length);            // 5 - .length là THUỘC TÍNH, không phải hàm

int[] mangRong = new int[10];   // mảng 10 phần tử, mặc định toàn số 0

// Mảng 2 chiều
int[][] maTran = {{1,2,3}, {4,5,6}};
System.out.println(maTran[1][2]);   // 6
Quan trọng
Truy cập chỉ số vượt quá kích thước mảng (VD: diem[10] trên mảng 5 phần tử) sẽ ném ra ArrayIndexOutOfBoundsException ngay lập tức — an toàn hơn C++ (nơi lỗi này gây "undefined behavior" khó lường).

📌 Tổng kết chương 9

Mảng Java có .length để lấy kích thước, tự động ném exception rõ ràng khi truy cập sai chỉ số — an toàn hơn mảng C-style của C++.
