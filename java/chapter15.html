Abstract Class

Class trung gian giữa class thường và interface — vừa có thể có phương thức đã triển khai, vừa có phương thức bắt buộc override.

Class trung gian giữa class thường và interface — vừa có thể có phương thức đã triển khai, vừa có phương thức bắt buộc override.

AbstractClass.java 
abstract class PhuongTien {              // "abstract" - KHÔNG THỂ tạo object trực tiếp
    protected String ten;
    public PhuongTien(String ten) { this.ten = ten; }

    public void thongTin() {                  // phương thức THƯỜNG - đã có sẵn triển khai
        System.out.println("Phương tiện: " + ten);
    }

    public abstract void diChuyen();          // phương thức TRỪU TƯỢNG - BẮT BUỘC class con override
}

class XeMay extends PhuongTien {
    public XeMay(String ten) { super(ten); }

    @Override
    public void diChuyen() {
        System.out.println(ten + " chạy bằng động cơ 2 bánh");
    }
}

// PhuongTien pt = new PhuongTien("X");   // LỖI - không thể khởi tạo abstract class
XeMay xm = new XeMay("Honda");
xm.thongTin();       // kế thừa từ abstract class
xm.diChuyen();          // Honda chạy bằng động cơ 2 bánh

📌 Tổng kết chương 15

Abstract class không thể khởi tạo trực tiếp, có thể chứa cả phương thức đã triển khai và phương thức trừu tượng bắt buộc override — dùng khi các class con có quan hệ họ hàng rõ ràng.
