Chương 23 — File I/O

Đọc và ghi file bằng các lớp hiện đại của Java (NIO) và cách xử lý cũ hơn (IO).

FileIODemo.java 
import java.nio.file.*;
import java.util.List;
import java.io.IOException;

public class FileIODemo {
    public static void main(String[] args) {
        try {
            // Ghi file - API hiện đại (java.nio.file)
            Files.writeString(Path.of("ghi_chu.txt"), "Xin chào Java!\n");

            // Đọc toàn bộ nội dung
            String noiDung = Files.readString(Path.of("ghi_chu.txt"));
            System.out.println(noiDung);

            // Đọc từng dòng vào List
            List<String> dongList = Files.readAllLines(Path.of("ghi_chu.txt"));
            for (String dong : dongList) {
                System.out.println(dong);
            }
        } catch (IOException e) {
            System.out.println("Lỗi đọc/ghi file: " + e.getMessage());
        }
    }
}
Ghi chú
java.nio.file (NIO.2, từ Java 7+) với các lớp Path/Files là API hiện đại, ngắn gọn hơn nhiều so với FileReader/BufferedReader kiểu cũ của java.io — nên ưu tiên dùng trong code mới.

📌 Tổng kết chương 23

Files.writeString()/readString()/readAllLines() (java.nio.file) là cách đọc/ghi file hiện đại, ngắn gọn nhất trong Java — luôn xử lý IOException có thể xảy ra.
