03 Chương trình đầu tiên

Viết, biên dịch và chạy "Hello, World!" — hiểu quy tắc đặt tên file bắt buộc của Java.

HelloWorld.java 
public class HelloWorld {                 // tên class PHẢI trùng tên file
    public static void main(String[] args) {   // điểm bắt đầu bắt buộc
        System.out.println("Hello, World!");
    }
}
terminal 
javac HelloWorld.java     # biên dịch -> tạo ra file HelloWorld.class (bytecode)
java HelloWorld              # chạy bytecode trên JVM (KHÔNG có đuôi .class khi chạy)
Quan trọng
Tên file .java phải trùng chính xác với tên class public bên trong nó (phân biệt hoa thường). File HelloWorld.java phải chứa public class HelloWorld — sai tên sẽ báo lỗi biên dịch.
Thành phầnÝ nghĩa
public class HelloWorldKhai báo class công khai, tên trùng tên file
public static void main(String[] args)Điểm bắt đầu chương trình — chữ ký này BẮT BUỘC chính xác
System.out.println()In ra màn hình kèm xuống dòng

📌 Tổng kết chương 3

Java yêu cầu tên file trùng tên class public, biên dịch bằng javac (tạo ra bytecode .class), rồi chạy bằng java.
