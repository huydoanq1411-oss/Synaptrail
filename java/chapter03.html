Chương 3 — Chương trình đầu tiên

Viết Hello World hoàn chỉnh, hiểu từng dòng và phân biệt sửa mã, biên dịch, chạy cùng lỗi ở mỗi bước.

1. Mục tiêu học

  • Tạo file đúng tên, biên dịch bằng javac và chạy bằng java.
  • Giải thích lớp, chữ ký main, chuỗi, dấu chấm phẩy và ngoặc khối.
  • Quan sát khác nhau giữa print và println; kiểm chứng thay đổi bằng đầu ra cụ thể.

Trước khi bắt đầu, cả java và javac phải hoạt động như chương 2. Chuẩn bị thư mục riêng và trình soạn thảo văn bản; chưa cần Maven, Gradle hoặc framework. Quy trình nhỏ này giúp bạn nhìn rõ từng bước trước khi IDE tự động hóa chúng.

2. Vấn đề thực tế

Bạn cần chương trình chào người dùng khi mở công cụ nhận hàng. Yêu cầu đầu tiên rất nhỏ: hiển thị lời chào đúng một lần và kết thúc. Một chương trình như vậy là phép kiểm tra tốt cho môi trường, vì không phụ thuộc dữ liệu bên ngoài hoặc giao diện phức tạp.

3. Lý thuyết nền

Trong mẫu truyền thống của bài, lớp public tổ chức mã và main là điểm vào chương trình. Chữ ký public static void main(String[] args) tương thích với Java 8 trở lên. Đây là quy ước dùng xuyên suốt ví dụ, không phải tuyên bố rằng mọi phiên bản Java mới chỉ cho phép một dạng chương trình.

Java phân biệt chữ hoa và chữ thường: main khác Main, String khác string. Một chuỗi văn bản đặt trong nháy kép. Lệnh gọi phương thức thường kết thúc bằng dấu chấm phẩy; ngoặc nhọn bao quanh khối mã. Khoảng trắng và thụt dòng giúp người đọc, còn dấu ngoặc quyết định cấu trúc.

Trong quy trình hai bước, javac nhận file .java; java nhận tên lớp để chạy bytecode đã có. Hai lệnh không thể đổi chỗ. Biên dịch thành công cho biết mã hợp lệ theo kiểm tra của compiler, không chứng minh chương trình đã thực hiện đúng yêu cầu người dùng.

4. Ví dụ từng bước

A. Viết và chạy Hello World

Tạo file HelloWorld.java, lưu dạng văn bản UTF-8. Kiểm tra trình soạn thảo không tự thêm đuôi .txt. Nhập mã sau thay vì sao chép kết quả đã chạy, rồi lưu trước khi mở terminal.

HelloWorld.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
  1. public class HelloWorld khai báo lớp công khai. Vì lớp này là public, file phải tên HelloWorld.java, đúng cả chữ hoa.
  2. public trong main cho phép truy cập; static cho phép gọi mà không tạo đối tượng HelloWorld trước.
  3. void nói rằng main không trả về giá trị. Bạn chưa cần viết return cho chương trình đơn giản này.
  4. String[] args là mảng tham số từ dòng lệnh. Ví dụ chưa đọc mảng; vẫn giữ khai báo để đúng mẫu.
  5. System.out.println gửi văn bản tới đầu ra chuẩn rồi xuống dòng. Nháy kép không được in; dấu chấm phẩy kết thúc lệnh.
  6. Dấu ngoặc đóng đầu tiên kết thúc main; dấu thứ hai kết thúc lớp. Thụt dòng cho thấy quan hệ bao chứa giữa các khối.
Terminal — cùng thư mục với mã nguồn
javac HelloWorld.java
java HelloWorld

Biên dịch xong sẽ có HelloWorld.class. Khi chạy, đầu ra cần đúng Hello, World! và một ký tự xuống dòng. Nếu không thấy file class hoặc có thông báo lỗi, dừng lại đọc lỗi đầu tiên trước khi thử chạy.

B. Kiểm soát xuống dòng

Ví dụ thứ hai chỉ thay cách in, không dùng thêm kiến thức về biến. Lưu trong file GreetingLines.java để cả hai chương trình tồn tại độc lập và bạn có thể đối chiếu.

GreetingLines.java
public class GreetingLines {
    public static void main(String[] args) {
        System.out.print("Hello, ");
        System.out.println("Synaptrail!");
        System.out.println("Ready to learn");
    }
}
  1. Dòng đầu đặt tên lớp mới; dòng main giữ nguyên điểm bắt đầu quen thuộc.
  2. print viết “Hello, ” nhưng chưa xuống dòng. Khoảng trắng sau dấu phẩy thuộc dữ liệu chuỗi.
  3. println tiếp theo nối “Synaptrail!” trên cùng dòng, rồi xuống dòng.
  4. Lệnh cuối in “Ready to learn” trên dòng mới. Hai ngoặc đóng kết thúc phương thức và lớp.

Biên dịch bằng javac GreetingLines.java, chạy java GreetingLines. Kết quả có hai dòng: Hello, Synaptrail! và Ready to learn. Đừng dự đoán ba dòng chỉ vì có ba lệnh in.

Đổi print đầu tiên thành println, biên dịch lại và quan sát kết quả thành ba dòng. Sau đó hoàn nguyên và chạy lại. Hãy giữ bản ghi đầu ra trước/sau, vì đó là bằng chứng rõ hơn cảm giác “code vẫn đúng”.

Khi thử nghiệm, chỉ thay một yếu tố mỗi lần: chuỗi, phương thức in hoặc tên lớp. Nếu đổi nhiều thứ cùng lúc rồi gặp lỗi, bạn khó biết thay đổi nào gây ra vấn đề. Đây là thói quen debug hữu ích ngay từ chương đầu tiên có mã.

5. Lỗi thường gặp

  • File và lớp public lệch tên: sửa cho trùng, kể cả hoa thường; không chỉ đổi nhãn hiển thị trong IDE.
  • Thiếu dấu chấm phẩy hoặc ngoặc: đọc lỗi compiler, kiểm tra dòng đó và dòng ngay trước; vị trí báo lỗi có thể nằm sau chỗ thiếu.
  • Chạy java HelloWorld.class: với chế độ chạy lớp, bỏ đuôi .class và đứng đúng thư mục hoặc cấu hình classpath.
  • Sửa chuỗi nhưng thấy kết quả cũ: lưu file và biên dịch lại, rồi xác nhận terminal đang dùng đúng thư mục.
  • Dùng dấu nháy cong từ trình soạn thảo văn bản: thay bằng nháy kép ASCII trong mã nguồn.

6. Bài tập ba mức

Dễ — Chào khóa học

Đổi Hello World thành “Hello Java”. Chạy chương trình; chỉ một dòng lời chào. Giữ tên lớp và file, không sửa chữ ký main.

Vừa — Thiết kế đầu ra

Viết ba lệnh in để tạo đúng hai dòng “Java lesson” và “Chapter 3”. Dùng ít nhất một print, một println. Ghi dự đoán trước khi chạy.

Khó — Phân loại lỗi

Tạo bản sao riêng, lần lượt thử sai tên file, thiếu chấm phẩy và quên biên dịch lại. Ghi bước phát hiện, thông báo hoặc đầu ra, rồi khôi phục bản đúng. Không ghi đè chương trình đã kiểm chứng.

7. Tóm tắt

Giữ đúng tên lớp/file và chữ ký main. javac biên dịch, java chạy. print không tự xuống dòng; println có xuống dòng. Kiểm chứng mỗi thay đổi bằng đầu ra và sửa một vấn đề mỗi lần.
