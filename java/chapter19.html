19 Stream API & Lambda

Xử lý Collection theo phong cách lập trình hàm (functional programming) — Java 8+.

StreamAPI.java 
import java.util.List;
import java.util.stream.Collectors;

List<Integer> so = List.of(5, 2, 8, 1, 9, 4);

List<Integer> soChan = so.stream()
    .filter(x -> x % 2 == 0)            // lambda expression - hàm ẩn danh ngắn gọn
    .collect(Collectors.toList());
System.out.println(soChan);              // [2, 8, 4]

int tong = so.stream()
    .mapToInt(Integer::intValue)           // method reference - cách viết gọn của lambda
    .sum();
System.out.println(tong);                     // 29

List<String> ten = List.of("Huy", "Lan", "Nam");
String ketQua = ten.stream()
    .filter(t -> t.length() > 3)
    .map(String::toUpperCase)
    .collect(Collectors.joining(", "));
System.out.println(ketQua);   // "LAN" nếu chỉ Lan/Nam đủ dài, tùy ví dụ
Mẹo
Stream API (filter/map/reduce/collect) là phong cách xử lý Collection hiện đại nhất của Java, tương đương map/filter/reduce của JavaScript hay list comprehension của Python — nên ưu tiên dùng thay vòng lặp thủ công khi xử lý dữ liệu.
