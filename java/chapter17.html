HashMap & HashSet

Chọn cấu trúc để tra cứu theo khóa, loại dữ liệu trùng và xử lý thống kê đơn giản bằng Java.

Làm quiz ở trang riêng

Chọn cấu trúc để tra cứu theo khóa, loại dữ liệu trùng và xử lý thống kê đơn giản bằng Java.

1. Mục tiêu học

  • Phân biệt cặp khóa–giá trị của HashMap với phần tử duy nhất của HashSet.
  • Thêm, cập nhật, tìm kiếm và xóa dữ liệu; dự đoán kết quả trước khi chạy.
  • Giải thích khóa trùng, giá trị mặc định và lựa chọn thứ tự duyệt.

Bạn cần biết biến, vòng lặp và lớp cơ bản. Ví dụ dưới đây là chương trình hoàn chỉnh, tương thích Java 8 trở lên; tên file phải trùng tên lớp public.

2. Vấn đề thực tế

Một cửa hàng nhận danh sách món hàng: sách, bút, sách, vở. Người quản lý cần biết mỗi món xuất hiện bao nhiêu lần và có bao nhiêu loại hàng khác nhau. Dùng danh sách rồi quét lại từ đầu cho từng món sẽ làm cách xử lý dài và khó mở rộng.

Hãy tách hai câu hỏi: “sách có số lượng bao nhiêu?” cần liên hệ tên hàng với số lượng; “đã gặp sách chưa?” chỉ cần kiểm tra sự tồn tại. Câu hỏi đầu phù hợp với map, câu hỏi sau phù hợp với set.

3. Lý thuyết nền

Map<K, V> biểu diễn quan hệ từ khóa K đến giá trị V. Mỗi khóa chỉ có một giá trị hiện tại; hai khóa khác nhau có thể cùng giá trị. Gọi put lần nữa với cùng khóa sẽ cập nhật giá trị, không tăng số khóa.

Set<E> chứa các phần tử không trùng theo quy tắc so sánh của chúng. add trả về true khi thêm thành công, false khi phần tử đã có. Nó không đếm số lần xuất hiện; muốn đếm, hãy dùng map.

Cả hai cấu trúc dùng mã băm để xác định vị trí lưu và dùng equals để phân biệt các đối tượng. Cùng mã băm chưa chắc là cùng phần tử. Với lớp tự tạo, hai đối tượng bằng nhau phải có cùng hashCode; tránh sửa thuộc tính tham gia so sánh khi đối tượng đang là khóa.

Chọn đúng cấu trúc

Tra cứu cơ bản thường đạt O(1) khi mã băm phân bố tốt, không phải bảo đảm cho mọi dữ liệu. HashMap và HashSet không cam kết thứ tự. Cần thứ tự chèn: chọn LinkedHashMap/LinkedHashSet; cần sắp xếp: cân nhắc TreeMap/TreeSet.

4. Ví dụ từng bước

A. Đếm số lần xuất hiện bằng HashMap

Lưu mã dưới đây thành HashMapDemo.java. Dự đoán ba dòng kết quả trước khi biên dịch, rồi đối chiếu dự đoán của bạn.

HashMapDemo.java 
import java.util.HashMap;
import java.util.Map;

public class HashMapDemo {
    public static void main(String[] args) {
        Map<String, Integer> counts = new HashMap<>();
        String[] items = {"sach", "but", "sach", "vo"};
        for (String item : items) {
            int previous = counts.getOrDefault(item, 0);
            counts.put(item, previous + 1);
        }
        System.out.println(counts.get("sach"));
        System.out.println(counts.getOrDefault("thuoc", 0));
        System.out.println(counts.size());
    }
}
  1. Hai dòng import đưa lớp triển khai và interface vào phạm vi sử dụng.
  2. public class đặt tên chương trình; main là điểm bắt đầu chạy.
  3. Dòng khai báo counts chọn khóa String và giá trị Integer, khởi tạo map rỗng.
  4. Mảng items mô phỏng dữ liệu cửa hàng; vòng for lấy từng tên hàng.
  5. getOrDefault lấy số đếm cũ; tên chưa có được tính là 0.
  6. put ghi số cũ cộng một. Lần gặp “sach” thứ hai cập nhật 1 thành 2.
  7. Ba dòng println lần lượt in số sách, số thước và số khóa: 2, 0, 3.
  8. Các dấu ngoặc đóng kết thúc vòng lặp, phương thức và lớp; không đặt lệnh ngoài phương thức.

B. Loại trùng bằng HashSet

HashSetDemo.java 
import java.util.HashSet;
import java.util.Set;

public class HashSetDemo {
    public static void main(String[] args) {
        Set<String> names = new HashSet<>();
        System.out.println(names.add("sach"));
        System.out.println(names.add("sach"));
        names.add("but");
        System.out.println(names.size());
        System.out.println(names.contains("but"));
        names.remove("but");
        System.out.println(names.contains("but"));
    }
}
  1. Hai import chọn HashSet và interface Set; khai báo lớp và main giống ví dụ A.
  2. Dòng tạo names chuẩn bị tập hợp String rỗng.
  3. Hai lần thêm “sach” in true rồi false: bản trùng không được thêm.
  4. Thêm “but” làm kích thước thành 2; kiểm tra tồn tại in true.
  5. remove xóa “but”; lần kiểm tra cuối in false. Các ngoặc đóng kết thúc chương trình.

Chạy bằng javac HashMapDemo.java HashSetDemo.java, sau đó java HashMapDemo và java HashSetDemo. Không so sánh thứ tự khi in cả map hoặc set.

5. Lỗi thường gặp

  • Đọc khóa thiếu bằng get rồi gán vào int có thể gây NullPointerException do tự mở hộp null. Với số đếm, dùng giá trị mặc định.
  • Cho rằng getOrDefault thay mọi null: khóa có giá trị null vẫn trả null. Ví dụ đếm trên luôn lưu số nguyên.
  • Trông chờ thứ tự chèn hoặc dùng vị trí chỉ số với HashSet. Set không phải danh sách.
  • Sửa cấu trúc trong lúc duyệt for-each có thể gây ConcurrentModificationException. Nếu cần xóa lúc duyệt, dùng iterator phù hợp.

6. Bài tập ba mức

Dễ — Đếm màu

Đếm mảng “do, xanh, do”. In số “do” và số màu khác nhau. Kết quả phải là 2 và 2; thử thêm mảng rỗng.

Vừa — Chuẩn hóa tên hàng

Loại khoảng trắng hai đầu và chuyển tên về chữ thường trước khi đếm. Với “ Sach ” và “sach”, chỉ còn một khóa, giá trị 2. Quy định rõ cách xử lý chuỗi rỗng.

Khó — Thống kê giỏ hàng

Viết phương thức trả map số lượng và tập hợp món xuất hiện ít nhất hai lần. Thử dữ liệu rỗng, toàn khác nhau và toàn trùng. Giải thích vì sao dùng cả map lẫn set; không dựa vào thứ tự duyệt.

7. Tóm tắt

Map trả lời “khóa này gắn với gì?”, set trả lời “phần tử này đã có chưa?”. Khóa trùng cập nhật map; phần tử trùng không tăng set. Chọn cấu trúc theo câu hỏi, rồi kiểm tra dữ liệu thiếu và trùng.
