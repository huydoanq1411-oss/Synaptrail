Chương 17 — HashMap & HashSet

Cấu trúc key-value và tập hợp không trùng lặp, dựa trên hash table — tra cứu cực nhanh.

HashMapDemo.java 
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> diem = new HashMap<>();
diem.put("Huy", 85);
diem.put("Lan", 92);

System.out.println(diem.get("Huy"));          // 85
System.out.println(diem.getOrDefault("Nam", 0));   // 0 - giá trị mặc định nếu key không tồn tại
System.out.println(diem.containsKey("Lan"));      // true

for (Map.Entry<String, Integer> entry : diem.entrySet()) {   // duyệt cặp key-value
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
HashSetDemo.java 
import java.util.HashSet;
import java.util.Set;

Set<Integer> ds = new HashSet<>();
ds.add(5); ds.add(2); ds.add(5);      // thêm 5 hai lần
System.out.println(ds.size());          // 2 - tự động loại trùng lặp
System.out.println(ds.contains(2));       // true
Quan trọng
HashMap/HashSet không đảm bảo thứ tự phần tử. Nếu cần giữ thứ tự chèn vào, dùng LinkedHashMap/LinkedHashSet; nếu cần tự sắp xếp theo key, dùng TreeMap/TreeSet.
