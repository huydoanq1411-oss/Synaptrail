ArrayList & LinkedList

Hai cài đặt phổ biến của interface List trong Collections Framework — danh sách động, khác mảng cố định.

Hai cài đặt phổ biến của interface List trong Collections Framework — danh sách động, khác mảng cố định.

ArrayListDemo.java 
import java.util.ArrayList;
import java.util.List;

List<String> ds = new ArrayList<>();    // khai báo kiểu interface List, khởi tạo ArrayList
ds.add("Táo");
ds.add("Cam");
ds.add("Chuối");

System.out.println(ds.get(0));               // "Táo" - truy cập theo chỉ số
ds.remove("Cam");                                // xóa theo GIÁ TRỊ
System.out.println(ds.size());                    // 2

for (String tc : ds) {                            // duyệt bằng enhanced for
    System.out.println(tc);
}
Tiêu chíArrayListLinkedList
Cấu trúc bên trongMảng độngDanh sách liên kết đôi
Truy cập theo chỉ sốO(1) - nhanhO(n) - chậm
Thêm/xóa ở đầuO(n) - chậmO(1) - nhanh
Dùng khiTruy cập ngẫu nhiên nhiềuThêm/xóa ở đầu/cuối thường xuyên
Mẹo
Luôn khai báo biến theo kiểu interface (List<String> ds = new ArrayList<>()) thay vì kiểu cụ thể — giúp dễ dàng đổi cài đặt (VD: sang LinkedList) sau này mà không cần sửa code sử dụng.

📌 Tổng kết chương 16

ArrayList phù hợp khi cần truy cập ngẫu nhiên nhanh, LinkedList phù hợp khi thêm/xóa nhiều ở đầu danh sách — cả hai đều triển khai interface List.
