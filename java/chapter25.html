Giới thiệu Spring Boot & Dependency Injection

Framework phổ biến nhất để xây dựng ứng dụng Java doanh nghiệp — giảm cấu hình thủ công tới mức tối thiểu.

Framework phổ biến nhất để xây dựng ứng dụng Java doanh nghiệp — giảm cấu hình thủ công tới mức tối thiểu.

Spring Boot là gì?

Spring Boot là framework xây dựng trên nền Spring Framework, giúp tạo ứng dụng Java (đặc biệt là web/REST API) nhanh chóng với cấu hình tối thiểu — theo triết lý "convention over configuration" (quy ước thay vì cấu hình thủ công).

Dependency Injection (DI) — khái niệm cốt lõi

DependencyInjection.java 
// KHÔNG dùng DI - class tự tạo dependency của mình -> khó test, khó thay đổi
class DichVuEmail {
    private KetNoiSMTP ketNoi = new KetNoiSMTP();   // tự tạo bên trong -> chặt chẽ, khó thay thế
}

// CÓ dùng DI - dependency được "tiêm" từ bên ngoài vào
@Service                                    // annotation đánh dấu đây là 1 Spring Bean
class DichVuEmail {
    private final KetNoiSMTP ketNoi;

    @Autowired                                // Spring TỰ ĐỘNG "tiêm" object KetNoiSMTP vào đây
    public DichVuEmail(KetNoiSMTP ketNoi) {
        this.ketNoi = ketNoi;
    }
}
Ghi chú
Dependency Injection giúp các class không cần tự tạo ra những thứ chúng phụ thuộc — Spring (gọi là "IoC Container") tự quản lý việc tạo và "tiêm" các object cần thiết, giúp code dễ test (thay bằng mock) và dễ thay đổi implementation.
Mẹo — Cách viết hiện đại hơn
Nếu class chỉ có đúng một constructor, Spring (từ bản 4.3 trở đi) tự động hiểu đó là nơi cần tiêm dependency — annotation @Autowired có thể LƯỢC BỎ hoàn toàn mà code vẫn chạy y hệt. Cách viết này (constructor injection không cần @Autowired) hiện là khuyến nghị phổ biến nhất trong cộng đồng Spring vì code gọn hơn mà vẫn rõ ràng.

📌 Tổng kết chương 25

Spring Boot giảm thiểu cấu hình thủ công cho ứng dụng Java doanh nghiệp. Dependency Injection (qua @Autowired) giúp các class nhận dependency từ bên ngoài thay vì tự tạo, dễ test và bảo trì hơn.
