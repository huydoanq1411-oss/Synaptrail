01 Giới thiệu Java

Java là gì, triết lý "Write Once, Run Anywhere", và vì sao nó vẫn là một trong những ngôn ngữ phổ biến nhất thế giới.

Java là gì?

Java là ngôn ngữ lập trình hướng đối tượng, được Sun Microsystems (nay thuộc Oracle) phát hành năm 1995. Điểm đặc biệt: code Java không biên dịch trực tiếp thành mã máy, mà thành bytecode chạy trên JVM (Java Virtual Machine) — nhờ đó cùng một chương trình chạy được trên Windows, macOS, Linux mà không cần sửa code.

Ghi chú — "Write Once, Run Anywhere" (WORA)
Đây là khẩu hiệu nổi tiếng của Java: viết code một lần, biên dịch ra bytecode, và bytecode đó chạy được trên bất kỳ máy nào có cài JVM tương ứng — không cần biên dịch lại cho từng hệ điều hành như C++.

Tại sao nên học Java?

  • Đa nền tảng thực sự nhờ JVM — một trong những lý do Java được doanh nghiệp lớn ưa chuộng.
  • Hướng đối tượng thuần túy — mọi thứ (trừ kiểu nguyên thủy) đều là object, giúp tư duy OOP rất rõ ràng.
  • Hệ sinh thái doanh nghiệp khổng lồ — Spring Framework, hầu hết hệ thống ngân hàng, bảo hiểm lớn dùng Java.
  • Ổn định, tương thích ngược tốt — code Java viết cách đây 10+ năm vẫn thường chạy được trên JVM mới.

Java dùng để làm gì?

Ứng dụng AndroidJava là một trong hai ngôn ngữ chính thức (cùng Kotlin)

Mẹo ghi nhớ
Nhớ Java qua cụm "JVM + OOP + Doanh nghiệp": chạy trên máy ảo Java (JVM), hướng đối tượng thuần túy, và là xương sống của rất nhiều hệ thống doanh nghiệp lớn trên thế giới.
