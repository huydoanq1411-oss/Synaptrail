Chương 14 — Đa hình & Interface

Interface định nghĩa "hợp đồng" mà class phải tuân theo — cách Java đạt được đa kế thừa hành vi.

Interface.java 
interface Hinh {                      // interface - chỉ khai báo phương thức, không có thân hàm
    double dienTich();                     // mặc định là public abstract
}

class HinhVuong implements Hinh {       // "implements" - class TUÂN THEO interface
    private double canh;
    public HinhVuong(double canh) { this.canh = canh; }

    @Override
    public double dienTich() {              // BẮT BUỘC triển khai mọi phương thức của interface
        return canh * canh;
    }
}

class HinhTron implements Hinh {
    private double banKinh;
    public HinhTron(double r) { this.banKinh = r; }

    @Override
    public double dienTich() {
        return 3.14 * banKinh * banKinh;
    }
}

// Đa hình: một biến kiểu Hinh có thể trỏ tới bất kỳ class nào implements nó
Hinh[] danhSach = {new HinhVuong(4), new HinhTron(3)};
for (Hinh h : danhSach) {
    System.out.println(h.dienTich());   // gọi ĐÚNG phiên bản của từng class
}
Mẹo
Một class Java có thể implements nhiều interface cùng lúc (khác với chỉ extends được một class) — đây là cách Java giải quyết nhu cầu "đa kế thừa hành vi" mà không gặp vấn đề phức tạp của đa kế thừa class như C++.

Interface định nghĩa hợp đồng các phương thức bắt buộc. Class dùng implements để tuân theo, có thể implements nhiều interface — nền tảng đa hình linh hoạt của Java.
