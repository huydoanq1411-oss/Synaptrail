20 Thread cơ bản

Chạy nhiều luồng thực thi song song trong Java — hai cách tạo Thread cơ bản.

ThreadDemo.java 
// Cách 1: kế thừa Thread
class TaiXuong extends Thread {
    public void run() {                          // override phương thức run()
        System.out.println("Đang tải file...");
    }
}

// Cách 2: implements Runnable (KHUYẾN NGHỊ - linh hoạt hơn vì Java chỉ đơn kế thừa)
class XuLyDuLieu implements Runnable {
    public void run() {
        System.out.println("Đang xử lý dữ liệu...");
    }
}

public class ThreadDemo {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new TaiXuong();
        Thread t2 = new Thread(new XuLyDuLieu());

        t1.start();      // start() - KHÔNG gọi run() trực tiếp, để JVM tạo luồng thật
        t2.start();
        t1.join();          // chờ t1 hoàn thành trước khi tiếp tục
        t2.join();
        System.out.println("Tất cả đã hoàn thành!");
    }
}
Quan trọng
Luôn gọi .start(), KHÔNG BAO GIỜ gọi .run() trực tiếp nếu muốn chạy song song thật sự — gọi .run() trực tiếp chỉ chạy như một method bình thường trên luồng hiện tại, không tạo luồng mới.

📌 Tổng kết chương 20

Nên ưu tiên implements Runnable hơn extends Thread vì Java chỉ đơn kế thừa class. .start() tạo luồng thật, .join() chờ luồng hoàn thành.
