OOP cơ bản (Class & Object)

Java là ngôn ngữ hướng đối tượng thuần túy — mọi chương trình đều xoay quanh class và object.

SinhVien.java 
public class SinhVien {
    private String ten;      // private = chỉ truy cập được bên trong class (encapsulation)
    private int tuoi;

    public SinhVien(String ten, int tuoi) {   // constructor - tên PHẢI trùng tên class
        this.ten = ten;          // "this" phân biệt biến của object với tham số cùng tên
        this.tuoi = tuoi;
    }

    public void gioiThieu() {
        System.out.println("Tôi tên " + this.ten + ", " + this.tuoi + " tuổi");
    }

    public int getTuoi() {         // getter - quy ước đặt tên "getXyz"
        return tuoi;
    }

    public void setTuoi(int tuoi) {   // setter - quy ước đặt tên "setXyz"
        if (tuoi > 0) {                 // có thể kiểm tra ràng buộc trước khi gán
            this.tuoi = tuoi;
        }
    }
}

// Trong file khác hoặc method main:
SinhVien sv = new SinhVien("Huy", 20);   // "new" tạo object mới
sv.gioiThieu();                              // Tôi tên Huy, 20 tuổi
sv.setTuoi(21);
System.out.println(sv.getTuoi());              // 21
Mẹo
Quy ước getter/setter (getXyz()/setXyz()) là chuẩn mực bắt buộc trong Java — nhiều framework (Spring, Jackson khi convert JSON) dựa vào đúng quy ước đặt tên này để hoạt động tự động.

📌 Tổng kết chương 11

Object được tạo bằng từ khóa new. this tham chiếu tới chính object hiện tại. Getter/setter là quy ước chuẩn để truy cập thuộc tính private có kiểm soát.
