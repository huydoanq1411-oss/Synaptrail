Kế thừa (extends)

Class con kế thừa từ class cha bằng từ khóa extends — Java chỉ hỗ trợ đơn kế thừa (một class chỉ extends được một class cha).

Class con kế thừa từ class cha bằng từ khóa extends — Java chỉ hỗ trợ đơn kế thừa (một class chỉ extends được một class cha).

Inheritance.java 
class DongVat {
    protected String ten;              // protected = truy cập được từ class con
    public DongVat(String ten) { this.ten = ten; }
    public void an() {
        System.out.println(ten + " đang ăn");
    }
}

class Cho extends DongVat {           // Cho KẾ THỪA từ DongVat
    public Cho(String ten) {
        super(ten);                       // gọi constructor của lớp cha - PHẢI là dòng đầu tiên
    }
    public void sua() {
        System.out.println(ten + " sủa: Gâu gâu!");
    }

    @Override                             // annotation - giúp trình biên dịch kiểm tra đúng override
    public void an() {
        super.an();                          // gọi lại phương thức GỐC của cha
        System.out.println(ten + " ăn rất ngon miệng");
    }
}

// Cho cho = new Cho("Milu");
// cho.an();    // gọi phiên bản ĐÃ OVERRIDE ở Cho
// cho.sua();
Quan trọng
Java chỉ hỗ trợ đơn kế thừa class (một class chỉ extends được đúng một class cha) — khác C++ cho phép đa kế thừa. Để có hành vi tương tự đa kế thừa, Java dùng interface (chương 14).

📌 Tổng kết chương 13

extends tạo quan hệ kế thừa, super() gọi constructor cha, @Override đánh dấu ghi đè phương thức. Java chỉ hỗ trợ đơn kế thừa class.
