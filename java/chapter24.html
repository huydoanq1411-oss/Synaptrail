Record & Optional

Hai tính năng hiện đại của Java (14+ và 8+) giúp code ngắn gọn và an toàn hơn với giá trị null.

Hai tính năng hiện đại của Java (14+ và 8+) giúp code ngắn gọn và an toàn hơn với giá trị null.

Record — class dữ liệu ngắn gọn (Java 14+)

RecordDemo.java 
record SinhVien(String ten, int tuoi, double diem) {}   // 1 dòng thay vì cả class dài với getter/equals/toString

public class Main {
    public static void main(String[] args) {
        SinhVien sv = new SinhVien("Huy", 20, 8.5);
        System.out.println(sv.ten());        // getter tự động sinh, tên = tên field (không có "get")
        System.out.println(sv);                // SinhVien[ten=Huy, tuoi=20, diem=8.5] - toString() tự sinh

        SinhVien sv2 = new SinhVien("Huy", 20, 8.5);
        System.out.println(sv.equals(sv2));      // true - equals() tự sinh, so sánh theo GIÁ TRỊ
    }
}

Optional — xử lý null an toàn (Java 8+)

OptionalDemo.java 
import java.util.Optional;

Optional<String> timEmail(int userId) {
    // giả lập tìm không thấy
    return Optional.empty();
}

Optional<String> ketQua = timEmail(5);
System.out.println(ketQua.isPresent());              // false
System.out.println(ketQua.orElse("Không có email"));   // "Không có email" - giá trị mặc định an toàn

ketQua.ifPresent(email -> System.out.println("Tìm thấy: " + email));   // chỉ chạy nếu CÓ giá trị
Mẹo
Optional giúp phương thức thể hiện rõ ràng "có thể không có giá trị trả về" ngay trong kiểu trả về, thay vì trả về null ngầm và dễ gây NullPointerException ở nơi gọi (đã học ở chương 12).

📌 Tổng kết chương 24

record (Java 14+) tạo class dữ liệu bất biến chỉ với 1 dòng, tự sinh constructor/getter/equals/toString. Optional (Java 8+) giúp xử lý giá trị có thể vắng mặt an toàn hơn null.
