Generics

Cho phép viết class/method hoạt động với nhiều kiểu dữ liệu khác nhau mà vẫn an toàn về kiểu (type-safe).

Cho phép viết class/method hoạt động với nhiều kiểu dữ liệu khác nhau mà vẫn an toàn về kiểu (type-safe).

Generics.java 
class Hop<T> {                    // T là kiểu tổng quát (type parameter) - có thể đặt tên khác
    private T noiDung;

    public void dat(T noiDung) {
        this.noiDung = noiDung;
    }

    public T lay() {
        return noiDung;
    }
}

Hop<String> hopChuoi = new Hop<>();     // T được thay bằng String
hopChuoi.dat("Xin chào");
String s = hopChuoi.lay();                    // KHÔNG cần ép kiểu, an toàn tại thời điểm biên dịch

Hop<Integer> hopSo = new Hop<>();
hopSo.dat(42);

// Generic method
static <T> T phanTuDauTien(List<T> ds) {
    return ds.get(0);
}
Ghi chú
Trước khi có Generics (trước Java 5), lập trình viên phải dùng Object chung chung rồi tự ép kiểu thủ công — dễ gây lỗi ClassCastException lúc runtime. Generics chuyển việc kiểm tra kiểu sang lúc biên dịch, an toàn hơn nhiều.

📌 Tổng kết chương 18

Generics (<T>) cho phép class/method hoạt động với nhiều kiểu dữ liệu mà vẫn kiểm tra kiểu tại thời điểm biên dịch, tránh lỗi ép kiểu runtime.
