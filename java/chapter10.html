Method (Hàm)

Trong Java, mọi hàm đều phải nằm trong một class — gọi là "method".

Trong Java, mọi hàm đều phải nằm trong một class — gọi là "method".

Method.java 
public class Toan {
    public static int cong(int a, int b) {    // static = gọi được KHÔNG CẦN tạo object
        return a + b;
    }

    public static int giaiThua(int n) {
        if (n <= 1) return 1;
        return n * giaiThua(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(cong(3, 5));       // 8
        System.out.println(giaiThua(5));        // 120
    }
}

Overloading — nhiều method cùng tên, khác tham số

overloading.java 
static int cong(int a, int b) { return a + b; }
static double cong(double a, double b) { return a + b; }     // overload theo kiểu tham số
static int cong(int a, int b, int c) { return a + b + c; }     // overload theo SỐ LƯỢNG tham số

// Java tự động chọn đúng method phù hợp dựa trên kiểu/số lượng tham số truyền vào
Ghi chú
Method Overloading (nhiều method cùng tên nhưng khác tham số) khác với Overriding (ghi đè method của lớp cha) — hai khái niệm dễ nhầm sẽ được phân biệt rõ ở phần OOP nâng cao.

📌 Tổng kết chương 10

Method luôn thuộc về một class. static cho phép gọi method mà không cần tạo object. Overloading cho phép nhiều method cùng tên với tham số khác nhau.
