Chương 27 — Service & Repository (JPA)

Kiến trúc 3 lớp chuẩn của Spring Boot: Controller → Service → Repository — và JPA để làm việc với database không cần viết SQL thủ công.

SinhVien.java (Entity) 
import jakarta.persistence.*;

@Entity                                    // đánh dấu class này ánh xạ với 1 bảng database
public class SinhVien {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)   // tự động tăng id
    private Long id;
    private String ten;
    private double diem;
    // constructor, getter, setter...
}
SinhVienRepository.java 
import org.springframework.data.jpa.repository.JpaRepository;

public interface SinhVienRepository extends JpaRepository<SinhVien, Long> {
    // KHÔNG CẦN viết implementation - Spring Data JPA tự sinh code thực thi!
    List<SinhVien> findByDiemGreaterThan(double diem);   // tự sinh câu truy vấn từ TÊN method
}
SinhVienService.java 
@Service
public class SinhVienService {
    private final SinhVienRepository repo;

    public SinhVienService(SinhVienRepository repo) {   // dependency injection qua constructor
        this.repo = repo;
    }

    public SinhVien taoSinhVien(SinhVien sv) {
        // có thể thêm logic nghiệp vụ (validate, tính toán...) TRƯỚC khi lưu
        return repo.save(sv);
    }

    public List<SinhVien> laySinhVienGioi() {
        return repo.findByDiemGreaterThan(8.0);
    }
}
Mẹo
Spring Data JPA có thể tự sinh câu truy vấn từ tên method (VD: findByDiemGreaterThan) — không cần viết SQL cho các truy vấn đơn giản, giúp tiết kiệm rất nhiều code lặp lại (boilerplate).

Kiến trúc 3 lớp: Controller (xử lý HTTP) → Service (logic nghiệp vụ) → Repository (truy cập dữ liệu). Spring Data JPA tự sinh truy vấn từ tên method, giảm code lặp lại đáng kể.
