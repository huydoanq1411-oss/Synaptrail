Độ phức tạp không gian (Space Complexity)

Đo lượng bộ nhớ bổ sung mà thuật toán cần — cũng quan trọng không kém độ phức tạp thời gian.

space_complexity.py 
def tong_O1_space(ds):          # O(1) space - chỉ dùng thêm 1 biến "tong", KHÔNG phụ thuộc n
    tong = 0
    for x in ds:
        tong += x
    return tong

def nhan_doi_On_space(ds):       # O(n) space - tạo MẢNG MỚI có kích thước tỉ lệ với n
    ket_qua = []
    for x in ds:
        ket_qua.append(x * 2)
    return ket_qua

def giai_thua_de_quy(n):           # O(n) space - MỖI lần gọi đệ quy tốn thêm 1 khung trên call stack
    if n <= 1:
        return 1
    return n * giai_thua_de_quy(n - 1)   # n lời gọi lồng nhau -> n khung stack
Quan trọng — Đánh đổi Time vs Space
Rất nhiều kỹ thuật tối ưu (như memoization ở chương Quy hoạch động) đánh đổi tốn thêm bộ nhớ để đổi lấy tốc độ nhanh hơn — đây là sự đánh đổi (trade-off) kinh điển mà người viết thuật toán phải cân nhắc tùy theo bài toán và giới hạn tài nguyên thực tế.
Ghi chú
Độ phức tạp không gian thường KHÔNG tính bộ nhớ của chính input đầu vào — chỉ tính bộ nhớ bổ sung (auxiliary space) mà thuật toán cần thêm để chạy.

📌 Tổng kết chương 4

Space complexity đo bộ nhớ bổ sung cần thiết, bao gồm cả call stack của đệ quy. Time và space thường đánh đổi lẫn nhau — tối ưu cái này có thể phải hy sinh cái kia.
