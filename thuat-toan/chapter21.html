Binary Search Tree (BST)

BST duy trì thứ tự trên toàn cây con; gốc có thể thay đổi sau cập nhật và độ cao không tự được đảm bảo.

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 5.3, BT5. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài tìm/thêm/xóa BST.
  • Xử lý ba trường hợp xóa và khóa trùng.

Vấn đề thực tế

Một tập khóa thay đổi cần duy trì thứ tự để tra cứu và liệt kê tăng dần mà không sắp lại toàn bộ sau mỗi lần thêm.

Lý thuyết nền

BST (Binary Search Tree, cây nhị phân tìm kiếm): mọi khóa trong cây con trái nhỏ hơn khóa nút, mọi khóa bên phải lớn hơn. Đây là điều kiện trên toàn cây con, không chỉ hai nút con trực tiếp. Khóa phải so sánh nhất quán; bản này dùng khóa số hữu hạn và bỏ qua lần thêm khóa trùng.

Tìm/thêm đi theo một nhánh từ gốc, chi phí O(h+1). Cây cân bằng h=O(log n); thêm dãy tăng vào BST thường có thể làm h=n−1, chi phí O(n). Duyệt LNR cho tăng dần.

Xóa: lá thành null; một con trả con thay thế; hai con thay khóa bằng successor (nút nhỏ nhất của cây con phải) rồi xóa successor ở vị trí cũ. Có thể dùng predecessor lớn nhất bên trái thay thế nhưng phải thống nhất. Mỗi thao tác trả gốc mới để bên gọi cập nhật, kể cả khi xóa gốc.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter21.cjs rồi chạy node chapter21.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter21.cjs · JavaScript
function node(key) { return {key, left:null, right:null}; }
 function insert(root, key) {
   if (!Number.isFinite(key)) throw new TypeError('Khóa phải là số hữu hạn');
   if (!root) return node(key);
   if (key < root.key) root.left = insert(root.left, key);
   else if (key > root.key) root.right = insert(root.right, key);
   return root;
 }
 function search(root, key) {
   while (root && root.key !== key) root = key < root.key ? root.left : root.right;
   return root;
 }
 function minimum(root) { while (root.left) root = root.left; return root; }
 function remove(root, key) {
   if (!root) return null;
   if (key < root.key) root.left = remove(root.left, key);
   else if (key > root.key) root.right = remove(root.right, key);
   else {
     if (!root.left) return root.right;
     if (!root.right) return root.left;
     root.key = minimum(root.right).key;
     root.right = remove(root.right, root.key);
   }
   return root;
 }
 function inorder(root, out = []) {
   if (root) { inorder(root.left, out); out.push(root.key); inorder(root.right, out); }
   return out;
 }
 let root = null;
 for (const x of [54,31,43,29,65,10,20,36,78,59]) root = insert(root, x);
 root = remove(root, 31);
 console.log(inorder(root)); // [10,20,29,36,43,54,59,65,78]
 console.log(search(root, 31)); // null

Giải thích các đoạn quan trọng

  1. node tạo lá. insert trả root ở mỗi mức và gán kết quả vào liên kết con phù hợp.
  2. search chỉ đi một nhánh; null báo không tìm thấy.
  3. remove trả ngay con thay thế ở trường hợp có tối đa một con.
  4. Với hai con, minimum đi hết nhánh trái của cây con phải; xóa bản sao cũ sau khi thay khóa.
  5. Lệnh root=remove(...) giữ được gốc mới; quy tắc tương tự cho thêm và cân bằng.

Lỗi thường gặp

  • Chỉ kiểm cha với con trực tiếp khi xác minh BST.
  • Bỏ qua giá trị trả về sau khi xóa gốc.
  • Thay khóa successor nhưng không xóa nút successor cũ.
