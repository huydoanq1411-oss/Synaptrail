Counting Sort & Radix Sort

Sắp phân phối cần điều kiện miền khóa; chi phí phụ thuộc K hoặc số chữ số d và cơ số b.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.10, 3.11. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Sắp theo tần suất hoặc từng chữ số.
  • Nêu miền giá trị, tính ổn định và chi phí.

Vấn đề thực tế

Điểm nguyên thuộc một miền hẹp hoặc mã số có số chữ số hữu hạn có thể được sắp bằng phân phối thay vì so mọi cặp.

Lý thuyết nền

Counting Sort đếm tần suất từng giá trị trong miền K, rồi phát lại theo thứ tự: O(n+K) thời gian, bản dưới dùng O(n+K) bộ nhớ kể cả đầu ra. Bản phát giá trị số không giữ dữ liệu bản ghi; muốn ổn định cho bản ghi cần mảng vị trí cộng dồn và đặt phần tử đúng thứ tự.

Radix Sort LSD (least significant digit, chữ số ít quan trọng trước) phân phối vào các bucket 0…b−1 từ hàng đơn vị lên. Mỗi lượt phải ổn định, giữ thứ tự trong từng bucket; nếu phá thứ tự thì kết quả từ lượt trước bị mất. Với d chữ số cơ số b, thời gian O(d(n+b)), bộ nhớ phụ O(n+b); không mặc định O(n log n).

Ví dụ dưới nhận số nguyên không âm an toàn của JavaScript. Số âm phải có quy ước xử lý dấu riêng. Counting Sort không phù hợp miền cực rộng; ví dụ giới hạn max ≤ 100000 để tránh cấp phát quá lớn.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter10.cjs rồi chạy node chapter10.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter10.cjs · JavaScript
function kiemTra(a) {
   if (!a.every(x => Number.isSafeInteger(x) && x >= 0))
     throw new RangeError('Cần số nguyên không âm an toàn');
 }
 function countingSort(a) {
   kiemTra(a); if (!a.length) return [];
   let max = 0; for (const x of a) max = Math.max(max, x);
   if (max > 100000) throw new RangeError('Miền đếm quá rộng');
   const count = Array(max + 1).fill(0), out = [];
   for (const x of a) count[x]++;
   for (let x = 0; x <= max; x++)
     for (let k = 0; k < count[x]; k++) out.push(x);
   return out;
 }
 function radixSort(a) {
   kiemTra(a); let out = [...a], max = 0;
   for (const x of a) max = Math.max(max, x);
   for (let exp = 1; Math.floor(max / exp) > 0; exp *= 10) {
     const buckets = Array.from({length: 10}, () => []);
     for (const x of out) buckets[Math.floor(x / exp) % 10].push(x);
     out = buckets.flat();
   }
   return out;
 }
 console.log(radixSort([7013,8425,1239,428,1424,7009,4518,3252,9170,999,1725,701]));
 // [428,701,999,1239,1424,1725,3252,4518,7009,7013,8425,9170]

Giải thích các đoạn quan trọng

  1. kiemTra ngăn số âm, số lẻ và số vượt miền nguyên chính xác.
  2. Counting tăng ô tần suất rồi phát lại count[x] lần.
  3. Radix dùng exp=1,10,100… để lấy từng chữ số; push giữ thứ tự vào bucket.
  4. flat nối bucket theo thứ tự chữ số. Số 0 và dãy rỗng không cần lượt phân phối nào và vẫn đúng.

Lỗi thường gặp

  • Dùng Array.fill([]) làm mọi bucket trỏ cùng mảng.
  • Đưa số âm trực tiếp vào chỉ số chữ số.

Bài tập ba mức

Mức 1 — Cơ bản

Đếm tần suất [2, 0, 2, 1].

Mức 2 — Vận dụng

Lập các bucket cho hàng đơn vị và chục của dãy trong ví dụ.

Mức 3 — Nâng cao

Bổ sung xử lý số âm và kiểm tra thứ tự, hoặc viết Counting ổn định cho bản ghi có cùng điểm.
