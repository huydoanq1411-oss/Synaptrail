Array vs Linked List

Chi phí tìm vị trí thường lớn hơn sửa liên kết; kiểu danh sách quyết định bất biến cần giữ.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 4.1, 4.5. Nguồn và mục lục đối chiếu.

Mục tiêu

  • So sánh truy cập, thêm/xóa và chi phí bộ nhớ.
  • Nhận biết danh sách đơn, kép và vòng.

Vấn đề thực tế

Danh sách sinh viên thay đổi thường xuyên; cần chọn mảng hay các nút liên kết theo thao tác chính thay vì chỉ theo số lượng dữ liệu.

Lý thuyết nền

Mảng cổ điển chứa các phần tử liên tiếp; chỉ số cho truy cập O(1). Chèn/xóa giữa mảng cần dịch O(n). Mảng động có thể tăng dung lượng; không nên phát biểu mọi mảng có kích thước cố định. JavaScript Array là cấu trúc của ngôn ngữ, không đảm bảo mọi kiểu phần tử có biểu diễn liên tiếp như mảng C++.

Linked List (danh sách liên kết) dùng node (nút) có dữ liệu và liên kết. Truy cập vị trí thứ i cần đi từ đầu O(n). Thêm sau một nút đã biết là O(1); nếu phải tìm nút trước thì tổng thao tác vẫn O(n). Nút và các liên kết có chi phí bộ nhớ; danh sách không mặc định tiết kiệm hơn mảng.

  • Đơn: mỗi nút có next; nút cuối next=null.
  • Kép: thêm prev, liên kết hai chiều; khi chèn/xóa phải sửa cả hai phía.
  • Vòng đơn: tail.next=head; vòng kép thêm head.prev=tail. Duyệt dừng khi quay lại nút đầu, không chờ null.

Trong C++ con trỏ là địa chỉ, cấp phát/giải phóng phải khớp nhau; JavaScript dùng tham chiếu đối tượng. Biến trỏ null khác với một nút chứa dữ liệu null.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter16.cjs rồi chạy node chapter16.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter16.cjs · JavaScript
const dau = {value: 'An', next: null};
 const cuoi = {value: 'Bình', next: null};
 dau.next = cuoi;
 function layTai(head, index) {
   if (!Number.isInteger(index) || index < 0) return null;
   let node = head;
   for (let i = 0; node && i < index; i++) node = node.next;
   return node;
 }
 console.log(layTai(dau, 1).value); // Bình
 const a = {value: 1, next: null, prev: null};
 const b = {value: 2, next: a, prev: a};
 a.next = b; a.prev = b; // Hai nút tạo danh sách kép vòng.
 const values = []; let p = a;
 do { values.push(p.value); p = p.next; } while (p !== a);
 console.log(values); // [1, 2]

Giải thích các đoạn quan trọng

  1. dau.next=cuoi thiết lập liên kết; không sao chép bản ghi cuối.
  2. layTai tăng qua next đúng index lần hoặc dừng khi hết.
  3. Hai nút vòng có cả next và prev trỏ đúng phía; nút cuối không chứa next=null.
  4. do…while ở đây chỉ dùng vì đã biết vòng không rỗng; với vòng rỗng phải kiểm head trước.

Lỗi thường gặp

  • Nói mọi thêm/xóa Linked List đều O(1) dù phải tìm vị trí.
  • Duyệt danh sách vòng bằng while(node !== null).

Bài tập ba mức

Mức 1 — Cơ bản

Lập bảng chi phí truy cập, tìm và chèn của mảng/danh sách.

Mức 2 — Vận dụng

Vẽ lại prev/next khi chèn một nút giữa hai nút của danh sách kép.

Mức 3 — Nâng cao

Thiết kế danh sách kép vòng cho chuyến bay, chèn tăng theo mã; truy vấn theo ngày và hủy danh sách khi kết thúc (BT4.6).
