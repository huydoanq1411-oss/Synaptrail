22 Cây cân bằng (AVL)

BST tự động "cân bằng lại" sau mỗi lần thêm/xóa — đảm bảo O(log n) LUÔN ĐÚNG, không suy biến như BST thường.

Hệ số cân bằng (Balance Factor)

Với mỗi node, hệ số cân bằng = chiều cao(nhánh trái) - chiều cao(nhánh phải). Cây AVL yêu cầu hệ số này luôn nằm trong khoảng [-1, 0, 1] ở MỌI node.

avl_rotation.py 
def chieu_cao(node):
    return node.chieu_cao if node else 0

def he_so_can_bang(node):
    return chieu_cao(node.trai) - chieu_cao(node.phai)

def xoay_phai(y):                        # xoay để cân bằng lại khi lệch trái quá nhiều
    x = y.trai
    T2 = x.phai
    x.phai = y
    y.trai = T2
    y.chieu_cao = 1 + max(chieu_cao(y.trai), chieu_cao(y.phai))
    x.chieu_cao = 1 + max(chieu_cao(x.trai), chieu_cao(x.phai))
    return x                                # x trở thành gốc mới của nhánh con này

def xoay_trai(x):                        # xoay để cân bằng lại khi lệch phải quá nhiều
    y = x.phai
    T2 = y.trai
    y.trai = x
    x.phai = T2
    x.chieu_cao = 1 + max(chieu_cao(x.trai), chieu_cao(x.phai))
    y.chieu_cao = 1 + max(chieu_cao(y.trai), chieu_cao(y.phai))
    return y

4 trường hợp mất cân bằng cần xử lý

Trường hợpCách xử lý
Left-Left (lệch trái của trái)Xoay phải MỘT LẦN
Right-Right (lệch phải của phải)Xoay trái MỘT LẦN
Left-Right (lệch trái rồi phải)Xoay trái nhánh con, rồi xoay phải
Right-Left (lệch phải rồi trái)Xoay phải nhánh con, rồi xoay trái
Ghi chú thực tế
Trong công việc hàng ngày, bạn hầu như không bao giờ tự cài đặt AVL Tree từ đầu — hiểu nguyên lý là đủ. Các ngôn ngữ/thư viện đã có cấu trúc cân bằng sẵn (VD: TreeMap trong Java dùng Red-Black Tree, một biến thể cây cân bằng khác).

📌 Tổng kết chương 22

AVL Tree tự cân bằng bằng các phép xoay (rotation) sau mỗi lần thêm/xóa, đảm bảo hệ số cân bằng luôn trong [-1,1] — giữ O(log n) trong MỌI trường hợp, khắc phục nhược điểm suy biến của BST thường.
