Cây cân bằng (AVL)

AVL giữ thứ tự BST và bất biến chiều cao; xóa cần phục hồi từ điểm xóa về tận gốc khi cần.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 5.4, BT5.c. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Nhận biết LL/LR/RR/RL.
  • Cài thêm/xóa và cập nhật chiều cao AVL.

Vấn đề thực tế

BST thêm dãy đã tăng bị dài như danh sách; cần tự phục hồi chiều cao sau các lần thêm hoặc xóa.

Lý thuyết nền

AVL là BST có chênh lệch chiều cao hai cây con tại mọi nút không quá 1. Quy ước trong code: height(null)=0, lá=1 (đếm theo số nút), balance=height(left)−height(right). Quy ước này khác bài chiều cao theo cạnh đúng 1 đơn vị, nhưng chênh lệch không đổi. Tài liệu gọi LH/EH/RH là lệch trái/cân bằng/lệch phải; không suy diễn dấu khi tài liệu dùng quy ước khác.

  • LL: nút lệch trái và con trái không lệch phải → quay phải.
  • LR: lệch trái nhưng con trái lệch phải → quay trái con trái, rồi quay phải nút.
  • RR: lệch phải và con phải không lệch trái → quay trái.
  • RL: lệch phải nhưng con phải lệch trái → quay phải con phải, rồi quay trái nút.

Phép quay giữ thứ tự LNR; phải cập nhật chiều cao nút cũ trước nút mới. Thêm như BST rồi cân bằng từ dưới lên. Xóa như BST rồi cân bằng mọi tổ tiên bị ảnh hưởng, có thể lan đến gốc; không chỉ xử lý một điểm. Tìm/thêm/xóa O(log n) vì AVL giữ chiều cao logarit. Code tự chứa, dùng khóa số hữu hạn, bỏ qua trùng.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter22.cjs rồi chạy node chapter22.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter22.cjs · JavaScript
const height = n => n ? n.height : 0;
 const balance = n => n ? height(n.left) - height(n.right) : 0;
 function update(n) { n.height = 1 + Math.max(height(n.left), height(n.right)); return n; }
 function rotateRight(y) {
   const x = y.left, middle = x.right;
   x.right = y; y.left = middle;
   update(y); return update(x);
 }
 function rotateLeft(x) {
   const y = x.right, middle = y.left;
   y.left = x; x.right = middle;
   update(x); return update(y);
 }
 function rebalance(n) {
   if (!n) return null; update(n);
   if (balance(n) > 1) {
     if (balance(n.left) < 0) n.left = rotateLeft(n.left);
     return rotateRight(n);
   }
   if (balance(n) < -1) {
     if (balance(n.right) > 0) n.right = rotateRight(n.right);
     return rotateLeft(n);
   }
   return n;
 }
 function avlInsert(n, key) {
   if (!Number.isFinite(key)) throw new TypeError('Khóa phải là số hữu hạn');
   if (!n) return {key, left:null, right:null, height:1};
   if (key < n.key) n.left = avlInsert(n.left, key);
   else if (key > n.key) n.right = avlInsert(n.right, key);
   else return n;
   return rebalance(n);
 }
 function avlRemove(n, key) {
   if (!n) return null;
   if (key < n.key) n.left = avlRemove(n.left, key);
   else if (key > n.key) n.right = avlRemove(n.right, key);
   else {
     if (!n.left) return n.right;
     if (!n.right) return n.left;
     let successor = n.right; while (successor.left) successor = successor.left;
     n.key = successor.key; n.right = avlRemove(n.right, successor.key);
   }
   return rebalance(n);
 }
 function inorder(n, out = []) {
   if (n) { inorder(n.left, out); out.push(n.key); inorder(n.right, out); }
   return out;
 }
 let root = null;
 for (const x of [54,31,43,29,65,10,20,36,78,59]) root = avlInsert(root, x);
 root = avlRemove(root, 31);
 console.log(inorder(root)); // [10,20,29,36,43,54,59,65,78]

Giải thích các đoạn quan trọng

  1. height/balance dùng số nút, update lấy chiều cao con rồi cộng 1.
  2. rotateRight chuyển cây giữa từ x.right sang y.left trước khi nối x làm gốc mới; thứ tự khóa được giữ.
  3. rebalance chọn phép quay từ dấu của nút và con, nên dùng được cả khi xóa (con có thể balance=0).
  4. avlInsert/avlRemove cập nhật liên kết bằng gốc trả về; mỗi tầng quay về rebalance.
  5. Xóa hai con dùng successor giống BST; chiều cao và cân bằng phải được kiểm lại dọc đường trở về.

Lỗi thường gặp

  • Cập nhật chiều cao gốc mới trước khi cập nhật nút cũ sau quay.
  • Chọn phép quay chỉ dựa trên khóa vừa thêm khi đang xử lý xóa.
  • Dừng cân bằng ngay sau một phép quay trong quá trình xóa.

Bài tập ba mức

Mức 1 — Cơ bản

Dùng [30,20,10], [30,10,20], [10,20,30], [10,30,20] để tạo bốn kiểu lệch.

Mức 2 — Vận dụng

BT5.c: xây lại cây từ bộ khóa bài 5 bằng AVL insert; vẽ các phép quay và kiểm LNR.

Mức 3 — Nâng cao

Xóa nhiều khóa liên tiếp, sau mỗi bước kiểm thứ tự, height lưu và |balance|≤1 ở mọi nút; có ít nhất một ca lan cân bằng nhiều tầng.
