Binary Search

Tìm kiếm nhị phân — O(log n), nhanh vượt trội so với Linear Search, nhưng YÊU CẦU dữ liệu đã sắp xếp.

binary_search.py 
def binary_search(ds, target):
    trai, phai = 0, len(ds) - 1
    while trai <= phai:
        giua = trai + (phai - trai) // 2       # tránh tràn số so với (trai+phai)//2 ở ngôn ngữ khác
        if ds[giua] == target:
            return giua
        elif ds[giua] < target:
            trai = giua + 1                        # target ở nửa PHẢI
        else:
            phai = giua - 1                          # target ở nửa TRÁI
    return -1

ds = [1, 3, 5, 7, 9, 11, 13, 15]
print(binary_search(ds, 11))   # 5

Trực quan hóa quá trình tìm kiếm

Tìm 11 trong [1, 3, 5, 7, 9, 11, 13, 15]

Bước 1: trai=0, phai=7, giua=3 -> ds[3]=7 < 11  -> tìm nửa PHẢI
Bước 2: trai=4, phai=7, giua=5 -> ds[5]=11 == 11 -> TÌM THẤY tại chỉ số 5

Chỉ mất 2 bước thay vì phải duyệt 6 phần tử như Linear Search!
binary_search_de_quy.py 
def binary_search_de_quy(ds, target, trai=0, phai=None):
    if phai is None:
        phai = len(ds) - 1
    if trai > phai:
        return -1
    giua = trai + (phai - trai) // 2
    if ds[giua] == target:
        return giua
    elif ds[giua] < target:
        return binary_search_de_quy(ds, target, giua + 1, phai)
    else:
        return binary_search_de_quy(ds, target, trai, giua - 1)
Quan trọng
Binary Search BẮT BUỘC dữ liệu phải đã được sắp xếp trước. Áp dụng lên dữ liệu chưa sắp xếp sẽ cho kết quả sai (hoặc không tìm thấy dù phần tử tồn tại) mà không hề báo lỗi — đây là bug rất khó phát hiện.

📌 Tổng kết chương 13

Binary Search liên tục chia đôi phạm vi tìm kiếm, đạt O(log n) — nhưng yêu cầu bắt buộc dữ liệu đã sắp xếp. Có thể cài đặt bằng vòng lặp hoặc đệ quy.
