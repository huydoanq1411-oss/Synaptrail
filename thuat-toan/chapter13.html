Mục tiêu

  • Cài Binary Search với biên đóng.
  • Giữ điều kiện mảng tăng không giảm.

Vấn đề thực tế

Đã có mảng mã tăng dần và cần tra cứu nhiều lần; bỏ một nửa phạm vi sau mỗi phép so sánh.

Lý thuyết nền

Binary Search (tìm nhị phân) cần dữ liệu có thứ tự theo đúng comparator tìm kiếm, và truy cập phần tử giữa hiệu quả. Mảng tăng không giảm có thể chứa khóa trùng; không bắt buộc tăng nghiêm ngặt. Với đoạn đóng [left,right], nếu a[mid]<x thì loại cả nửa trái gồm mid; nếu lớn hơn thì loại nửa phải.

Bất biến: nếu x còn tồn tại trong phần chưa loại, nó nằm trong [left,right]. Dùng while(left ≤ right) để mảng rỗng không bị đọc. Thời gian tốt nhất O(1), xấu nhất O(log n); bộ nhớ phụ O(1). Sắp trước tốn chi phí riêng; không nên sắp chỉ cho một lần tìm khi tuyến tính là đủ.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter13.cjs rồi chạy node chapter13.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter13.cjs · JavaScript
function binarySearch(a, x) {
   let left = 0, right = a.length - 1;
   while (left <= right) {
     const mid = left + Math.floor((right - left) / 2);
     if (a[mid] === x) return mid;
     if (a[mid] < x) left = mid + 1;
     else right = mid - 1;
   }
   return -1;
 }
 const a = [1,2,3,4,5,6,7,8,9];
 const viTri = binarySearch(a, 5);
 if (viTri !== -1) a.splice(viTri, 1);
 console.log(a); // [1,2,3,4,6,7,8,9]
 console.log(binarySearch([], 5)); // -1

Giải thích các đoạn quan trọng

  1. right=n−1 làm đoạn rỗng khi n=0; while không chạy nên an toàn.
  2. mid tính từ độ dài đoạn; công thức cũng tránh cộng hai chỉ số lớn trong ngôn ngữ số nguyên hữu hạn.
  3. mid±1 bỏ vị trí đã xét và làm đoạn nhỏ lại.
  4. splice xóa một phần tử sau khi tìm, cần dịch phần sau nên tổng tìm-rồi-xóa vẫn có thể O(n).

Lỗi thường gặp

  • Tìm nhị phân trên dữ liệu chưa sắp.
  • Dùng do…while khiến mảng rỗng vẫn đọc mid một lần.
  • Kết luận thao tác xóa mảng O(log n) chỉ vì tìm vị trí O(log n).

Bài tập ba mức

Mức 1 — Cơ bản

Theo dõi left/right/mid khi tìm 8 trong [1…9].

Mức 2 — Vận dụng

Nhập mảng, sắp tăng, tìm X và xóa một lần xuất hiện nếu có; thử X ngoài miền.

Mức 3 — Nâng cao

So sánh một lần tìm với nhiều lần tìm, tính cả chi phí sắp trước và dịch sau xóa.
