15 Hashing & Tra cứu O(1)

Kỹ thuật cho phép tra cứu gần như tức thì — nền tảng của dictionary/HashMap trong mọi ngôn ngữ.

Hash Function là gì?

Hàm băm (hash function) chuyển đổi một giá trị bất kỳ (chuỗi, số, object...) thành một chỉ số nguyên trong một phạm vi cố định — dùng chỉ số đó để lưu/tra cứu trực tiếp trong mảng, tránh phải tìm kiếm tuần tự.

hashing_concept.py 
# Minh họa ý tưởng (không phải cài đặt thực tế của Python dict)
def hash_don_gian(key, kich_thuoc_bang):
    return sum(ord(c) for c in key) % kich_thuoc_bang    # cộng mã ASCII rồi lấy phần dư

print(hash_don_gian("Huy", 10))     # luôn cho cùng 1 kết quả với cùng input
print(hash_don_gian("Lan", 10))

# Trong thực tế, chỉ cần dùng dict/set có sẵn - đã cài đặt hashing tối ưu bên dưới
demo = {}
demo["Huy"] = 85          # O(1) trung bình để THÊM
print(demo["Huy"])          # O(1) trung bình để TRA CỨU

Xung đột hash (Collision) và cách xử lý

Hai key khác nhau có thể cho ra cùng một chỉ số hash (gọi là "va chạm"/collision). Hai kỹ thuật xử lý phổ biến:

Kỹ thuậtCách hoạt động
ChainingMỗi ô của bảng hash chứa một danh sách liên kết các phần tử va chạm
Open AddressingKhi va chạm, tìm ô trống tiếp theo theo một quy tắc dò tuyến tính/bậc hai
Quan trọng
Độ phức tạp O(1) của hash table là trung bình (average case), không phải đảm bảo tuyệt đối — trường hợp xấu nhất (rất nhiều va chạm) có thể suy biến thành O(n). Trong thực tế, các cài đặt hash table tốt (như Python dict) hiếm khi rơi vào trường hợp này.

Ứng dụng: Two Sum tối ưu bằng Hashing

two_sum_hashing.py 
def two_sum(ds, target):              # O(n) nhờ hashing, thay vì O(n²) duyệt lồng nhau
    da_thay = {}
    for i, x in enumerate(ds):
        con_lai = target - x
        if con_lai in da_thay:            # tra cứu O(1) trong dict
            return [da_thay[con_lai], i]
        da_thay[x] = i
    return []

print(two_sum([2, 7, 11, 15], 9))   # [0, 1]

Hashing chuyển key thành chỉ số để tra cứu O(1) trung bình, xử lý va chạm bằng chaining hoặc open addressing — kỹ thuật cực kỳ quan trọng để tối ưu độ phức tạp từ O(n²) xuống O(n) trong nhiều bài toán.
