Biến thể Binary Search

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 2.3. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Tìm biên trái/phải khi có khóa trùng.
  • Dùng n như vị trí chèn hợp lệ.

Vấn đề thực tế

Tìm số lượng bản ghi có cùng điểm: một vị trí bất kỳ chưa đủ, cần cả đầu và cuối đoạn có cùng khóa.

Lý thuyết nền

Phần mở rộng từ Binary Search: lower_bound là vị trí đầu có a[i] ≥ x; upper_bound là vị trí đầu có a[i] > x. Không có vị trí thỏa thì trả n. Dùng đoạn nửa mở [left,right), ban đầu right=n; khi left=right đó là vị trí chèn.

Đếm số lần xuất hiện x bằng upper−lower. Chỉ đọc a[lower] nếu lower<n. Tìm đầu tiên chính là lower nếu khóa khớp; cuối cùng là upper−1 khi đoạn không rỗng. Mỗi lần tìm biên O(log n), phụ O(1). Nội dung biến thể này mở rộng tài liệu, quiz chỉ hỏi những gì đã giải thích ở đây.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter14.cjs rồi chạy node chapter14.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter14.cjs · JavaScript
function lowerBound(a, x) {
   let left = 0, right = a.length;
   while (left < right) {
     const mid = left + Math.floor((right - left) / 2);
     if (a[mid] < x) left = mid + 1;
     else right = mid;
   }
   return left;
 }
 function upperBound(a, x) {
   let left = 0, right = a.length;
   while (left < right) {
     const mid = left + Math.floor((right - left) / 2);
     if (a[mid] <= x) left = mid + 1;
     else right = mid;
   }
   return left;
 }
 const a = [1,2,2,2,4];
 console.log(lowerBound(a, 2), upperBound(a, 2)); // 1 4
 console.log(upperBound(a, 2) - lowerBound(a, 2)); // 3

Giải thích các đoạn quan trọng

  1. right không thuộc đoạn nên vòng lặp dùng <, không dùng <=.
  2. lower đẩy trái chỉ khi nhỏ hơn x; upper đẩy trái cả khi bằng x.
  3. right=mid giữ ứng viên làm biên, không loại nó như bản tìm một khóa.
  4. Hai kết quả 1 và 4 tạo đoạn [1,4), dài 3.

Lỗi thường gặp

  • Trộn cập nhật của đoạn đóng với điều kiện của đoạn nửa mở.
  • Đọc a[n] sau khi không có phần tử thỏa.

Bài tập ba mức

Mức 1 — Cơ bản

Tính hai biên của 2 trong [1,2,2,4].

Mức 2 — Vận dụng

Trả vị trí đầu/cuối hoặc −1 cho khóa không xuất hiện.

Mức 3 — Nâng cao

Đếm phần tử trong khoảng giá trị [L,R] bằng hai phép tìm biên; thử L>R.
