Chương 14 — Biến thể Binary Search

Các bài toán mở rộng từ ý tưởng chia đôi — rất hay gặp trong phỏng vấn kỹ thuật.

Tìm vị trí chèn (Lower Bound)

lower_bound.py 
def tim_vi_tri_chen(ds, target):
    trai, phai = 0, len(ds)
    while trai < phai:
        giua = (trai + phai) // 2
        if ds[giua] < target:
            trai = giua + 1
        else:
            phai = giua
    return trai      # vị trí ĐẦU TIÊN có thể chèn target mà vẫn giữ thứ tự sắp xếp

print(tim_vi_tri_chen([1, 3, 3, 5, 7], 3))   # 1 - vị trí đầu tiên của giá trị 3
print(tim_vi_tri_chen([1, 3, 3, 5, 7], 4))   # 3 - chèn giữa 3 và 5

Tìm kiếm trong mảng xoay (Rotated Sorted Array)

search_rotated_array.py 
# Mảng đã sắp xếp nhưng bị "xoay" tại một điểm nào đó, VD: [4,5,6,7,0,1,2]
def search_rotated(ds, target):
    trai, phai = 0, len(ds) - 1
    while trai <= phai:
        giua = (trai + phai) // 2
        if ds[giua] == target:
            return giua
        if ds[trai] <= ds[giua]:              # nửa TRÁI đang có thứ tự (không bị xoay)
            if ds[trai] <= target < ds[giua]:
                phai = giua - 1
            else:
                trai = giua + 1
        else:                                    # nửa PHẢI đang có thứ tự
            if ds[giua] < target <= ds[phai]:
                trai = giua + 1
            else:
                phai = giua - 1
    return -1

print(search_rotated([4,5,6,7,0,1,2], 0))   # 4

Binary Search trên đáp số (Binary Search on Answer)

Kỹ thuật nâng cao: áp dụng ý tưởng chia đôi không phải trên mảng, mà trên không gian đáp số có thể có của bài toán — miễn là đáp số có tính chất "đơn điệu" (monotonic).

Mẹo
Dấu hiệu nhận biết bài toán phù hợp với "Binary Search on Answer": câu hỏi dạng "giá trị nhỏ nhất/lớn nhất thỏa mãn điều kiện X là bao nhiêu?" và việc kiểm tra "X có thỏa mãn không" có thể làm nhanh (thường O(n)).

📌 Tổng kết chương 14

Ý tưởng chia đôi của Binary Search mở rộng ra nhiều bài toán: tìm vị trí chèn, tìm kiếm trong mảng xoay, và "binary search on answer" — kỹ thuật rất mạnh trong các bài toán tối ưu hóa.
