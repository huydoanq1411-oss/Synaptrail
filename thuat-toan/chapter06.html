Insertion Sort & Shell Sort

Insertion tận dụng thứ tự có sẵn; Shell cho phần tử dịch xa trước nhưng cần khai báo rõ dãy gap.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.4, 3.8. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài Insertion Sort và Shell Sort.
  • Giải thích ảnh hưởng của khoảng cách gap.

Vấn đề thực tế

Xếp một lá bài mới vào phần bài đã có thứ tự; nếu phần tử cách vị trí đúng rất xa thì có thể dịch chuyển theo khoảng lớn trước.

Lý thuyết nền

Insertion Sort (chèn trực tiếp) duy trì đoạn đầu đã sắp. Giữ key, dịch các phần tử lớn hơn sang phải rồi chèn key vào chỗ trống. Với dãy đã tăng, vòng trong dừng ngay: Θ(n); trung bình và xấu nhất Θ(n²). Dùng so sánh nghiêm ngặt > để giữ ổn định, bộ nhớ phụ O(1).

Shell Sort áp dụng chèn trực tiếp trên các dãy con cách nhau gap vị trí. Giảm gap dần và kết thúc bằng gap = 1. Ví dụ tài liệu dùng 3 rồi 1 cho dãy bảy phần tử. Bản dưới chọn floor(n/2), chia đôi đến 1. Không ổn định; cận phụ thuộc dãy gap, bản chia đôi có xấu nhất O(n²), không gán chung O(n log n).

Ví dụ có thể chạy

chapter06.cjs · JavaScript
function insertionSort(a) {
   for (let i = 1; i < a.length; i++) {
     const key = a[i]; let j = i - 1;
     while (j >= 0 && a[j] > key) {
       a[j + 1] = a[j]; j--;
     }
     a[j + 1] = key;
   }
   return a;
 }
 function shellSort(a) {
   for (let gap = Math.floor(a.length / 2); gap > 0;
        gap = Math.floor(gap / 2)) {
     for (let i = gap; i < a.length; i++) {
       const key = a[i]; let j = i;
       while (j >= gap && a[j - gap] > key) {
         a[j] = a[j - gap]; j -= gap;
       }
       a[j] = key;
     }
   }
   return a;
 }
 console.log(shellSort([1, 4, 8, 9, 0, 12, -5]));
 // [-5, 0, 1, 4, 8, 9, 12]

Giải thích các đoạn quan trọng

  1. key giữ giá trị trước khi dịch để không ghi mất phần tử cần chèn.
  2. Kiểm tra j >= 0 trước truy cập a[j]; chèn tại j+1 khi vòng trong dừng.
  3. Shell thay bước 1 bằng gap; j >= gap đảm bảo j−gap hợp lệ.
  4. Với n=7, gap lần lượt là 3 và 1; lượt cuối chèn trên toàn dãy.

Lỗi thường gặp

  • Đọc a[j] trước khi kiểm tra chỉ số trong C/C++.
  • Quên gap=1 hoặc để gap không giảm, làm sai kết quả hay không dừng.

Bài tập ba mức

Mức 1 — Cơ bản

Chèn 0 vào đoạn [1, 4, 8, 9] và ghi các lần dịch.

Mức 2 — Vận dụng

Theo dõi Shell với gap 3, 1 trên dãy bảy số trong tài liệu.

Mức 3 — Nâng cao

So sánh số lần dịch trên dãy đã sắp và đảo; nêu rõ không suy ra cận tổng quát từ một lần đo.
