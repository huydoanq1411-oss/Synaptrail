Chương 12 — Linear Search

Thuật toán tìm kiếm đơn giản nhất — duyệt tuần tự từng phần tử cho tới khi tìm thấy.

linear_search.py 
def linear_search(ds, target):
    for i, x in enumerate(ds):
        if x == target:
            return i          # trả về chỉ số ngay khi tìm thấy
    return -1                    # không tìm thấy

print(linear_search([4, 2, 7, 1, 9], 7))   # 2
print(linear_search([4, 2, 7, 1, 9], 100)) # -1
Trường hợpĐộ phức tạp
Tốt nhất (phần tử đầu tiên)O(1)
Xấu nhất (phần tử cuối/không có)O(n)
Mẹo
Linear Search là lựa chọn DUY NHẤT khi dữ liệu chưa được sắp xếp — không có cách nào tìm nhanh hơn O(n) nếu không biết trước thứ tự của dữ liệu.

📌 Tổng kết chương 12

Linear Search duyệt tuần tự, O(n), hoạt động với mọi loại dữ liệu kể cả chưa sắp xếp — nhưng chậm hơn nhiều so với Binary Search khi dữ liệu đã sắp xếp.
