Linear Search

Tìm một khóa có thể dừng sớm; lọc/xóa toàn bộ phải quét hết và bảo vệ dữ liệu chưa đọc.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 2.1, 2.2, 2.4, BT2. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài tìm tuyến tính và lính canh.
  • Lọc/xóa theo điều kiện mà không bỏ sót phần tử.

Vấn đề thực tế

Dữ liệu chưa sắp cần tìm mã, lọc số dương chia hết cho 3 hoặc xóa các số dương có hai chữ số.

Lý thuyết nền

Linear Search / Sequential Search (tìm tuyến tính/tuần tự) so khóa từng phần tử đến khi tìm thấy hoặc hết dãy. Không cần dữ liệu đã sắp; trả chỉ số đầu tiên hoặc −1. Tốt nhất Θ(1), xấu nhất Θ(n), phụ O(1). Tìm mọi phần tử thỏa điều kiện vẫn phải xét hết.

Sentinel (lính canh) đặt một bản sao của khóa ở ô cuối bổ sung để vòng quét không cần kiểm biên mỗi lượt. Trong C/C++ phải thật sự có ô hợp lệ a[n], không được ghi ngoài vùng cấp phát. Bản dưới sao chép rồi thêm lính canh nên dùng O(n) phụ; kiểm i < n để phân biệt khóa thật với lính canh.

Xóa nhiều phần tử bằng dịch trái cần kiểm lại vị trí vừa dịch về. Có thể dùng kỹ thuật hai chỉ số đọc/ghi để nén mảng một lượt; chỉ ghi những phần tử muốn giữ, rồi thu ngắn length.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter12.cjs rồi chạy node chapter12.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter12.cjs · JavaScript
function linearSearch(a, x) {
   for (let i = 0; i < a.length; i++) if (a[i] === x) return i;
   return -1;
 }
 function sentinelSearch(a, x) {
   const b = [...a, x], n = a.length; let i = 0;
   while (b[i] !== x) i++;
   return i < n ? i : -1;
 }
 function xoaDuongHaiChuSo(a) {
   let ghi = 0;
   for (let doc = 0; doc < a.length; doc++)
     if (!(a[doc] >= 10 && a[doc] <= 99)) a[ghi++] = a[doc];
   a.length = ghi;
   return a;
 }
 console.log([0,9,12,-4,5,-1,22,4].filter(x => x > 0 && x % 3 === 0)); // [9,12]
 console.log(xoaDuongHaiChuSo([3,11,44,55,6,9,122])); // [3,6,9,122]
 console.log(sentinelSearch([2, 4, 4], 4)); // 1

Giải thích các đoạn quan trọng

  1. linearSearch trả ngay chỉ số đầu tiên. −1 là tín hiệu không có khóa, không phải chỉ số cần đọc.
  2. b có n+1 ô, nên chắc chắn gặp x; chỉ số n chỉ là lính canh.
  3. doc quét mọi ô ban đầu; ghi luôn không vượt doc nên không ghi hỏng phần chưa đọc.
  4. Cuối vòng, length=ghi bỏ các ô dư. Ví dụ áp dụng trên số nguyên, không dùng khoảng 10…99 để phân loại số thực.

Lỗi thường gặp

  • Xem chỉ số 0 là false và kết luận không tìm thấy.
  • Tăng chỉ số sau xóa bằng dịch trái làm bỏ sót hai phần tử liên tiếp cần xóa.

Bài tập ba mức

Mức 1 — Cơ bản

Tìm các số lẻ trong A và lưu sang B; thử cả số âm, rỗng và không có số lẻ.

Mức 2 — Vận dụng

Đếm khoảng trắng, chữ số ASCII 0–9 và chữ hoa A–Z trong chuỗi; ghi rõ nếu mở rộng Unicode.

Mức 3 — Nâng cao

Viết và so sánh xóa bằng dịch trái với nén hai chỉ số trên dãy có nhiều số hai chữ số liên tiếp.
