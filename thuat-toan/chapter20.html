Binary Tree & Duyệt cây

Chốt quy ước chiều cao và thứ tự duyệt; toàn bộ phép duyệt luôn phải thăm từng nút.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 5.1, 5.2, BT5.a. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Hiểu thuật ngữ cây và cách biểu diễn.
  • Duyệt đủ sáu thứ tự và tính đúng chi phí.

Vấn đề thực tế

Thư mục và biểu thức toán có cấu trúc phân cấp; cần thăm từng nút theo thứ tự phục vụ in biểu thức hay xóa cây.

Lý thuyết nền

Tree (cây) có root (gốc), quan hệ parent/child (cha/con), leaf (lá, không con), subtree (cây con). Bậc nút là số con; bậc cây là bậc lớn nhất. Depth/level là số cạnh từ gốc, gốc mức 0. Quy ước ở bài này: height (chiều cao) tính theo cạnh, cây rỗng −1, lá 0.

Binary tree (cây nhị phân) có tối đa hai con phân biệt trái/phải. Mức i tối đa 2ⁱ nút; cây cao h ≥ 0 có từ h+1 đến 2^(h+1)−1 nút. Perfect (cây hoàn hảo) lấp đầy mọi mức; complete (cây hoàn chỉnh) lấp đầy các mức trước, mức cuối dồn trái. Cây complete n nút cao floor(log₂ n), còn công thức log₂(n+1)−1 chính xác với perfect.

Biểu diễn bằng nút left/right và tùy chọn parent; mảng theo chỉ số con 2i+1/2i+2 phù hợp cây hoàn chỉnh nhưng lãng phí với cây lệch; mảng parent lưu chỉ số cha cần quy ước riêng. Cây biểu thức có toán tử tại nút trong, toán hạng ở lá.

N là nút, L trái, R phải: NLR/NRL là tiền tự; LNR/RNL là trung tự; LRN/RLN là hậu tự. Thăm đủ n nút mất Θ(n), stack O(h+1), không phải O(log h). Trung tự chỉ tăng khi cây có thêm tính chất BST.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter20.cjs rồi chạy node chapter20.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter20.cjs · JavaScript
function duyet(root, order = 'LNR', out = []) {
   if (!['NLR','NRL','LNR','RNL','LRN','RLN'].includes(order))
     throw new RangeError('Thứ tự không hợp lệ');
   if (!root) return out;
   for (const step of order) {
     if (step === 'N') out.push(root.key);
     else duyet(step === 'L' ? root.left : root.right, order, out);
   }
   return out;
 }
 function chieuCao(root) {
   return root ? 1 + Math.max(chieuCao(root.left), chieuCao(root.right)) : -1;
 }
 const tree = {key:2, left:{key:1,left:null,right:null}, right:{key:3,left:null,right:null}};
 for (const order of ['NLR','NRL','LNR','RNL','LRN','RLN'])
   console.log(order, duyet(tree, order));
 // NLR [2,1,3]; NRL [2,3,1]; LNR [1,2,3]; RNL [3,2,1]
 // LRN [1,3,2]; RLN [3,1,2]
 console.log(chieuCao(tree)); // 1

Giải thích các đoạn quan trọng

  1. root=null là điểm dừng của mỗi cây con.
  2. Vòng theo chuỗi order quyết định lúc thăm N và lúc đệ quy L/R; mỗi chữ xuất hiện đúng một lần.
  3. out chung tích lũy kết quả, không tạo một danh sách mới ở từng nút.
  4. chieuCao dùng −1 cho rỗng để lá có chiều cao 0; không trộn với quy ước tính theo số nút.

Lỗi thường gặp

  • Nhầm 2i với 2ⁱ cho số nút tối đa ở mức i.
  • Gọi mọi cây nhị phân là BST.
  • Gán chi phí logarit cho thao tác phải in đủ n nút.
