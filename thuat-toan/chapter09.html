09 Heap Sort

Sắp xếp dựa trên cấu trúc dữ liệu Heap — đảm bảo O(n log n) mọi trường hợp, sắp xếp tại chỗ (in-place).

heap_sort.py 
def heapify(ds, n, i):
    lon_nhat = i
    trai, phai = 2 * i + 1, 2 * i + 2

    if trai < n and ds[trai] > ds[lon_nhat]:
        lon_nhat = trai
    if phai < n and ds[phai] > ds[lon_nhat]:
        lon_nhat = phai

    if lon_nhat != i:
        ds[i], ds[lon_nhat] = ds[lon_nhat], ds[i]
        heapify(ds, n, lon_nhat)          # tiếp tục "vun đống" xuống dưới

def heap_sort(ds):
    n = len(ds)
    for i in range(n // 2 - 1, -1, -1):        # xây max-heap từ dưới lên
        heapify(ds, n, i)

    for i in range(n - 1, 0, -1):
        ds[0], ds[i] = ds[i], ds[0]               # đưa phần tử lớn nhất (gốc heap) ra cuối
        heapify(ds, i, 0)                            # "vun đống" lại phần còn lại
    return ds
Mẹo
Nhắc lại từ giáo trình Python (chương 62): module heapq cài đặt sẵn min-heap. Heap Sort tận dụng tính chất "gốc heap luôn là phần tử lớn nhất/nhỏ nhất" để liên tục trích xuất và sắp xếp.
