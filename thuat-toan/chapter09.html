Heap Sort

Xây heap một lần rồi thu nhỏ miền; chỉ số và biên size quyết định tính đúng.

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.7. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Xây max-heap từ dưới lên.
  • Tách vùng heap khỏi vùng đã sắp.

Vấn đề thực tế

Cần liên tục lấy số lớn nhất và đặt về cuối mảng mà không tìm lại toàn bộ dãy mỗi lần.

Lý thuyết nền

Max-heap là cây nhị phân hoàn chỉnh có khóa cha ≥ khóa con. Với chỉ số từ 0, con của i ở 2i+1 và 2i+2. Sift-down (vun xuống) đổi nút với con lớn hơn cho đến khi đúng tính chất heap.

Xây heap bắt đầu từ nút cha cuối floor(n/2)−1 về gốc; chi phí tổng O(n), không phải n lần vun từ gốc. Heap Sort đổi gốc lớn nhất với cuối vùng heap, thu nhỏ vùng rồi vun lại gốc. Bản này có thời gian O(n log n), xấu nhất Θ(n log n), bộ nhớ phụ O(1), không ổn định. Heap chỉ đảm bảo quan hệ cha-con, chưa phải toàn mảng đã sắp.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter09.cjs rồi chạy node chapter09.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter09.cjs · JavaScript
function siftDown(a, i, size) {
   while (2 * i + 1 < size) {
     let child = 2 * i + 1;
     if (child + 1 < size && a[child + 1] > a[child]) child++;
     if (a[i] >= a[child]) break;
     [a[i], a[child]] = [a[child], a[i]];
     i = child;
   }
 }
 function heapSort(a) {
   for (let i = Math.floor(a.length / 2) - 1; i >= 0; i--)
     siftDown(a, i, a.length);
   for (let end = a.length - 1; end > 0; end--) {
     [a[0], a[end]] = [a[end], a[0]];
     siftDown(a, 0, end);
   }
   return a;
 }
 console.log(heapSort([1, 4, 8, 9, 0, 12, -5]));
 // [-5, 0, 1, 4, 8, 9, 12]

Giải thích các đoạn quan trọng

  1. size là biên loại trừ; chỉ các vị trí nhỏ hơn size còn thuộc heap.
  2. Chọn con lớn hơn trước khi so với cha, nhờ vậy đổi chỗ giữ heap của cây con.
  3. Xây từ cha cuối vì các lá vốn đã là heap đơn.
  4. Sau đổi gốc với end, gọi size=end để không kéo phần tử đã sắp trở vào heap.

Lỗi thường gặp

  • Nhầm size là chỉ số cuối có tính cả phần tử đó.
  • Chọn con trái mà không so con phải.

Bài tập ba mức

Mức 1 — Cơ bản

Vẽ max-heap cho [1, 4, 8, 9, 0, 12, −5].

Mức 2 — Vận dụng

Ghi trạng thái sau mỗi lần lấy gốc và vun lại.

Mức 3 — Nâng cao

Giải thích vì sao cộng chi phí vun theo chiều cao nút cho O(n) ở bước xây heap.
