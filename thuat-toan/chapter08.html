Quick Sort

Thuật toán sắp xếp nhanh nhất trong thực tế trung bình — được dùng làm mặc định trong nhiều ngôn ngữ.

Khoảng 10 phút · Thời lượng ước tính

quick_sort.py 
def quick_sort(ds):
    if len(ds) <= 1:
        return ds
    diem_chot = ds[len(ds) // 2]          # chọn pivot (điểm chốt) - ở đây chọn phần tử giữa
    nho_hon = [x for x in ds if x < diem_chot]
    bang = [x for x in ds if x == diem_chot]
    lon_hon = [x for x in ds if x > diem_chot]
    return quick_sort(nho_hon) + bang + quick_sort(lon_hon)   # đệ quy 2 nửa rồi ghép lại

print(quick_sort([5, 2, 8, 1, 9, 3]))   # [1, 2, 3, 5, 8, 9]

Cách hoạt động

  1. Chọn một phần tử làm pivot (điểm chốt).
  2. Phân hoạch (partition): đưa phần tử nhỏ hơn pivot sang trái, lớn hơn sang phải.
  3. Đệ quy sắp xếp hai nửa trái/phải độc lập.
Cảnh báo — Trường hợp xấu nhất O(n²)
Nếu luôn chọn pivot là phần tử nhỏ nhất/lớn nhất (VD: mảng đã sắp xếp sẵn, chọn pivot là phần tử đầu), Quick Sort suy biến thành O(n²). Cách khắc phục: chọn pivot ngẫu nhiên, hoặc dùng kỹ thuật "median-of-three".
Trường hợpĐộ phức tạp
Trung bìnhO(n log n)
Xấu nhất (pivot chọn tệ liên tục)O(n²)
Không gianO(log n) - đệ quy, sắp xếp gần tại chỗ

Quick Sort chọn pivot, phân hoạch rồi đệ quy — nhanh nhất trong thực tế trung bình (O(n log n)) nhưng có thể suy biến O(n²) nếu chọn pivot tệ liên tục.
