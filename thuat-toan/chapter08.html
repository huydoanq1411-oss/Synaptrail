Quick Sort

Phân hoạch phải tiến triển và đoạn đệ quy phải nhỏ đi; trường hợp xấu của Quick Sort vẫn bậc hai.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.6. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Hiểu pivot và phân hoạch hai đầu.
  • Xử lý đúng dãy trùng khóa, rỗng và một phần tử.

Vấn đề thực tế

Cần sắp một mảng ngay trong vùng dữ liệu hiện có bằng cách đưa phần tử nhỏ về trái, lớn về phải một giá trị chốt.

Lý thuyết nền

Quick Sort chọn pivot (chốt), quét từ hai đầu để tìm phần tử nằm sai phía rồi đổi. Sau phân hoạch, tiếp tục sắp các đoạn chưa hoàn tất. Biến thể dưới lấy giá trị giữa làm chốt, dùng hai chỉ số i và j; pivot không nhất thiết nằm ở vị trí cuối cùng sau một lượt.

Ngay cả khi hai phần tử bằng pivot, sau đổi vẫn phải tăng i và giảm j để vòng lặp tiến triển. Dừng đệ quy khi left ≥ right trước khi đọc pivot. Phân hoạch cân đối cho Θ(n log n); trung bình cần giả thiết đầu vào/chọn chốt; xấu nhất Θ(n²). Stack thường O(log n) khi cân đối và có thể O(n) khi lệch.

Ví dụ có thể chạy

Lưu thành chapter08.cjs rồi chạy node chapter08.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter08.cjs · JavaScript
function quickSort(a, left = 0, right = a.length - 1) {
   if (left >= right) return a;
   const pivot = a[Math.floor((left + right) / 2)];
   let i = left, j = right;
   while (i <= j) {
     while (a[i] < pivot) i++;
     while (a[j] > pivot) j--;
     if (i <= j) {
       [a[i], a[j]] = [a[j], a[i]];
       i++; j--;
     }
   }
   if (left < j) quickSort(a, left, j);
   if (i < right) quickSort(a, i, right);
   return a;
 }
 console.log(quickSort([1, 4, 8, 9, 0, 12, -5]));
 // [-5, 0, 1, 4, 8, 9, 12]

Giải thích các đoạn quan trọng

  1. Điều kiện đầu hàm bảo vệ mảng rỗng và đoạn đơn.
  2. Hai while dừng tại cặp sai phía hoặc bằng chốt; đổi cặp rồi tiến cả hai chỉ số.
  3. Khi i vượt j, phân hoạch đã hoàn tất; đệ quy chỉ trên left…j và i…right.
  4. Chốt đầu tiên bằng 9; đổi 9 với −5, sau đó tiếp tục chia các đoạn còn lại.

Lỗi thường gặp

  • Quên cập nhật i/j khi khóa trùng.
  • Khẳng định mọi cách chọn chốt đều đảm bảo O(n log n).

Bài tập ba mức

Mức 1 — Cơ bản

Theo dõi i/j trên [3, 1, 2].

Mức 2 — Vận dụng

Thử dãy tất cả phần tử bằng nhau và giải thích vì sao dừng.

Mức 3 — Nâng cao

So sánh chọn chốt đầu, giữa và ngẫu nhiên trên các họ đầu vào; trình bày rủi ro stack.
