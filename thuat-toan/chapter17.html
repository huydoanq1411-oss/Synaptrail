Cài đặt Linked List

Tự xây dựng Singly và Doubly Linked List từ đầu — hiểu rõ cách con trỏ hoạt động bên dưới.

Khoảng 10 phút · Thời lượng ước tính

Singly Linked List — liên kết một chiều

singly_linked_list.py 
class Node:
    def __init__(self, gia_tri):
        self.gia_tri = gia_tri
        self.tiep_theo = None

class SinglyLinkedList:
    def __init__(self):
        self.dau = None

    def them_dau(self, gia_tri):          # O(1) - điểm mạnh của linked list
        node_moi = Node(gia_tri)
        node_moi.tiep_theo = self.dau
        self.dau = node_moi

    def them_cuoi(self, gia_tri):          # O(n) - phải duyệt tới cuối
        node_moi = Node(gia_tri)
        if not self.dau:
            self.dau = node_moi
            return
        hien_tai = self.dau
        while hien_tai.tiep_theo:
            hien_tai = hien_tai.tiep_theo
        hien_tai.tiep_theo = node_moi

    def xoa(self, gia_tri):                  # O(n) - phải tìm trước khi xóa
        if not self.dau:
            return
        if self.dau.gia_tri == gia_tri:
            self.dau = self.dau.tiep_theo
            return
        hien_tai = self.dau
        while hien_tai.tiep_theo:
            if hien_tai.tiep_theo.gia_tri == gia_tri:
                hien_tai.tiep_theo = hien_tai.tiep_theo.tiep_theo
                return
            hien_tai = hien_tai.tiep_theo

    def hien_thi(self):
        ket_qua = []
        hien_tai = self.dau
        while hien_tai:
            ket_qua.append(hien_tai.gia_tri)
            hien_tai = hien_tai.tiep_theo
        return ket_qua

ll = SinglyLinkedList()
ll.them_dau(3); ll.them_dau(2); ll.them_dau(1)
print(ll.hien_thi())   # [1, 2, 3]

Doubly Linked List — liên kết hai chiều

doubly_linked_list.py 
class DoublyNode:
    def __init__(self, gia_tri):
        self.gia_tri = gia_tri
        self.tiep_theo = None
        self.truoc = None      # con trỏ THÊM trỏ về node TRƯỚC - điểm khác biệt so với singly

# Ưu điểm: có thể duyệt CẢ HAI CHIỀU, xóa node hiện tại KHÔNG CẦN biết node trước nó
# Đánh đổi: tốn thêm bộ nhớ cho con trỏ "truoc" ở mỗi node
Ghi chú
Python's collections.deque (đã dùng ở giáo trình Python chương 31) thực chất được cài đặt dựa trên ý tưởng tương tự doubly linked list — cho phép thêm/xóa O(1) ở CẢ HAI đầu.

📌 Tổng kết chương 17

Singly Linked List chỉ có con trỏ tiến, đơn giản và tiết kiệm bộ nhớ hơn. Doubly Linked List có thêm con trỏ lùi, cho phép duyệt hai chiều và xóa node hiệu quả hơn, đánh đổi bằng bộ nhớ.
