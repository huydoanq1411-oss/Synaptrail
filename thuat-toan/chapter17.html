Cài đặt Linked List

Mọi thao tác phải giữ head/tail và liên kết cuối; kiểm rỗng, một nút, đầu/cuối và không tìm thấy.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 4.2, BT4. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài đầu/cuối, chèn, tìm, duyệt, sửa và xóa.
  • Giữ bất biến ở danh sách rỗng và một nút.

Vấn đề thực tế

Quản lý sinh viên cần thêm sau mã chỉ định và xóa đúng bản ghi, kể cả khi đó là phần tử đầu hoặc cuối duy nhất.

Lý thuyết nền

Danh sách rỗng có head=tail=null. Nếu không rỗng thì tail.next=null. Thêm đầu: nối nút mới với head cũ rồi đổi head; thêm cuối: nối tail cũ với nút mới rồi đổi tail. Khi đang rỗng phải cập nhật cả hai.

Thêm sau q: nút mới nhận q.next trước, rồi q.next nhận nút mới. Nếu q là tail thì cập nhật tail. Bản này tìm q theo khóa, không nhận nút từ danh sách khác; không có khóa thì trả null để báo thất bại.

Xóa cần biết nút trước. Nếu xóa head thì đổi head; nếu xóa tail thì đổi tail; xóa nút duy nhất làm cả hai bằng null. JavaScript bỏ liên kết và để bộ thu gom rác thu hồi khi không còn tham chiếu; trong C++ phải giải phóng đúng đối tượng, không dùng lại con trỏ đã giải phóng.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter17.cjs rồi chạy node chapter17.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter17.cjs · JavaScript
class LinkedList {
   constructor() { this.head = null; this.tail = null; }
   prepend(value) {
     const node = {value, next: this.head};
     this.head = node; if (!this.tail) this.tail = node;
     return node;
   }
   append(value) {
     const node = {value, next: null};
     if (this.tail) this.tail.next = node; else this.head = node;
     this.tail = node; return node;
   }
   find(value) {
     for (let p = this.head; p; p = p.next) if (p.value === value) return p;
     return null;
   }
   insertAfter(value, newValue) {
     const q = this.find(value); if (!q) return null;
     const node = {value: newValue, next: q.next}; q.next = node;
     if (this.tail === q) this.tail = node;
     return node;
   }
   remove(value) {
     let prev = null, p = this.head;
     while (p && p.value !== value) { prev = p; p = p.next; }
     if (!p) return false;
     if (prev) prev.next = p.next; else this.head = p.next;
     if (this.tail === p) this.tail = prev;
     p.next = null; return true;
   }
   values() {
     const out = []; for (let p = this.head; p; p = p.next) out.push(p.value);
     return out;
   }
   clear() { this.head = this.tail = null; }
 }
 const list = new LinkedList();
 list.append(12); list.prepend(3); list.insertAfter(12, 20);
 list.find(3).value = 4; // Sửa dữ liệu của nút đã tìm.
 list.remove(20);
 console.log(list.values(), list.tail.value); // [4,12] 12

Giải thích các đoạn quan trọng

  1. constructor thiết lập danh sách rỗng. prepend và append luôn trả nút vừa tạo.
  2. find đi theo next; insertAfter lấy liên kết cũ trước khi đổi q.next.
  3. remove giữ prev để nối bỏ p; cập nhật tail cả khi xóa nút duy nhất.
  4. values duyệt hết, chi phí O(n); clear bỏ hai điểm giữ danh sách. Nếu code bên ngoài giữ tham chiếu node thì node đó vẫn còn sống.

Lỗi thường gặp

  • Đổi q.next trước khi lưu phần đuôi, làm mất đoạn sau.
  • Xóa tail mà không đổi tail.
  • Cho rằng clear trong JavaScript tương đương delete từng nút C++.

Bài tập ba mức

Mức 1 — Cơ bản

Thêm/xóa trên danh sách rỗng, một nút và nhiều nút; kiểm head/tail.

Mức 2 — Vận dụng

Quản lý sinh viên (mã, họ tên, năm sinh, điểm): nhập, in, tìm theo tên, chèn sau mã, xóa theo mã, sắp mã/tên và hủy danh sách (BT4.1).

Mức 3 — Nâng cao

Quản lý thành phố (tên, diện tích, dân số): nhập/xuất, tìm diện tích lớn nhất và chèn sau, xóa Ha Noi nếu có, sắp dân số tăng (BT4.5).
