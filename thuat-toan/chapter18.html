Stack — Ứng dụng thực tế

Stack giữ thứ tự ngược; kiểm đầy/rỗng, thứ tự toán hạng và trạng thái khung công việc là phần quyết định tính đúng.

Khoảng 13 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 4.3, BT4.2, BT4.3. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài Stack bằng mảng và danh sách.
  • Áp dụng đổi cơ số, đảo chuỗi, biểu thức và khử đệ quy.

Vấn đề thực tế

Nút Undo phải hoàn tác thao tác vừa thực hiện; xử lý ngoặc phải ghép dấu đóng với dấu mở gần nhất chưa ghép.

Lý thuyết nền

Stack (ngăn xếp) theo LIFO: vào sau ra trước. push thêm đỉnh, pop lấy và bỏ đỉnh, peek xem đỉnh, isEmpty kiểm rỗng. Với mảng cố định capacity, top=−1 khi rỗng, đầy khi top=capacity−1. Kiểm đầy trước ghi và kiểm rỗng trước đọc. Với danh sách đơn, dùng head làm đỉnh; push/pop sửa liên kết O(1), mỗi nút có chi phí vùng nhớ.

Ứng dụng

  • Đổi cơ số: chia liên tiếp số nguyên không âm cho b, đẩy các phần dư; pop cho chữ số từ cao xuống thấp. Số 0 cần trả riêng “0”.
  • Đảo chuỗi: đẩy từng ký tự, lấy ngược. Ví dụ dùng Array.from để không tách đôi surrogate pair; chưa xử lý mọi grapheme gồm nhiều code point.
  • Hậu tố (postfix): toán hạng vào stack; gặp toán tử lấy phải trước, trái sau. Ví dụ 2 3 + 4 * cho 20. Biểu thức sai phải báo lỗi, không dùng eval.
  • Trung tố sang hậu tố: toán hạng ra output, dấu mở vào stack, dấu đóng lấy đến dấu mở; toán tử chờ các toán tử ưu tiên cao hơn hoặc bằng ở đỉnh rồi mới push. Ví dụ chỉ hỗ trợ + − * / hai ngôi, ngoặc và số nguyên không âm, không có dấu âm đơn ngôi.
  • Khử đệ quy: lưu khung công việc vào stack thay call stack. Tháp Hà Nội: chuyển n−1 từ nguồn sang tạm, chuyển đĩa lớn sang đích, chuyển n−1 từ tạm sang đích. Vì LIFO, đẩy ba việc theo thứ tự ngược. Số bước 2ⁿ−1; dùng stack không làm bài toán thành thời gian tuyến tính.

class ArrayStack {
   constructor(capacity = 100) {
     if (!Number.isInteger(capacity) || capacity < 1) throw new RangeError('Sức chứa sai');
     this.a = Array(capacity); this.top = -1;
   }
   isEmpty() { return this.top === -1; }
   push(x) {
     if (this.top + 1 === this.a.length) throw new RangeError('Stack đầy');
     this.a[++this.top] = x;
   }
   peek() { if (this.isEmpty()) throw new RangeError('Stack rỗng'); return this.a[this.top]; }
   pop() { const x = this.peek(); this.a[this.top--] = undefined; return x; }
 }
 class LinkedStack {
   constructor() { this.head = null; }
   isEmpty() { return this.head === null; }
   push(value) { this.head = {value, next: this.head}; }
   peek() { if (this.isEmpty()) throw new RangeError('Stack rỗng'); return this.head.value; }
   pop() { const x = this.peek(); this.head = this.head.next; return x; }
 }
 function doiCoSo(n, b) {
   if (!Number.isSafeInteger(n) || n < 0 || !Number.isInteger(b) || b < 2 || b > 36)
     throw new RangeError('Cần n nguyên không âm, cơ số 2..36');
   if (n === 0) return '0';
   const stack = new LinkedStack(), digits = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ';
   while (n > 0) { stack.push(n % b); n = Math.floor(n / b); }
   let out = ''; while (!stack.isEmpty()) out += digits[stack.pop()];
   return out;
 }
 function daoChuoi(s) {
   const stack = Array.from(s), out = [];
   while (stack.length) out.push(stack.pop()); return out.join('');
 }
 function hauTo(tokens) {
   const s = [];
   for (const token of tokens) {
     if (/^\d+$/.test(token)) { s.push(Number(token)); continue; }
     if (!['+', '-', '*', '/'].includes(token) || s.length < 2)
       throw new SyntaxError('Hậu tố sai');
     const right = s.pop(), left = s.pop();
     if (token === '/' && right === 0) throw new RangeError('Chia cho 0');
     s.push(token === '+' ? left + right : token === '-' ? left - right :
       token === '*' ? left * right : left / right);
   }
   if (s.length !== 1) throw new SyntaxError('Thừa hoặc thiếu toán hạng');
   return s[0];
 }
 function sangHauTo(tokens) {
   const out = [], ops = [], rank = {'+':1, '-':1, '*':2, '/':2};
   let canSo = true;
   for (const t of tokens) {
     if (/^\d+$/.test(t)) {
       if (!canSo) throw new SyntaxError('Thiếu toán tử');
       out.push(t); canSo = false;
     } else if (t === '(') {
       if (!canSo) throw new SyntaxError('Thiếu toán tử trước ngoặc'); ops.push(t);
     } else if (t === ')') {
       if (canSo) throw new SyntaxError('Thiếu toán hạng');
       while (ops.length && ops.at(-1) !== '(') out.push(ops.pop());
       if (ops.pop() !== '(') throw new SyntaxError('Lệch ngoặc');
     } else if (Object.hasOwn(rank, t)) {
       if (canSo) throw new SyntaxError('Thiếu toán hạng');
       while (ops.length && ops.at(-1) !== '(' && rank[ops.at(-1)] >= rank[t]) out.push(ops.pop());
       ops.push(t); canSo = true;
     } else throw new SyntaxError('Token không hỗ trợ');
   }
   if (canSo) throw new SyntaxError('Biểu thức chưa đủ');
   while (ops.length) { const t = ops.pop(); if (t === '(') throw new SyntaxError('Lệch ngoặc'); out.push(t); }
   return out;
 }
 function haNoi(n) {
   if (!Number.isInteger(n) || n < 0 || n > 15) throw new RangeError('Ví dụ giới hạn 0..15 đĩa');
   const todo = [{n, from:'A', to:'B', via:'C'}], moves = [];
   while (todo.length) {
     const t = todo.pop(); if (t.n === 0) continue;
     if (t.n === 1) { moves.push([t.from, t.to]); continue; }
     todo.push({n:t.n-1, from:t.via, to:t.to, via:t.from});
     todo.push({n:1, from:t.from, to:t.to, via:t.via});
     todo.push({n:t.n-1, from:t.from, to:t.via, via:t.to});
   }
   return moves;
 }
 console.log(doiCoSo(26, 16), daoChuoi('An')); // 1A nA
 console.log(hauTo(sangHauTo(['(', '2', '+', '3', ')', '*', '4']))); // 20
 console.log(haNoi(3).length); // 7

Giải thích các đoạn quan trọng

  1. ArrayStack dùng ++top trước ghi và giảm top sau đọc; LinkedStack đặt node mới trước head.
  2. Đổi cơ số đẩy phần dư theo thứ tự từ thấp lên cao, lấy ra theo thứ tự ngược.
  3. hauTo luôn pop right trước left: phép trừ/chia sẽ sai nếu đảo.
  4. sangHauTo kiểm tra thứ tự token và ngoặc; rank quy định * / cao hơn + −, đều kết hợp trái.
  5. haNoi đẩy việc cuối trước; đầu stack luôn là việc cần làm tiếp. Giới hạn 15 đĩa chỉ bảo vệ ví dụ khỏi tạo quá nhiều bước.

Lỗi thường gặp

  • Pop/peek khi rỗng hoặc ghi vượt mảng cố định.
  • Đảo thứ tự toán hạng phép trừ và chia.
  • Đẩy ba việc Hà Nội theo thứ tự thực hiện thay vì thứ tự ngược.
