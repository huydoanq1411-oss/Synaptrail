Chương 18 — Stack — Ứng dụng thực tế

Cấu trúc LIFO (Last In First Out) — không chỉ là lý thuyết, mà là nền tảng của rất nhiều tính năng bạn dùng hàng ngày.

stack_basic.py 
stack = []
stack.append(1)     # push
stack.append(2)
stack.append(3)
print(stack.pop())    # 3 - lấy ra phần tử THÊM SAU CÙNG

Ứng dụng 1: Kiểm tra ngoặc hợp lệ

valid_parentheses.py 
def ngoac_hop_le(s):
    stack = []
    cap = {")": "(", "]": "[", "}": "{"}
    for ky_tu in s:
        if ky_tu in "([{":
            stack.append(ky_tu)
        elif ky_tu in cap:
            if not stack or stack.pop() != cap[ky_tu]:
                return False
    return len(stack) == 0

Ứng dụng 2: Chức năng Undo (hoàn tác)

undo_feature.py 
class TrinhSoanThao:
    def __init__(self):
        self.noi_dung = ""
        self.lich_su = []           # stack lưu lịch sử các trạng thái

    def go_chu(self, chu):
        self.lich_su.append(self.noi_dung)    # lưu trạng thái TRƯỚC khi thay đổi
        self.noi_dung += chu

    def hoan_tac(self):                          # Ctrl+Z
        if self.lich_su:
            self.noi_dung = self.lich_su.pop()      # quay về trạng thái gần nhất

soan_thao = TrinhSoanThao()
soan_thao.go_chu("Xin"); soan_thao.go_chu(" chào")
print(soan_thao.noi_dung)   # "Xin chào"
soan_thao.hoan_tac()
print(soan_thao.noi_dung)   # "Xin"

Ứng dụng 3: Duyệt DFS trên đồ thị (xem lại ở phần Đồ thị)

Cả đệ quy VÀ Depth-First Search (DFS) đều dựa trên nguyên lý stack — thực tế, đệ quy chính là dùng "call stack" của chương trình một cách ngầm định.

Mẹo ghi nhớ
Dấu hiệu nhận biết bài toán cần Stack: cần xử lý theo thứ tự "cái vào sau cùng, xử lý trước" — undo/redo, kiểm tra cân bằng ngoặc, đánh giá biểu thức toán học, duyệt DFS.

📌 Tổng kết chương 18

Stack (LIFO) ứng dụng trong kiểm tra ngoặc hợp lệ, tính năng Undo, và là nền tảng ngầm định của đệ quy/DFS — một trong những cấu trúc dữ liệu được dùng nhiều nhất trong thực tế.
