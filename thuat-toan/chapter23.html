23 Heap & Priority Queue

Cây nhị phân đặc biệt luôn giữ phần tử ưu tiên nhất ở gốc — nền tảng của hàng đợi ưu tiên và Heap Sort (đã học ở chương 9).

heap_module.py 
import heapq

min_heap = [5, 2, 8, 1, 9]
heapq.heapify(min_heap)              # biến list thành min-heap tại chỗ, O(n)
print(min_heap[0])                      # phần tử NHỎ NHẤT luôn ở gốc -> 1

heapq.heappush(min_heap, 0)              # thêm - O(log n)
print(heapq.heappop(min_heap))             # lấy + xóa phần tử nhỏ nhất - O(log n) -> 0

print(heapq.nsmallest(3, [9,3,7,1,8,2]))    # 3 phần tử nhỏ nhất -> [1, 2, 3]

Ứng dụng thực tế: Hệ thống ưu tiên xử lý ticket hỗ trợ

priority_queue_demo.py 
import heapq

hang_doi = []
heapq.heappush(hang_doi, (1, "Server sập - khẩn cấp"))      # (độ ưu tiên, mô tả)
heapq.heappush(hang_doi, (3, "Yêu cầu thêm tính năng"))
heapq.heappush(hang_doi, (2, "Lỗi hiển thị giao diện"))

while hang_doi:
    uu_tien, mo_ta = heapq.heappop(hang_doi)
    print(f"[Ưu tiên {uu_tien}] {mo_ta}")
# Xử lý ĐÚNG THỨ TỰ ưu tiên, không phải thứ tự đưa vào

Ứng dụng: Tìm K phần tử lớn nhất (Top-K)

top_k.py 
import heapq

def top_k_lon_nhat(ds, k):
    return heapq.nlargest(k, ds)           # hiệu quả hơn sort() toàn bộ rồi lấy k phần tử

print(top_k_lon_nhat([5, 2, 8, 1, 9, 3], 3))   # [9, 8, 5]
Mẹo ghi nhớ
Dấu hiệu nhận biết bài toán cần Heap/Priority Queue: cần liên tục lấy ra phần tử "tốt nhất/ưu tiên nhất" trong một tập hợp đang thay đổi động — lập lịch, thuật toán Dijkstra (chương Đồ thị), tìm K phần tử lớn/nhỏ nhất.

📝 Quiz tổng kết — Phần Cây

1. Độ phức tạp thêm một phần tử vào Heap là gì?

O(log n) O(1) O(n)

📌 Tổng kết chương 23

Heap giữ phần tử ưu tiên nhất ở gốc, thao tác thêm/lấy đạt O(log n). Priority Queue (cài bằng heap) dùng cho lập lịch theo độ ưu tiên, tìm Top-K, và là thành phần cốt lõi của thuật toán Dijkstra sắp học.
