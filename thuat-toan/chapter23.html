Heap & Priority Queue

Heap phục vụ cực trị hiệu quả; không thay thế BST cho duyệt có thứ tự hoặc tìm khóa bất kỳ.

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.7. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Phân biệt heap với BST.
  • Cài min-heap và hàng ưu tiên.

Vấn đề thực tế

Tác vụ có độ ưu tiên nhỏ hơn phải chạy trước; không cần sắp cả tập sau mỗi lần thêm một tác vụ.

Lý thuyết nền

Phần mở rộng của heap trong tài liệu: Priority Queue (hàng ưu tiên) hỗ trợ push, peek phần tử ưu tiên nhất, pop lấy phần tử đó. Min-heap lưu cha ≤ con; trái/phải không có quan hệ thứ tự BST. peek O(1), push/pop O(log n) xấu nhất theo thao tác heap; mảng động có chi phí cấp phát riêng.

push nối ở cuối rồi sift-up (vun lên) theo cha floor((i−1)/2). pop lấy gốc, chuyển phần tử cuối về đầu rồi sift-down. Trả undefined khi rỗng trong bản này, khác với Stack/Queue bài trước dùng ngoại lệ; phải ghi rõ hợp đồng API. Nếu cần FIFO khi bằng ưu tiên, comparator phải xét thêm số thứ tự đưa vào.

chapter23.cjs · JavaScript
class MinHeap {
   constructor() { this.a = []; }
   peek() { return this.a[0]; }
   push(x) {
     if (!Number.isFinite(x)) throw new TypeError('Ưu tiên phải là số hữu hạn');
     this.a.push(x); let i = this.a.length - 1;
     while (i > 0) {
       const p = Math.floor((i - 1) / 2);
       if (this.a[p] <= this.a[i]) break;
       [this.a[p], this.a[i]] = [this.a[i], this.a[p]]; i = p;
     }
   }
   pop() {
     if (!this.a.length) return undefined;
     const result = this.a[0], last = this.a.pop();
     if (!this.a.length) return result;
     this.a[0] = last; let i = 0;
     while (2 * i + 1 < this.a.length) {
       let c = 2 * i + 1;
       if (c + 1 < this.a.length && this.a[c + 1] < this.a[c]) c++;
       if (this.a[i] <= this.a[c]) break;
       [this.a[i], this.a[c]] = [this.a[c], this.a[i]]; i = c;
     }
     return result;
   }
 }
 const pq = new MinHeap();
 for (const x of [5,1,3,1]) pq.push(x);
 console.log(pq.pop(), pq.pop(), pq.pop(), pq.pop(), pq.pop());
 // 1 1 3 5 undefined

Giải thích các đoạn quan trọng

  1. push giữ chỉ số mới và đổi lên cha đến khi đúng heap hoặc tới gốc.
  2. pop lưu gốc trước khi lấy cuối; ca một phần tử trả ngay, không gán lại ô 0.
  3. Trong sift-down chọn con nhỏ hơn, ngược max-heap ở bài Heap Sort.
  4. Ví dụ có hai ưu tiên bằng 1: đảm bảo giá trị đúng, chưa đảm bảo thứ tự tác vụ nếu dùng bản ghi.

Lỗi thường gặp

  • Tìm khóa tùy ý trong heap rồi cho rằng O(log n) như BST.
  • Trộn quy tắc min-heap và max-heap.
  • Giả định hàng ưu tiên mặc định giữ FIFO khi bằng khóa.

Bài tập ba mức

Mức 1 — Cơ bản

Mức 2 — Vận dụng
