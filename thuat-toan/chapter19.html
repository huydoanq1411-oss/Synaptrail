Queue & Deque

FIFO quyết định thứ tự phục vụ; mảng vòng và danh sách đầu/cuối cung cấp thao tác hiệu quả khi giữ đúng bất biến.

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 4.4, BT4.4. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Cài Queue mảng vòng và danh sách.
  • Phân biệt FIFO, Deque và hàng ưu tiên.

Vấn đề thực tế

Khách đến thuê máy trước cần được phục vụ trước khi có máy trống; trả máy phải đưa máy về hàng sẵn sàng.

Lý thuyết nền

Queue (hàng đợi) theo FIFO: vào trước ra trước. enqueue thêm cuối, dequeue lấy đầu, front/peek xem đầu, isEmpty/isFull kiểm trạng thái. Hai biến head và tail xác định đầu/cuối. Danh sách đơn giữ cả head và tail giúp thêm cuối/lấy đầu O(1).

Mảng tuyến tính chỉ tăng chỉ số cuối có thể “đầy giả” khi đầu đã có ô trống; dịch cả mảng sau mỗi dequeue lại tốn O(n). Circular queue (hàng đợi vòng) dùng chỉ số modulo capacity và size để phân biệt rỗng/đầy, tái sử dụng ô. Bản dưới cho phép dùng đủ capacity ô.

Deque (double-ended queue, hàng đợi hai đầu) cho thêm/lấy ở cả hai đầu, phù hợp danh sách kép hoặc mảng vòng có thêm thao tác đầu. Priority Queue (hàng ưu tiên) chọn theo độ ưu tiên, không tự tuân FIFO. Đây là phần mở rộng; không nhầm ba kiểu dữ liệu trừu tượng.

class RingQueue {
   constructor(capacity) {
     if (!Number.isInteger(capacity) || capacity < 1) throw new RangeError('Sức chứa sai');
     this.a = Array(capacity); this.head = 0; this.size = 0;
   }
   isEmpty() { return this.size === 0; }
   isFull() { return this.size === this.a.length; }
   enqueue(x) {
     if (this.isFull()) throw new RangeError('Queue đầy');
     this.a[(this.head + this.size) % this.a.length] = x; this.size++;
   }
   peek() { if (this.isEmpty()) throw new RangeError('Queue rỗng'); return this.a[this.head]; }
   dequeue() {
     const x = this.peek(); this.a[this.head] = undefined;
     this.head = (this.head + 1) % this.a.length; this.size--; return x;
   }
 }
 class LinkedQueue {
   constructor() { this.head = this.tail = null; this.size = 0; }
   isEmpty() { return this.head === null; }
   enqueue(value) {
     const node = {value, next: null};
     if (this.tail) this.tail.next = node; else this.head = node;
     this.tail = node; this.size++;
   }
   peek() { if (this.isEmpty()) throw new RangeError('Queue rỗng'); return this.head.value; }
   dequeue() {
     const x = this.peek(); this.head = this.head.next;
     if (!this.head) this.tail = null;
     this.size--; return x;
   }
 }
 const q = new RingQueue(2);
 q.enqueue('An'); q.enqueue('Bình'); console.log(q.dequeue()); // An
 q.enqueue('Châu');
 console.log(q.dequeue(), q.dequeue()); // Bình Châu

Giải thích các đoạn quan trọng

  1. RingQueue lưu head và size; vị trí ghi tiếp là (head+size)%capacity.
  2. dequeue xóa tham chiếu trong ô vừa dùng, dịch head theo modulo và giảm size.
  3. LinkedQueue nối tail; khi lấy hết nút cuối phải gán tail=null.
  4. Ví dụ hai ô vẫn nhận Châu sau khi An rời hàng, minh họa tái sử dụng ô đầu.

Lỗi thường gặp

  • Dùng head=tail cho cả rỗng và đầy mà không có quy ước bổ sung.
  • Xóa nút cuối danh sách nhưng giữ tail cũ.
  • Dùng Array.shift cho hàng lớn rồi giả định thao tác luôn O(1).

Bài tập ba mức

Mức 1 — Cơ bản

Theo dõi head/size qua các lượt thêm/lấy của mảng vòng capacity=3.

Mức 2 — Vận dụng

Viết Deque có thêm/lấy hai đầu và thử rỗng, một phần tử, vòng chỉ số.

Mức 3 — Nâng cao

BT4.4: mô phỏng phòng NET với queue máy trống A, queue khách chờ Q và danh sách đang thuê H (tên, giờ bắt đầu, số máy). Đăng ký, trả máy và phục vụ phải cập nhật nhất quán A/Q/H, không cấp một máy cho hai khách.
