Queue & Deque

Cấu trúc FIFO (First In First Out) và biến thể hai đầu — nền tảng xử lý theo thứ tự và duyệt BFS.

queue_basic.py 
from collections import deque      # dùng deque, KHÔNG dùng list.pop(0) vì list chậm O(n)

hang_doi = deque()
hang_doi.append(1)       # enqueue - thêm vào CUỐI
hang_doi.append(2)
hang_doi.append(3)
print(hang_doi.popleft())  # 1 - dequeue - lấy ra từ ĐẦU

Ứng dụng: Hệ thống xếp hàng in tài liệu

print_queue.py 
class HangDoiIn:
    def __init__(self):
        self.hang_doi = deque()

    def them_yeu_cau(self, ten_file):
        self.hang_doi.append(ten_file)
        print(f"Đã thêm '{ten_file}' vào hàng đợi in")

    def in_tiep_theo(self):
        if self.hang_doi:
            file_dang_in = self.hang_doi.popleft()   # in file được YÊU CẦU SỚM NHẤT trước
            print(f"Đang in: {file_dang_in}")
            return file_dang_in

hd = HangDoiIn()
hd.them_yeu_cau("bao_cao.pdf")
hd.them_yeu_cau("hop_dong.docx")
hd.in_tiep_theo()   # in bao_cao.pdf TRƯỚC vì được yêu cầu sớm hơn

Deque (Double-Ended Queue) — hàng đợi hai đầu

deque_both_ends.py 
d = deque([2, 3, 4])
d.appendleft(1)     # thêm vào ĐẦU - O(1)
d.append(5)             # thêm vào CUỐI - O(1)
print(d)                   # deque([1, 2, 3, 4, 5])
print(d.popleft())          # 1
print(d.pop())                # 5
Quan trọng
Queue là cấu trúc dữ liệu bắt buộc để cài đặt BFS (Breadth-First Search) — sẽ học chi tiết ở phần Đồ thị. Việc chọn đúng Queue thay vì Stack là điểm khác biệt cốt lõi giữa BFS và DFS.

📌 Tổng kết chương 19

Queue (FIFO) xử lý theo thứ tự đến trước, dùng collections.deque để đạt O(1) ở cả hai đầu. Deque tổng quát hóa cả Stack lẫn Queue trong một cấu trúc duy nhất, và là nền tảng bắt buộc của thuật toán BFS.
