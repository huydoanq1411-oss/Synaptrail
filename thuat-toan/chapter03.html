Chương 3 — Phân tích độ phức tạp

Cách tự tính Big O cho một đoạn code bất kỳ — kỹ năng thực hành quan trọng nhất của chương này.

Quy tắc cộng và nhân

quy_tac_phan_tich.py 
def vi_du_cong(ds):        # O(n) + O(n) = O(2n) -> RÚT GỌN thành O(n)
    for x in ds: print(x)      # O(n)
    for x in ds: print(x)      # O(n) - hai vòng lặp KHÔNG lồng nhau -> CỘNG

def vi_du_nhan(ds):        # O(n) * O(n) = O(n²)
    for i in ds:                # O(n)
        for j in ds:               # O(n) - LỒNG NHAU -> NHÂN
            print(i, j)

def vi_du_giam_bien(ds):   # O(n + m), giữ riêng biến cho từng input khác nhau
    for x in ds: print(x)       # n phần tử
    # for y in ds2: print(y)    # m phần tử (danh sách khác) -> KHÔNG được gộp thành O(n) nếu n≠m

Quy tắc bỏ qua hằng số và số hạng bậc thấp

quy_tac_rut_gon.py 
# Độ phức tạp thực tế: 3n² + 5n + 100
# Big O chỉ giữ lại số hạng TĂNG NHANH NHẤT khi n rất lớn, bỏ hằng số nhân:
# -> O(n²)  (bỏ 3, bỏ 5n, bỏ 100 vì khi n cực lớn, n² áp đảo hoàn toàn các số hạng còn lại)
Cấu trúc codeĐộ phức tạp
Vòng lặp đơn duyệt hết n phần tửO(n)
Hai vòng lặp liên tiếp (không lồng)O(n) + O(n) = O(n)
Hai vòng lặp lồng nhauO(n) × O(n) = O(n²)
Vòng lặp chia đôi mỗi bước (VD: i *= 2)O(log n)
Đệ quy chia đôi + xử lý tuyến tính mỗi bước (Merge Sort)O(n log n)
Mẹo thực hành
Khi phân tích code, hãy tự hỏi: "Vòng lặp này chạy bao nhiêu lần theo n?" và "Các vòng lặp có LỒNG NHAU hay chỉ ĐỨNG CẠNH NHAU?" — lồng nhau thì nhân, đứng cạnh nhau thì cộng (rồi lấy số hạng lớn nhất).

📌 Tổng kết chương 3

Vòng lặp lồng nhau nhân độ phức tạp, vòng lặp liên tiếp cộng rồi lấy số hạng lớn nhất. Big O luôn bỏ qua hằng số nhân và số hạng bậc thấp hơn.
