Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 1.3.3, 2.4, 3.11. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Đếm vòng lặp liên tiếp, lồng nhau và chia đôi.
  • Phân biệt phân tích toán học với đo thực nghiệm.

Vấn đề thực tế

Cần dự đoán thuật toán còn dùng được khi số bản ghi tăng lên, thay vì chỉ đo một bộ dữ liệu nhỏ.

Lý thuyết nền

Vòng lặp liên tiếp cộng chi phí; lồng nhau phải tính tổng số lượt thực tế. Hai vòng mỗi vòng n lượt cho Θ(n²); vòng trong chỉ chạy j < i cho n(n−1)/2, vẫn Θ(n²). Nếu mỗi bước giảm một nửa miền tìm kiếm thì số bước Θ(log n).

Tìm tuyến tính thành công ở vị trí i cần i+1 so sánh khóa. Với các vị trí có xác suất bằng nhau, trung bình (n+1)/2; tìm thất bại cần n. Binary Search cần tối đa bậc logarit trên mảng đã sắp.

Thực nghiệm đo phụ thuộc bộ dữ liệu, mã, trình chạy và máy. Thử dữ liệu rỗng, đã sắp, đảo, trùng và ngẫu nhiên; dùng cùng điều kiện khi so sánh. Phân tích tiệm cận bổ sung chứ không thay cho kiểm thử tính đúng.

Ví dụ có thể chạy

JavaScript, Node.js 22 trở lên; không dùng thư viện ngoài. Đây là bản chuyển thể cho website, không phải bản chép mã C/C++ bị dính dòng trong tài liệu Markdown. Lưu thành chapter03.cjs rồi chạy node chapter03.cjs. Các số trong ví dụ nằm trong miền nguyên an toàn, trừ phép chia biểu thức được giải thích riêng.

chapter03.cjs · JavaScript
function demCap(n) {
   let dem = 0;
   for (let i = 0; i < n; i++) {
     for (let j = 0; j < i; j++) dem++;
   }
   return dem;
 }
 function demChiaDoi(n) {
   let buoc = 0;
   while (n > 1) { n = Math.floor(n / 2); buoc++; }
   return buoc;
 }
 console.log(demCap(5), demChiaDoi(16)); // 10 4

Giải thích các đoạn quan trọng

  1. Với i cố định, j nhận i giá trị; cộng i từ 0 đến n−1 được n(n−1)/2.
  2. demChiaDoi giảm n bằng phép chia nguyên mỗi lượt; n = 16 đi qua 8, 4, 2, 1.
  3. console.log kiểm chứng một đầu vào, không chứng minh cận cho mọi n.

Lỗi thường gặp

  • Thấy hai vòng lặp là kết luận ngay n² mà không xem giới hạn.
  • Đếm thời gian nhập/xuất chung với phần thuật toán rồi so sánh thiếu công bằng.

Bài tập ba mức

Mức 1 — Cơ bản

Tính demCap với n = 0, 1, 4.

Mức 2 — Vận dụng

Phân tích một vòng n lượt tiếp theo một vòng n² lượt.

Mức 3 — Nâng cao

Đếm phép so sánh của Insertion Sort trên dãy tăng và đảo; giải thích vì sao hai kết quả khác bậc.

Tóm tắt
