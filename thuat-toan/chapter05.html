Interchange, Selection & Bubble Sort

Ba thuật toán khác thời điểm và khoảng cách đổi chỗ; số phép so sánh không đồng nghĩa số lần đổi.

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.1, 3.2, 3.3, 3.5. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Phân biệt đổi chỗ trực tiếp, chọn trực tiếp và nổi bọt.
  • Theo dõi bất biến sau mỗi lượt.

Vấn đề thực tế

Cần sắp danh sách điểm tăng dần và hiểu vì sao có thuật toán đổi nhiều lần, có thuật toán chỉ đổi một lần mỗi lượt.

Lý thuyết nền

Sắp xếp là đổi thứ tự bản ghi theo khóa. Interchange Sort (đổi chỗ trực tiếp) so sánh a[i] với mọi a[j] phía sau và đổi ngay nếu nhỏ hơn. Selection Sort (chọn trực tiếp) tìm vị trí nhỏ nhất rồi mới đổi một lần. Sau lượt i, a[i] là phần tử nhỏ nhất của đoạn chưa sắp.

Bubble Sort (nổi bọt) chỉ đổi cặp kề nhau. Biến thể đi từ cuối về đầu đưa phần tử nhỏ nhất về vị trí i. Nếu một lượt không đổi thì dừng sớm. Đổi chỗ trực tiếp và chọn trực tiếp so sánh n(n−1)/2 lần: Θ(n²) cả dãy đã sắp. Bubble có cờ dừng: tốt nhất Θ(n), trung bình/xấu nhất Θ(n²). Các bản ở đây dùng O(1) phụ.

Stable (ổn định) là giữ thứ tự tương đối của các bản ghi có khóa bằng nhau. Bubble chỉ đổi khi lớn hơn nên ổn định; Selection và Interchange với đổi chỗ xa không đảm bảo ổn định.

chapter05.cjs · JavaScript
function interchangeSort(a) {
   for (let i = 0; i < a.length - 1; i++)
     for (let j = i + 1; j < a.length; j++)
       if (a[j] < a[i]) [a[i], a[j]] = [a[j], a[i]];
   return a;
 }
 function selectionSort(a) {
   for (let i = 0; i < a.length - 1; i++) {
     let min = i;
     for (let j = i + 1; j < a.length; j++)
       if (a[j] < a[min]) min = j;
     [a[i], a[min]] = [a[min], a[i]];
   }
   return a;
 }
 function bubbleSort(a) {
   for (let i = 0; i < a.length - 1; i++) {
     let doi = false;
     for (let j = a.length - 1; j > i; j--)
       if (a[j] < a[j - 1]) {
         [a[j], a[j - 1]] = [a[j - 1], a[j]]; doi = true;
       }
     if (!doi) break;
   }
   return a;
 }
 console.log(selectionSort([1, 4, 8, 9, 0, 12, -5]));
 // [-5, 0, 1, 4, 8, 9, 12]

Giải thích các đoạn quan trọng

  1. Interchange đổi ngay trong vòng j; Selection chỉ cập nhật min trong vòng j và đổi sau vòng đó.
  2. Bubble đi j từ cuối về i+1; so sánh hai hàng xóm và ghi nhận có đổi.
  3. doi được đặt lại mỗi lượt i. Không có đổi nghĩa là đoạn còn lại đã có thứ tự.
  4. Với dãy minh họa, lượt Selection đầu đưa −5 về đầu; lượt kế đưa 0 về vị trí 1.

Lỗi thường gặp

  • Nhầm Interchange với Selection chỉ vì cùng hai vòng lặp.
  • Dùng >= ở Bubble khiến bản ghi bằng khóa có thể đổi thứ tự.

Mức 2 — Vận dụng

Mức 3 — Nâng cao

Sắp các bản ghi có khóa trùng và nhãn khác nhau; tìm phản ví dụ tính ổn định của Selection.
