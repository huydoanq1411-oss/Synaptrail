Chương 5 — Bubble Sort & Selection Sort

Hai thuật toán sắp xếp đơn giản nhất — dễ hiểu nhưng kém hiệu quả, chủ yếu mang tính giáo dục.

Bubble Sort — "nổi bọt"

Liên tục so sánh và đổi chỗ hai phần tử liền kề nếu sai thứ tự — phần tử lớn "nổi" dần lên cuối mảng sau mỗi lượt.

bubble_sort.py 
def bubble_sort(ds):
    n = len(ds)
    for i in range(n):
        da_doi_cho = False
        for j in range(0, n - i - 1):
            if ds[j] > ds[j + 1]:
                ds[j], ds[j + 1] = ds[j + 1], ds[j]
                da_doi_cho = True
        if not da_doi_cho:          # tối ưu: nếu không có đổi chỗ nào -> đã sắp xếp xong, dừng sớm
            break
    return ds

Selection Sort — "chọn lựa"

Mỗi lượt tìm phần tử nhỏ nhất trong phần chưa sắp xếp, đưa nó về đúng vị trí.

selection_sort.py 
def selection_sort(ds):
    n = len(ds)
    for i in range(n):
        idx_min = i
        for j in range(i + 1, n):
            if ds[j] < ds[idx_min]:
                idx_min = j
        ds[i], ds[idx_min] = ds[idx_min], ds[i]   # chỉ đổi chỗ MỘT LẦN mỗi lượt
    return ds

Ghi chú — Thuật toán ổn định (Stable)
Thuật toán sắp xếp "ổn định" giữ nguyên thứ tự tương đối của các phần tử bằng nhau. Điều này quan trọng khi sắp xếp dữ liệu theo nhiều tiêu chí (VD: sắp theo điểm, nếu bằng điểm giữ nguyên thứ tự alphabet đã có).

📌 Tổng kết chương 5

Bubble Sort và Selection Sort đều O(n²), đơn giản để học nhưng không dùng trong thực tế với dữ liệu lớn. Bubble Sort ổn định và có thể tối ưu dừng sớm; Selection Sort ít swap hơn nhưng không ổn định.
