Merge Sort

Trộn tuyến tính từng tầng, có số tầng logarit; phải giữ cả phần dư và thứ tự các khóa bằng nhau.

Khoảng 10 phút · Thời lượng ước tính

Làm quiz ở trang riêng

Biên soạn theo tài liệu Cấu trúc dữ liệu và giải thuật — ThS. Bùi Văn Thượng, UTH. Đối chiếu mục 3.9. Nguồn và mục lục đối chiếu.

Mục tiêu

  • Trộn hai đoạn đã sắp.
  • Cài bản đệ quy và bản lặp bottom-up.

Vấn đề thực tế

Hai lớp đã xếp điểm tăng dần cần gộp thành một danh sách có thứ tự mà không sắp lại từ đầu bằng thuật toán bậc hai.

Lý thuyết nền

Merge Sort (sắp xếp trộn) chia để trị: sắp hai nửa rồi trộn. Trong bước trộn, so phần tử chưa lấy đầu tiên của mỗi nửa; lấy phần tử nhỏ hơn và nối phần dư khi một nửa hết. Lấy bên trái khi bằng nhau để ổn định.

Bottom-up (từ dưới lên) đúng với ý tưởng của tài liệu: ban đầu mỗi phần tử là một run (đoạn đã sắp) dài 1; trộn từng cặp run với độ dài 1, 2, 4… cho đến phủ cả dãy. Đoạn cuối có thể thiếu phần tử, luôn chặn biên bằng min. Thời gian Θ(n log n) với n ≥ 2, bộ nhớ phụ O(n); bản đệ quy thêm stack O(log n).

chapter07.cjs · JavaScript
function merge(left, right) {
   const out = []; let i = 0, j = 0;
   while (i < left.length && j < right.length) {
     if (left[i] <= right[j]) out.push(left[i++]);
     else out.push(right[j++]);
   }
   while (i < left.length) out.push(left[i++]);
   while (j < right.length) out.push(right[j++]);
   return out;
 }
 function mergeSort(a) {
   if (a.length < 2) return [...a];
   const mid = Math.floor(a.length / 2);
   return merge(mergeSort(a.slice(0, mid)), mergeSort(a.slice(mid)));
 }
 function mergeBottomUp(a) {
   let out = [...a];
   for (let width = 1; width < out.length; width *= 2) {
     const next = [];
     for (let i = 0; i < out.length; i += 2 * width) {
       const end = Math.min(i + 2 * width, out.length);
       next.push(...merge(out.slice(i, i + width), out.slice(i + width, end)));
     }
     out = next;
   }
   return out;
 }
 console.log(mergeBottomUp([1, 4, 8, 9, 0, 12, -5]));
 // [-5, 0, 1, 4, 8, 9, 12]

Giải thích các đoạn quan trọng

  1. i và j đánh dấu đầu phần chưa lấy; mỗi lượt tăng đúng một chỉ số.
  2. Hai vòng sau nối phần dư; bỏ chúng sẽ làm mất dữ liệu.
  3. Bản đệ quy dừng với 0 hoặc 1 phần tử. Bản lặp nhân đôi width sau mỗi tầng.
  4. Ví dụ bảy phần tử có các run cuối không đều, nên cần chặn end. Spread vào push phù hợp dữ liệu nhỏ của bài; bản sản phẩm lớn nên nối bằng vòng lặp để tránh giới hạn số đối số.

Lỗi thường gặp

  • Trộn hai đoạn chưa sắp.
  • Chỉ xử lý cặp đủ độ dài rồi bỏ đoạn dư ở cuối.

Bài tập ba mức

Mức 1 — Cơ bản

Trộn [1, 4, 8] và [0, 9, 12].

Mức 2 — Vận dụng

Vẽ các run độ dài 1, 2, 4 với dãy bảy phần tử.

Mức 3 — Nâng cao

Viết bản dùng một bộ đệm tái sử dụng và comparator cho bản ghi sinh viên; kiểm tra tính ổn định.
