Merge Sort

Thuật toán "chia để trị" kinh điển — hiệu năng ổn định O(n log n) trong MỌI trường hợp.

Khoảng 10 phút · Thời lượng ước tính

merge_sort.py 
def merge_sort(ds):
    if len(ds) <= 1:
        return ds
    giua = len(ds) // 2
    trai = merge_sort(ds[:giua])        # chia (divide)
    phai = merge_sort(ds[giua:])
    return tron(trai, phai)                # trị (conquer) - trộn 2 mảng đã sắp xếp

def tron(trai, phai):
    ket_qua = []
    i = j = 0
    while i < len(trai) and j < len(phai):
        if trai[i] <= phai[j]:
            ket_qua.append(trai[i]); i += 1
        else:
            ket_qua.append(phai[j]); j += 1
    ket_qua.extend(trai[i:])                # thêm phần còn lại (nếu có)
    ket_qua.extend(phai[j:])
    return ket_qua

Quan trọng
Merge Sort đảm bảo O(n log n) trong MỌI trường hợp (tốt nhất, trung bình, xấu nhất đều như nhau) — khác với Quick Sort có thể suy biến thành O(n²) trong trường hợp xấu nhất. Đánh đổi: Merge Sort cần O(n) bộ nhớ phụ, không sắp xếp tại chỗ.
