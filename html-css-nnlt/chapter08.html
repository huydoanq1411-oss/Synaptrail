Giới thiệu CSS & Selector

CSS (Cascading Style Sheets) trình bày giao diện cho các thẻ HTML — bắt đầu phần "trang điểm" cho bộ xương đã xây.

CSS (Cascading Style Sheets) trình bày giao diện cho các thẻ HTML — bắt đầu phần "trang điểm" cho bộ xương đã xây.

3 cách áp dụng CSS

3_cach_dung_css.html 
<!-- Cách 1: Inline - viết trực tiếp trên thẻ (ít dùng, khó bảo trì) -->
<p style="color: red;">Chữ màu đỏ</p>

<!-- Cách 2: Internal - viết trong thẻ style ở head -->
<head>
    <style>
        p { color: blue; }
    </style>
</head>

<!-- Cách 3: External - file .css riêng, LIÊN KẾT vào HTML (CÁCH CHUẨN, nên dùng) -->
<head>
    <link rel="stylesheet" href="style.css">
</head>

Các loại Selector cơ bản

style.css 
p { color: navy; }                  /* Selector theo THẺ - áp dụng cho MỌI thẻ <p> */
.canh-bao { color: red; }             /* Selector theo CLASS - dùng dấu chấm, tái sử dụng nhiều lần */
#tieu-de-chinh { font-size: 32px; }     /* Selector theo ID - dấu #, CHỈ DÙNG 1 LẦN/trang */
p.canh-bao { font-weight: bold; }         /* Kết hợp: thẻ p VÀ có class canh-bao */
div p { margin: 10px; }                     /* Selector con cháu: mọi p BÊN TRONG div */
SelectorCú phápKhi nào dùng
Thẻp { }Style chung cho mọi thẻ cùng loại
Class.ten-class { }Tái sử dụng cho NHIỀU phần tử — phổ biến nhất
ID#ten-id { }CHỈ 1 phần tử duy nhất trên trang
Mẹo
Luôn ưu tiên external CSS (file .css riêng) — tách biệt nội dung (HTML) và trình bày (CSS), giúp dễ bảo trì và tái sử dụng style cho nhiều trang. Chỉ dùng inline CSS khi thực sự cần override nhanh, tạm thời.

📌 Tổng kết chương 8

CSS có 3 cách áp dụng (inline/internal/external), nên ưu tiên external. Selector theo class là phổ biến nhất vì tái sử dụng được cho nhiều phần tử.
