Dự án: Landing Page — Style CSS hoàn chỉnh

Áp dụng toàn bộ kiến thức CSS đã học: biến, Flexbox, Grid, responsive — để hoàn thiện giao diện.

Áp dụng toàn bộ kiến thức CSS đã học: biến, Flexbox, Grid, responsive — để hoàn thiện giao diện.

style.css 
* { box-sizing: border-box; margin: 0; padding: 0; }    /* reset cơ bản - chương 10 */

:root {                                                     /* CSS Variables - chương 15 */
    --mau-chinh: #4f46e5;
    --mau-chu: #1f2937;
    --mau-nen-nhat: #f9fafb;
    --bo-goc: 12px;
}

body { font-family: 'Segoe UI', sans-serif; color: var(--mau-chu); line-height: 1.6; }

.navbar {                                                    /* Flexbox cho thanh nav - chương 12 */
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 20px 40px;
}
.nav-links { display: flex; list-style: none; gap: 32px; }
.nav-links a { text-decoration: none; color: var(--mau-chu); }

.btn {
    padding: 12px 28px;
    border: none;
    border-radius: var(--bo-goc);
    cursor: pointer;
    font-weight: 600;
    transition: transform 0.2s ease;                          /* transition - chương 15 */
}
.btn:hover { transform: translateY(-2px); }
.btn-primary { background: var(--mau-chinh); color: white; }

.hero {                                                     /* Flexbox căn giữa - chương 12 */
    display: flex;
    flex-direction: column;
    align-items: center;
    text-align: center;
    padding: 100px 20px;
    background: var(--mau-nen-nhat);
}
.hero h1 { font-size: 3rem; max-width: 700px; margin-bottom: 20px; }
.hero p { font-size: 1.2rem; color: #6b7280; max-width: 550px; margin-bottom: 32px; }

.features { padding: 80px 40px; text-align: center; }
.features h2 { font-size: 2.2rem; margin-bottom: 48px; }

.features-grid {                                             /* CSS Grid - chương 13 */
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 32px;
}
.feature-card {
    padding: 32px;
    border-radius: var(--bo-goc);
    background: white;
    box-shadow: 0 2px 12px rgba(0,0,0,.08);
}

.footer { text-align: center; padding: 30px; background: var(--mau-chu); color: white; }

/* Responsive - chương 14 */
@media (max-width: 768px) {
    .nav-links { display: none; }                            /* ẩn menu trên mobile (thực tế cần thêm hamburger menu) */
    .hero h1 { font-size: 2rem; }
    .features-grid { grid-template-columns: 1fr; }            /* chuyển về 1 cột trên mobile */
}
Quan trọng
Đây là ví dụ về cách các kỹ thuật CSS đã học kết hợp với nhau trong một dự án thực tế: Flexbox cho các thanh ngang (navbar, hero), Grid cho lưới card tính năng, CSS Variables cho theme nhất quán, và media query để responsive — không có kỹ thuật nào đứng riêng lẻ trong thực tế.

📌 Tổng kết chương 17

Dự án tổng hợp: reset CSS, CSS Variables cho theme, Flexbox cho bố cục ngang, Grid cho lưới card, transition cho tương tác mượt, và media query cho responsive — toàn bộ kỹ thuật của giáo trình trong một file thực tế.
