Chương 12 — Flexbox

Hệ thống layout một chiều mạnh mẽ nhất của CSS hiện đại — giải quyết hầu hết bài toán căn chỉnh, phân bố không gian.

flexbox_basic.css 
.container {
    display: flex;                    /* BIẾN container thành flex container */
    flex-direction: row;                 /* row (ngang, mặc định) hoặc column (dọc) */
    justify-content: center;               /* căn chỉnh theo TRỤC CHÍNH (main axis) */
    align-items: center;                     /* căn chỉnh theo TRỤC PHỤ (cross axis) */
    gap: 16px;                                  /* khoảng cách giữa các phần tử con */
    flex-wrap: wrap;                               /* cho phép xuống dòng khi không đủ chỗ */
}

.item {
    flex: 1;                            /* phần tử con TỰ GIÃN NỞ đều chia không gian còn lại */
}

Các giá trị justify-content phổ biến

Giá trịHiệu ứng
flex-startDồn về đầu (mặc định)
centerCăn giữa
flex-endDồn về cuối
space-betweenPhần tử đầu/cuối sát mép, khoảng cách đều nhau ở giữa
space-aroundKhoảng cách đều nhau xung quanh MỖI phần tử

Ví dụ thực tế: Căn giữa hoàn hảo (huyền thoại "centering problem")

can_giua_hoan_hao.css 
.can-giua-man-hinh {
    display: flex;
    justify-content: center;   /* căn giữa theo chiều ngang */
    align-items: center;         /* căn giữa theo chiều dọc */
    height: 100vh;                  /* chiều cao bằng TOÀN BỘ màn hình */
}
/* Chỉ 4 dòng CSS đã giải quyết vấn đề "căn giữa div" từng là nỗi ám ảnh trước khi có Flexbox! */
Mẹo ghi nhớ
justify-content luôn theo trục chính (main axis — mặc định là ngang), align-items luôn theo trục phụ (cross axis — mặc định là dọc). Đổi flex-direction: column thì hai trục này HOÁN ĐỔI vai trò cho nhau.

📝 Quiz tổng kết cuối phần

1. Thuộc tính nào biến một phần tử thành Flex Container?

display: flex position: flex flex: container

📌 Tổng kết chương 12

Flexbox (display: flex) là công cụ layout một chiều mạnh mẽ, giải quyết căn chỉnh/phân bố không gian dễ dàng với justify-content (trục chính) và align-items (trục phụ).
