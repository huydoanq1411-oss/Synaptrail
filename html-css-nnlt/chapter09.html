Màu sắc & Typography

Các cách khai báo màu sắc và kiểm soát kiểu chữ trong CSS.

Các cách khai báo màu sắc và kiểm soát kiểu chữ trong CSS.

mau_sac_typography.css 
.vi-du-mau {
    color: red;                      /* tên màu có sẵn */
    color: #ff0000;                    /* mã hex - PHỔ BIẾN NHẤT trong thực tế */
    color: rgb(255, 0, 0);               /* red, green, blue - mỗi giá trị 0-255 */
    color: rgba(255, 0, 0, 0.5);           /* thêm alpha - độ trong suốt 0-1 */
    background-color: #f0f0f0;               /* màu NỀN, khác với "color" là màu CHỮ */
}

.vi-du-chu {
    font-family: 'Arial', sans-serif;        /* luôn có font dự phòng (fallback) */
    font-size: 16px;                            /* 16px là kích thước chuẩn dễ đọc */
    font-weight: bold;                            /* độ đậm: normal/bold/100-900 */
    font-style: italic;                              /* in nghiêng */
    text-align: center;                                /* căn giữa văn bản */
    line-height: 1.6;                                    /* khoảng cách dòng - ảnh hưởng LỚN tới dễ đọc */
    text-decoration: underline;                            /* gạch chân (mặc định của thẻ a) */
}
Ghi chú — Đơn vị đo trong CSS
px (pixel) là đơn vị cố định. %, em, rem là đơn vị TƯƠNG ĐỐI — rem tính theo cỡ chữ gốc của toàn trang (thường 16px), giúp thiết kế responsive nhất quán hơn em (tính theo phần tử cha).

📌 Tổng kết chương 9

Màu khai báo qua tên/hex/rgb(a); hex phổ biến nhất trong thực tế. Typography kiểm soát qua font-family/size/weight, luôn đặt font dự phòng và chú ý line-height để dễ đọc.
