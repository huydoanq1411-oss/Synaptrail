Box Model

Mọi phần tử HTML đều là một "hộp" — hiểu Box Model là nền tảng bắt buộc để làm chủ CSS layout.

Mọi phần tử HTML đều là một "hộp" — hiểu Box Model là nền tảng bắt buộc để làm chủ CSS layout.

box_model.css 
.hop {
    width: 300px;
    height: 150px;
    padding: 20px;          /* khoảng cách BÊN TRONG, giữa nội dung và viền */
    border: 2px solid black;   /* đường viền */
    margin: 10px;                 /* khoảng cách BÊN NGOÀI, giữa hộp này và hộp khác */
}

Cấu trúc Box Model (từ trong ra ngoài)

┌─────────── margin (khoảng cách với hộp khác) ───────────┐
│  ┌───────── border (đường viền) ─────────┐               │
│  │  ┌────── padding (đệm bên trong) ───┐  │               │
│  │  │         content (nội dung)        │  │               │
│  │  └────────────────────────────────┘  │               │
│  └────────────────────────────────────┘               │
└──────────────────────────────────────────────────────┘

box-sizing — thuộc tính cực kỳ quan trọng

box_sizing.css 
* {
    box-sizing: border-box;   /* NÊN đặt cho MỌI phần tử ngay từ đầu dự án */
}
/* Mặc định (content-box): width chỉ tính content, padding/border CỘNG THÊM ra ngoài
   -> hộp thực tế LỚN HƠN width đã khai báo, rất dễ gây lỗi layout khó hiểu

   border-box: width đã BAO GỒM cả padding và border
   -> hộp thực tế ĐÚNG BẰNG width đã khai báo, dễ kiểm soát hơn nhiều */
Quan trọng
* { box-sizing: border-box; } gần như là dòng CSS đầu tiên bắt buộc trong mọi dự án thực tế — giúp việc tính toán kích thước layout trực quan và dễ dự đoán hơn rất nhiều.

📌 Tổng kết chương 10

Box Model gồm content-padding-border-margin từ trong ra ngoài. Luôn đặt box-sizing: border-box toàn cục để width bao gồm cả padding/border, tránh lỗi layout khó hiểu.
