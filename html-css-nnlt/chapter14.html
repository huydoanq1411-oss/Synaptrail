Làm cho trang web hiển thị tốt trên MỌI kích thước màn hình — điện thoại, tablet, desktop.

media_query.css 
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);   /* mặc định: 3 cột trên màn hình LỚN */
}

/* Mobile-first: viết style MẶC ĐỊNH cho màn hình nhỏ trước, sau đó "nới rộng" dần */
@media (max-width: 768px) {                    /* áp dụng khi màn hình <= 768px (tablet) */
    .container {
        grid-template-columns: repeat(2, 1fr);   /* chỉ còn 2 cột */
    }
}

@media (max-width: 480px) {                    /* áp dụng khi màn hình <= 480px (điện thoại) */
    .container {
        grid-template-columns: 1fr;              /* chỉ còn 1 cột, xếp chồng dọc */
    }
}

Quan trọng — Mobile-First
Cách tiếp cận hiện đại là viết CSS mặc định cho màn hình nhỏ trước (mobile-first), rồi dùng @media (min-width: ...) để "mở rộng" cho màn hình lớn hơn — thay vì làm ngược lại. Cách này giúp trang tải nhanh hơn trên mobile (thiết bị chiếm phần lớn lưu lượng truy cập web hiện nay).
Ghi chú — Container Query
Media Query chỉ phản ứng theo kích thước TOÀN MÀN HÌNH. Từ 2023, các trình duyệt hiện đại hỗ trợ thêm Container Query (@container) — cho phép một component tự đổi layout dựa theo kích thước của CHÍNH THẺ CHA chứa nó, bất kể màn hình to hay nhỏ. Rất hữu ích cho component tái sử dụng (VD: một card hiển thị khác nhau tùy đặt trong sidebar hẹp hay khu vực chính rộng): 
.card-container { container-type: inline-size; }

@container (min-width: 400px) {
    .card { display: flex; }   /* đổi layout khi THẺ CHA rộng >= 400px, không phải màn hình */
}

📌 Tổng kết chương 14

@media query áp dụng CSS khác nhau theo kích thước màn hình. Luôn có thẻ viewport, và ưu tiên cách tiếp cận mobile-first cho hiệu năng tốt hơn.
