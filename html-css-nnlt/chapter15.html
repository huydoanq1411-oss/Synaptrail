Chương 15 — CSS Variables & Transition/Animation

Biến CSS giúp quản lý style nhất quán toàn dự án; transition/animation thổi hồn chuyển động vào giao diện.

CSS Custom Properties (Biến CSS)

css_variables.css 
:root {                                  /* khai báo biến TOÀN CỤC ở gốc tài liệu */
    --mau-chinh: #3b82f6;
    --mau-phu: #f59e0b;
    --khoang-cach: 16px;
    --bo-goc: 8px;
}

.nut {
    background-color: var(--mau-chinh);       /* dùng biến bằng var() */
    padding: var(--khoang-cach);
    border-radius: var(--bo-goc);
}

/* Đổi 1 chỗ duy nhất -> áp dụng cho TOÀN BỘ trang dùng biến đó - rất tiện khi đổi theme */
[data-theme="dark"] {
    --mau-chinh: #60a5fa;
}

Transition — chuyển động mượt khi thuộc tính thay đổi

transition.css 
.nut {
    background-color: #3b82f6;
    transition: background-color 0.3s ease, transform 0.2s ease;   /* thuộc tính, thời gian, kiểu chuyển động */
}
.nut:hover {
    background-color: #2563eb;      /* nhờ transition, màu ĐỔI TỪ TỪ thay vì đổi đột ngột */
    transform: translateY(-2px);       /* hiệu ứng "nhấc lên" nhẹ khi hover */
}

Animation — chuyển động phức tạp, lặp lại

animation.css 
@keyframes nhap-nhay {                 /* định nghĩa các "mốc" của chuyển động */
    0%   { opacity: 0; transform: translateY(10px); }
    100% { opacity: 1; transform: translateY(0); }
}

.thong-bao {
    animation: nhap-nhay 0.5s ease-out;   /* tên animation, thời gian, kiểu chuyển động */
}

.icon-xoay {
    animation: xoay 2s linear infinite;      /* infinite = lặp lại VÔ HẠN */
}
@keyframes xoay {
    from { transform: rotate(0deg); }
    to   { transform: rotate(360deg); }
}
Mẹo
transition phù hợp cho chuyển động ĐƠN GIẢN, phản ứng với sự kiện (hover, click). animation + @keyframes phù hợp cho chuyển động PHỨC TẠP, nhiều bước, hoặc lặp lại tự động không cần sự kiện kích hoạt.

📌 Tổng kết chương 15

CSS Variables (--ten: giá-trị + var()) giúp quản lý style nhất quán, dễ đổi theme. transition cho chuyển động đơn giản phản ứng sự kiện, animation/@keyframes cho chuyển động phức tạp/lặp lại.
