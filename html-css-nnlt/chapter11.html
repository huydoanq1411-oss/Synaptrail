Thuộc tính position

position.css 
.static-vi-du   { position: static; }     /* MẶC ĐỊNH - theo dòng chảy tự nhiên của trang */
.relative-vi-du { position: relative; top: 10px; left: 10px; }  /* dịch chuyển SO VỚI vị trí gốc của chính nó */
.absolute-vi-du { position: absolute; top: 0; right: 0; }         /* định vị SO VỚI phần tử cha GẦN NHẤT có position khác static */
.fixed-vi-du    { position: fixed; bottom: 20px; right: 20px; }     /* định vị SO VỚI TRÌNH DUYỆT, không cuộn theo trang */
.sticky-vi-du   { position: sticky; top: 0; }                          /* "dính" lại khi cuộn qua một điểm nhất định */
Quan trọng
position: absolute định vị theo phần tử cha gần nhất có position KHÁC static — nếu không có cha nào như vậy, nó sẽ định vị theo toàn bộ trang (<html>). Đây là nguồn gốc của rất nhiều lỗi layout khó hiểu với người mới.

📌 Tổng kết chương 11

display kiểm soát cách phần tử chiếm không gian (block/inline/inline-block). position kiểm soát vị trí chính xác (static/relative/absolute/fixed/sticky) theo các hệ quy chiếu khác nhau.
