Chương 13 — CSS Grid

Hệ thống layout HAI CHIỀU (hàng và cột đồng thời) — bổ sung hoàn hảo cho Flexbox (một chiều).

grid_basic.css 
.container {
    display: grid;
    grid-template-columns: 200px 1fr 1fr;    /* 3 cột: cố định 200px, hai cột còn lại chia đều phần dư */
    grid-template-rows: 80px auto 60px;        /* 3 hàng: header cố định, content tự động, footer cố định */
    gap: 16px;                                    /* khoảng cách giữa các ô, cả hàng lẫn cột */
}

.header { grid-column: 1 / -1; }    /* chiếm TOÀN BỘ chiều ngang (từ cột 1 tới cột cuối cùng) */
.sidebar { grid-row: 2; grid-column: 1; }
.content { grid-row: 2; grid-column: 2 / 4; }   /* chiếm từ cột 2 tới trước cột 4 (tức cột 2-3) */

Đơn vị fr — phần tỉ lệ độc quyền của Grid

fr_unit.css 
.grid-3-cot-deu {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;    /* 3 cột chia đều KHÔNG GIAN CÒN LẠI */
}

.grid-ty-le {
    display: grid;
    grid-template-columns: 2fr 1fr;    /* cột đầu RỘNG GẤP ĐÔI cột sau */
}

grid-template-areas — đặt tên trực quan cho layout

grid_areas.css 
.container {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-areas:
        "sidebar header"
        "sidebar content"
        "sidebar footer";                /* trực quan hóa layout NGAY TRONG CSS */
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }
Mẹo — Khi nào dùng Grid, khi nào dùng Flexbox?
Grid cho bố cục TỔNG THỂ trang (header/sidebar/content/footer) — cần kiểm soát cả hàng LẪN cột. Flexbox cho bố cục các phần tử NHỎ theo MỘT hướng (thanh menu ngang, danh sách card). Hai công cụ này bổ sung cho nhau, không thay thế nhau.

📌 Tổng kết chương 13

CSS Grid (display: grid) kiểm soát layout 2 chiều với grid-template-columns/rows, đơn vị fr, và grid-template-areas để đặt tên trực quan — công cụ mạnh nhất cho bố cục tổng thể trang.
