Cấu trúc trang HTML

Bộ khung tối thiểu mà mọi trang HTML đều cần có.

Bộ khung tối thiểu mà mọi trang HTML đều cần có.

index.html 
<!DOCTYPE html>                          <!-- khai báo đây là tài liệu HTML5 -->
<html lang="vi">                           <!-- thẻ gốc, lang giúp trình duyệt/SEO biết ngôn ngữ -->
<head>
    <meta charset="UTF-8">                    <!-- mã hóa ký tự, BẮT BUỘC để hiển thị đúng tiếng Việt -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Trang web đầu tiên</title>           <!-- hiện trên tab trình duyệt -->
</head>
<body>
    <h1>Xin chào, đây là trang web đầu tiên của tôi!</h1>
    <p>Nội dung hiển thị trên trang nằm trong thẻ body.</p>
</body>
</html>
ThẻVai trò
<!DOCTYPE html>Khai báo phiên bản HTML5, luôn ở dòng đầu tiên
<head>Thông tin "ẩn" — không hiển thị trực tiếp (title, meta, link CSS)
<body>Toàn bộ nội dung HIỂN THỊ trên trang
Quan trọng
<meta charset="UTF-8"> gần như luôn bắt buộc với trang tiếng Việt — thiếu dòng này, các ký tự có dấu sẽ hiển thị thành ký tự lỗi (mojibake) trên một số trình duyệt/hệ thống.

📌 Tổng kết chương 2

Mọi trang HTML cần khung tối thiểu: DOCTYPE, html, head (chứa meta/title), và body (chứa nội dung hiển thị). Luôn khai báo charset="UTF-8".
