Chương 1 — Giới thiệu HTML

HTML là "bộ xương" của mọi trang web — ngôn ngữ đánh dấu (markup), không phải ngôn ngữ lập trình.

HTML là gì?

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu dùng để xây dựng cấu trúc và nội dung của trang web — tiêu đề, đoạn văn, hình ảnh, liên kết... Trình duyệt đọc file HTML và hiển thị thành trang web mà người dùng nhìn thấy.

Quan trọng
HTML KHÔNG phải ngôn ngữ lập trình — nó không có biến, vòng lặp, hay logic điều kiện. HTML chỉ mô tả cấu trúc/nội dung; CSS lo phần trình bày; JavaScript lo phần tương tác/logic. Ba thứ này luôn đi cùng nhau khi xây dựng web.

Bộ ba nền tảng của web

Công nghệVai trò
HTMLCấu trúc & nội dung ("bộ xương")
CSSTrình bày & bố cục ("quần áo, trang điểm")
JavaScriptTương tác & logic ("bộ não, hành động")
Mẹo
Không cần cài đặt gì để bắt đầu học HTML — chỉ cần một trình soạn thảo (VS Code) và một trình duyệt. Tạo file .html, mở bằng trình duyệt là thấy kết quả ngay lập tức.

📌 Tổng kết chương 1

HTML là ngôn ngữ đánh dấu xây dựng cấu trúc trang web, luôn đi cùng CSS (trình bày) và JavaScript (tương tác) để tạo nên một trang web hoàn chỉnh.
