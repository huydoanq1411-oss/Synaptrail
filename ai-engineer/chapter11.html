11 Dự án: Chatbot hỗ trợ khách hàng hoàn chỉnh

Tổng hợp toàn bộ kiến thức: system prompt, lịch sử hội thoại, và RAG đơn giản — trong một chatbot console hoàn chỉnh.

chatbot_ho_tro_khach_hang.py 
import anthropic
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

client = anthropic.Anthropic()  # đọc ANTHROPIC_API_KEY từ biến môi trường

# ---- Cơ sở tri thức (RAG) ----
tai_lieu = [
    "Giờ mở cửa: 8h-22h hàng ngày, kể cả cuối tuần và ngày lễ.",
    "Bảo hành: 12 tháng cho lỗi nhà sản xuất, không áp dụng cho hư hỏng do người dùng.",
    "Đổi trả: Miễn phí trong 7 ngày, sản phẩm còn nguyên tem mác, hộp đầy đủ.",
    "Vận chuyển: 15.000đ nội thành, 30.000đ ngoại thành, miễn phí đơn từ 500.000đ.",
]
vectorizer = TfidfVectorizer()
vector_tai_lieu = vectorizer.fit_transform(tai_lieu)

def tim_tai_lieu_lien_quan(cau_hoi):
    vector_hoi = vectorizer.transform([cau_hoi])
    diem = cosine_similarity(vector_hoi, vector_tai_lieu)[0]
    chi_so = diem.argmax()
    return tai_lieu[chi_so] if diem[chi_so] > 0.15 else None

# ---- Chatbot ----
SYSTEM_PROMPT = """Bạn là trợ lý hỗ trợ khách hàng của TechShop.
Trả lời ngắn gọn, thân thiện, bằng tiếng Việt.
Nếu có "Thông tin tham khảo" được cung cấp, PHẢI dựa vào đó để trả lời.
Nếu không có thông tin liên quan, xin lỗi và hướng dẫn liên hệ hotline 1900-xxxx."""

lich_su = []

def chat(tin_nhan_nguoi_dung):
    thong_tin = tim_tai_lieu_lien_quan(tin_nhan_nguoi_dung)

    noi_dung_gui = tin_nhan_nguoi_dung
    if thong_tin:
        noi_dung_gui = f"Thông tin tham khảo: {thong_tin}\n\nCâu hỏi: {tin_nhan_nguoi_dung}"

    lich_su.append({"role": "user", "content": noi_dung_gui})

    response = client.messages.create(
        model="YOUR_CURRENT_CLAUDE_MODEL_ID",
        max_tokens=500,
        system=SYSTEM_PROMPT,
        messages=lich_su,
    )
    tra_loi = response.content[0].text
    lich_su.append({"role": "assistant", "content": tra_loi})
    return tra_loi

# ---- Vòng lặp chat ----
print("Chatbot TechShop đã sẵn sàng! (gõ 'thoát' để kết thúc)")
while True:
    nguoi_dung = input("\nBạn: ")
    if nguoi_dung.lower() == "thoát":
        break
    print("Bot:", chat(nguoi_dung))
Phạm vi của project mẫu
Ví dụ console này chỉ phù hợp cho một tiến trình và một người dùng. Danh sách lich_su dùng chung giữa các phiên nếu đem nguyên trạng lên web; không dùng như vậy trong ứng dụng nhiều người dùng. Hãy cô lập hội thoại theo người dùng đã xác thực, lưu trữ có kiểm soát truy cập và chỉ giữ dữ liệu trong thời hạn cần thiết.
Hướng mở rộng tiếp theo
  • Thay TF-IDF bằng embedding thật (VD: OpenAI/Cohere embeddings) để tìm kiếm ngữ nghĩa chính xác hơn
  • Dùng vector database chuyên dụng (Pinecone, Chroma, FAISS) khi tài liệu lớn hàng nghìn đoạn
  • Thêm giao diện web bằng Flask/FastAPI (đã học ở giáo trình Python) thay vì chỉ chạy console
  • Ghi log hội thoại để phân tích câu hỏi khách hàng thường gặp nhất
