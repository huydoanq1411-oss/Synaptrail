Chương 19 — Streaming Response & UX Chatbot

Tại sao ChatGPT/Claude hiển thị câu trả lời "gõ dần từng chữ" thay vì đợi xong toàn bộ mới hiện? Đây không phải hiệu ứng trang trí.

Vấn đề: đợi phản hồi đầy đủ mất quá lâu

Một câu trả lời dài có thể mất 10-20 giây để LLM tạo XONG hoàn toàn — nếu bắt người dùng nhìn màn hình trống trong lúc đó, trải nghiệm rất tệ. Streaming hiển thị TỪNG PHẦN ngay khi LLM tạo ra, giống cách con người đang gõ chữ.

streaming_backend.py 
import anthropic

client = anthropic.Anthropic()

with client.messages.stream(
    model="YOUR_CURRENT_CLAUDE_MODEL_ID",
    max_tokens=1000,
    messages=[{"role": "user", "content": "Giải thích Big O notation"}]
) as stream:
    for text in stream.text_stream:            # nhận từng ĐOẠN NHỎ ngay khi có, không đợi xong hết
        print(text, end="", flush=True)         # in ngay lập tức, tạo hiệu ứng "gõ dần"
ChatUI.jsx 
function ChatUI() {
    const [tinNhanDangGo, setTinNhanDangGo] = useState('');

    async function guiTinNhan(cauHoi) {
        const response = await fetch('/api/chat-stream', {
            method: 'POST', body: JSON.stringify({ cauHoi })
        });
        const reader = response.body.getReader();
        let ketQua = '';

        while (true) {
            const { done, value } = await reader.read();
            if (done) break;
            ketQua += new TextDecoder().decode(value);
            setTinNhanDangGo(ketQua);              // cập nhật giao diện LIÊN TỤC theo từng đoạn nhận được
        }
    }
    // ...
}
Mẹo UX
Ngoài streaming, các chi tiết nhỏ khác cải thiện trải nghiệm chatbot đáng kể: hiển thị trạng thái "đang suy nghĩ..." (typing indicator), nút "dừng tạo" giữa chừng, và nút "thử lại" khi câu trả lời không như mong đợi.

Streaming cần quản lý vòng đời request

Thiết kế stream phải xử lý lỗi giữa chừng, ngắt kết nối, timeout và thao tác dừng tạo; khi client hủy request, backend nên hủy tác vụ upstream nếu SDK hỗ trợ. Chọn SSE hoặc WebSocket theo nhu cầu, gửi sự kiện lỗi/kết thúc rõ ràng và không giả định mỗi chunk tương ứng một token hay một ký tự. Tránh cập nhật UI quá dày; gom chunk theo nhịp render và giữ nút thử lại có kiểm soát.
