08 Gọi API LLM (OpenAI/Anthropic)

Chatbot hiện đại nhất: không tự huấn luyện mô hình, mà GỌI API của LLM đã có sẵn (Claude, GPT...) để tạo câu trả lời.

goi_api_claude.py 
# pip install anthropic
import anthropic

client = anthropic.Anthropic()   # SDK đọc ANTHROPIC_API_KEY từ biến môi trường

def hoi_ai(cau_hoi):
    response = client.messages.create(
        model="YOUR_CURRENT_CLAUDE_MODEL_ID",
        max_tokens=1000,
        messages=[
            {"role": "user", "content": cau_hoi}
        ]
    )
    return response.content[0].text

print(hoi_ai("Giải thích ngắn gọn Big O notation là gì"))

Duy trì hội thoại nhiều lượt (multi-turn)

chatbot_multi_turn.py 
lich_su_hoi_thoai = []

def chat(tin_nhan_moi):
    lich_su_hoi_thoai.append({"role": "user", "content": tin_nhan_moi})

    response = client.messages.create(
        model="YOUR_CURRENT_CLAUDE_MODEL_ID",
        max_tokens=1000,
        messages=lich_su_hoi_thoai       # gửi TOÀN BỘ lịch sử, không chỉ câu mới nhất
    )

    tra_loi = response.content[0].text
    lich_su_hoi_thoai.append({"role": "assistant", "content": tra_loi})   # lưu lại để lượt sau "nhớ"
    return tra_loi

print(chat("Tôi tên là Huy"))
print(chat("Tôi vừa nói tên tôi là gì?"))   # AI "nhớ" được nhờ lich_su_hoi_thoai
Quan trọng
LLM về bản chất không có trí nhớ giữa các lần gọi API — mỗi lần gọi là một lượt xử lý ĐỘC LẬP hoàn toàn. Cảm giác "AI nhớ cuộc trò chuyện trước" thực chất là vì ứng dụng chủ động gửi lại TOÀN BỘ lịch sử hội thoại kèm theo mỗi lần gọi API mới.
Cảnh báo — Chi phí & Bảo mật
Gọi API LLM tốn phí theo số token xử lý — lịch sử hội thoại càng dài, chi phí mỗi lượt gọi càng cao. Luôn lưu API key trong biến môi trường, KHÔNG BAO GIỜ viết trực tiếp trong code (đặc biệt nếu code được đưa lên GitHub công khai).

Gọi API như một dịch vụ không đáng tin cậy

Request có thể timeout, bị giới hạn tốc độ, hết quota hoặc trả lỗi tạm thời. Ứng dụng cần đặt timeout, phân loại lỗi, retry có backoff chỉ với lỗi tạm thời, và giới hạn tổng số lần thử để tránh tạo vòng gọi tốn phí. Không retry mù các thao tác có tác dụng phụ; dùng idempotency key nếu nhà cung cấp hỗ trợ. Ghi log mã request và số token, nhưng không ghi API key hay dữ liệu nhạy cảm.

Thay YOUR_CURRENT_CLAUDE_MODEL_ID bằng model ID đang được nhà cung cấp hỗ trợ; kiểm tra tài liệu chính thức và giới hạn theo tài khoản trước khi chạy ví dụ.
