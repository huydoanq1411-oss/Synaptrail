Tái sử dụng khối CSS bằng Mixin, và cách tổ chức nhiều file .scss cho dự án lớn theo chuẩn thực tế.

Mixin — "hàm" cho CSS

mixin.scss 
@mixin flex-center($huong: row) {     // mixin có THAM SỐ, giá trị mặc định row
    display: flex;
    flex-direction: $huong;
    justify-content: center;
    align-items: center;
}

.hero {
    @include flex-center();              // dùng mixin, giống gọi hàm
    height: 100vh;
}

.sidebar {
    @include flex-center(column);          // truyền tham số khác giá trị mặc định
}

@use để chia nhỏ file SCSS (cách hiện đại, thay cho @import cũ)

cấu trúc thư mục dự án SCSS chuẩn 
styles/
├── main.scss              # file gốc, @use các file khác
├── _variables.scss          # biến màu, khoảng cách... (dấu _ = "partial", không tự biên dịch riêng)
├── _mixins.scss               # các mixin dùng chung
├── _navbar.scss                 # style riêng cho navbar
└── _footer.scss                   # style riêng cho footer
main.scss 
@use 'variables' as v;
@use 'mixins' as m;
@use 'navbar';
@use 'footer';

.hero {
    @include m.flex-center();
    background: v.$mau-chinh;
}
Mẹo
Tên file bắt đầu bằng dấu gạch dưới (VD: _variables.scss) được gọi là "partial" — Sass biết đây chỉ là file để @use/@import vào file khác, không tự biên dịch thành file .css riêng lẻ.

📌 Tổng kết chương 2

Mixin (@mixin/@include) tái sử dụng khối CSS như hàm, có thể nhận tham số. Dự án lớn nên tách nhiều file .scss theo chức năng (biến, mixin, từng component), dùng @use để ghép lại.
