Chương 1 — SASS/SCSS — Biến & Nesting

CSS Preprocessor — viết CSS với cú pháp mạnh mẽ hơn (biến, lồng nhau, hàm...), rồi biên dịch ra CSS thuần.

Biến trong SCSS

style.scss 
$mau-chinh: #4f46e5;          // biến SCSS dùng dấu $ (khác CSS Variables dùng --)
$khoang-cach: 16px;
$bo-goc: 8px;

.nut {
    background-color: $mau-chinh;
    padding: $khoang-cach;
    border-radius: $bo-goc;
}

Nesting — lồng selector theo cấu trúc HTML

nesting.scss 
.navbar {
    background: white;

    .logo {                    // tương đương .navbar .logo trong CSS thường
        font-weight: bold;
    }

    ul {
        list-style: none;

        li {                      // tương đương .navbar ul li
            display: inline-block;

            &:hover {                 // & = tham chiếu tới chính selector cha (.navbar ul li:hover)
                color: $mau-chinh;
            }

            &.active {                 // tương đương .navbar ul li.active
                font-weight: bold;
            }
        }
    }
}
Quan trọng
Trình duyệt KHÔNG hiểu file .scss trực tiếp — cần công cụ biên dịch (Sass CLI, hoặc tích hợp sẵn trong Vite/Webpack) để chuyển .scss thành file .css thuần trước khi trình duyệt có thể sử dụng.
terminal 
npm install -g sass
sass style.scss style.css          # biên dịch 1 lần
sass --watch style.scss:style.css     # tự động biên dịch lại mỗi khi file .scss thay đổi
