Matplotlib, Seaborn & Plotly

Ba thư viện trực quan hóa dữ liệu phổ biến nhất, từ cơ bản đến tương tác.

Ba thư viện trực quan hóa dữ liệu phổ biến nhất, từ cơ bản đến tương tác.

Matplotlib — thư viện vẽ biểu đồ nền tảng

matplotlib_basic.py 
# pip install matplotlib
import matplotlib.pyplot as plt

thang = ["T1", "T2", "T3", "T4"]
doanh_thu = [120, 150, 90, 200]

plt.plot(thang, doanh_thu, marker="o")
plt.title("Doanh thu theo tháng")
plt.xlabel("Tháng")
plt.ylabel("Doanh thu (triệu)")
plt.savefig("bieu_do.png")   # lưu ra file ảnh
plt.show()

Seaborn — biểu đồ thống kê đẹp hơn, ít code hơn

seaborn_basic.py 
# pip install seaborn
import seaborn as sns
import pandas as pd

df = pd.DataFrame({"loai": ["A","A","B","B"], "gia_tri": [10, 15, 7, 9]})
sns.barplot(data=df, x="loai", y="gia_tri")   # biểu đồ cột với style đẹp sẵn

Plotly — biểu đồ tương tác

plotly_basic.py 
# pip install plotly
import plotly.express as px

fig = px.line(x=thang, y=doanh_thu, title="Doanh thu theo tháng (tương tác)")
fig.show()   # biểu đồ có thể zoom, hover xem giá trị trực tiếp trên trình duyệt
