Cấu trúc lưu trữ dữ liệu theo cặp key–value, tra cứu cực nhanh theo key.

dict.py 
sv = {
    "ten": "Huy",
    "tuoi": 20,
    "diem": [8.5, 9.0, 7.5]
}

print(sv["ten"])          # Huy
print(sv.get("dia_chi", "Chưa có"))  # tránh lỗi KeyError nếu key không tồn tại

sv["dia_chi"] = "TP.HCM"   # thêm key mới
sv["tuoi"] = 21              # cập nhật giá trị
del sv["diem"]                # xóa một key

for key, value in sv.items():
    print(f"{key}: {value}")

# Dict comprehension
binh_phuong = {x: x**2 for x in range(5)}
print(binh_phuong)   # {0:0, 1:1, 2:4, 3:9, 4:16}
Quan trọng
Nên dùng .get(key, gia_tri_mac_dinh) thay vì dict[key] khi không chắc key có tồn tại — tránh lỗi KeyError làm crash chương trình.

Bài tập thực hành

Đề bài: Đếm số lần xuất hiện của mỗi ký tự trong chuỗi "python".

chuoi = "python"
dem = {}
for ky_tu in chuoi:
    dem[ky_tu] = dem.get(ky_tu, 0) + 1
print(dem)  # {'p':1,'y':1,'t':1,'h':1,'o':1,'n':1}

📌 Tổng kết chương 30

Dictionary lưu trữ dữ liệu key-value, tra cứu theo key rất nhanh (O(1)). Dùng .get() để tránh lỗi khi key không tồn tại.
