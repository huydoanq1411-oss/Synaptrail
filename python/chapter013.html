Câu lệnh điều kiện — cho phép chương trình đưa ra quyết định dựa trên dữ liệu.

Cấu trúc cơ bản

if_else.py 
tuoi = 20

if tuoi < 13:
    print("Trẻ em")
elif tuoi < 18:
    print("Thiếu niên")
else:
    print("Người lớn")
Quan trọng
Python dùng thụt lề (indentation) để xác định khối lệnh, không dùng dấu ngoặc nhọn {} như C/Java. Thụt lề sai sẽ gây lỗi IndentationError. Quy ước chuẩn: 4 dấu cách cho mỗi cấp thụt lề.

Điều kiện lồng nhau (nested if)

nested_if.py 
diem = 8.5
dat = True

if dat:
    if diem >= 8:
        print("Loại Giỏi")
    else:
        print("Đạt nhưng chưa Giỏi")
else:
    print("Không đạt")

Toán tử điều kiện rút gọn (ternary)

ternary.py 
tuoi = 20
trang_thai = "Người lớn" if tuoi >= 18 else "Trẻ em"
print(trang_thai)
Mẹo
Có thể kết hợp nhiều điều kiện bằng and, or: if tuoi >= 18 and co_the_sinh_vien: — giúp code ngắn gọn hơn so với if lồng nhau.

📌 Tổng kết chương 13

if / elif / else dùng để rẽ nhánh chương trình. Python dùng thụt lề để xác định khối lệnh — đây là điểm khác biệt lớn so với nhiều ngôn ngữ khác.
