Tương tác với hệ điều hành và môi trường chạy chương trình.

Module os

os_module.py 
import os

print(os.getcwd())                # thư mục hiện tại
print(os.listdir("."))              # danh sách file/thư mục trong "."
os.mkdir("thu_muc_moi")             # tạo thư mục mới
os.rename("a.txt", "b.txt")          # đổi tên file
print(os.path.exists("b.txt"))        # kiểm tra file có tồn tại
print(os.path.join("data", "file.txt"))  # nối đường dẫn đúng chuẩn hệ điều hành
print(os.environ.get("PATH"))          # đọc biến môi trường

Module sys

sys_module.py 
import sys

print(sys.argv)          # danh sách tham số dòng lệnh khi chạy script
print(sys.version)        # phiên bản Python đang chạy
sys.exit(0)                 # thoát chương trình với mã trạng thái 0 (thành công)
Mẹo
Luôn dùng os.path.join() thay vì tự nối chuỗi đường dẫn bằng + "/" — giúp code chạy đúng trên cả Windows (dùng \) lẫn macOS/Linux (dùng /).

📌 Tổng kết chương 48

os tương tác với hệ thống file và biến môi trường. sys tương tác với môi trường thực thi Python (tham số dòng lệnh, thoát chương trình...).
