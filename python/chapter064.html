Trie & Union Find

Hai cấu trúc dữ liệu chuyên biệt cho các bài toán cụ thể: xử lý chuỗi và nhóm phần tử.

Trie — cây tiền tố, tối ưu cho tìm kiếm chuỗi

trie.py 
class TrieNode:
    def __init__(self):
        self.con = {}
        self.ket_thuc_tu = False

class Trie:
    def __init__(self):
        self.goc = TrieNode()

    def them(self, tu):
        node = self.goc
        for ky_tu in tu:
            node = node.con.setdefault(ky_tu, TrieNode())
        node.ket_thuc_tu = True

    def tim_kiem(self, tu):
        node = self.goc
        for ky_tu in tu:
            if ky_tu not in node.con:
                return False
            node = node.con[ky_tu]
        return node.ket_thuc_tu

trie = Trie()
for tu in ["python", "java", "javascript"]:
    trie.them(tu)
print(trie.tim_kiem("java"))    # True
print(trie.tim_kiem("jav"))     # False - "jav" chưa được thêm như 1 từ hoàn chỉnh

Trie được dùng trong tính năng autocomplete / gợi ý từ khóa — rất phổ biến trong thanh tìm kiếm, bàn phím điện thoại.

Union Find (Disjoint Set) — quản lý các nhóm phần tử

union_find.py 
class UnionFind:
    def __init__(self, n):
        self.cha = list(range(n))   # ban đầu mỗi phần tử là gốc của chính nó

    def tim_goc(self, x):
        if self.cha[x] != x:
            self.cha[x] = self.tim_goc(self.cha[x])   # nén đường dẫn (path compression)
        return self.cha[x]

    def hop_nhat(self, x, y):
        goc_x, goc_y = self.tim_goc(x), self.tim_goc(y)
        if goc_x != goc_y:
            self.cha[goc_x] = goc_y

uf = UnionFind(5)
uf.hop_nhat(0, 1)
uf.hop_nhat(1, 2)
print(uf.tim_goc(0) == uf.tim_goc(2))   # True - 0 và 2 cùng nhóm
print(uf.tim_goc(0) == uf.tim_goc(3))   # False - khác nhóm
Ghi chú
Union Find rất hữu ích cho bài toán kiểm tra kết nối mạng, phát hiện chu trình trong đồ thị vô hướng, và thuật toán Kruskal tìm cây khung nhỏ nhất (Minimum Spanning Tree).

📌 Tổng kết chương 64

Trie tối ưu tìm kiếm/gợi ý chuỗi theo tiền tố. Union Find quản lý hiệu quả việc gộp nhóm và kiểm tra hai phần tử có cùng nhóm hay không.
