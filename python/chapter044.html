Chủ động ném lỗi và tự định nghĩa loại lỗi riêng cho ứng dụng.

raise — chủ động ném lỗi

raise.py 
def rut_tien(so_du, so_tien):
    if so_tien > so_du:
        raise ValueError("Số dư không đủ để rút!")
    return so_du - so_tien

try:
    rut_tien(100000, 500000)
except ValueError as e:
    print(f"Lỗi: {e}")

Custom Exception — lớp lỗi tự định nghĩa

custom_exception.py 
class SoDuKhongDuException(Exception):
    """Lỗi tùy chỉnh khi số dư tài khoản không đủ."""
    def __init__(self, so_du, so_tien_can):
        self.so_du = so_du
        self.so_tien_can = so_tien_can
        super().__init__(f"Cần {so_tien_can} nhưng chỉ có {so_du}")

def rut_tien(so_du, so_tien):
    if so_tien > so_du:
        raise SoDuKhongDuException(so_du, so_tien)
    return so_du - so_tien

try:
    rut_tien(100000, 500000)
except SoDuKhongDuException as e:
    print(f"Giao dịch thất bại: {e}")
Ghi chú
Custom exception luôn kế thừa từ Exception (hoặc một lớp lỗi con cháu của nó), giúp phân biệt rõ ràng lỗi nghiệp vụ riêng của ứng dụng so với lỗi hệ thống chung.

📌 Tổng kết chương 44

raise chủ động ném lỗi khi phát hiện điều kiện bất thường. Custom Exception (kế thừa từ Exception) giúp định nghĩa các loại lỗi nghiệp vụ riêng, rõ ràng hơn.
