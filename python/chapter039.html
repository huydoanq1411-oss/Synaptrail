Magic Methods

Các phương thức đặc biệt (dunder methods, có dạng __xxx__) cho phép tùy chỉnh hành vi mặc định của object.

Các phương thức đặc biệt (dunder methods, có dạng __xxx__) cho phép tùy chỉnh hành vi mặc định của object.

magic_methods.py 
class DiemSo:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):          # gọi khi print(object) hoặc str(object)
        return f"Điểm({self.x}, {self.y})"

    def __eq__(self, khac):     # gọi khi dùng ==
        return self.x == khac.x and self.y == khac.y

    def __add__(self, khac):    # gọi khi dùng +
        return DiemSo(self.x + khac.x, self.y + khac.y)

    def __len__(self):          # gọi khi dùng len()
        return 2

p1 = DiemSo(1, 2)
p2 = DiemSo(3, 4)
print(p1)          # Điểm(1, 2) - nhờ __str__
print(p1 == p2)     # False - nhờ __eq__
print(p1 + p2)       # Điểm(4, 6) - nhờ __add__

Magic methods (dunder methods) cho phép object tùy chỉnh cách hoạt động với các toán tử và hàm dựng sẵn của Python như print(), ==, +, len().
