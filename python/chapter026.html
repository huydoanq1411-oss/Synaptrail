Hàm "bọc" một hàm khác để mở rộng chức năng mà không cần sửa code gốc.

decorator.py 
def do_thoi_gian(func):
    def wrapper(*args, **kwargs):
        import time
        bat_dau = time.time()
        ket_qua = func(*args, **kwargs)
        print(f"{func.__name__} chạy trong {time.time()-bat_dau:.4f}s")
        return ket_qua
    return wrapper

@do_thoi_gian
def tinh_tong_lon(n):
    return sum(range(n))

tinh_tong_lon(1000000)

Cú pháp @do_thoi_gian đặt phía trên hàm tương đương với việc viết tinh_tong_lon = do_thoi_gian(tinh_tong_lon).

Mẹo
Decorator được dùng rất nhiều trong thực tế: đo thời gian chạy, ghi log, kiểm tra quyền truy cập (authentication) trong Flask/Django, cache kết quả (@functools.lru_cache)...
