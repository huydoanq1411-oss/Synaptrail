Cấu trúc package chuẩn

cấu trúc thư mục 
ten_thu_vien/
├── pyproject.toml
├── README.md
├── LICENSE
└── src/
    └── ten_thu_vien/
        ├── __init__.py
        └── core.py

pyproject.toml — cấu hình chuẩn hiện đại

pyproject.toml 
[build-system]
requires = ["setuptools>=61.0"]
build-backend = "setuptools.build_meta"

[project]
name = "ten-thu-vien-cua-ban"
version = "0.1.0"
description = "Mô tả ngắn gọn về thư viện"
authors = [{name = "Tên bạn", email = "email@example.com"}]
dependencies = ["requests>=2.28"]
requires-python = ">=3.9"

Build và phát hành lên PyPI

terminal 
pip install build twine

python -m build                    # tạo file phân phối trong thư mục dist/
twine upload --repository testpypi dist/*   # tải lên TestPyPI để thử nghiệm trước
twine upload dist/*                            # tải lên PyPI thật

# Sau khi phát hành, ai cũng có thể cài bằng:
pip install ten-thu-vien-cua-ban
Mẹo
Luôn thử nghiệm trên TestPyPI (test.pypi.org) trước khi đăng lên PyPI thật — vì mỗi tên package và phiên bản trên PyPI là vĩnh viễn không thể xóa/đổi sau khi đã tải lên.
Cách làm gọn hơn với uv
Nếu dự án của bạn đã dùng uv (xem lại chương 42), việc build và phát hành gói còn gọn hơn nữa — không cần cài riêng build và twine: 
uv build                       # tạo file phân phối trong thư mục dist/
uv publish --index testpypi    # tải lên TestPyPI để thử nghiệm
uv publish                     # tải lên PyPI thật
