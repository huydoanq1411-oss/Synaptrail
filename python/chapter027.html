Danh sách có thứ tự, có thể thay đổi (mutable), chứa nhiều kiểu dữ liệu khác nhau.

Tạo và truy cập List

list_basic.py 
trai_cay = ["táo", "cam", "chuối", "xoài"]
print(trai_cay[0])      # táo
print(trai_cay[-1])     # xoài (phần tử cuối)
print(trai_cay[1:3])    # ['cam', 'chuối'] - slicing

hon_hop = [1, "hai", 3.0, True, [4, 5]]  # list chứa nhiều kiểu, kể cả list lồng

Các thao tác thường dùng

list_methods.py 
ds = [3, 1, 4, 1, 5]

ds.append(9)          # thêm vào cuối -> [3,1,4,1,5,9]
ds.insert(0, 100)     # chèn vào vị trí 0 -> [100,3,1,4,1,5,9]
ds.remove(1)           # xóa PHẦN TỬ đầu tiên có giá trị 1
ds.pop()                # xóa và trả về phần tử CUỐI
ds.sort()                # sắp xếp tăng dần (thay đổi list gốc)
ds.reverse()             # đảo ngược thứ tự
print(len(ds))           # độ dài danh sách
print(9 in ds)            # kiểm tra tồn tại

# List comprehension - cách tạo list ngắn gọn, "rất Pythonic"
binh_phuong = [x**2 for x in range(6)]
print(binh_phuong)   # [0, 1, 4, 9, 16, 25]

so_chan = [x for x in range(20) if x % 2 == 0]
print(so_chan)
Mẹo
List comprehension là một trong những đặc trưng "rất Python" — luôn ưu tiên dùng thay vì vòng lặp for thủ công khi tạo list mới từ một tập hợp khác.
Quan trọng
List là mutable (có thể thay đổi trực tiếp): ds[0] = 100 hợp lệ — khác hoàn toàn với chuỗi (immutable).

📌 Tổng kết chương 27

List là cấu trúc dữ liệu có thứ tự, có thể thay đổi, hỗ trợ rất nhiều phương thức (append, sort, remove...) và list comprehension để tạo danh sách ngắn gọn.
