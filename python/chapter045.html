Đọc và ghi dữ liệu văn bản thuần vào file trên ổ đĩa.

Đọc và ghi dữ liệu văn bản thuần vào file trên ổ đĩa.

file_txt.py 
# Ghi file - "w" = write (ghi đè), "a" = append (nối thêm)
with open("ghi_chu.txt", "w", encoding="utf-8") as f:
    f.write("Xin chào Python!\n")
    f.write("Dòng thứ hai.")

# Đọc toàn bộ file
with open("ghi_chu.txt", "r", encoding="utf-8") as f:
    noi_dung = f.read()
    print(noi_dung)

# Đọc từng dòng
with open("ghi_chu.txt", "r", encoding="utf-8") as f:
    for dong in f:
        print(dong.strip())
Quan trọng
Luôn dùng with open(...) as f: thay vì f = open(...) thủ công — cú pháp with tự động đóng file kể cả khi có lỗi xảy ra, tránh rò rỉ tài nguyên (resource leak).
Chế độÝ nghĩa
"r"Đọc (mặc định, báo lỗi nếu file không tồn tại)
"w"Ghi, xóa toàn bộ nội dung cũ nếu file đã tồn tại
"a"Ghi nối thêm vào cuối file
"r+"Vừa đọc vừa ghi
