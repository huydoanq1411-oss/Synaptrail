Module math

math_module.py 
import math

print(round(3.7))        # 4 - làm tròn
print(abs(-5))            # 5 - giá trị tuyệt đối
print(math.sqrt(16))      # 4.0 - căn bậc hai
print(math.floor(3.9))    # 3 - làm tròn xuống
print(math.ceil(3.1))     # 4 - làm tròn lên
print(max(3, 7, 2))        # 7
print(min(3, 7, 2))        # 2
Ghi chú
Python 3 hỗ trợ số nguyên có độ lớn không giới hạn (chỉ giới hạn bởi bộ nhớ máy tính) — khác với nhiều ngôn ngữ khác có giới hạn kiểu int cố định (như 32-bit hay 64-bit).
