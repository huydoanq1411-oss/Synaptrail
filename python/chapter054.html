Big O Notation

Ký hiệu đo lường độ phức tạp thời gian/bộ nhớ của thuật toán khi kích thước dữ liệu tăng lên.

Ký hiệu đo lường độ phức tạp thời gian/bộ nhớ của thuật toán khi kích thước dữ liệu tăng lên.

Ký hiệuTên gọiVí dụ
O(1)Hằng sốTruy cập phần tử theo index

def tim_max_On(ds):        # O(n) - duyệt 1 lần qua toàn bộ list
    lon_nhat = ds[0]
    for x in ds:
        if x > lon_nhat:
            lon_nhat = x
    return lon_nhat

def co_cap_On2(ds):        # O(n²) - vòng lặp lồng nhau
    cap = []
    for i in ds:
        for j in ds:
            cap.append((i, j))
    return cap
Mẹo
Big O mô tả xu hướng khi n rất lớn, không quan tâm hằng số nhỏ. Luôn ưu tiên chọn thuật toán có độ phức tạp thấp hơn khi làm việc với dữ liệu lớn — sự khác biệt giữa O(n) và O(n²) có thể là vài giây so với vài giờ chạy.
