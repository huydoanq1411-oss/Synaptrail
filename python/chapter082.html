TensorFlow / Keras

tensorflow_basic.py 
# pip install tensorflow
import tensorflow as tf
from tensorflow import keras

mo_hinh = keras.Sequential([
    keras.layers.Input(shape=(4,)),                                   # lớp input tường minh (cách viết khuyến nghị)
    keras.layers.Dense(16, activation="relu"),                        # lớp ẩn
    keras.layers.Dense(1, activation="sigmoid")                       # lớp đầu ra (phân loại nhị phân)
])

mo_hinh.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
# mo_hinh.fit(X_train, y_train, epochs=10)   # huấn luyện (cần dữ liệu thực tế)
Ghi chú: Keras 3
Từ TensorFlow 2.16 trở đi, tf.keras mặc định chạy trên Keras 3 — bản viết lại hỗ trợ đa backend (chạy được trên TensorFlow, PyTorch hoặc JAX với cùng một đoạn code). Tham số input_shape truyền thẳng vào Dense vẫn hoạt động nhưng cách viết khuyến nghị hiện nay là khai báo keras.layers.Input(shape=...) làm lớp đầu tiên, như ví dụ trên.

PyTorch

pytorch_basic.py 
# pip install torch
import torch
import torch.nn as nn

class MangNoRon(nn.Module):
    def __init__(self):
        super().__init__()
        self.lop_an = nn.Linear(4, 16)
        self.lop_ra = nn.Linear(16, 1)

    def forward(self, x):
        x = torch.relu(self.lop_an(x))
        x = torch.sigmoid(self.lop_ra(x))
        return x

model = MangNoRon()
print(model)
Tiêu chíTensorFlow/KerasPyTorch
Phong cáchKhai báo (declarative), dễ tiếp cậnHướng đối tượng, linh hoạt (giống viết Python thuần)
Phổ biến trong (2026)Triển khai sản phẩm ở quy mô doanh nghiệp, mobile (TF Lite), huấn luyện trên TPUNghiên cứu (hơn 50% bài báo AI dùng PyTorch), phần lớn hệ sinh thái mô hình sinh (generative AI/LLM)
Ghi chú
Tính đến 2026, PyTorch đang chiếm ưu thế rõ rệt trong nghiên cứu và các dự án AI tạo sinh, trong khi TensorFlow vẫn mạnh ở mảng triển khai sản phẩm quy mô lớn và phần cứng TPU của Google. Với sự xuất hiện của Keras 3 (đa backend), ranh giới giữa hai framework đang mờ dần — bạn có thể viết một model bằng Keras rồi chạy nó trên cả TensorFlow lẫn PyTorch. Cả hai framework đều cần kiến thức nền về đại số tuyến tính và mạng nơ-ron để sử dụng hiệu quả — nội dung này thuộc phạm vi một giáo trình Deep Learning chuyên sâu riêng.
