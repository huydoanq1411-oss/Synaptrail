Lỗi thường gặp (Common Mistakes)

  • Mutable default argument: def f(ds=[]) — list mặc định bị CHIA SẺ giữa các lần gọi hàm. Nên dùng def f(ds=None): ds = ds or [].
  • So sánh float trực tiếp: 0.1 + 0.2 == 0.3 trả về False do sai số dấu phẩy động — nên dùng math.isclose().
  • Sửa list khi đang duyệt: xóa phần tử trong lúc for x in ds: gây bỏ sót phần tử — nên duyệt trên bản sao ds[:] hoặc dùng list comprehension.
  • Quên self trong phương thức của class — lỗi rất phổ biến với người mới học OOP.
