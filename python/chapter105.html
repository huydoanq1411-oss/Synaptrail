Regular Expressions (re)

Ngôn ngữ mô tả mẫu (pattern) để tìm kiếm, kiểm tra và thay thế văn bản — kỹ năng cực kỳ hữu dụng trong xử lý dữ liệu thực tế.

Ngôn ngữ mô tả mẫu (pattern) để tìm kiếm, kiểm tra và thay thế văn bản — kỹ năng cực kỳ hữu dụng trong xử lý dữ liệu thực tế.

Các hàm chính của module re

re_basic.py 
import re

# match/search - tìm kiếm mẫu
ket_qua = re.search(r"\d+", "Tôi có 25 quyển sách")
print(ket_qua.group())   # "25"

# findall - tìm TẤT CẢ các mẫu khớp
so_dien_thoai = re.findall(r"\d{4}", "Số: 0912 3456 hoặc 0987 6543")
print(so_dien_thoai)   # ['0912', '3456', '0987', '6543']

# sub - thay thế theo mẫu
chuoi_an_toan = re.sub(r"\d", "*", "Mật khẩu: 12345")
print(chuoi_an_toan)   # "Mật khẩu: *****"

# split - tách chuỗi theo mẫu
tu = re.split(r"[,;]\s*", "táo, cam;chuối, xoài")
print(tu)   # ['táo', 'cam', 'chuối', 'xoài']

Các ký hiệu (metacharacter) thường dùng

Ký hiệuÝ nghĩaVí dụ
\dMột chữ số\d+ khớp "123"
\wChữ, số hoặc gạch dưới\w+ khớp "bien_so1"
\sKhoảng trắng\s+ khớp nhiều dấu cách
.Bất kỳ ký tự nào (trừ xuống dòng)a.c khớp "abc", "axc"
*, +, ?0+, 1+, 0-hoặc-1 lần lặpab* khớp "a", "ab", "abb"
^, $Đầu chuỗi, cuối chuỗi^Xin khớp chuỗi bắt đầu bằng "Xin"
()Nhóm (group) để trích xuất riêng(\d{3})-(\d{4})

Named groups — trích xuất dữ liệu có tên

re_named_groups.py 
mau = r"(?P\w+)@(?P\w+\.\w+)"
ket_qua = re.search(mau, "Liên hệ: huy@example.com")
print(ket_qua.group("ten"))    # huy
print(ket_qua.group("mien"))    # example.com
Mẹo
Luôn dùng chuỗi raw string (tiền tố r"...") khi viết regex — tránh xung đột giữa ký tự escape của Python (\n, \t) và của regex (\d, \w).

📌 Tổng kết chương 105

Module re cung cấp search/findall/sub/split để tìm kiếm và xử lý văn bản theo mẫu. Named groups giúp trích xuất dữ liệu có cấu trúc rõ ràng, dễ đọc hơn group theo số thứ tự.
