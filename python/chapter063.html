Cấu trúc gồm các đỉnh (node) và cạnh (edge) nối chúng — mô hình hóa mạng xã hội, bản đồ, mạng máy tính...

Biểu diễn đồ thị bằng adjacency list

graph_representation.py 
do_thi = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"]
}

BFS — duyệt theo chiều rộng

bfs.py 
from collections import deque

def bfs(do_thi, bat_dau):
    da_tham = {bat_dau}
    hang_doi = deque([bat_dau])
    thu_tu = []
    while hang_doi:
        node = hang_doi.popleft()
        thu_tu.append(node)
        for hang_xom in do_thi[node]:
            if hang_xom not in da_tham:
                da_tham.add(hang_xom)
                hang_doi.append(hang_xom)
    return thu_tu

print(bfs(do_thi, "A"))   # ['A', 'B', 'C', 'D', 'E']

DFS — duyệt theo chiều sâu

dfs.py 
def dfs(do_thi, node, da_tham=None):
    if da_tham is None:
        da_tham = set()
    da_tham.add(node)
    print(node, end=" ")
    for hang_xom in do_thi[node]:
        if hang_xom not in da_tham:
            dfs(do_thi, hang_xom, da_tham)

dfs(do_thi, "A")   # A B D C E (thứ tự có thể khác tùy cấu trúc)
Mẹo
BFS phù hợp để tìm đường đi ngắn nhất (số cạnh ít nhất) trong đồ thị không trọng số. DFS phù hợp để kiểm tra tính liên thông, phát hiện chu trình, hoặc khi cần duyệt sâu trước khi quay lại.

📌 Tổng kết chương 63

Đồ thị gồm đỉnh và cạnh, thường biểu diễn bằng adjacency list. BFS (dùng queue) và DFS (dùng đệ quy/stack) là hai thuật toán duyệt đồ thị nền tảng.
