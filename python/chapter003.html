Viết và chạy "Hello, World!" — truyền thống của mọi lập trình viên.

Viết chương trình

Tạo file hello.py với nội dung:

hello.py 
print("Hello, World!")
print("Xin chào, Python!")

Chạy chương trình

Có 2 cách phổ biến:

  1. Qua terminal: mở terminal tại thư mục chứa file, gõ python hello.py
  2. Qua VS Code: nhấn nút "Run" (▷) ở góc trên bên phải, hoặc phím tắt Ctrl+F5
terminal 
python hello.py
# Output:
# Hello, World!
# Xin chào, Python!
Mẹo
Hàm print() là công cụ debug đơn giản nhất — dùng nó để "in ra màn hình" giá trị biến bất cứ khi nào bạn muốn kiểm tra chương trình đang chạy đúng hay không.

Bài tập thực hành

Đề bài: Viết chương trình in ra 3 dòng: tên bạn, tuổi, và sở thích.

Đáp án gợi ý:

print("Tên: Nguyễn Văn A")
print("Tuổi: 20")
print("Sở thích: Lập trình")

📌 Tổng kết chương 3

Chương trình Python được lưu trong file .py và chạy bằng lệnh python ten_file.py. Hàm print() dùng để xuất dữ liệu ra màn hình.
