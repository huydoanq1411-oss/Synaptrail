threading & multiprocessing

threading — đa luồng

threading_module.py 
import threading, time

def tai_xuong(ten):
    print(f"Bắt đầu tải {ten}")
    time.sleep(2)
    print(f"Hoàn thành tải {ten}")

t1 = threading.Thread(target=tai_xuong, args=("file1.zip",))
t2 = threading.Thread(target=tai_xuong, args=("file2.zip",))
t1.start(); t2.start()
t1.join(); t2.join()   # chờ cả hai luồng hoàn thành
print("Tất cả đã hoàn thành!")

multiprocessing — đa tiến trình

multiprocessing_module.py 
from multiprocessing import Process

def tinh_toan_nang(n):
    print(sum(i*i for i in range(n)))

if __name__ == "__main__":
    p1 = Process(target=tinh_toan_nang, args=(10_000_000,))
    p2 = Process(target=tinh_toan_nang, args=(10_000_000,))
    p1.start(); p2.start()
    p1.join(); p2.join()
Ghi chú — GIL (Global Interpreter Lock)
Do giới hạn GIL của Python, threading phù hợp cho tác vụ I/O-bound (chờ mạng, chờ đọc file). Với tác vụ CPU-bound (tính toán nặng), nên dùng multiprocessing để thực sự chạy song song trên nhiều lõi CPU.

📌 Tổng kết chương 52

threading phù hợp cho tác vụ I/O-bound. multiprocessing tạo tiến trình riêng biệt, phù hợp cho tác vụ CPU-bound, vượt qua giới hạn GIL.
