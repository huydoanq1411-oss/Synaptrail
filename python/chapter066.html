Context Manager

Đảm bảo tài nguyên (file, kết nối mạng, khóa luồng) luôn được giải phóng đúng cách, kể cả khi có lỗi.

Đảm bảo tài nguyên (file, kết nối mạng, khóa luồng) luôn được giải phóng đúng cách, kể cả khi có lỗi.

Dùng với with (đã thấy ở chương File)

with_review.py 
with open("data.txt") as f:
    noi_dung = f.read()
# file tự động đóng khi ra khỏi khối with, kể cả khi có lỗi xảy ra bên trong

Tự viết Context Manager bằng class

context_manager_class.py 
class KetNoiDatabase:
    def __enter__(self):
        print("Mở kết nối database")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Đóng kết nối database")   # luôn chạy, kể cả khi có lỗi

with KetNoiDatabase() as db:
    print("Đang truy vấn dữ liệu...")
# Output: Mở kết nối -> Đang truy vấn -> Đóng kết nối

Cách gọn hơn: @contextmanager

context_manager_decorator.py 
from contextlib import contextmanager

@contextmanager
def ket_noi_database():
    print("Mở kết nối database")
    yield "ket_noi_gia_lap"
    print("Đóng kết nối database")

with ket_noi_database() as db:
    print(f"Đang dùng: {db}")

📌 Tổng kết chương 66

Context Manager (qua with) đảm bảo tài nguyên được dọn dẹp đúng cách. Có thể tự viết bằng __enter__/__exit__ hoặc gọn hơn bằng @contextmanager.
