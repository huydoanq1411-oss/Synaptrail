Metaclass & Reflection

Reflection — kiểm tra object lúc runtime

reflection.py 
class SinhVien:
    def __init__(self, ten):
        self.ten = ten
    def chao(self):
        print(f"Xin chào, tôi là {self.ten}")

sv = SinhVien("Huy")
print(hasattr(sv, "ten"))         # True - kiểm tra object có thuộc tính này không
print(getattr(sv, "ten"))          # "Huy" - lấy giá trị thuộc tính theo tên (chuỗi)
setattr(sv, "tuoi", 20)              # gán thuộc tính mới theo tên (chuỗi)
print(sv.tuoi)                        # 20
print(type(sv).__name__)              # "SinhVien"
print(isinstance(sv, SinhVien))       # True
print(callable(sv.chao))               # True - kiểm tra có gọi được như hàm không

Metaclass — "class của class"

metaclass.py 
class MetaLog(type):
    def __new__(cls, ten, bases, atts):
        print(f"Đang tạo class: {ten}")
        return super().__new__(cls, ten, bases, atts)

class SanPham(metaclass=MetaLog):   # in ra "Đang tạo class: SanPham" ngay khi định nghĩa
    pass
Lưu ý
Metaclass là kỹ thuật rất nâng cao, hiếm khi cần trong công việc hàng ngày — chủ yếu dùng khi xây dựng framework (như Django ORM). Câu nói kinh điển: "Nếu bạn không chắc mình có cần metaclass hay không, thì bạn không cần nó."

📌 Tổng kết chương 68

Reflection cho phép kiểm tra/thao tác object linh hoạt lúc runtime (hasattr, getattr, setattr). Metaclass kiểm soát cách class được tạo ra — kỹ thuật nâng cao dùng trong framework.
