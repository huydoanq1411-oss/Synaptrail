Comment

Ghi chú trong code — Python bỏ qua khi chạy chương trình, nhưng giúp con người hiểu code.

Ghi chú trong code — Python bỏ qua khi chạy chương trình, nhưng giúp con người hiểu code.

Comment một dòng

comment.py 
# Đây là comment một dòng
x = 5  # comment ở cuối dòng cũng được

Comment nhiều dòng

Python không có cú pháp comment nhiều dòng thật sự, nhưng thường dùng chuỗi ba dấu ngoặc kép (docstring) cho mục đích này:

comment_nhieu_dong.py 
"""
Đây là comment nhiều dòng
thường dùng để mô tả file hoặc hàm
"""
def cong(a, b):
    """Hàm này cộng hai số và trả về kết quả."""
    return a + b
Mẹo
Viết comment giải thích "tại sao" code làm vậy, chứ không chỉ lặp lại "cái gì" code đang làm — code đã tự nói lên nó làm gì rồi.

📌 Tổng kết chương 8

Dùng # cho comment một dòng, và chuỗi ba dấu ngoặc kép """...""" cho comment/docstring nhiều dòng.
