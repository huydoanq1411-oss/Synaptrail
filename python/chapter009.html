Chuyển đổi giá trị từ kiểu dữ liệu này sang kiểu dữ liệu khác.

Làm quiz ở trang riêng

Chuyển đổi giá trị từ kiểu dữ liệu này sang kiểu dữ liệu khác.

ep_kieu.py 
a = "10"
b = int(a)        # ép chuỗi thành số nguyên -> 10
c = float(a)       # ép chuỗi thành số thực -> 10.0
d = str(25)         # ép số thành chuỗi -> "25"
e = bool(0)         # ép số thành boolean -> False
f = list("abc")     # ép chuỗi thành danh sách -> ['a', 'b', 'c']

print(b, c, d, e, f)
HàmChức năng
int()Chuyển sang số nguyên
float()Chuyển sang số thực
str()Chuyển sang chuỗi
bool()Chuyển sang boolean
list(), tuple(), set()Chuyển sang các kiểu tập hợp
Lỗi thường gặp
int("Xin chào") sẽ gây lỗi ValueError vì chuỗi đó không phải là số. Chỉ ép kiểu được khi nội dung chuỗi thực sự hợp lệ với kiểu đích.
Ghi chú
Các giá trị được coi là "False" khi ép sang boolean: 0, 0.0, "" (chuỗi rỗng), [], {}, None. Tất cả giá trị khác đều là True.

📌 Tổng kết chương 9

Dùng int(), float(), str(), bool() để ép kiểu dữ liệu. Luôn chắc chắn giá trị nguồn hợp lệ với kiểu đích để tránh ValueError.
