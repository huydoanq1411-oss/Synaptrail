match-case

Cấu trúc so khớp mẫu (pattern matching), tương tự switch-case, có từ Python 3.10.

Cấu trúc so khớp mẫu (pattern matching), tương tự switch-case, có từ Python 3.10.

Cú pháp cơ bản

match_case.py 
def xep_hang(diem):
    match diem:
        case 10:
            return "Xuất sắc"
        case 8 | 9:
            return "Giỏi"
        case 6 | 7:
            return "Khá"
        case _:
            return "Cần cố gắng"

print(xep_hang(9))   # Giỏi
print(xep_hang(3))   # Cần cố gắng

case _ đóng vai trò như default trong các ngôn ngữ khác — bắt mọi trường hợp còn lại.

Match với cấu trúc dữ liệu

match_structure.py 
def mo_ta_toa_do(diem):
    match diem:
        case (0, 0):
            return "Gốc tọa độ"
        case (x, 0):
            return f"Nằm trên trục X tại {x}"
        case (0, y):
            return f"Nằm trên trục Y tại {y}"
        case (x, y):
            return f"Điểm ({x}, {y})"

print(mo_ta_toa_do((0, 5)))  # Nằm trên trục Y tại 5
Ghi chú
match-case chỉ khả dụng từ Python 3.10 trở lên. Nếu dùng phiên bản cũ hơn, phải dùng chuỗi if/elif/else thay thế.

📌 Tổng kết chương 14

match-case giúp code rẽ nhánh theo nhiều giá trị trở nên gọn gàng hơn, hỗ trợ cả so khớp cấu trúc dữ liệu phức tạp (tuple, list, object).
