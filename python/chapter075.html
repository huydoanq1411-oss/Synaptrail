Framework hiện đại, hiệu năng cao, tự động sinh tài liệu API, tận dụng type hints của Python.

main.py 
# pip install fastapi uvicorn
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class SinhVien(BaseModel):    # Pydantic model - tự validate dữ liệu đầu vào
    ten: str
    tuoi: int
    diem: float = 0.0

@app.get("/")
def trang_chu():
    return {"thong_bao": "Chào mừng đến với FastAPI"}

@app.post("/sinh-vien")
def tao_sinh_vien(sv: SinhVien):   # tự động validate: sai kiểu -> trả lỗi 422 rõ ràng
    return {"da_them": sv}

# Chạy: uvicorn main:app --reload
# Tài liệu API tự sinh tại: http://127.0.0.1:8000/docs
Mẹo
FastAPI tự động sinh giao diện tài liệu API tương tác (Swagger UI) tại /docs — không cần viết tài liệu API thủ công, rất tiện cho việc test và làm việc nhóm.
Ghi chú
FastAPI được xây dựng trên nền asyncio (chương 53), hỗ trợ native async def cho endpoint — hiệu năng cao khi xử lý nhiều request I/O-bound đồng thời.

📌 Tổng kết chương 75

FastAPI kết hợp type hints, Pydantic validation và async để tạo API hiệu năng cao, tự động sinh tài liệu — lựa chọn hiện đại rất được ưa chuộng cho microservice.
