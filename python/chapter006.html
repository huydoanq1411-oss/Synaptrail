Toán tử logic

toan_tu_logic.py 
a = True
b = False

print(a and b)   # False - cả hai đều True mới True
print(a or b)    # True  - chỉ cần một cái True
print(not a)     # False - đảo ngược giá trị
Lỗi thường gặp
Nhầm lẫn giữa = (gán giá trị) và == (so sánh bằng). if x = 5: sẽ gây lỗi cú pháp — phải viết if x == 5:.

📌 Tổng kết chương 6

Python có toán tử số học, so sánh và logic. Lưu ý phân biệt / (chia thực) với // (chia nguyên), và = (gán) với == (so sánh).
