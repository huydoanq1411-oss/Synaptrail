Chương 6 — Toán tử (Operators)

Các phép toán để xử lý và so sánh dữ liệu.

Toán tử số học

Toán tửÝ nghĩaVí dụKết quả
+Cộng5 + 38
-Trừ5 - 32
*Nhân5 * 315
/Chia (trả về float)5 / 31.666...
//Chia lấy phần nguyên5 // 31
%Chia lấy dư (modulo)5 % 32
**Lũy thừa5 ** 225

Toán tử so sánh

Toán tửÝ nghĩa
==Bằng nhau
!=Khác nhau
>, <Lớn hơn, nhỏ hơn
>=, <=Lớn hơn/nhỏ hơn hoặc bằng

Toán tử logic

toan_tu_logic.py 
a = True
b = False

print(a and b)   # False - cả hai đều True mới True
print(a or b)    # True  - chỉ cần một cái True
print(not a)     # False - đảo ngược giá trị
Lỗi thường gặp
Nhầm lẫn giữa = (gán giá trị) và == (so sánh bằng). if x = 5: sẽ gây lỗi cú pháp — phải viết if x == 5:.

Python có toán tử số học, so sánh và logic. Lưu ý phân biệt / (chia thực) với // (chia nguyên), và = (gán) với == (so sánh).
