Cơ sở dữ liệu quan hệ nhẹ, không cần cài server riêng, có sẵn trong thư viện chuẩn Python — lý tưởng để học và cho ứng dụng nhỏ.

Cơ sở dữ liệu quan hệ nhẹ, không cần cài server riêng, có sẵn trong thư viện chuẩn Python — lý tưởng để học và cho ứng dụng nhỏ.

sqlite_basic.py 
import sqlite3

conn = sqlite3.connect("truong_hoc.db")   # tạo/mở file database
cur = conn.cursor()

# Tạo bảng
cur.execute("""
    CREATE TABLE IF NOT EXISTS sinh_vien (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        ten TEXT NOT NULL,
        tuoi INTEGER,
        diem REAL
    )
""")

# Thêm dữ liệu - LUÔN dùng dấu ? để tránh SQL Injection
cur.execute("INSERT INTO sinh_vien (ten, tuoi, diem) VALUES (?, ?, ?)", ("Huy", 20, 8.5))
conn.commit()   # lưu thay đổi xuống file

# Truy vấn dữ liệu
cur.execute("SELECT * FROM sinh_vien WHERE diem > ?", (8.0,))
for dong in cur.fetchall():
    print(dong)

conn.close()
Bảo mật quan trọng — SQL Injection
Luôn dùng tham số hóa (? kèm tuple) như ví dụ trên, KHÔNG BAO GIỜ nối chuỗi trực tiếp: f"SELECT * FROM sv WHERE ten='{ten}'" — cách này mở toang lỗ hổng SQL Injection cực kỳ nguy hiểm.

📌 Tổng kết chương 70

SQLite tích hợp sẵn trong Python qua module sqlite3, phù hợp học tập và ứng dụng nhỏ. Luôn dùng tham số hóa truy vấn để tránh SQL Injection.
