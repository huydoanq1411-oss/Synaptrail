Hàm ẩn danh (không tên), viết gọn trong một dòng — thường dùng cho các thao tác ngắn.

Hàm ẩn danh (không tên), viết gọn trong một dòng — thường dùng cho các thao tác ngắn.

lambda.py 
binh_phuong = lambda x: x ** 2
print(binh_phuong(5))   # 25

# Tương đương với:
def binh_phuong_v2(x):
    return x ** 2

Lambda kết hợp với hàm bậc cao

lambda_higher_order.py 
so = [5, 2, 8, 1, 9]

# sắp xếp danh sách sinh viên theo điểm bằng lambda làm khóa (key)
sinh_vien = [("Huy", 8.5), ("Lan", 9.2), ("Nam", 7.0)]
sinh_vien.sort(key=lambda x: x[1], reverse=True)
print(sinh_vien)

binh_phuong_list = list(map(lambda x: x**2, so))
print(binh_phuong_list)   # [25, 4, 64, 1, 81]

so_chan = list(filter(lambda x: x % 2 == 0, so))
print(so_chan)   # [2, 8]
Mẹo
Chỉ dùng lambda cho logic thật ngắn gọn (1 biểu thức). Nếu logic phức tạp hơn, hãy dùng def để code dễ đọc hơn.

📌 Tổng kết chương 23

Lambda tạo hàm ẩn danh ngắn gọn, thường dùng làm tham số cho sort(), map(), filter().
