Kiểu phức tạp với module typing

typing_advanced.py 
from typing import List, Dict, Optional, Union

def tinh_trung_binh(diem: List[float]) -> float:
    return sum(diem) / len(diem)

def tim_sinh_vien(ma: int) -> Optional[str]:   # trả về str HOẶC None
    du_lieu = {1: "Huy", 2: "Lan"}
    return du_lieu.get(ma)

def xu_ly(gia_tri: Union[int, str]) -> str:    # nhận int HOẶC str
    return str(gia_tri)

thong_tin: Dict[str, int] = {"tuoi": 20, "diem": 85}
Quan trọng
Type hints trong Python không được kiểm tra khi chạy chương trình (Python vẫn là dynamically typed) — chúng chỉ có tác dụng với IDE và các công cụ kiểm tra tĩnh như mypy. Viết sai kiểu vẫn chạy được, chỉ là công cụ sẽ cảnh báo.
