BeautifulSoup & Requests

Cặp thư viện kinh điển để lấy dữ liệu từ trang web tĩnh (web scraping).

Cặp thư viện kinh điển để lấy dữ liệu từ trang web tĩnh (web scraping).

scraping_basic.py 
# pip install requests beautifulsoup4
import requests
from bs4 import BeautifulSoup

url = "https://example.com/tin-tuc"
response = requests.get(url)                 # gửi request lấy HTML trang web

if response.status_code == 200:
    soup = BeautifulSoup(response.text, "html.parser")

    tieu_de = soup.find("h1").text              # lấy thẻ h1 đầu tiên
    print(tieu_de)

    tat_ca_link = soup.find_all("a")               # lấy TẤT CẢ thẻ a
    for link in tat_ca_link:
        print(link.get("href"))

    # Tìm theo class CSS
    bai_viet = soup.find_all("div", class_="bai-viet")
    for bv in bai_viet:
        print(bv.find("h2").text)
Quan trọng — Đạo đức khi scraping
Luôn kiểm tra file robots.txt của trang web và điều khoản sử dụng trước khi scraping. Thêm độ trễ (time.sleep()) giữa các request để không gây quá tải server, và tuyệt đối không scraping dữ liệu cá nhân/nhạy cảm trái phép.
