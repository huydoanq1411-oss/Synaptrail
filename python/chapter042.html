pip & Virtual Environment

Quản lý thư viện bên thứ ba và cô lập môi trường cho từng dự án.

Quản lý thư viện bên thứ ba và cô lập môi trường cho từng dự án.

pip — trình quản lý gói của Python

terminal 
pip install requests          # cài một thư viện
pip install requests==2.31.0   # cài đúng phiên bản cụ thể
pip uninstall requests          # gỡ thư viện
pip list                          # xem các thư viện đã cài
pip freeze > requirements.txt     # xuất danh sách thư viện ra file
pip install -r requirements.txt    # cài lại toàn bộ từ file

Virtual Environment (venv) — môi trường ảo

Mỗi dự án nên có một môi trường ảo riêng để tránh xung đột phiên bản thư viện giữa các dự án khác nhau.

terminal 
python -m venv venv           # tạo môi trường ảo tên "venv"

# Kích hoạt môi trường ảo:
venv\Scripts\activate           # trên Windows
source venv/bin/activate         # trên macOS/Linux

deactivate                        # thoát môi trường ảo
Quan trọng
Luôn tạo môi trường ảo riêng cho mỗi dự án. Nếu cài thư viện trực tiếp vào Python hệ thống, các dự án khác nhau yêu cầu phiên bản thư viện khác nhau sẽ dễ xung đột và gây lỗi khó debug.

uv — công cụ hiện đại thay thế pip + venv + pyenv

pip và venv vẫn hoạt động tốt và bạn nên hiểu cách chúng vận hành, nhưng kể từ 2025-2026 phần lớn dự án Python mới chuyển sang dùng uv (của công ty Astral — cũng là tác giả linter ruff). uv viết bằng Rust, gộp chung việc cài Python, tạo môi trường ảo, cài thư viện và khóa phiên bản (lockfile) vào một công cụ duy nhất, nhanh hơn pip từ 10-100 lần.

terminal 
# Cài uv (một lần duy nhất trên máy)
curl -LsSf https://astral.sh/uv/install.sh | sh   # macOS/Linux

# Khởi tạo dự án mới (tự tạo pyproject.toml + môi trường ảo .venv)
uv init ten-du-an
cd ten-du-an

# Thêm thư viện — uv tự tạo/khoá môi trường ảo, không cần activate thủ công
uv add requests pandas

# Chạy code trong đúng môi trường ảo của dự án
uv run python main.py

# Đồng bộ lại toàn bộ dependency từ file khoá (uv.lock) — dùng khi clone dự án về máy khác
uv sync
Ghi chú
Nếu chỉ cần cài nhanh một thư viện vào môi trường ảo hiện có theo kiểu pip truyền thống, uv vẫn hỗ trợ: uv pip install requests. Điều này giúp chuyển đổi dần dần từ pip sang uv mà không phải học lại từ đầu.

📌 Tổng kết chương 42

pip quản lý cài đặt thư viện bên thứ ba, venv tạo môi trường ảo cô lập — đây là kiến thức nền tảng bắt buộc phải hiểu. Trong thực tế công việc năm 2026, nhiều đội nhóm dùng uv để làm cả hai việc đó nhanh hơn và gọn hơn, thông qua các lệnh uv add, uv run, uv sync.
