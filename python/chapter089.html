Git & GitHub

Hệ thống quản lý phiên bản code — kỹ năng bắt buộc với mọi lập trình viên.

Hệ thống quản lý phiên bản code — kỹ năng bắt buộc với mọi lập trình viên.

terminal 
git init                              # khởi tạo repository Git trong thư mục hiện tại
git add file.py                       # đưa file vào staging area
git add .                                # đưa TẤT CẢ thay đổi vào staging area
git commit -m "Thêm chức năng đăng nhập"  # lưu lại một "điểm mốc" với mô tả rõ ràng
git status                                 # xem trạng thái hiện tại
git log                                       # xem lịch sử commit

git branch tinh-nang-moi                        # tạo nhánh mới
git checkout tinh-nang-moi                        # chuyển sang nhánh đó
git checkout -b tinh-nang-moi                       # tạo và chuyển nhánh cùng lúc

git remote add origin https://github.com/user/repo.git
git push -u origin main                # đẩy code lên GitHub
git pull                                  # kéo code mới nhất về máy
git merge tinh-nang-moi                    # gộp nhánh vào nhánh hiện tại

Quy trình làm việc nhóm điển hình (Feature Branch Workflow)

  1. Tạo nhánh riêng cho mỗi tính năng: git checkout -b tinh-nang-x
  2. Code và commit thường xuyên với message rõ ràng.
  3. Đẩy nhánh lên GitHub: git push origin tinh-nang-x
  4. Tạo Pull Request để đồng đội review code trước khi merge vào main.
Quan trọng
Luôn viết commit message rõ ràng, mô tả "tại sao" thay đổi chứ không chỉ "cái gì" — giúp cả nhóm (và chính bạn sau này) hiểu lịch sử phát triển dự án dễ dàng hơn.

Git quản lý phiên bản code qua commit và branch, GitHub là nền tảng lưu trữ và cộng tác. Quy trình branch + Pull Request là chuẩn làm việc nhóm phổ biến nhất hiện nay.
