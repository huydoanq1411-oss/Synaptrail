File XML & Pickle

XML cho dữ liệu có cấu trúc phân cấp, Pickle để lưu trực tiếp object Python.

XML cho dữ liệu có cấu trúc phân cấp, Pickle để lưu trực tiếp object Python.

XML

file_xml.py 
import xml.etree.ElementTree as ET

# Đọc file XML (giả sử có file "data.xml")
# Huy20
tree = ET.parse("data.xml")
root = tree.getroot()
for sv in root.findall("sv"):
    print(sv.find("ten").text, sv.find("tuoi").text)

# Tạo file XML mới
root_moi = ET.Element("root")
sv_moi = ET.SubElement(root_moi, "sv")
ET.SubElement(sv_moi, "ten").text = "Lan"
ET.ElementTree(root_moi).write("output.xml", encoding="utf-8")

Pickle — lưu trực tiếp object Python

file_pickle.py 
import pickle

du_lieu = {"ten": "Huy", "diem": [8.5, 9.0]}

# Lưu object xuống file nhị phân
with open("data.pkl", "wb") as f:
    pickle.dump(du_lieu, f)

# Đọc lại object từ file
with open("data.pkl", "rb") as f:
    data = pickle.load(f)
    print(data)
Cảnh báo bảo mật
Không bao giờ dùng pickle.load() với file không tin cậy (tải từ nguồn không rõ ràng) — pickle có thể thực thi mã độc tùy ý khi giải mã (deserialize) dữ liệu.

📌 Tổng kết chương 47

XML phù hợp cho dữ liệu phân cấp phức tạp (thường gặp trong hệ thống cũ/doanh nghiệp). Pickle lưu trực tiếp object Python nhưng chỉ nên dùng với dữ liệu đáng tin cậy.
