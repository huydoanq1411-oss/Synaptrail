Fibonacci với Memoization

fib_memo.py 
def fib_memo(n, cache={}):
    if n in cache:
        return cache[n]
    if n <= 1:
        return n
    cache[n] = fib_memo(n - 1, cache) + fib_memo(n - 2, cache)
    return cache[n]

print(fib_memo(50))   # tính tức thì, thay vì mất rất lâu như đệ quy thường (O(2ⁿ))

Từ O(2ⁿ) (đệ quy thường ở chương 24), memoization giảm độ phức tạp xuống còn O(n) — vì mỗi giá trị chỉ tính một lần rồi lưu lại tái sử dụng.

Bài toán cái túi (Knapsack) — DP kiểu bottom-up

knapsack.py 
def knapsack(trong_luong, gia_tri, suc_chua):
    n = len(trong_luong)
    dp = [[0] * (suc_chua + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(suc_chua + 1):
            if trong_luong[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], gia_tri[i-1] + dp[i-1][w - trong_luong[i-1]])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][suc_chua]

print(knapsack([2, 3, 4], [3, 4, 5], 5))   # 7
Mẹo ghi nhớ
Dấu hiệu nhận biết bài toán cần DP: có thể chia thành các bài toán con lặp lại, và bài toán lớn có thể xây dựng từ lời giải của bài toán con nhỏ hơn (optimal substructure).
