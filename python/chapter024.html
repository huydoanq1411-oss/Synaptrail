Recursion (Đệ quy)

Hàm tự gọi lại chính nó để giải quyết bài toán bằng cách chia nhỏ thành các bài toán con giống hệt cấu trúc.

Hàm tự gọi lại chính nó để giải quyết bài toán bằng cách chia nhỏ thành các bài toán con giống hệt cấu trúc.

recursion.py 
def giai_thua(n):
    if n <= 1:          # điều kiện dừng (base case) - BẮT BUỘC phải có
        return 1
    return n * giai_thua(n - 1)   # gọi lại chính nó (recursive case)

print(giai_thua(5))   # 5*4*3*2*1 = 120
Quan trọng
Mọi hàm đệ quy đều phải có điều kiện dừng (base case). Thiếu điều kiện dừng sẽ gây lỗi RecursionError: maximum recursion depth exceeded (tràn ngăn xếp gọi hàm).

Ví dụ: dãy Fibonacci

fibonacci.py 
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

for i in range(8):
    print(fibonacci(i), end=" ")   # 0 1 1 2 3 5 8 13
Cảnh báo hiệu năng
Đệ quy Fibonacci kiểu trên có độ phức tạp O(2ⁿ) — rất chậm với n lớn vì tính lặp lại nhiều lần. Kỹ thuật memoization (lưu kết quả đã tính) sẽ được giới thiệu ở phần Thuật toán để tối ưu việc này.

📌 Tổng kết chương 24

Đệ quy là kỹ thuật hàm tự gọi chính nó, luôn cần điều kiện dừng rõ ràng. Hữu ích cho các bài toán có cấu trúc lặp lại tự nhiên như giai thừa, Fibonacci, duyệt cây.
