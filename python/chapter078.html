Thư viện nền tảng cho tính toán số học hiệu năng cao với mảng đa chiều (array).

numpy_basic.py 
# pip install numpy
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr * 2)              # [2 4 6 8 10] - áp dụng lên toàn bộ mảng, không cần vòng lặp

ma_tran = np.array([[1, 2], [3, 4]])
print(ma_tran.shape)          # (2, 2) - kích thước ma trận
print(ma_tran.T)                # ma trận chuyển vị (transpose)

print(np.zeros((2, 3)))          # ma trận toàn số 0
print(np.arange(0, 10, 2))         # [0 2 4 6 8]
print(np.linspace(0, 1, 5))          # 5 số cách đều từ 0 đến 1

print(arr.mean(), arr.sum(), arr.max())   # thống kê nhanh: trung bình, tổng, lớn nhất
Mẹo hiệu năng
Phép toán trên NumPy array (gọi là vectorization) nhanh hơn rất nhiều so với vòng lặp for thuần Python — vì NumPy thực thi bằng code C được biên dịch sẵn bên dưới.
