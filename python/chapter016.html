Vòng lặp while

Lặp lại một khối lệnh miễn là điều kiện còn đúng.

Lặp lại một khối lệnh miễn là điều kiện còn đúng.

Cấu trúc cơ bản

while.py 
dem = 0
while dem < 5:
    print(dem)
    dem += 1   # QUAN TRỌNG: phải cập nhật biến điều kiện
Quan trọng
Nếu quên cập nhật biến điều kiện, vòng lặp sẽ chạy mãi mãi (infinite loop) và làm treo chương trình. Luôn kiểm tra chắc chắn điều kiện dừng sẽ đạt được sau một số hữu hạn bước lặp.

while True kèm break

while_true.py 
while True:
    lenh = input("Nhập 'q' để thoát: ")
    if lenh == 'q':
        break
    print(f"Bạn đã nhập: {lenh}")
