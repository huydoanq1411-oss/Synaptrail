Sorting (Thuật toán sắp xếp)

Các thuật toán sắp xếp kinh điển — nền tảng của khoa học máy tính.

Bubble Sort — O(n²)

bubble_sort.py 
def bubble_sort(ds):
    n = len(ds)
    for i in range(n):
        for j in range(0, n - i - 1):
            if ds[j] > ds[j + 1]:
                ds[j], ds[j + 1] = ds[j + 1], ds[j]   # đổi chỗ (swap)
    return ds

print(bubble_sort([5, 2, 8, 1, 9]))   # [1, 2, 5, 8, 9]

Merge Sort — O(n log n)

merge_sort.py 
def merge_sort(ds):
    if len(ds) <= 1:
        return ds
    giua = len(ds) // 2
    trai = merge_sort(ds[:giua])       # chia đôi (divide)
    phai = merge_sort(ds[giua:])
    return tron(trai, phai)               # trộn lại (conquer)

def tron(trai, phai):
    ket_qua = []
    i = j = 0
    while i < len(trai) and j < len(phai):
        if trai[i] <= phai[j]:
            ket_qua.append(trai[i]); i += 1
        else:
            ket_qua.append(phai[j]); j += 1
    return ket_qua + trai[i:] + phai[j:]

print(merge_sort([5, 2, 8, 1, 9]))   # [1, 2, 5, 8, 9]
Ghi chú thực tế
Trong công việc thực tế, hầu như luôn dùng sorted(ds) hoặc ds.sort() có sẵn của Python (thuật toán Timsort, độ phức tạp O(n log n), rất tối ưu) thay vì tự viết lại thuật toán sắp xếp — trừ khi mục đích là học thuật hoặc phỏng vấn.

Bubble Sort đơn giản nhưng chậm O(n²). Merge Sort nhanh hơn với O(n log n) nhờ chiến lược chia để trị (divide and conquer).
