Đóng gói ứng dụng cùng toàn bộ môi trường chạy vào một "container" — chạy nhất quán ở mọi nơi.

Dockerfile 
FROM python:3.12-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

CMD ["python", "app.py"]
terminal 
docker build -t ung-dung-python .     # xây dựng image từ Dockerfile
docker run -p 5000:5000 ung-dung-python  # chạy container, map cổng 5000
docker ps                                    # xem các container đang chạy
docker stop <container_id>                     # dừng container
Ghi chú
Docker giải quyết câu nói kinh điển "chạy trên máy tôi thì được mà!" — vì container đóng gói toàn bộ dependency và cấu hình, đảm bảo ứng dụng chạy giống hệt nhau trên mọi máy, mọi môi trường.
