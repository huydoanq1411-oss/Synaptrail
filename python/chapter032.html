Chương 32 — Collections

Module chuẩn cung cấp các cấu trúc dữ liệu mở rộng, mạnh mẽ hơn list/dict thông thường.

collections_module.py 
from collections import Counter, defaultdict, namedtuple, OrderedDict

# Counter - đếm tần suất cực nhanh
dem = Counter("mississippi")
print(dem)               # Counter({'i':4, 's':4, 'p':2, 'm':1})
print(dem.most_common(2))  # 2 ký tự xuất hiện nhiều nhất

# defaultdict - dict với giá trị mặc định tự động, tránh KeyError
nhom = defaultdict(list)
nhom["A"].append("Huy")   # không cần kiểm tra "A" đã tồn tại hay chưa
nhom["A"].append("Lan")
print(nhom)   # defaultdict(<class 'list'>, {'A': ['Huy', 'Lan']})

# namedtuple - tuple có tên trường, code dễ đọc hơn
Diem = namedtuple("Diem", ["x", "y"])
p = Diem(10, 20)
print(p.x, p.y)   # 10 20
LớpCông dụng
CounterĐếm tần suất phần tử
defaultdictDict tự tạo giá trị mặc định cho key mới
namedtupleTuple có tên trường, dễ đọc hơn index số
OrderedDictDict giữ thứ tự chèn (Python 3.7+ dict thường đã tự giữ thứ tự)
dequeHàng đợi hai đầu hiệu năng cao
