Class & Object

Nền tảng của lập trình hướng đối tượng: class là "khuôn mẫu", object là "thực thể" tạo ra từ khuôn mẫu đó.

Nền tảng của lập trình hướng đối tượng: class là "khuôn mẫu", object là "thực thể" tạo ra từ khuôn mẫu đó.

class_object.py 
class SinhVien:
    truong = "Đại học Bách Khoa"   # thuộc tính lớp (class attribute) - dùng chung cho mọi object

    def gioi_thieu(self):           # phương thức (method) - self đại diện cho chính object
        print(f"Tôi học tại {self.truong}")

sv1 = SinhVien()   # tạo object (instance) từ class
sv2 = SinhVien()
sv1.gioi_thieu()   # Tôi học tại Đại học Bách Khoa

print(sv1 is sv2)   # False - hai object khác nhau dù cùng class
Ghi chú
self là tham số đầu tiên của mọi phương thức trong class, đại diện cho chính object đang gọi phương thức đó. Python tự động truyền vào, không cần truyền tay khi gọi.

📌 Tổng kết chương 33

Class là khuôn mẫu định nghĩa thuộc tính và phương thức. Object là thực thể cụ thể được tạo ra từ class đó bằng cách gọi TenClass().
