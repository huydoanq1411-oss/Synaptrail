Constructor (__init__)

Phương thức đặc biệt tự động chạy khi một object được tạo ra, dùng để khởi tạo thuộc tính ban đầu.

Phương thức đặc biệt tự động chạy khi một object được tạo ra, dùng để khởi tạo thuộc tính ban đầu.

constructor.py 
class SinhVien:
    def __init__(self, ten, tuoi):   # constructor - chạy khi tạo object
        self.ten = ten                  # thuộc tính object (instance attribute)
        self.tuoi = tuoi

    def gioi_thieu(self):
        print(f"Tôi tên {self.ten}, {self.tuoi} tuổi")

sv1 = SinhVien("Huy", 20)
sv2 = SinhVien("Lan", 22)
sv1.gioi_thieu()   # Tôi tên Huy, 20 tuổi
sv2.gioi_thieu()   # Tôi tên Lan, 22 tuổi
Quan trọng
Thuộc tính khai báo qua self.ten = ten trong __init__ là instance attribute — mỗi object có bản sao riêng, khác với class attribute dùng chung cho tất cả object.

📌 Tổng kết chương 34

__init__ là constructor, tự động chạy khi tạo object, dùng để gán giá trị ban đầu cho các thuộc tính riêng của object đó.
