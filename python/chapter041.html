Module & Package

Cách tổ chức code Python thành các file và thư mục có thể tái sử dụng.

Cách tổ chức code Python thành các file và thư mục có thể tái sử dụng.

Module — một file .py chứa code tái sử dụng

toan_hoc.py (module tự viết) 
def cong(a, b):
    return a + b

def tru(a, b):
    return a - b
main.py 
import toan_hoc                      # import cả module
print(toan_hoc.cong(3, 5))

from toan_hoc import tru               # import hàm cụ thể
print(tru(10, 4))

import toan_hoc as th                    # đặt bí danh (alias)
print(th.cong(1, 1))

Package — thư mục chứa nhiều module

cấu trúc thư mục 
du_an/
├── main.py
└── tien_ich/            # package (thư mục có __init__.py)
    ├── __init__.py
    ├── toan_hoc.py
    └── chuoi.py

Import từ package: from tien_ich import toan_hoc hoặc from tien_ich.toan_hoc import cong.

Ghi chú
File __init__.py (có thể để rỗng) đánh dấu một thư mục là package, cho phép Python nhận diện và import được từ thư mục đó.

📌 Tổng kết chương 41

Module là file .py chứa code tái sử dụng, import bằng import/from...import. Package là thư mục chứa nhiều module, có file __init__.py.
