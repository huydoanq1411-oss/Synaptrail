Cấu trúc dữ liệu phân cấp — nền tảng cho nhiều bài toán và cấu trúc dữ liệu khác (thư mục file, DOM, cây quyết định...).

Cấu trúc dữ liệu phân cấp — nền tảng cho nhiều bài toán và cấu trúc dữ liệu khác (thư mục file, DOM, cây quyết định...).

Binary Tree — mỗi node có tối đa 2 con

binary_tree.py 
class NodeCay:
    def __init__(self, gia_tri):
        self.gia_tri = gia_tri
        self.trai = None
        self.phai = None

def duyet_inorder(node, ket_qua=None):   # duyệt Trái -> Gốc -> Phải
    if ket_qua is None:
        ket_qua = []
    if node:
        duyet_inorder(node.trai, ket_qua)
        ket_qua.append(node.gia_tri)
        duyet_inorder(node.phai, ket_qua)
    return ket_qua

Binary Search Tree (BST) — cây tìm kiếm nhị phân

Quy tắc: node trái luôn nhỏ hơn node cha, node phải luôn lớn hơn node cha — giúp tìm kiếm đạt O(log n) trung bình.

bst.py 
def them_vao_bst(node, gia_tri):
    if node is None:
        return NodeCay(gia_tri)
    if gia_tri < node.gia_tri:
        node.trai = them_vao_bst(node.trai, gia_tri)
    else:
        node.phai = them_vao_bst(node.phai, gia_tri)
    return node

goc = None
for x in [5, 3, 8, 1, 4, 7, 9]:
    goc = them_vao_bst(goc, x)
print(duyet_inorder(goc))   # [1, 3, 4, 5, 7, 8, 9] - inorder của BST luôn cho kết quả đã sắp xếp!
Mẹo ghi nhớ
Duyệt inorder (Trái-Gốc-Phải) trên một BST luôn cho ra dãy giá trị đã sắp xếp tăng dần — đây là tính chất đặc trưng rất hay được hỏi khi phỏng vấn.
