Kiểu dữ liệu

Các kiểu dữ liệu cơ bản mà Python hỗ trợ sẵn.

Các kiểu dữ liệu cơ bản mà Python hỗ trợ sẵn.

KiểuMô tảVí dụ
intSố nguyên10, -5
floatSố thực (dấu phẩy động)3.14, -0.5
strChuỗi ký tự"Xin chào"
boolĐúng/SaiTrue, False
listDanh sách có thể thay đổi[1, 2, 3]
tupleDanh sách không thể thay đổi(1, 2, 3)
dictTừ điển key-value{"a": 1}
setTập hợp không trùng lặp{1, 2, 3}
NoneTypeGiá trị rỗng/không xác địnhNone

Kiểm tra kiểu dữ liệu

kieu_du_lieu.py 
x = 10
y = "Python"
z = 3.14

print(type(x))  # <class 'int'>
print(type(y))  # <class 'str'>
print(type(z))  # <class 'float'>
Ghi chú
Python là ngôn ngữ động về kiểu (dynamically typed) nhưng vẫn kiểm tra kiểu chặt chẽ (strongly typed) — nghĩa là bạn không cần khai báo kiểu, nhưng Python sẽ không tự động cộng "5" (chuỗi) với 5 (số) mà không báo lỗi.

Bài tập thực hành

Đề bài: Cho các biến sau, hãy in ra kiểu dữ liệu của từng biến: a = 5, b = "5", c = 5.0, d = [5].

a = 5
b = "5"
c = 5.0
d = [5]
print(type(a), type(b), type(c), type(d))
# Kết quả: <class 'int'> <class 'str'> <class 'float'> <class 'list'>

📌 Tổng kết chương 5

Python có nhiều kiểu dữ liệu dựng sẵn: số (int, float), chuỗi (str), luận lý (bool), và các kiểu tập hợp (list, tuple, dict, set). Dùng type() để kiểm tra kiểu của một giá trị.
