JWT (JSON Web Token) là gì?

JWT là một chuỗi mã hóa gồm 3 phần (header.payload.signature), được server cấp cho client sau khi đăng nhập thành công, và client gửi kèm token này trong các request tiếp theo để chứng minh danh tính.

jwt_example.py 
# pip install pyjwt
import jwt
import datetime

SECRET_KEY = "chuoi-bi-mat-cua-server"   # trong thực tế lưu ở biến môi trường, KHÔNG hardcode

def tao_token(user_id):
    payload = {
        "user_id": user_id,
        "exp": datetime.datetime.utcnow() + datetime.timedelta(hours=2)   # hết hạn sau 2 giờ
    }
    return jwt.encode(payload, SECRET_KEY, algorithm="HS256")

def xac_thuc_token(token):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        return payload["user_id"]
    except jwt.ExpiredSignatureError:
        return "Token đã hết hạn"
    except jwt.InvalidTokenError:
        return "Token không hợp lệ"

token = tao_token(user_id=42)
print(token)
print(xac_thuc_token(token))   # 42

Luồng xác thực JWT điển hình

  1. Client gửi username/password tới /login.
  2. Server kiểm tra hợp lệ, trả về JWT token.
  3. Client lưu token, gửi kèm trong header Authorization: Bearer <token> ở mọi request cần xác thực.
  4. Server giải mã token để xác định người dùng, không cần truy vấn database để kiểm tra session mỗi lần.
Quan trọng
Không bao giờ lưu mật khẩu dạng plain text trong database — luôn băm (hash) bằng thuật toán chuyên dụng như bcrypt. JWT xác nhận danh tính nhưng không thay thế việc mã hóa mật khẩu.
