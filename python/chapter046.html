File CSV & JSON

Hai định dạng dữ liệu phổ biến nhất để trao đổi dữ liệu có cấu trúc.

Hai định dạng dữ liệu phổ biến nhất để trao đổi dữ liệu có cấu trúc.

CSV — dữ liệu dạng bảng

file_csv.py 
import csv

# Ghi file CSV
with open("sinh_vien.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["ten", "tuoi", "diem"])
    writer.writerow(["Huy", 20, 8.5])
    writer.writerow(["Lan", 22, 9.0])

# Đọc file CSV
with open("sinh_vien.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)   # đọc mỗi dòng thành dict
    for dong in reader:
        print(dong["ten"], dong["diem"])

JSON — dữ liệu dạng key-value lồng nhau

file_json.py 
import json

du_lieu = {
    "ten": "Huy",
    "tuoi": 20,
    "mon_hoc": ["Toán", "Lý", "Python"]
}

# Ghi ra file JSON
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(du_lieu, f, ensure_ascii=False, indent=2)

# Đọc từ file JSON
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    print(data["ten"])

# Chuyển đổi giữa string và object JSON
chuoi_json = json.dumps(du_lieu, ensure_ascii=False)   # object -> string
lai_object = json.loads(chuoi_json)                       # string -> object
Ghi chú
JSON gần như là "ngôn ngữ chung" để trao đổi dữ liệu giữa các hệ thống — hầu hết các REST API đều trả về/nhận dữ liệu dạng JSON.

📌 Tổng kết chương 46

Module csv xử lý dữ liệu dạng bảng, module json xử lý dữ liệu key-value lồng nhau — cả hai đều rất phổ biến khi làm việc với dữ liệu thực tế.
