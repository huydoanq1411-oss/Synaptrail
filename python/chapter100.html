List có thể thay đổi (mutable), Tuple bất biến (immutable). Tuple nhanh hơn và có thể dùng làm key trong dict/phần tử trong set, List thì không (xem lại chương 27-28).

GIL là cơ chế khóa chỉ cho phép một luồng thực thi bytecode Python tại một thời điểm, ngay cả trên máy đa lõi. Đây là lý do threading không tăng tốc tác vụ CPU-bound, phải dùng multiprocessing (xem lại chương 52).

== so sánh giá trị, is so sánh xem hai biến có cùng trỏ tới một object trong bộ nhớ hay không.

a = [1, 2]
b = [1, 2]
print(a == b)   # True - giá trị giống nhau
print(a is b)   # False - hai object khác nhau trong bộ nhớ

Shallow copy (copy.copy()) chỉ sao chép lớp ngoài cùng — các object lồng bên trong vẫn được tham chiếu chung. Deep copy (copy.deepcopy()) sao chép toàn bộ, kể cả các object lồng nhau, hoàn toàn độc lập với bản gốc.

Dạng bài LeetCode kinh điển

two_sum.py — "Two Sum" (bài LeetCode #1 kinh điển) 
def two_sum(nums, target):
    da_thay = {}   # dùng hash map để đạt O(n) thay vì O(n²) - xem lại chương 56
    for i, so in enumerate(nums):
        con_lai = target - so
        if con_lai in da_thay:
            return [da_thay[con_lai], i]
        da_thay[so] = i
    return []

print(two_sum([2, 7, 11, 15], 9))   # [0, 1]
