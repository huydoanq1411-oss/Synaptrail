Tập hợp không có thứ tự, không chứa phần tử trùng lặp.

set.py 
so = {1, 2, 3, 2, 1}
print(so)   # {1, 2, 3} - tự động loại bỏ trùng lặp

so.add(4)
so.discard(1)
print(so)   # {2, 3, 4}

# Các phép toán tập hợp
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)   # hợp (union): {1,2,3,4,5,6}
print(a & b)   # giao (intersection): {3,4}
print(a - b)    # hiệu (difference): {1,2}
print(a ^ b)    # đối xứng (symmetric difference): {1,2,5,6}
Mẹo
Dùng set để loại bỏ phần tử trùng lặp trong một list rất nhanh: list(set(ds)). Set cũng kiểm tra "phần tử có tồn tại" nhanh hơn nhiều so với list (độ phức tạp O(1) so với O(n)).

📌 Tổng kết chương 29

Set lưu trữ phần tử duy nhất, không có thứ tự, hỗ trợ các phép toán tập hợp (hợp, giao, hiệu) và tra cứu rất nhanh.
