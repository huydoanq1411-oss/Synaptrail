Cách viết class chứa dữ liệu ngắn gọn hơn nhiều, tự động sinh __init__, __repr__, __eq__.

dataclass.py 
from dataclasses import dataclass

@dataclass
class SinhVien:
    ten: str
    tuoi: int
    diem: float = 0.0   # có thể đặt giá trị mặc định

sv1 = SinhVien("Huy", 20, 8.5)
sv2 = SinhVien("Huy", 20, 8.5)

print(sv1)             # SinhVien(ten='Huy', tuoi=20, diem=8.5) - tự có __repr__
print(sv1 == sv2)      # True - tự có __eq__ so sánh theo giá trị

So với class thông thường, @dataclass giúp tiết kiệm việc phải tự viết __init__, __repr__, __eq__ thủ công — rất phù hợp cho các class chủ yếu chỉ chứa dữ liệu.
