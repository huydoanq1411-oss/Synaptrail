Bước 1: Cài đặt Python

  1. Truy cập python.org/downloads và tải bản Python mới nhất (khuyến nghị Python 3.13 trở lên; bản ổn định mới nhất hiện tại là Python 3.14).
  2. Khi cài trên Windows, nhớ tick chọn "Add Python to PATH" — đây là bước rất nhiều người mới bỏ sót.
  3. Sau khi cài xong, mở Terminal/Command Prompt và gõ lệnh kiểm tra.
terminal 
python --version
# Kết quả mong đợi: Python 3.14.x (hoặc 3.13.x nếu bạn chọn bản LTS hơn)
Cách hiện đại hơn: dùng uv
Ngoài cài trực tiếp từ python.org, nhiều dự án năm 2026 dùng uv (công cụ của Astral, viết bằng Rust) để cài và quản lý luôn nhiều phiên bản Python cùng lúc, nhanh hơn cách truyền thống rất nhiều. Chỉ cần một lệnh: 
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows PowerShell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# Cài một phiên bản Python cụ thể bằng uv
uv python install 3.14
Mình sẽ tìm hiểu kỹ hơn về uv ở chương 42 (pip & Virtual Environment).

Bước 2: Chọn công cụ soạn thảo (IDE)

Công cụƯu điểmPhù hợp
VS CodeNhẹ, miễn phí, nhiều extensionNgười mới → chuyên nghiệp
PyCharmTính năng mạnh, debug tốt, tích hợp sẵn nhiều công cụDự án lớn, chuyên nghiệp
Ghi chú
Với VS Code, hãy cài thêm extension chính thức "Python" (của Microsoft) để có gợi ý code (IntelliSense), debug và chạy code trực tiếp.

Bước 3: Kiểm tra môi trường

Tạo một file tên test.py, viết một dòng code đơn giản rồi chạy để chắc chắn mọi thứ hoạt động.

test.py 
print("Môi trường đã sẵn sàng!")
Cảnh báo
Nếu terminal báo lỗi "python is not recognized", nguyên nhân thường gặp nhất là quên tick "Add Python to PATH" lúc cài đặt. Cách khắc phục: gỡ cài đặt và cài lại, nhớ tick ô đó.

📌 Tổng kết chương 2

Cần cài Python (nhớ tick Add to PATH) và một IDE như VS Code hoặc PyCharm. Luôn kiểm tra bằng lệnh python --version trước khi bắt đầu.
