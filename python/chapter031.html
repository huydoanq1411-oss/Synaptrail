Stack & Queue

Hai cấu trúc dữ liệu nền tảng mô tả cách thêm/lấy phần tử theo thứ tự đặc thù.

Hai cấu trúc dữ liệu nền tảng mô tả cách thêm/lấy phần tử theo thứ tự đặc thù.

Stack (Ngăn xếp) — LIFO

LIFO = Last In, First Out (vào sau ra trước) — giống chồng đĩa, lấy đĩa trên cùng ra trước. Trong Python, dùng list để mô phỏng Stack:

stack.py 
stack = []
stack.append(1)    # push
stack.append(2)
stack.append(3)
print(stack.pop())  # 3 - lấy ra phần tử THÊM VÀO SAU CÙNG
print(stack)         # [1, 2]

Queue (Hàng đợi) — FIFO

FIFO = First In, First Out (vào trước ra trước) — giống hàng đợi mua vé. Nên dùng collections.deque thay vì list (vì list.pop(0) rất chậm với dữ liệu lớn):

queue.py 
from collections import deque

hang_doi = deque()
hang_doi.append(1)     # enqueue
hang_doi.append(2)
hang_doi.append(3)
print(hang_doi.popleft())  # 1 - lấy ra phần tử VÀO ĐẦU TIÊN
print(hang_doi)              # deque([2, 3])
Ghi chú
deque (double-ended queue) hỗ trợ thêm/xóa ở cả hai đầu với độ phức tạp O(1), trong khi list.pop(0) có độ phức tạp O(n) vì phải dịch chuyển toàn bộ phần tử còn lại.

📌 Tổng kết chương 31

Stack (LIFO) dùng list với append/pop. Queue (FIFO) nên dùng collections.deque với append/popleft để đạt hiệu năng tốt.
