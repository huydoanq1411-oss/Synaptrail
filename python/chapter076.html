REST API

Kiến trúc thiết kế API phổ biến nhất, dựa trên các phương thức HTTP chuẩn để thao tác tài nguyên (resource).

Kiến trúc thiết kế API phổ biến nhất, dựa trên các phương thức HTTP chuẩn để thao tác tài nguyên (resource).

Phương thứcÝ nghĩaVí dụ endpoint
GETLấy dữ liệuGET /san-pham
POSTTạo mớiPOST /san-pham
PUTCập nhật toàn bộPUT /san-pham/5
PATCHCập nhật một phầnPATCH /san-pham/5
DELETEXóaDELETE /san-pham/5

Mã trạng thái HTTP quan trọng

MãÝ nghĩa
200 OKThành công
201 CreatedTạo mới thành công
400 Bad RequestDữ liệu gửi lên không hợp lệ
401 UnauthorizedChưa xác thực (chưa đăng nhập)
403 ForbiddenĐã xác thực nhưng không có quyền
404 Not FoundKhông tìm thấy tài nguyên
500 Internal Server ErrorLỗi phía server
Mẹo thiết kế REST tốt
Dùng danh từ số nhiều cho endpoint (/san-pham thay vì /getSanPham), dùng đúng phương thức HTTP thay vì nhét mọi thứ vào GET/POST, và trả về mã trạng thái HTTP chính xác với ý nghĩa của kết quả.

REST API dùng các phương thức HTTP chuẩn (GET/POST/PUT/DELETE) để thao tác tài nguyên, kết hợp mã trạng thái HTTP để phản ánh chính xác kết quả xử lý.
