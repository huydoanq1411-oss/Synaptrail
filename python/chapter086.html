PyAutoGUI — điều khiển chuột & bàn phím

pyautogui_basic.py 
# pip install pyautogui
import pyautogui
import time

pyautogui.moveTo(500, 300, duration=1)   # di chuyển chuột tới tọa độ (500,300) trong 1s
pyautogui.click()                             # click chuột trái
pyautogui.typewrite("Xin chào Python!", interval=0.05)   # gõ chữ mô phỏng bàn phím
pyautogui.hotkey("ctrl", "s")                                  # nhấn tổ hợp phím Ctrl+S

vi_tri_anh = pyautogui.locateOnScreen("nut_luu.png")   # tìm ảnh trên màn hình (image recognition)
Cảnh báo
Di chuyển chuột lên góc trên bên trái màn hình (0,0) sẽ kích hoạt "fail-safe" của PyAutoGUI và dừng chương trình ngay lập tức — đây là cơ chế an toàn để bạn có thể dừng khẩn cấp khi script chạy sai.

Schedule — lên lịch chạy tác vụ định kỳ

schedule_basic.py 
# pip install schedule
import schedule
import time

def gui_bao_cao():
    print("Đang gửi báo cáo hàng ngày...")

schedule.every().day.at("08:00").do(gui_bao_cao)   # chạy mỗi ngày lúc 8h sáng
schedule.every(30).minutes.do(gui_bao_cao)            # chạy mỗi 30 phút

while True:
    schedule.run_pending()
    time.sleep(60)

📌 Tổng kết chương 86

PyAutoGUI tự động hóa thao tác chuột/bàn phím trên máy tính. schedule lên lịch chạy tác vụ Python định kỳ mà không cần công cụ hệ thống bên ngoài (như cron).
