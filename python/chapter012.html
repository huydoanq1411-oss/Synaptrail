Kiểu dữ liệu chỉ có hai giá trị: Đúng (True) hoặc Sai (False).

boolean.py 
dang_hoc = True
da_nghi_huu = False

print(type(dang_hoc))     # <class 'bool'>
print(5 > 3)                # True
print(5 == 3)               # False
print(bool(""))             # False
print(bool("Python"))       # True

Boolean trong câu điều kiện

dieu_kien.py 
tuoi = 20
du_tuoi_bau_cu = tuoi >= 18
print(f"Đủ tuổi bầu cử: {du_tuoi_bau_cu}")
Mẹo ghi nhớ
Trong Python, bool thực chất là kiểu con của int: True tương đương 1, False tương đương 0. Vì vậy True + True cho kết quả 2.

📌 Tổng kết chương 12

Boolean chỉ có hai giá trị True/False, là kết quả tự nhiên của các phép so sánh và là nền tảng cho câu lệnh điều kiện — chủ đề của phần tiếp theo.
