Heap

Cây nhị phân đặc biệt luôn giữ phần tử nhỏ nhất (hoặc lớn nhất) ở gốc — nền tảng của hàng đợi ưu tiên (priority queue).

Cây nhị phân đặc biệt luôn giữ phần tử nhỏ nhất (hoặc lớn nhất) ở gốc — nền tảng của hàng đợi ưu tiên (priority queue).

heap_module.py 
import heapq

ds = [5, 2, 8, 1, 9]
heapq.heapify(ds)          # biến list thành min-heap tại chỗ, O(n)
print(ds[0])                  # phần tử nhỏ nhất luôn ở đầu -> 1

heapq.heappush(ds, 0)         # thêm phần tử, tự động giữ tính chất heap
print(heapq.heappop(ds))       # lấy và xóa phần tử nhỏ nhất -> 0

# Ứng dụng thực tế: tìm k phần tử nhỏ nhất
print(heapq.nsmallest(3, [9, 3, 7, 1, 8, 2]))   # [1, 2, 3]
Ghi chú
Module heapq của Python chỉ hỗ trợ min-heap (phần tử nhỏ nhất ở gốc). Muốn dùng max-heap, một mẹo phổ biến là đảo dấu giá trị khi đưa vào heap (-x) rồi đảo lại khi lấy ra.

Ứng dụng: Priority Queue

priority_queue.py 
import heapq

hang_doi_uu_tien = []
heapq.heappush(hang_doi_uu_tien, (2, "Xử lý đơn hàng"))   # (độ ưu tiên, công việc)
heapq.heappush(hang_doi_uu_tien, (1, "Sửa lỗi khẩn cấp"))
heapq.heappush(hang_doi_uu_tien, (3, "Viết tài liệu"))

while hang_doi_uu_tien:
    uu_tien, viec = heapq.heappop(hang_doi_uu_tien)
    print(f"[{uu_tien}] {viec}")
# Kết quả: việc ưu tiên 1 được xử lý trước tiên
