Generator & Iterator

Sinh giá trị "lười" (lazy) từng phần tử một, tiết kiệm bộ nhớ đáng kể với dữ liệu lớn.

Sinh giá trị "lười" (lazy) từng phần tử một, tiết kiệm bộ nhớ đáng kể với dữ liệu lớn.

Iterator — đối tượng có thể lặp qua

iterator.py 
ds = [1, 2, 3]
it = iter(ds)          # tạo iterator từ list
print(next(it))          # 1
print(next(it))          # 2
print(next(it))          # 3
# print(next(it))        # StopIteration - đã hết phần tử

Generator — hàm sinh giá trị bằng yield

generator.py 
def dem_so(gioi_han):
    n = 0
    while n < gioi_han:
        yield n         # "tạm dừng" hàm tại đây, trả về giá trị, chờ lần gọi next() kế tiếp
        n += 1

for so in dem_so(5):
    print(so)   # 0 1 2 3 4

# Generator expression - giống list comprehension nhưng dùng ()
binh_phuong_gen = (x**2 for x in range(1000000))   # KHÔNG tạo ngay 1 triệu phần tử trong bộ nhớ
print(next(binh_phuong_gen))   # 0 - chỉ tính khi cần
Quan trọng
Generator chỉ tính giá trị khi cần (lazy evaluation) và không lưu toàn bộ dữ liệu trong bộ nhớ — cực kỳ hữu ích khi xử lý file lớn hoặc dãy số vô hạn, so với list thông thường phải tạo toàn bộ dữ liệu ngay lập tức.

📌 Tổng kết chương 65

Iterator là đối tượng hỗ trợ next(). Generator (dùng yield) là cách dễ nhất để tạo iterator tùy chỉnh, tiết kiệm bộ nhớ nhờ tính "lười".
