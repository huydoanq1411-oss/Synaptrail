Chương 56 — Searching & Hashing

Kỹ thuật tìm kiếm phần tử trong tập hợp dữ liệu.

Linear Search — O(n)

linear_search.py 
def linear_search(ds, target):
    for i, x in enumerate(ds):
        if x == target:
            return i
    return -1

Binary Search — O(log n) (yêu cầu dữ liệu đã sắp xếp)

binary_search.py 
def binary_search(ds, target):
    trai, phai = 0, len(ds) - 1
    while trai <= phai:
        giua = (trai + phai) // 2
        if ds[giua] == target:
            return giua
        elif ds[giua] < target:
            trai = giua + 1
        else:
            phai = giua - 1
    return -1

ds = [1, 3, 5, 7, 9, 11]
print(binary_search(ds, 7))   # 3

Hashing — tra cứu O(1) trung bình

Dictionary và set trong Python được xây dựng dựa trên hash table — đây là lý do việc tra cứu key in dict nhanh gần như tức thì bất kể dữ liệu lớn cỡ nào.

hashing.py 
# Tìm 2 số trong list có tổng bằng target - dùng hashing để đạt O(n)
def hai_so_co_tong(ds, target):
    da_thay = {}
    for i, x in enumerate(ds):
        con_lai = target - x
        if con_lai in da_thay:      # tra cứu O(1) nhờ dict/hash table
            return (da_thay[con_lai], i)
        da_thay[x] = i
    return None

print(hai_so_co_tong([2, 7, 11, 15], 9))   # (0, 1)

📌 Tổng kết chương 56

Linear Search đơn giản O(n). Binary Search nhanh O(log n) nhưng cần dữ liệu đã sắp xếp. Hashing (dict/set) đạt tra cứu O(1) trung bình — kỹ thuật cực kỳ quan trọng để tối ưu thuật toán.
