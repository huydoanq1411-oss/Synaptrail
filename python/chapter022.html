Giá trị trả về (Return)

Kết quả mà hàm gửi trả về nơi gọi nó.

Kết quả mà hàm gửi trả về nơi gọi nó.

return.py 
def cong(a, b):
    return a + b

ket_qua = cong(3, 5)
print(ket_qua)   # 8

def khong_tra_ve():
    print("Hàm này không có return")

x = khong_tra_ve()
print(x)   # None -> hàm không có return sẽ tự trả về None

Trả về nhiều giá trị

return_multi.py 
def chia(a, b):
    thuong = a // b
    du = a % b
    return thuong, du   # thực chất trả về 1 tuple (thuong, du)

t, d = chia(17, 5)
print(t, d)   # 3 2
Ghi chú
return ngay lập tức kết thúc hàm — mọi dòng code sau return trong cùng khối lệnh sẽ không bao giờ được chạy.

📌 Tổng kết chương 22

return trả kết quả về nơi gọi hàm và kết thúc hàm ngay lập tức. Hàm không có return tường minh sẽ trả về None.
