Giả lập (mock) các phần phụ thuộc bên ngoài (API, database) để kiểm thử code một cách độc lập.

mock_basic.py 
from unittest.mock import Mock, patch
import requests

def lay_gia_bitcoin():
    response = requests.get("https://api.example.com/bitcoin")
    return response.json()["gia"]

# Giả lập requests.get để KHÔNG thực sự gọi API thật khi test
@patch("requests.get")
def test_lay_gia_bitcoin(mock_get):
    mock_response = Mock()
    mock_response.json.return_value = {"gia": 50000}
    mock_get.return_value = mock_response

    ket_qua = lay_gia_bitcoin()
    assert ket_qua == 50000   # kiểm tra logic hàm mà không cần gọi API thật
Ghi chú
Mock rất quan trọng khi test code phụ thuộc vào các yếu tố bên ngoài không ổn định hoặc tốn kém: gọi API thật, truy vấn database thật, gửi email thật — giúp test chạy nhanh, ổn định và không có tác dụng phụ ngoài ý muốn.
