Abstraction (Trừu tượng)

Định nghĩa "khung sườn bắt buộc" mà các class con phải triển khai, ẩn đi chi tiết triển khai cụ thể.

Định nghĩa "khung sườn bắt buộc" mà các class con phải triển khai, ẩn đi chi tiết triển khai cụ thể.

abstraction.py 
from abc import ABC, abstractmethod

class PhuongTien(ABC):        # lớp trừu tượng - không thể tạo object trực tiếp
    @abstractmethod
    def di_chuyen(self):        # phương thức bắt buộc phải override
        pass

class XeMay(PhuongTien):
    def di_chuyen(self):
        print("Xe máy chạy bằng động cơ 2 bánh")

# pt = PhuongTien()   # LỖI - không thể khởi tạo class trừu tượng
xm = XeMay()
xm.di_chuyen()   # Xe máy chạy bằng động cơ 2 bánh
Mẹo
Dùng abstraction khi thiết kế hệ thống lớn, cần bắt buộc mọi class con phải triển khai một tập phương thức nhất định — giúp tránh sai sót và đảm bảo tính nhất quán của interface.
