Flask

Micro-framework nhẹ, linh hoạt — lựa chọn phổ biến để bắt đầu học web development với Python.

Micro-framework nhẹ, linh hoạt — lựa chọn phổ biến để bắt đầu học web development với Python.

app.py 
# pip install flask
from flask import Flask, jsonify, request

app = Flask(__name__)

sinh_vien_db = [{"id": 1, "ten": "Huy"}]

@app.route("/")
def trang_chu():
    return "Chào mừng đến với Flask!"

@app.route("/sinh-vien", methods=["GET"])
def lay_danh_sach():
    return jsonify(sinh_vien_db)

@app.route("/sinh-vien", methods=["POST"])
def them_sinh_vien():
    du_lieu = request.get_json()
    sinh_vien_db.append(du_lieu)
    return jsonify(du_lieu), 201

if __name__ == "__main__":
    app.run(debug=True)   # chạy tại http://127.0.0.1:5000
Ghi chú
debug=True chỉ nên dùng khi phát triển (development) — tự động reload khi sửa code và hiển thị traceback chi tiết. Không bao giờ bật debug mode ở môi trường production vì lộ thông tin nhạy cảm.

Flask là micro-framework nhẹ, dùng decorator @app.route() để định nghĩa endpoint, phù hợp cho API nhỏ và học tập.
