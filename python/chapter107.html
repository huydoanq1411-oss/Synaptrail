GUI với Tkinter

Thư viện giao diện đồ họa (GUI) có sẵn trong Python, không cần cài đặt thêm — phù hợp xây dựng ứng dụng desktop đơn giản.

Thư viện giao diện đồ họa (GUI) có sẵn trong Python, không cần cài đặt thêm — phù hợp xây dựng ứng dụng desktop đơn giản.

tkinter_basic.py 
import tkinter as tk
from tkinter import messagebox

cua_so = tk.Tk()
cua_so.title("Ứng dụng quản lý công việc")
cua_so.geometry("400x300")

def them_cong_viec():
    noi_dung = o_nhap.get()
    if noi_dung.strip() == "":
        messagebox.showwarning("Cảnh báo", "Vui lòng nhập công việc!")
        return
    danh_sach.insert(tk.END, noi_dung)
    o_nhap.delete(0, tk.END)

nhan = tk.Label(cua_so, text="Nhập công việc mới:", font=("Arial", 12))
nhan.pack(pady=10)

o_nhap = tk.Entry(cua_so, width=30)
o_nhap.pack()

nut_them = tk.Button(cua_so, text="Thêm", command=them_cong_viec)
nut_them.pack(pady=10)

danh_sach = tk.Listbox(cua_so, width=40, height=10)
danh_sach.pack()

cua_so.mainloop()   # vòng lặp chính, giữ cửa sổ luôn hiển thị
WidgetCông dụng
LabelHiển thị văn bản/hình ảnh tĩnh
EntryÔ nhập liệu một dòng
ButtonNút bấm, gắn hàm xử lý qua command=
ListboxDanh sách các mục có thể chọn
pack()/grid()Hai cách sắp xếp bố cục (layout) phổ biến
Ghi chú
Với ứng dụng GUI phức tạp hơn, chuyên nghiệp hơn, thường chuyển sang PyQt/PySide hoặc Kivy (cho mobile) — nhưng Tkinter vẫn là lựa chọn tốt nhất để bắt đầu vì không cần cài đặt gì thêm.

📌 Tổng kết chương 107

Tkinter cung cấp các widget cơ bản (Label, Entry, Button, Listbox) để xây dựng ứng dụng desktop nhanh chóng, tích hợp sẵn trong Python không cần cài đặt.
