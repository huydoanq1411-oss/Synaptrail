Thử từng lựa chọn, nếu không dẫn tới lời giải thì quay lui và thử lựa chọn khác.

Bài toán N-Queens (rút gọn)

n_queens.py 
def giai_n_queens(n):
    ket_qua = []
    cot_da_dung = set()

    def thu(hang, vi_tri):
        if hang == n:
            ket_qua.append(vi_tri[:])
            return
        for cot in range(n):
            if cot in cot_da_dung:
                continue   # đã có quân hậu ở cột này -> bỏ qua
            vi_tri.append(cot)
            cot_da_dung.add(cot)
            thu(hang + 1, vi_tri)        # thử tiếp hàng kế
            vi_tri.pop()                    # QUAY LUI: hoàn tác lựa chọn
            cot_da_dung.remove(cot)

    thu(0, [])
    return ket_qua

print(len(giai_n_queens(4)))   # 2 cách sắp xếp hợp lệ với bàn cờ 4x4
Ghi chú
Backtracking = đệ quy + hoàn tác lựa chọn khi thất bại. Thường dùng cho các bài toán tổ hợp: sinh hoán vị, giải Sudoku, tìm đường trong mê cung, N-Queens...
