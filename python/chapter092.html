Đo lường và tối ưu hiệu năng, bộ nhớ của chương trình Python.

Profiling — đo thời gian thực thi

profiling.py 
import cProfile

def tinh_toan_nang():
    return sum(i*i for i in range(1_000_000))

cProfile.run("tinh_toan_nang()")   # in ra báo cáo chi tiết: số lần gọi, thời gian mỗi hàm

# Đo nhanh một đoạn code với timeit
import timeit
thoi_gian = timeit.timeit("sum(range(1000))", number=10000)
print(f"Thời gian trung bình: {thoi_gian:.6f}s")

Memory Optimization — tối ưu bộ nhớ

memory_optimization.py 
# Dùng generator thay vì list khi không cần lưu toàn bộ trong bộ nhớ
tong_generator = sum(x**2 for x in range(10_000_000))   # tiết kiệm bộ nhớ hơn nhiều

# __slots__ giảm bộ nhớ cho class có nhiều instance
class DiemToaDo:
    __slots__ = ("x", "y")   # ngăn Python tạo __dict__ cho mỗi object, tiết kiệm bộ nhớ đáng kể
    def __init__(self, x, y):
        self.x = x
        self.y = y
Mẹo tối ưu tổng quát
Luôn đo trước khi tối ưu (dùng profiler) — đừng đoán mò phần nào chậm. Thường thì 80% thời gian chạy tập trung ở 20% code, tối ưu đúng chỗ mang lại hiệu quả lớn nhất.

📌 Tổng kết chương 92

cProfile/timeit đo hiệu năng thực thi. Generator và __slots__ là hai kỹ thuật phổ biến để giảm sử dụng bộ nhớ trong chương trình Python.
