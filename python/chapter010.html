Tạo chuỗi

chuoi.py 
s1 = 'Xin chào'
s2 = "Xin chào"
s3 = """Chuỗi
nhiều dòng"""

Các thao tác thường dùng

thao_tac_chuoi.py 
s = "Python thật tuyệt vời"

print(len(s))            # độ dài chuỗi
print(s.upper())         # PYTHON THẬT TUYỆT VỜI
print(s.lower())         # python thật tuyệt vời
print(s.replace("tuyệt", "rất tuyệt"))
print(s.split(" "))      # tách thành list theo khoảng trắng
print(s[0:6])             # cắt chuỗi (slicing): "Python"
print(s[-1])               # ký tự cuối cùng: "i"
print("Python" in s)      # kiểm tra chứa chuỗi con -> True
print(s.strip())          # xóa khoảng trắng đầu/cuối

Nối chuỗi và lặp lại

noi_chuoi.py 
a = "Hello"
b = "World"
print(a + " " + b)   # Hello World
print(a * 3)          # HelloHelloHello
Quan trọng
Chuỗi trong Python là immutable (bất biến) — không thể thay đổi trực tiếp một ký tự trong chuỗi (s[0] = 'X' sẽ báo lỗi). Mọi thao tác như .replace() đều trả về một chuỗi mới.

Bài tập thực hành

Đề bài: Viết chương trình đảo ngược một chuỗi bất kỳ.

s = "Python"
dao_nguoc = s[::-1]
print(dao_nguoc)  # nohtyP

📌 Tổng kết chương 10

Chuỗi hỗ trợ slicing, nối, lặp và rất nhiều phương thức xử lý sẵn (upper(), split(), replace()...). Chuỗi là bất biến — mọi thao tác đều tạo ra chuỗi mới.
