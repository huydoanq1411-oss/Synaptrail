Design Patterns

Các giải pháp thiết kế đã được kiểm chứng cho những vấn đề lặp lại thường gặp trong lập trình.

Singleton — đảm bảo chỉ có một instance duy nhất

singleton.py 
class KetNoiDatabase:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = KetNoiDatabase()
b = KetNoiDatabase()
print(a is b)   # True - cùng một object duy nhất

Factory — tạo object mà không cần biết class cụ thể

factory.py 
class ThongBaoEmail:
    def gui(self, noi_dung): print(f"Gửi email: {noi_dung}")

class ThongBaoSMS:
    def gui(self, noi_dung): print(f"Gửi SMS: {noi_dung}")

def tao_thong_bao(loai):    # "nhà máy" quyết định tạo class nào
    if loai == "email":
        return ThongBaoEmail()
    elif loai == "sms":
        return ThongBaoSMS()

tb = tao_thong_bao("email")
tb.gui("Đơn hàng đã được xác nhận")

Observer — thông báo tự động khi trạng thái thay đổi

observer.py 
class KenhYoutube:
    def __init__(self):
        self.nguoi_dang_ky = []

    def dang_ky(self, nguoi_xem):
        self.nguoi_dang_ky.append(nguoi_xem)

    def dang_video_moi(self, ten_video):
        for nguoi_xem in self.nguoi_dang_ky:      # tự động thông báo cho TẤT CẢ observer
            nguoi_xem.nhan_thong_bao(ten_video)

class NguoiXem:
    def __init__(self, ten):
        self.ten = ten
    def nhan_thong_bao(self, ten_video):
        print(f"{self.ten} nhận thông báo: video mới '{ten_video}'")

kenh = KenhYoutube()
kenh.dang_ky(NguoiXem("Huy"))
kenh.dang_ky(NguoiXem("Lan"))
kenh.dang_video_moi("Học Python trong 10 phút")
Mẹo
Không cần cố nhồi nhét design pattern vào mọi bài toán — chỉ áp dụng khi thực sự giải quyết đúng vấn đề đang gặp phải. Lạm dụng pattern không cần thiết làm code phức tạp hóa vô ích.

📌 Tổng kết chương 95

Design Patterns (Singleton, Factory, Observer...) là các giải pháp thiết kế tái sử dụng cho vấn đề lặp lại, giúp giao tiếp ý tưởng thiết kế nhanh chóng giữa các lập trình viên.
