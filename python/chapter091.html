CI/CD

Tự động hóa quy trình kiểm thử và triển khai mỗi khi có thay đổi code (Continuous Integration / Continuous Deployment).

Tự động hóa quy trình kiểm thử và triển khai mỗi khi có thay đổi code (Continuous Integration / Continuous Deployment).

.github/workflows/ci.yml (GitHub Actions) 
name: CI Pipeline

on: [push, pull_request]     # chạy mỗi khi push code hoặc tạo pull request

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3            # lấy code về
      - name: Cài đặt Python
        uses: actions/setup-python@v4
        with:
          python-version: "3.12"
      - name: Cài thư viện
        run: pip install -r requirements.txt
      - name: Chạy test
        run: pytest                              # tự động chạy toàn bộ test
Khái niệmÝ nghĩa
CI (Continuous Integration)Tự động build và test code mỗi khi có thay đổi được đẩy lên
CD (Continuous Deployment)Tự động triển khai code đã qua kiểm thử lên môi trường production
Mẹo
CI/CD giúp phát hiện lỗi sớm (ngay khi push code) thay vì để tới lúc release mới phát hiện — giảm đáng kể chi phí sửa lỗi và tăng tốc độ phát hành sản phẩm.

CI/CD tự động hóa việc test và triển khai code, thường cấu hình bằng file YAML (GitHub Actions, GitLab CI...), giúp đội ngũ phát hành phần mềm nhanh và an toàn hơn.
