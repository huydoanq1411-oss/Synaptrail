Polymorphism (Đa hình)

Nhiều class khác nhau có thể được sử dụng thông qua cùng một giao diện (interface) chung.

Nhiều class khác nhau có thể được sử dụng thông qua cùng một giao diện (interface) chung.

polymorphism.py 
class HinhVuong:
    def __init__(self, canh):
        self.canh = canh
    def dien_tich(self):
        return self.canh ** 2

class HinhTron:
    def __init__(self, ban_kinh):
        self.ban_kinh = ban_kinh
    def dien_tich(self):
        return 3.14 * self.ban_kinh ** 2

danh_sach_hinh = [HinhVuong(4), HinhTron(3)]

for hinh in danh_sach_hinh:
    # cùng gọi .dien_tich() nhưng mỗi object thực thi theo cách riêng của nó
    print(f"{type(hinh).__name__}: {hinh.dien_tich()}")
Ghi chú
Đa hình giúp viết code tổng quát, xử lý được nhiều loại object khác nhau mà không cần biết chính xác class cụ thể của từng object — chỉ cần chúng cùng "hiểu" phương thức được gọi.
