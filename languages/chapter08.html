Chương 8 — Giao tiếp & Viết — Viết CV & Portfolio IT

Xây dựng hồ sơ ứng tuyển nổi bật — CV tập trung vào kết quả, portfolio thể hiện năng lực thực chiến.

Cấu trúc CV IT chuẩn

MụcNội dung nên có
Thông tin liên hệTên, email, số điện thoại, link GitHub/LinkedIn/Portfolio
Tóm tắt (Summary)2–3 câu nêu định hướng, thế mạnh chính
Kỹ năngNgôn ngữ, framework, công cụ — nhóm theo mức độ thành thạo
Kinh nghiệm/Dự ánTên dự án, công nghệ dùng, vai trò, kết quả đạt được (số liệu nếu có)
Học vấn/Chứng chỉTrường, chuyên ngành, chứng chỉ liên quan
Nguyên tắc viết mục Kinh nghiệm/Dự án
Dùng công thức: Hành động + Công nghệ + Kết quả đo lường được. Ví dụ: "Xây dựng API RESTful bằng Node.js & Express, giảm 40% thời gian phản hồi so với bản cũ" — thay vì chỉ liệt kê "Làm backend cho dự án X".

Xây dựng Portfolio thuyết phục

  • Chọn 3–5 dự án tốt nhất thay vì liệt kê tất cả — chất lượng hơn số lượng.
  • Mỗi dự án nên có: mô tả bài toán, công nghệ dùng, link demo/GitHub, ảnh chụp màn hình.
  • GitHub profile sạch sẽ: README rõ ràng, commit message có ý nghĩa, không để code rác/dự án dở dang không chú thích.
  • Có ít nhất 1 dự án thể hiện chiều sâu kỹ thuật (không chỉ CRUD cơ bản) để nổi bật giữa nhiều ứng viên.
Lỗi thường gặp
CV quá dài (trên 2 trang cho junior/mid), liệt kê kỹ năng chung chung không kèm bằng chứng, hoặc portfolio có link demo/GitHub bị lỗi không truy cập được.

📌 Tổng kết chương 12

CV và Portfolio là "landing page" cá nhân — cần rõ ràng, có bằng chứng cụ thể (số liệu, link thực tế) và được cập nhật thường xuyên theo dự án/kỹ năng mới học được.
