Chương 3 — Triển khai VPS DigitalOcean

Đưa ứng dụng lên internet thật — từ máy tính cá nhân tới một server có thể truy cập toàn cầu.

VPS là gì?

VPS (Virtual Private Server) là một máy chủ ảo thuê từ nhà cung cấp (DigitalOcean, Linode, AWS EC2...) — bạn có toàn quyền kiểm soát như một máy Linux thật, cài đặt bất cứ thứ gì cần thiết để chạy ứng dụng.

Quy trình triển khai cơ bản

terminal (trên VPS, qua SSH) 
# 1. Kết nối vào VPS
ssh root@dia_chi_ip_vps

# 2. Cài đặt Docker trên VPS (nếu dùng Docker để triển khai)
curl -fsSL https://get.docker.com | sh

# 3. Clone code từ GitHub về VPS
git clone https://github.com/user/du-an.git
cd du-an

# 4. Chạy ứng dụng bằng Docker Compose đã chuẩn bị sẵn
docker compose up -d

# 5. Cấu hình Nginx làm reverse proxy - chuyển traffic từ cổng 80 (web chuẩn) vào app
sudo apt install nginx
/etc/nginx/sites-available/du-an 
server {
    listen 80;
    server_name tenmien.com;

    location / {
        proxy_pass http://localhost:3000;    # chuyển tiếp request tới app Node.js đang chạy nội bộ
        proxy_set_header Host $host;
    }
}
BướcCông cụ
Thuê serverDigitalOcean Droplet, AWS EC2, Linode...
Kết nối quản trịSSH (Secure Shell)
Chạy ứng dụngDocker/Docker Compose (đã học chương 1–2)
Định tuyến traffic webNginx (reverse proxy) — ẩn cổng thật, hỗ trợ tên miền/HTTPS
HTTPS miễn phíLet's Encrypt (qua certbot)
Mẹo
Reverse proxy (Nginx) là mắt xích quan trọng: nó nhận request ở cổng 80/443 (chuẩn web), rồi chuyển tiếp NỘI BỘ tới ứng dụng đang chạy ở cổng khác (VD: 3000) — cho phép chạy nhiều ứng dụng trên cùng 1 VPS, mỗi ứng dụng một tên miền/subdomain.

📌 Tổng kết chương 3

Triển khai lên VPS gồm: SSH vào server, cài Docker, chạy ứng dụng qua Docker Compose, và dùng Nginx làm reverse proxy để định tuyến traffic web tới ứng dụng nội bộ.
