Làm quiz ở trang riêng

Thư viện component dựng sẵn (nút, form, modal, navbar...) và các class tiện ích giúp code HTML thuần gần như không cần viết CSS riêng.

components.html 
<!-- Navbar -->
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
        <a class="navbar-brand" href="#">TechShop</a>
    </div>
</nav>

<!-- Card -->
<div class="card" style="width: 18rem;">
    <div class="card-body">
        <h5 class="card-title">Sản phẩm A</h5>
        <p class="card-text">Mô tả ngắn gọn về sản phẩm.</p>
        <button class="btn btn-primary">Mua ngay</button>
    </div>
</div>

<!-- Modal (popup) -->
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">Mở popup</button>
<div class="modal" id="myModal">
    <div class="modal-dialog">
        <div class="modal-content">
            <div class="modal-body">Nội dung popup</div>
        </div>
    </div>
</div>

Utility classes — tiện ích nhanh

ClassCông dụng
d-flex, justify-content-centerTương đương display:flex, justify-content:center
mt-3, p-4margin-top cấp 3, padding cấp 4 (thang đo 0-5 của Bootstrap)
text-center, fw-boldCăn giữa chữ, chữ đậm
d-none d-md-blockẨn trên mobile, hiện từ tablet trở lên (responsive utility)
Mẹo
Component tương tác (modal, dropdown, carousel...) cần JavaScript của Bootstrap (bootstrap.bundle.min.js) — chỉ nhúng CSS thôi thì các component này sẽ có giao diện đúng nhưng KHÔNG hoạt động (mở/đóng) được.

📌 Tổng kết chương 2

Bootstrap cung cấp component dựng sẵn (navbar, card, modal) và utility class (d-flex, mt-3, text-center) giúp xây giao diện nhanh — component tương tác cần nhúng thêm phần JavaScript.
