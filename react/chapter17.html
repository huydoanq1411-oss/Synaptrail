React.memo & Tối ưu re-render

React.memo bỏ qua việc render lại component khi props không đổi.

Làm quiz ở trang riêng

React.memo bỏ qua việc render lại component khi props không đổi.

Khi nào component render lại?

Một component render lại khi state của nó đổi, khi component cha render lại, hoặc khi context nó dùng đổi. Mặc định, cha render thì mọi con đều render theo, kể cả khi props không đổi.

React.memo

Dong.jsx 
import { memo } from 'react';

const DongSanPham = memo(function DongSanPham({ sp, onXoa }) {
  console.log('render', sp.id);
  return <li>{sp.ten} <button onClick={() => onXoa(sp.id)}>Xóa</button></li>;
});

memo so sánh nông (shallow) props cũ và mới. Nếu bằng nhau, React dùng lại kết quả render trước đó.

⚠️ Cạm bẫy
Truyền object, mảng hoặc hàm tạo mới ở mỗi lần render (ví dụ style={{ color: "red" }} hoặc onXoa={() => ...}) làm so sánh nông luôn thất bại, memo trở nên vô ích. Kết hợp với useCallback và useMemo để giữ tham chiếu ổn định.
💡 Mẹo
Trước khi dùng memo, thử "nâng" phần thay đổi thường xuyên xuống component con riêng hoặc truyền children. Nhiều khi cách này đã đủ mà không cần memo.

📌 Tổng kết chương 17

React.memo tránh render lại khi props không đổi (so sánh nông). Cần giữ tham chiếu props ổn định bằng useCallback/useMemo.
