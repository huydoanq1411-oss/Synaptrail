Chương 16 — Performance — useMemo & useCallback

useMemo nhớ kết quả tính toán nặng, useCallback nhớ hàm — chỉ dùng khi thực sự cần.

useMemo — nhớ giá trị tính toán

Loc.jsx 
const dsLoc = useMemo(() => {
  return sanPham.filter(sp => sp.ten.includes(tuKhoa)).sort(soSanh);
}, [sanPham, tuKhoa]);

Kết quả chỉ tính lại khi sanPham hoặc tuKhoa thay đổi, không phải mỗi lần render.

useCallback — nhớ hàm

Cha.jsx 
const xoa = useCallback(id => {
  setDs(ds => ds.filter(x => x.id !== id));
}, []);

return <DanhSach items={ds} onXoa={xoa} />;

Mỗi lần render, một hàm mới được tạo ra. Nếu truyền hàm đó cho component con bọc React.memo, con sẽ render lại vô ích. useCallback giữ nguyên tham chiếu hàm giữa các lần render.

⚠️ Đừng lạm dụng
Hai hook này cũng tốn bộ nhớ và công so sánh. Hãy đo hiệu năng bằng React DevTools Profiler trước, chỉ tối ưu chỗ thực sự chậm.

📝 Quiz nhanh — Chương 16

1. useMemo trả về gì?

Một hàm Giá trị đã tính, được nhớ Một component Một ref

2. useCallback giúp giữ nguyên điều gì?

Tham chiếu hàm Giá trị state Tên biến Thứ tự render

3. Nên dùng useMemo ở đâu?

Mọi biến Phép tính nặng hoặc tham chiếu cần ổn định Chỉ trong class Trước mọi return
