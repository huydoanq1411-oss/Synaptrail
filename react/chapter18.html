Error Boundaries & Xử lý lỗi

Error Boundary bắt lỗi khi render trong cây con và hiển thị giao diện dự phòng thay vì làm sập cả ứng dụng.

Error Boundary bắt lỗi khi render trong cây con và hiển thị giao diện dự phòng thay vì làm sập cả ứng dụng.

Viết Error Boundary (class component)

ErrorBoundary.jsx 
import { Component } from 'react';

export class ErrorBoundary extends Component {
  state = { loi: null };

  static getDerivedStateFromError(loi) {
    return { loi };
  }

  componentDidCatch(loi, info) {
    console.error('Lỗi UI:', loi, info.componentStack);
  }

  render() {
    if (this.state.loi) return this.props.fallback ?? <h2>Đã có lỗi xảy ra.</h2>;
    return this.props.children;
  }
}

📌 Lưu ý
Error Boundary hiện vẫn phải viết bằng class. Có thể dùng thư viện react-error-boundary để có phiên bản dùng hàm kèm nút "Thử lại". Lỗi trong event handler hoặc async hãy xử lý bằng try/catch thông thường.
