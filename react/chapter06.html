Render danh sách bằng map() và vì sao mỗi phần tử cần một key ổn định.

Render danh sách với map()

DanhSachTen.jsx 
const sinhVien = [
  { id: 1, ten: 'An' },
  { id: 2, ten: 'Bình' },
  { id: 3, ten: 'Chi' },
];

function DanhSachTen() {
  return (
    <ul>
      {sinhVien.map(sv => (
        <li key={sv.id}>{sv.ten}</li>
      ))}
    </ul>
  );
}

Vì sao cần key?

key giúp React nhận biết phần tử nào được thêm, xóa hay đổi chỗ giữa các lần render, nhờ đó chỉ cập nhật đúng phần cần thiết và giữ đúng state của từng phần tử.

Loại keyĐánh giá
id duy nhất từ dữ liệuTốt nhất
Chỉ số indexChỉ dùng khi danh sách tĩnh, không sắp xếp/xóa
Math.random()Không dùng: key đổi mỗi lần render
⚠️ Lỗi thường gặp
Quên key sẽ có cảnh báo trong console. Dùng index làm key khi danh sách có thể xóa hoặc sắp xếp sẽ làm lệch state của ô nhập liệu.

Lọc và sắp xếp trước khi render

const dsHienThi = sinhVien
