15 Styling trong React — CSS Modules & styled-components

Các cách tạo kiểu cho component: CSS thường, CSS Modules và styled-components.

CSS Modules — class cục bộ theo file

Nut.module.css 
.nut { padding: 8px 16px; border-radius: 8px; background: #22d3ee; }
.nut:hover { opacity: .85; }
Nut.jsx 
import styles from './Nut.module.css';

export default function Nut({ children }) {
  return <button className={styles.nut}>{children}</button>;
}

Tên class được tự động băm thành chuỗi duy nhất nên không bị đụng tên với component khác.

styled-components — CSS viết trong JavaScript

terminal 
npm install styled-components
NutStyled.jsx 
import styled from 'styled-components';

const Nut = styled.button`
  padding: 8px 16px;
  border-radius: 8px;
  background: ${props => (props.primary ? '#22d3ee' : '#e5e7eb')};
`;

// <Nut primary>Lưu</Nut>

💡 Mẹo
Với dự án mới, CSS Modules hoặc Tailwind CSS là lựa chọn phổ biến vì ít tốn chi phí runtime. Chọn một cách và dùng nhất quán trong cả dự án.
