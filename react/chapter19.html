Portals — Modal & Tooltip

Portal render một phần giao diện ra ngoài cây DOM của cha, rất hợp cho modal và tooltip.

createPortal

Modal.jsx 
import { createPortal } from 'react-dom';

export function Modal({ mo, dong, children }) {
  if (!mo) return null;
  return createPortal(
    <div className="overlay" onClick={dong}>
      <div className="hop" onClick={e => e.stopPropagation()}>
        {children}
        <button onClick={dong}>Đóng</button>
      </div>
    </div>,
    document.body
  );
}

Về mặt DOM, modal nằm trực tiếp trong document.body nên không bị cắt bởi overflow: hidden hay lệch bởi z-index của cha. Về mặt React, nó vẫn là con của component gọi nó: sự kiện nổi bọt (bubbling) lên cha theo cây React và context vẫn dùng được.

💡 Mẹo trải nghiệm
Modal tốt cần: đóng bằng phím Esc, khóa cuộn nền, đưa focus vào modal và trả focus về nút mở khi đóng. Có thể dùng thẻ <dialog> gốc của HTML để có sẵn nhiều hành vi này.

📌 Tổng kết chương 19

createPortal đưa phần tử ra ngoài cây DOM của cha nhưng vẫn giữ quan hệ cha-con trong React, phù hợp cho modal, tooltip, dropdown.
