Next.js là framework React cho ứng dụng production: định tuyến theo thư mục, render phía server (SSR) và nhiều tối ưu sẵn có.

Tạo dự án

terminal 
npx create-next-app@latest my-app

Định tuyến theo file (App Router)

Đường dẫn fileURL
app/page.jsx/
app/gioi-thieu/page.jsx/gioi-thieu
app/blog/[slug]/page.jsx/blog/bat-ky-slug-nao
app/blog/[slug]/page.jsx 
// Server Component mặc định: chạy trên server, gọi dữ liệu trực tiếp
export default async function BaiViet({ params }) {
  const { slug } = await params;
  const res = await fetch(`https://api.example.com/posts/${slug}`);
  const bai = await res.json();
  return <article><h1>{bai.tieuDe}</h1><p>{bai.noiDung}</p></article>;
}
📝 Server vs Client Component
Mặc định component trong app/ là Server Component (không dùng được useState, useEffect). Thêm dòng "use client" ở đầu file khi cần state hoặc tương tác trình duyệt.
💡 Mẹo
SSR giúp trang có nội dung ngay khi tải (tốt cho SEO và tốc độ hiển thị đầu). Cú pháp và API của Next.js thay đổi theo phiên bản, hãy đối chiếu tài liệu chính thức của phiên bản bạn dùng.

📌 Tổng kết chương 24

Next.js cho định tuyến theo file, SSR và Server Component. Dùng "use client" khi component cần state hoặc sự kiện trình duyệt.
