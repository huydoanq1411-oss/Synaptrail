13 React Router — Điều hướng SPA cơ bản

React Router biến ứng dụng thành SPA nhiều trang: đổi URL mà không tải lại toàn bộ trang.

Cài đặt và khai báo route

terminal 
npm install react-router-dom
App.jsx 
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Trang chủ</Link> | <Link to="/gioi-thieu">Giới thiệu</Link>
      </nav>
      <Routes>
        <Route path="/" element={<TrangChu />} />
        <Route path="/gioi-thieu" element={<GioiThieu />} />
        <Route path="*" element={<h1>404 - Không tìm thấy</h1>} />
      </Routes>
    </BrowserRouter>
  );
}
💡 Mẹo
Dùng <Link> hoặc <NavLink> thay cho thẻ <a> để điều hướng không tải lại trang. NavLink tự thêm class active cho liên kết đang chọn.

Điều hướng bằng code

Redirect.jsx 
import { useNavigate } from 'react-router-dom';

function DangNhap() {
  const navigate = useNavigate();
  const xuLy = () => { /* ... xác thực ... */ navigate('/'); };
  return <button onClick={xuLy}>Đăng nhập</button>;
}
