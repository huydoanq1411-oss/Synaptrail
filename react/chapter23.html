Kiểm thử component bằng Jest (hoặc Vitest) và React Testing Library: test theo cách người dùng sử dụng.

Nguyên tắc

Testing Library khuyến khích kiểm thử hành vi nhìn thấy được (chữ trên màn hình, nút bấm) thay vì chi tiết cài đặt bên trong như tên state hay hàm nội bộ.

Ví dụ test bộ đếm

Dem.test.jsx 
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import Dem from './Dem';

test('bấm + thì số tăng lên 1', async () => {
  render(<Dem />);
  expect(screen.getByText('0')).toBeInTheDocument();

  await userEvent.click(screen.getByRole('button', { name: '+' }));

  expect(screen.getByText('1')).toBeInTheDocument();
});
Truy vấnDùng khi
getBy...Phần tử phải có ngay, không có thì lỗi
queryBy...Kiểm tra phần tử KHÔNG tồn tại
findBy...Phần tử xuất hiện bất đồng bộ (chờ)
💡 Mẹo
Ưu tiên truy vấn theo getByRole và getByLabelText: vừa giống người dùng thật, vừa khuyến khích viết HTML dễ truy cập (accessibility).

📌 Tổng kết chương 23

Test theo cách người dùng tương tác: render, truy vấn bằng role/label, mô phỏng bằng userEvent, và chọn đúng getBy/queryBy/findBy.
