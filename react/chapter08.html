Gọi API bằng fetch trong useEffect, quản lý ba trạng thái: đang tải, lỗi và dữ liệu.

Mẫu fetch chuẩn với ba trạng thái

NguoiDung.jsx 
function DanhSachUser() {
  const [users, setUsers] = useState([]);
  const [dangTai, setDangTai] = useState(true);
  const [loi, setLoi] = useState(null);

  useEffect(() => {
    const ctrl = new AbortController();
    fetch('https://jsonplaceholder.typicode.com/users', { signal: ctrl.signal })
      .then(res => {
        if (!res.ok) throw new Error('HTTP ' + res.status);
        return res.json();
      })
      .then(setUsers)
      .catch(e => { if (e.name !== 'AbortError') setLoi(e.message); })
      .finally(() => setDangTai(false));
    return () => ctrl.abort();
  }, []);

  if (dangTai) return <p>Đang tải...</p>;
  if (loi) return <p>Lỗi: {loi}</p>;
  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
⚠️ Đừng quên
fetch không tự ném lỗi khi server trả 404/500. Hãy kiểm tra res.ok rồi tự ném lỗi như ví dụ trên.

AbortController hủy request khi component bị gỡ hoặc khi tham số đổi, tránh cập nhật state sau khi component đã biến mất và tránh lỗi race condition.

💡 Mẹo
Với ứng dụng thực tế, cân nhắc thư viện như TanStack Query hoặc SWR: chúng lo sẵn cache, retry, refetch và trạng thái tải.

Fetch trong useEffect, quản lý trạng thái tải/lỗi/dữ liệu, kiểm tra res.ok và hủy request bằng AbortController.
