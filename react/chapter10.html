Chương 10 — useRef & Thao tác DOM trực tiếp

useRef giữ một giá trị không làm render lại, và truy cập trực tiếp phần tử DOM.

Truy cập DOM với ref

Focus.jsx 
import { useRef } from 'react';

function OTimKiem() {
  const inputRef = useRef(null);
  return (
    <>
      <input ref={inputRef} placeholder="Tìm kiếm..." />
      <button onClick={() => inputRef.current.focus()}>Focus vào ô</button>
    </>
  );
}

Lưu giá trị qua các lần render

Ref cũng là nơi lưu giá trị "ẩn" như id của timer hay giá trị trước đó. Thay đổi ref.current không kích hoạt render lại.

⚠️ Lưu ý
Không đọc hoặc ghi ref.current trong lúc render (trừ khởi tạo). Hãy đọc/ghi trong event handler hoặc effect. Chỉ thao tác DOM trực tiếp khi thực sự cần, như focus, cuộn hoặc đo kích thước.
