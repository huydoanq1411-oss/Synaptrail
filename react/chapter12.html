Chương 12 — useReducer — Quản lý state phức tạp

useReducer gom logic cập nhật state phức tạp vào một hàm reducer, theo mô hình action.

Reducer và dispatch

GioHang.jsx 
import { useReducer } from 'react';

function reducer(state, action) {
  switch (action.type) {
    case 'them':  return [...state, action.sp];
    case 'xoa':   return state.filter(sp => sp.id !== action.id);
    case 'reset': return [];
    default: throw new Error('Action không hợp lệ: ' + action.type);
  }
}

function GioHang() {
  const [gio, dispatch] = useReducer(reducer, []);
  return (
    <>
      <button onClick={() => dispatch({ type: 'them', sp: { id: Date.now(), ten: 'Áo' } })}>
        Thêm
      </button>
      <ul>
        {gio.map(sp => (
          <li key={sp.id}>
            {sp.ten} <button onClick={() => dispatch({ type: 'xoa', id: sp.id })}>Xóa</button>
          </li>
        ))}
      </ul>
    </>
  );
}

📌 Quy tắc
Reducer phải là hàm thuần: không gọi API, không sửa trực tiếp state cũ, luôn trả về state mới.
