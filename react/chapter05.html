Hiển thị giao diện khác nhau tùy theo state hoặc props: if, toán tử ba ngôi, && và return sớm.

Dùng if / return sớm

Component chỉ là một hàm JavaScript, nên bạn có thể dùng if trước return để chọn giao diện cần hiển thị.

DangTai.jsx 
function DanhSach({ dangTai, loi, items }) {
  if (dangTai) return <p>Đang tải...</p>;
  if (loi) return <p className="loi">Có lỗi: {loi}</p>;
  return (
    <ul>
      {items.map(i => <li key={i.id}>{i.ten}</li>)}
    </ul>
  );
}

Toán tử ba ngôi và && trong JSX

Bên trong JSX bạn không viết được câu lệnh if, nhưng dùng được biểu thức: toán tử ba ngôi ? : khi có hai nhánh, và && khi chỉ cần hiển thị hoặc không.

DangNhap.jsx 
function Chao({ user }) {
  return (
    <div>
      {user ? <h2>Chào {user.ten}</h2> : <h2>Vui lòng đăng nhập</h2>}
      {user && user.laAdmin && <button>Quản trị</button>}
    </div>
  );
}
⚠️ Cạm bẫy với số 0
Viết {soLuong && <Badge />} khi soLuong = 0 sẽ in ra chữ 0 trên màn hình vì 0 là giá trị falsy nhưng vẫn render được. Hãy viết {soLuong > 0 && ...} để an toàn.
💡 Mẹo
Nếu điều kiện phức tạp, hãy tách thành biến hoặc component riêng thay vì lồng nhiều toán tử ba ngôi trong JSX.
