Chương 20 — Redux Toolkit — Giới thiệu & Store

Redux Toolkit (RTK) là cách chính thức, gọn nhất để dùng Redux quản lý state toàn cục.

Cài đặt

terminal 
npm install @reduxjs/toolkit react-redux

Tạo store và bọc ứng dụng

store.js 
import { configureStore } from '@reduxjs/toolkit';
import demReducer from './demSlice';

export const store = configureStore({
  reducer: { dem: demReducer },
});
main.jsx 
import { Provider } from 'react-redux';
import { store } from './store';

createRoot(document.getElementById('root')).render(
  <Provider store={store}>
    <App />
  </Provider>
);

Luồng dữ liệu một chiều

Thành phầnVai trò
StoreNơi giữ toàn bộ state
ActionMô tả "điều gì đã xảy ra"
ReducerTính state mới từ state cũ và action
SelectorĐọc phần state cần dùng
📝 Khi nào cần Redux?
Không phải dự án nào cũng cần. State cục bộ dùng useState, chia sẻ ít dùng Context. Redux hợp khi nhiều phần xa nhau cùng đọc/ghi state, logic phức tạp, cần công cụ debug time-travel.
