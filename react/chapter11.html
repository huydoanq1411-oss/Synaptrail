Chương 11 — Context API — Chia sẻ state toàn cục

Context chia sẻ dữ liệu cho cả cây component mà không phải truyền props qua từng tầng (prop drilling).

Tạo và cung cấp Context

ThemeContext.jsx 
import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext('sang');

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('sang');
  const doi = () => setTheme(t => (t === 'sang' ? 'toi' : 'sang'));
  return (
    <ThemeContext.Provider value={{ theme, doi }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);

Dùng ở component con bất kỳ

NutDoiTheme.jsx 
function NutDoiTheme() {
  const { theme, doi } = useTheme();
  return <button onClick={doi}>Đang là: {theme}</button>;
}
⚠️ Hiệu năng
Mọi component dùng useContext sẽ render lại khi value đổi. Đừng nhét state thay đổi liên tục vào một context lớn; hãy tách context hoặc dùng thư viện state riêng khi cần.
💡 Mẹo
Context hợp với dữ liệu ít đổi và dùng ở nhiều nơi: theme, ngôn ngữ, người dùng đăng nhập.
