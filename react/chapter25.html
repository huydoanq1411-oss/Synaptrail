Đóng gói ứng dụng React và đưa lên internet: build, biến môi trường, hosting tĩnh và kiểm tra trước khi phát hành.

Build production

terminal 
npm run build      # tạo thư mục dist (Vite) hoặc build
npm run preview    # chạy thử bản build ở máy

Biến môi trường

.env 
VITE_API_URL=https://api.example.com
dung.js 
const api = import.meta.env.VITE_API_URL;
⚠️ Bảo mật
Mọi biến nhúng vào bundle frontend đều lộ công khai. Tuyệt đối không đặt khóa bí mật (secret key, mật khẩu database) trong mã React. Khóa bí mật chỉ để ở server.

📌 Với SPA dùng React Router
Cần cấu hình server trả về index.html cho mọi đường dẫn (rewrite), nếu không tải lại trang ở /gioi-thieu sẽ báo 404.

📌 Tổng kết chương 25

Build bằng npm run build, không để bí mật trong frontend, chọn nền tảng phù hợp và cấu hình rewrite cho SPA.
